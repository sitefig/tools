## Verification of built tools (test/new09.mjs)
- redos-checker: flagged patterns (a+)+$ and (\w+\s?)*$ really take seconds in V8; unflagged ones are instant. Heuristic: can miss backreference and lookaround cases.
- levenshtein-calculator, string-similarity-comparer: 300 random cases vs an independent DP (Levenshtein and OSA); Jaro and Jaro-Winkler vs published Winkler examples (MARTHA/MARHTA, DWAYNE/DUANE, DIXON/DICKSONX); Dice for night/nacht.
- grep-lines: output equal to GNU grep for -n -C, -v, -w, -i, -E, -A, -c, -o.
- glob-pattern-tester: 15 patterns compared with real bash (globstar, extglob) on a file tree. Negated extglob !(...) rejected, not supported.
- ip-address-extractor: every extracted address accepted by node:net; invalid forms (256.1.1.1, 01.2.3.4, 1::2::3, 12345::1) rejected.
- ecdsa-key-generator: P-256/384/521 PEM loaded and re-derived by openssl pkey (curve name, -pubout equal).
- jwk-pem-converter: EC round trip and RSA 2048 openssl key (PKCS#8 and PKCS#1) to JWK and back, modulus equal to openssl -modulus.
- totp-qr-builder: RFC 6238 test vectors (SHA1 and SHA256, 8 digits). The QR comes from the existing encoder in gen.js (imported, not copied); the scan itself was not tested with a phone app.
- ksuid-tool: Segment README example (0ujtsYcgvSTl8PAuAdqWYSMnLOv) decodes to timestamp 107608047 and the listed payload; epoch 1400000000 inferred from it and from the README text.
- ulid-decoder: 5 generated ULIDs plus the spec example vs a Python decode.
- snowflake-id-decoder: Twitter layout checked with IDs built from the twepoch and shifts in the Twitter source; Discord layout from the Discord API reference (epoch 1420070400000, 5+5+12), example ID 175928847299117063 decodes to 2016-04-30T11:18:25.796Z. Instagram (and other) layouts were not looked up (source unreachable), so only Custom covers them.
- entropy-calculator: Shannon values equal the formula in the test.
- random-ip-generator: CIDR membership and exclusion lists checked in the test. The IPv4 special-purpose list was compared with the IANA registry (fetched 2026-10-23). The IPv6 public exclusions (2001::/23, 2001:db8::/32, 2002::/16) were not re-checked against the IANA IPv6 registry.
- random-date-generator, random-number-generator, dummy-file-generator: ranges, uniqueness, weekdays and exact byte sizes checked.
- Not verified: the regex-railroad-diagram layout was inspected visually in Chrome on two patterns only; the tool pages were not walked through with a screen reader; fuzzy-search-playground and test-email-generator have no oracle (heuristics stated on the page).
