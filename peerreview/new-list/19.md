## Verification
- Loudness: ffmpeg ebur128 (integrated LUFS agreed to 0.1 LU; K-weight 48 kHz first tap equals the BS.1770 value 1.53512486). True peak is a 4x cubic estimate (about 0.6 dB under ffmpeg on noisy test signal).
- FLAC: ffmpeg decode with CRC checking, bit-exact on mono, stereo, 24-bit, 6-channel and tiny files.
- MP3 tags: ffprobe/ffmpeg read written tags and cover; v2.3 and v2.4 sources tested. ID3v2.2 reader written, not tested. Camelot codes and Krumhansl-Kessler values written from memory (not looked up); synthetic keys all identified.
- WSOLA, pitch shift, resampler, noise reduction, EQ band gains, silence, fade, join, limiter: checked on synthetic signals (frequency, duration, RMS, gain). BPM: synthetic click tracks, within about 1 percent; octave errors possible (70 read as 139.7). No real music tested.
- PDF: n-up, booklet, blank pages, grayscale (zero channel spread in poppler), flatten (pixel identical to poppler render with annotations), image overlay on rotated and cropped pages, text extraction vs pdftotext (simple and Type0/ToUnicode, rotated page), images vs pdfimages (identical pixels, alpha from SMask), bookmarks (Ghostscript re-read all titles; own reader read levels and pages), OCR overlay vs pdftotext.
- Browser (Chrome): drum machine play/stop and URL state, spectrogram viewer render, PDF signer preview and typed signature. Not verified in a browser: spectrum analyzer (mic/file), hearing test, sleep noise, PDF OCR end to end (OCR and overlay tested in Node with poppler renders), PDF text/table/image tools through the page form (functions tested in Node).
