## Verification of built tools
- csv-delimiter-converter, csv-deduplicator, sql-insert-to-csv: output re-read with Python csv module and compared.
- endianness-swapper: Python int.from_bytes for 4 inputs.
- iso-8601-date-parser: Python datetime (fromisocalendar, strptime %j, isocalendar) on 13 values. Not checked against the ISO text (paywalled); the fraction-on-last-unit note is from memory and phrased "normally".
- toml-to-yaml: PyYAML load equals tomllib load. properties-to-yaml: PyYAML load checked by hand against expected structure; Java properties rules written from memory of the Properties.load documentation, not looked up.
- css-color-formats: five colours compared with Chrome (color-mix serialisation) for hwb, lab, lch, oklab, oklch, display-p3: all match to shown digits.
- xsd-validator: valid/invalid verdict matched lxml XMLSchema on 20 documents (sequence, choice, all, extension, enumeration, pattern, range, simpleContent, occurrence limits). Error messages not compared. Namespaces, key/keyref/unique, import/include, substitution groups not supported.
- xslt-playground: sample and an xml-output case run in Chrome; no oracle comparison.
- ndjson-viewer, yaml-validator: sample runs only; no external oracle.
