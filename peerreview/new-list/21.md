# Batch 21: Charts & Data Visualization, Spreadsheet & Data Cleaning, Maps & Geo (rows 1399 to 1481)

Counts: 61 BUILT (module src/tools/new21.js, 61 tools), 5 COVERED, 17 SKIPPED (of which 15 need a server, API or map tiles).
Bundled data: data/world-110m.json (Natural Earth 1:110m admin-0 countries, public domain; source, date, hash in data/SOURCES-new21.md). Loaded with a same-origin fetch only by choropleth-map-maker, csv-to-map-plotter, geojson-viewer-validator, travel-map-pinner and geography-quiz-map.

General limit on all chart tools: output is SVG (copy or download) shown with a data table; PNG, WebM and drag interactions from the row text are not offered. Keyboard routes replace pointer interactions (typed filters, typed zoom path, level limits, checkbox list, typing mode).

Verification (oracle run on this machine, 2026-10-23): UTM vs PROJ/pyproj 3.8 on 308 points (max 0.5 m, which is the metre rounding of the output); MGRS encode vs python mgrs 1.6 (308/308 equal after zero-padding the zone to two digits) and decode (differences 0.5 to 1 m = cell corner vs centre convention); Plus Codes vs openlocationcode 1.0.1 (308/308); Vincenty vs the Geoscience Australia test line (54972.271 m, exact); haversine vs a Python formula; sun times vs PyEphem (seven place/date cases, within 3 s to 47 s) and sun elevation/azimuth vs PyEphem (max 0.04 deg); phone numbers vs libphonenumber-js 1.11.5 (differences only where 00 is treated as the international prefix, and where libphonenumber says invalid but the length check says ok, which is documented); dates vs python-dateutil (differences only where dateutil guesses day-first for ISO); quartiles, regression, histogram bins vs Python statistics and a manual count; xlsx and zip checked with unzip -t and Python ElementTree/zipfile; GPX output parsed with gpxpy; KML parsed with ElementTree. Not verified: Excel/LibreOffice opening the generated xlsx; screen reader use; dark theme look of the two interactive map tools (they use light-dark()).
