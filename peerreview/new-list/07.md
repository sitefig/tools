## Verification of built tools

- Encoders: Ascii85 and uuencode round-trip against Python base64.a85encode and binascii.b2a_uu on random bytes (lengths 1 to 1000, including zero blocks): 0 mismatches. Z85 against the RFC 32 vector (86 4F D2 6F B5 59 F7 5B = HelloWorld) both ways. MIME encoded words against Python email.header (decode and encode round trip). Bencode info hash against hashlib.sha1 of an independently built info dictionary. Protobuf decoder against bytes built by a separate Python encoder (varint, fixed32/64, nested, bytes). Data URI and base64-to-file checked by hand on a PNG, not against an oracle.
- Go: re-indenting gofmt-formatted stdlib files (208): 202 identical; with all indentation stripped (187): 166 identical, 35 of 42,666 lines differ. Break mode output of 210 files accepted by gofmt -e.
- Rust: rustfmt output with indentation stripped (127 files): 107 identical. Break mode output of 357 files accepted by rustfmt.
- Python: 465 stdlib files plus 60 with tabs and 3-space indents: ast.dump identical before and after. Black/Ruff were not available, so blank-line rules follow Black documentation and were not compared with it.
- Shell: 398 system scripts: bash -n passes and non-whitespace text unchanged. shfmt not available, layout not compared.
- PHP: 80 files, php -l passes after break mode; JS-like TS: src/*.js break output passes node --check; C: gcc -fsyntax-only on a break-mode sample; Java: javac on a break-mode sample. Whitespace-only invariant and idempotence hold on all tested files (java: only one hand sample, JDK sources were not available).
- Markdown: 500 real .md files rendered with markdown-it (CommonMark + tables) before and after: 498 equal; second set 99 of 100. Differences: mixed bullet markers at one level, unclosed final fence.
- Log tools: run on a generated 133-line sample; per-day counts, status classes and discovery lag checked by reading against the sample; no independent log analyser was available. Crawler names come from user-agent text only. Googlebot smartphone user agent checked against Google documentation (developers.google.com common crawlers page, fetched 2026-10-23). Search Console crawl stats time zone could not be found, so the page says not verified. AI crawler purposes are copied from ai-crawler-user-agent-directory (another batch, vendor pages read 2026-10-23), not re-checked.
- Lua, LaTeX, Dockerfile, crontab, line endings, log prettifier: only whitespace-invariant checks on available files (150 Lua, 9 tex, 10 Dockerfiles); no Lua interpreter, LaTeX or docker tools available. Browser behaviour of file-input tools (file-to-data-uri, bencode-decoder file, line-ending-normalizer file, custom blob previews) not verified in a browser.

## For the owner

- Log tools take IP addresses and URLs: consider adding the 18 log tool ids (and log-line-prettifier) to the sensitive rules in site.config.json so input is not auto-written to the URL. uuencode-decoder, file-to-data-uri, base64-to-file, mime-encoded-word-decoder could also hold private data.
- css-format bug: a trailing "// comment" line becomes "// comment;".
