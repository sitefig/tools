# Batch 12 decisions (rows 766-848)

Method: existing tools were matched by title and description against assets/tools.json and src/tools/*.js; covered ids marked "run" were run with `node cli/ft.mjs run <id> --sample`, others were matched by description only (not verified by running). New tools are in src/tools/new12.js (55 tools).

Oracles used: ssh -G (ssh-config-builder), git diff --numstat (unified-diff-viewer), Python re on generated regexes (log-format-to-regex), Python nearest-rank percentiles (response-time-percentiles), grep -n -C (log-grep-context), Python epoch conversions (log-timestamp-normalizer), Python byte offsets on an 11 MB file (large-log-file-viewer lib), the RFC 5424 syslog example lines, the HAProxy manual example line, the Kubernetes Quantity doc examples (1.5 -> 1500m, 1.5Gi -> 1536Mi).
Facts read at source: RFC 5424 tables 1 and 2, Heroku error codes page, HAProxy manual section 8 (termination state, httplog fields), pfSense syslog.inc (filterlog field order), AWS docs (ALB, CloudFront, S3 field lists), Microsoft Learn event pages (titles of 20 Security event IDs), commitlint config-conventional source, GitLab CI YAML reference keyword headings, TSConfig Reference option names, Kubernetes Quantity reference.
Not verified: real-world samples for ALB, S3, CloudTrail, Azure, Vercel, Netlify, Cloudflare, Fastly, Akamai, iOS .crash text and Windows XML (built from documentation, tested on hand-made samples only); commitlint itself (rules read from source, subject-case is approximate); the large-log-file-viewer UI in a real browser (logic tested in Node, UI not clicked); tsconfig descriptions are my summaries.
