## Verification
- JSON parser (jsonld tools): error line and column compared with Python `json` on 8 broken documents (all match); fuzz of 3000 valid documents and 3000 one-character deletions agrees with `JSON.parse` on validity.
- GTIN check digit: compared with an independent Python GS1 implementation (4006381333931 valid, ...932 invalid, 036000291452 valid, 96385074 valid).
- Hreflang sitemap output parsed with lxml (namespaces, url count, 3 links per url); html -> header -> sitemap -> html round trip kept the same set.
- Every generator sample output was run through schema-property-checker; this found a real error in my shipping builder (deliveryTime is not a ShippingConditions property; Google puts handlingTime on ShippingService and transitTime on ShippingConditions), fixed.
- Opening hours output compared by eye with the examples in Google's local business page (closed 00:00-00:00, open 24h 00:00-23:59, seasonal validFrom/validThrough).
- ISO code lists and Schema.org vocabulary are embedded data from the sources above; Intl-based tools use the browser's CLDR (not independently verified; ran in Node 22).

## Not verified
- Microdata and RDFa conversion: hand-checked on samples against the specs; no independent converter was installed. RDFa is a subset.
- Google requirement tables copied from the docs of 2026-10-23 by reading extracted text; the FAQ restriction history before 2026 and anything outside the changelog text is not covered.
- RTL checker, language detector, title width, URL structure advisor and GSC checker are heuristics and say so on the page.
- Not tried in a real browser: the two iframe-result tools (schema-graph-visualizer, hreflang-cluster-visualizer) and the banner script. Smoke test runs them in Node only for the text parts.
