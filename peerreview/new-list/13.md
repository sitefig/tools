## Verification

- isbn-validator-converter: check digits and conversions compared with an independent Python implementation (5 vectors, all agree; 978-0-306-40615-7 is the classic valid example).
- number-extractor-sum: sum of sample compared with Python Decimal (1253.95).
- x-post-character-counter: weights and URL length 23, max 280 read from the twitter-text v3 config and the X documentation (docs.x.com counting characters) via fetch; hand-checked on latin, emoji, CJK, URL and ZWJ emoji. Bare domains without a scheme are not detected.
- Threads 500 limit checked in Meta docs. Bluesky 300, Mastodon 500, Instagram 2200, LinkedIn 3000 and Reddit title 300: could not be fetched or confirmed; stated as not verified on the page.
- social-image-size-reference: YouTube thumbnail values checked at support.google.com/youtube (3840x2160, min width 640; Shorts 2160x3840); all other rows not verified (X cards page returned 402).
- social-share-link-generator and whatsapp-link-generator: URL formats from memory, WhatsApp help and Meta docs pages could not be read. Said so on the page; links were not opened.
- linkedin-text-formatter: code point blocks checked with Python unicodedata names (sans-serif bold, italic, bold italic).
- Not verified: headline-capitalizer rules (from commonly published AP/APA/Chicago/MLA rules, not checked against current manuals), all word lists (cliches, jargon, bias, adverbs, acronyms, names), rates in earnings tools (user inputs, defaults are labelled placeholders), Instagram invisible-character behaviour.
- All tools run on their sample in Node (node test/smoke.mjs src/tools/new13.js: 43 ran, 0 failed). social-post-preview returns an HTML string; not looked at in a browser.
