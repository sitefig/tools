## Verification
- hex-to-css-filter: five colours checked against Chrome canvas ctx.filter, all channels within 3/255.
- tailwind-to-css: ~45 classes compared with real Tailwind v4.3.3 CLI output (node_modules): same values, v4 writes var()/calc where this writes resolved values. Colour data is copied from tailwindcss/theme.css.
- html-to-pug: compiled with pug (npm, scratch only) and compared with the input HTML on 3 documents: equal except attribute order, quoting and doctype case.
- rst-to-html: compared with docutils 0.23 on 3 documents: same structure; docutils wraps list items in p, uses span/aside classes; field list followed by a quote differs. Not full docutils.
- html-sanitizer, bbcode-to-html: 25 adversarial inputs (javascript:, entities, svg, noscript, textarea, data:) produced no executable output.
- latex-to-mathml: output inspected only; Chrome rendering not checked. MathML element names from the MathML Core spec, from memory.
- html-validator, markdown-toc-generator (GitHub slug rule), mjml-subset-compiler, email-css-inliner, html-dom-diff, css generators: no external oracle; checked by hand on samples. Obsolete tag list and HTML element list written from memory of the HTML spec, not looked up.
