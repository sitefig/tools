Theme Color Meta Tag Generator (Light and Dark)

Writes the theme-color meta tags for both color schemes.

Use the tool

Why this tool exists

The theme-color tag tints the browser toolbar on supporting mobile browsers. With a media attribute you can set one color for light mode and another for dark.

Enter the two colors as hex, rgb() or hsl(). The preview is a simple mock of the toolbar, not a real browser. Also set theme_color in your manifest if you have one.

How to use it

  1. Type the light mode color.
  2. Type the dark mode color.
  3. Tick color-scheme if your site supports both.
  4. Copy the tags into the head.

Frequently asked questions

Do all browsers support it?

Support is mostly on mobile Chrome and Safari; others ignore it.

Why the media attribute?

It lets the browser pick the tag that matches the user setting.

Is there a color picker?

No, type a color value.

What about the manifest?

Set theme_color there as well for installed apps.
