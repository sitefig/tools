TDMRep Builder: tdm-reservation Header, Meta Tag and tdmrep.json

Builds tdm-reservation and tdm-policy as headers, meta tags and a tdmrep.json file from your settings.

Use the tool

Why this tool exists

In the EU, rightsholders can reserve their rights against text and data mining in a machine-readable way. The W3C community report on the TDM Reservation Protocol defines how: an HTTP header, an HTML meta tag or a JSON file at /.well-known/tdmrep.json.

Choose reserved or not, add a policy URL and optional path rules and get the snippets for Apache and Nginx too. The spec says to use one technique, and later sources override earlier ones. This is a technical signal, not legal advice.

How to use it

  1. Choose 1 (reserved) or 0 and a policy URL.
  2. Optionally add path rules.
  3. Copy the header, meta or JSON.
  4. Validate the JSON with the TDMRep validator.

Frequently asked questions

Header, meta or JSON file?

The spec advises one. The JSON file suits many paths, headers suit servers, meta tags suit CMS pages.

What does a policy do?

It links to a licence or terms. It is not processed when the reservation is 0.

Is this legal advice?

No.

Do crawlers read it?

Some do, not all. Combine with robots.txt.
