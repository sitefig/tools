AI Speech to Text (Whisper tiny, English, Offline in Your Browser)

Transcribe English speech to text with Whisper tiny running entirely in your browser, from a file or the microphone.

Use the tool

Why this tool exists

Most dictation and transcription services send your audio to a server. Whisper is an open speech recognition model, and the tiny English version is small enough (39 million parameters, 43 MB with int8 weights) to run in a tab, so interviews, meetings and voice notes can be transcribed without leaving your device.

It is slow: expect roughly 20 seconds of processing for each 30-second window on a laptop, so it suits short clips. Audio is cut into fixed 30-second windows, which can split a word at a boundary. Like all Whisper models it can invent text on silence or music and mishears names and jargon, so proofread. Our JavaScript engine reproduces the reference PyTorch transcript token for token on the test clip.

How to use it

  1. Choose an audio or video file, or press Record from the microphone and stop when finished.
  2. Press Transcribe; the first run downloads 43 MB once.
  3. Watch the progress per window, then copy or download the text.

Frequently asked questions

Is my audio uploaded?

No. It is decoded and transcribed in your tab. The only download is the model file from this site.

Why is it slow?

The model runs on one CPU thread in JavaScript, and Whisper always processes a full 30-second window. A GPU-based tool would be much faster but would need a server or a larger download.

Which languages work?

This is the English-only tiny model. Other languages need the multilingual Whisper models, which are larger.
