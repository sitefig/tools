fetch() to cURL

Converts a JavaScript fetch(url, { method, headers, body }) call into a curl command. It understands JSON.stringify bodies, string literals and object literals, and never runs your code.

Use the tool

Why this tool exists

A failing request in the browser is often easier to reproduce from a terminal: you can change headers, see raw responses and share a one-line command with a colleague. DevTools can copy a request as curl, but when you have only a code snippet, such as a fetch call from an issue, a tutorial or your own source, you have to rewrite it by hand. This tool reads the call as text and builds the equivalent command: the method, each header, and the body, including a body written with JSON.stringify of an object literal. It does not execute your code, so nothing in the snippet can run, and it stays in your browser. Features without a curl equivalent, such as credentials: "include", are ignored.

How to use it

  1. Paste the fetch(...) call, with its options object, into the input box.
  2. Run the conversion to get the curl command.
  3. Copy it into your terminal and replace any placeholder tokens before running it.

Frequently asked questions

Does it run my JavaScript?

No. The call is read as text and parsed with simple rules. Variables, function calls and template placeholders cannot be evaluated, so use literal values for the best result.

Which options are converted?

The URL, method, headers and body. A JSON.stringify of an object literal becomes a JSON body. Options with no curl equivalent, like credentials, mode or cache, are skipped.

What if my body is built from variables?

Replace the variables with sample values first. The tool can only convert what it can read as a literal.

Can I go the other way?

Yes, the cURL to Code tool and the other cURL converters on this site turn a curl command into fetch and other languages.

Tools often used together

  • cURL to CodeConvert a curl command to fetch, Node (http/https), Python requests or PHP cURL.
  • cURL Command BuilderFill in method, URL, headers, body, auth and flags to get a correctly quoted curl command.
  • cURL to C# / Java / Axios / Guzzle / FaradayConvert a curl command (-X -H -d --data-urlencode --json -F -u -k -L) into C# HttpClient, Java 11 HttpClient, JavaScript axios, PHP Guzzle or Ruby Faraday. Python, fetch, Node and plain PHP live in the main cURL to Code tool; Go and Rust have their own tools. Multipart (-F) is supported for C#, Guzzle and Faraday; Java and axios convert it to a urlencoded body.
  • HTTP Raw Message <-> JSON (wire format)Parse a raw HTTP/1.x request or response (start line, headers, body, chunked transfer decoding, Content-Length check, query string, cookies, Basic auth) into structured JSON, or build a correctly framed raw HTTP message (CRLF line endings, Host and Content-Length) from JSON. Useful for debugging proxies, WAF rules, request smuggling cases and hand-written test fixtures.
  • HTTP Headers to JSONConvert raw HTTP request/response headers (or a status line plus headers) to a JSON object; repeated headers become arrays.
  • cURL to Postman CollectionConvert one or more curl commands (one per blank-line separated block) into an importable Postman Collection v2.1 JSON with headers, query params, raw/urlencoded/form-data body and basic auth.
