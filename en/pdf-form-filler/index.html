Fill PDF Form Fields

Fill a fillable PDF form by name and optionally flatten it into plain page content. Run it empty first to see every field.

Use the tool

Why this tool exists

Fillable PDF forms store their fields in an AcroForm. This tool reads that structure, lists each field with its type and current value, and fills the ones you name.

Run it with the value box empty to get the field list. Then write one line per field, for example Name = Ada Lovelace or Subscribe = yes, and run it again. Text fields get a freshly generated appearance using the font and size set in the form (size 0 shrinks to fit), alignment, background and border colours; multi-line fields wrap, and \n starts a new line. Checkboxes take yes or no, radio buttons the name of a choice, and drop-downs one of their options.

Tick Flatten and the filled widgets are drawn into the page as fixed content and the form is removed, which is what you want before sending a final copy. Without it the form stays editable. Limits: no XFA (dynamic) forms, comb fields appear as plain text, rotated widgets are left to the viewer, JavaScript calculations are not run and signature fields cannot be filled. Encrypted files must be unlocked first. Everything stays in your browser.

How to use it

  1. Choose the form PDF and run the tool with the value box empty to list the fields.
  2. Write one "field name = value" line per field you want to fill.
  3. Tick Flatten if the form should become fixed text.
  4. Run again and download the filled PDF.

Frequently asked questions

Why does the tool say there are no form fields?

The PDF has no AcroForm. It may be a flat scan, or an XFA form made by LiveCycle. For flat PDFs use the annotate tool to place text instead.

What does flatten do?

It paints the field appearances into the page content, removes the widgets and deletes the AcroForm. The values can no longer be edited, and the file works in any viewer.

How do I check a checkbox or choose a radio button?

Write yes, on, true or 1 to tick a checkbox and no to clear it. For a radio group write the name of the choice exactly as the field list prints it.

Will calculated fields update?

No. JavaScript calculations and validations do not run here. Fill the final values yourself.

Are non-Latin characters supported?

Values are stored correctly, but the generated appearance uses Western European characters in the form font; others show as a question mark. Viewers that regenerate appearances may show the stored value.
