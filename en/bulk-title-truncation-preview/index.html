Bulk Title Truncation Preview (CSV)

Shows an estimated width and cut-off point for each title in a list or CSV.

Use the tool

Why this tool exists

Checking titles one by one is slow. Paste hundreds, see which would be cut and where the text after the cut falls.

Widths are estimated from Arial-like metrics at 20px, and the desktop and mobile limits are adjustable estimates. Search engines use their own fonts and often rewrite titles, so this is a guide. Edit the list and run again to test rewrites.

How to use it

  1. Paste titles one per line, or a CSV with a title column.
  2. Adjust the pixel limits if you want.
  3. Run the tool.
  4. Edit the long titles and re-run.

Frequently asked questions

How accurate are the pixels?

Approximate. They come from font metrics, not a real search page.

Why two limits?

Desktop and mobile results truncate differently.

How many titles?

Up to 5,000.

Can it export?

Copy the table; the preview column shows the cut.
