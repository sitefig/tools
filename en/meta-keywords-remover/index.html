Legacy Meta Tag Remover (meta keywords and more)

Strips meta keywords and other old meta tags from HTML.

Use the tool

Why this tool exists

Google has said it does not use the meta keywords tag, and it only reveals your target terms to competitors. Old templates carry other dead tags too.

The tool removes keywords and, if you leave the option on, a list of legacy names such as revisit-after, distribution and rating. That list is my own judgement of tags no major engine documents, so review the removed list before shipping.

How to use it

  1. Paste the head or the page source.
  2. Choose whether to remove other legacy tags.
  3. Run the tool.
  4. Check the list of removed tags and copy the cleaned HTML.

Frequently asked questions

Does removing keywords hurt SEO?

Google ignores it. Other engines may have used it long ago.

What else is removed?

Names like revisit-after, distribution, rating and classification, if enabled.

Does it touch robots or description?

No.

Is the original kept?

The removed tags are listed in a comment at the end.
