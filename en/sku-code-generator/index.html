SKU Code Generator From Product Attributes

Turns a list of product attributes into consistent stock keeping unit codes.

Use the tool

Why this tool exists

A good SKU is short, readable and the same every time. Building it from attributes means two people produce the same code for the same product, and a code can be read without a lookup.

The tool strips accents and symbols, keeps the first letters of each word segment, leaves numeric sizes whole, and can append a running number. It warns when two products get the same code so you can lengthen the segments.

How to use it

  1. Write one product per line with attributes separated by commas.
  2. Set the prefix, separator and segment length.
  3. Add a running number if you need a unique code per item.

Frequently asked questions

Why do some SKUs repeat?

Short segments can collide, for example two colours starting with the same letters. Use more letters or a running number.

Can SKUs have spaces?

The tool removes them, since many systems break on spaces.

Is a SKU the same as a barcode?

No. A SKU is your own code; a GTIN or EAN is a global product number.
