EU VAT Number Format Validator

Paste EU VAT numbers one per line and see whether each matches the format used by its country prefix. This checks the pattern only, not registration.

Use the tool

Why this tool exists

Invoicing forms, checkout pages and supplier imports all collect VAT numbers, and a lot of them arrive with the wrong shape: missing prefix, extra dots, a letter in the wrong place. Catching those before submission saves a failed lookup or a rejected invoice.

This tool normalises each line by removing spaces, dots and hyphens, reads the two-letter country prefix and tests the rest against that country's pattern. It supports the EU member prefixes, including EL for Greece. It is a first-pass format check. It does not call VIES, so it cannot confirm that a number is registered, active or belongs to the named company, and some countries have checksum rules that are not applied. Your data stays in the browser.

How to use it

  1. Paste VAT numbers into the box, one per line, each starting with the country prefix.
  2. Run the check.
  3. Read the result next to each number: format OK or wrong format for that country.
  4. Verify important numbers against the official VIES service.

Frequently asked questions

Does this confirm a business is VAT registered?

No. It only checks that the pattern fits the country. To confirm registration you need the European Commission's VIES service or your tax authority, which this page does not contact.

How do I write Greece and Northern Ireland?

Greece uses the prefix EL, not GR. Northern Ireland uses XI, which is not in this tool's list, so those numbers are reported as unknown prefix. Other non-EU prefixes are also flagged.

Are spaces and dots allowed?

Yes. Spaces, dots and hyphens are removed before checking, so DE 123.456.789 is treated like DE123456789. The original text is still shown in the result.

Why can a number pass but still be wrong?

Format checks cannot detect a mistyped digit that keeps the right pattern. Several countries also use checksum digits that this tool does not verify, so treat OK as plausible, not proven.
