Email and IP Hasher for Pseudonymized Uploads

Normalizes each value (trim, lowercase, optional plus-tag removal) and hashes it with an optional salt.

Use the tool

Why this tool exists

Ad and analytics platforms often let you upload hashed emails for matching. The hash only matches if both sides normalize the same way: trimmed, lowercase, sometimes without plus tags or dots.

This tool applies those steps and hashes each line, so you can check what a hash should look like. Remember that a hashed email is still personal data: anyone with a list of candidate addresses can hash them and compare. Hashing is pseudonymisation, not anonymisation. Hashes are computed in your browser and nothing is uploaded.

How to use it

  1. Paste one value per line.
  2. Pick the type, algorithm and salt.
  3. Read the normalized value and hash.
  4. Match the normalization rules of the platform you upload to.

Frequently asked questions

Is a hashed email anonymous?

No. It is pseudonymised data and remains personal data under the GDPR.

Which normalization do platforms expect?

Usually trim and lowercase. Some also treat gmail dots and plus tags. Check each platform's documentation.

Does the salt help?

It stops simple lookup tables, but the other side cannot match your hashes unless they know the salt.
