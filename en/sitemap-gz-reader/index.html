Gzipped Sitemap Reader (.xml.gz)

Opens a gzipped sitemap file, shows the XML formatted, counts the URLs and lets you save the plain .xml.

Use the tool

Why this tool exists

Many sites publish sitemap.xml.gz, which you cannot read in an editor. Command line tools work, but not everyone has one at hand.

This tool uses the decompression built into your browser. It also accepts a plain .xml file. Very long files show the first 1,500 lines, and the download has everything.

How to use it

  1. Choose a .xml.gz or .xml file.
  2. Read the size before and after unzipping and the URL count.
  3. Scan the formatted XML.
  4. Save the plain XML file if needed.

Frequently asked questions

Does it upload my file?

No. The file is read and unzipped locally.

Why is only part shown?

Long files are cut at 1,500 lines on screen. The download is complete.

Can it read .br files?

No. Browsers do not expose Brotli decompression to pages.

Does it check the sitemap?

It checks the root element and the limits. Use the validator for a full check.
