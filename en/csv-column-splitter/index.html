CSV Column Splitter (One Column into Several by a Separator)

Splits one column into several parts, for example Smith, John into surname and first name, leaving all other columns where they are.

Use the tool

Why this tool exists

Names, addresses and codes often arrive packed into one column. Splitting on the separator gives you sortable, filterable fields.

Set a maximum number of parts so extra separators stay in the last part, such as middle names. Name the new columns or let the tool call them name_1, name_2. Rows with fewer parts get empty cells. The original column can be kept or removed.

How to use it

  1. Paste the CSV with a header.
  2. Enter the column and the separator text.
  3. Set a maximum number of parts and optional new names.
  4. Copy or download the result.

Frequently asked questions

Can the separator be several characters?

Yes, any text, for example " - ".

How do I split on a tab?

Type \t as the separator.

What about a quoted comma?

The CSV is parsed first, so commas inside quotes are not column breaks, but your separator still applies inside the cell.

Are values trimmed?

Yes, each part is trimmed of surrounding spaces.
