Domain Expiry Date Tracker (From Your Own List)

Takes a list of domains and expiry dates you already have and sorts them by days left, marking expired domains and those that need renewing soon.

Use the tool

Why this tool exists

Missed renewals cost money and sometimes the domain. A spreadsheet works, but you need the date maths and the sorting every time you look.

This tool does only that part. It does not look dates up, because a web page cannot query registries without a server. Copy the dates from your registrar or from the WHOIS and RDAP tools and check them again before you rely on them.

How to use it

  1. Write one domain and date per line, for example example.com, 2030-08-13.
  2. Set the warning threshold in days.
  3. Optionally set a fixed "today" date.
  4. Read the sorted table.

Frequently asked questions

Does it look up expiry dates?

No. It only calculates from the dates you enter.

Which date formats work?

YYYY-MM-DD, optionally followed by a time. Anything else is reported as an error.

Which time zone is used?

Dates are treated as UTC days.

Can it send reminders?

No. It runs once in your browser and stores nothing.
