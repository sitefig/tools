Text to Mermaid Flowchart (Arrows, Outlines and Numbered Steps)

Write a process in plain text and get Mermaid flowchart or mind map code.

Use the tool

Why this tool exists

Mermaid diagrams are easy to read but fiddly to type. This converter takes lines such as "Start -> Check stock -> In stock? yes: Ship / no: Backorder", numbered step lists or an indented outline and outputs flowchart or mindmap code with sensible shapes (decisions as diamonds, start and end as rounded boxes) and labelled branches.

It is a small syntax converter, not an AI diagram generator: it only understands the notations described here. Paste the result into the Mermaid renderer on this site or any Markdown tool that supports Mermaid.

How to use it

  1. Write arrow chains, numbered steps or an indented outline.
  2. Choose the direction or leave the input style on Auto.
  3. Copy the Mermaid code into your diagram tool.

Frequently asked questions

How do I write a decision?

End a step with ? and add "yes: X / no: Y" after it.

Can it draw the diagram?

Paste the output into the Mermaid renderer tool.

What are the limits?

No subgraphs, styling or sequence diagrams; edit the generated code for those.
