CircleCI Config Generator (.circleci/config.yml)

Get a working CircleCI 2.1 configuration without reading the docs first.

Use the tool

Why this tool exists

Choose a language and image version, optionally change the install and test commands, and add a deploy command. The output defines a test job on a cimg convenience image with restore_cache and save_cache keyed on your lockfile checksum, and a workflow that runs deploy only on the main branch after tests pass. Docker builds get setup_remote_docker.

The YAML was parsed to confirm its structure. Adjust images, resource classes, orbs and secrets for your project; keep deploy credentials in CircleCI contexts, not in the file.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Pick the language and version.
  2. Set install, test and deploy commands if the defaults do not fit.
  3. Save the output as .circleci/config.yml.
  4. Push and watch the pipeline.

Frequently asked questions

What are cimg images?

CircleCI's maintained convenience images, such as cimg/node:22.11.

How does the cache key work?

It includes a checksum of the lockfile, so the cache refreshes when dependencies change.

Where do secrets go?

In project or context environment variables, never in the YAML.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
