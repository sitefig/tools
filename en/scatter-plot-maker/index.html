Scatter Plot Maker with Trendline and Pearson Correlation

Plots paired numbers as points, fits an ordinary least-squares line and reports slope, intercept, Pearson correlation r and R squared.

Use the tool

Why this tool exists

A scatter plot answers whether two measures move together. The trendline and r make that concrete, and the data table keeps every point readable without sight.

The fit is simple linear regression of y on x. It says nothing about causation, and a high r can come from one outlier, so look at the plot before trusting the number. Axes use rounded tick values and the chart is plain SVG you can restyle.

How to use it

  1. Paste two columns, x then y. A header row sets the axis names.
  2. Leave the trendline on or turn it off.
  3. Read the equation, r and R squared printed on the chart.
  4. Copy or download the SVG.

Frequently asked questions

What does r mean?

Pearson r runs from -1 to 1. Near 0 means no straight-line relationship; the sign gives the direction.

Which regression is used?

Ordinary least squares of y on x, with all points weighted equally.

Can it plot groups in colours?

Not in this tool. Use the bubble chart for a third variable.

Is r checked?

Yes against a hand calculation in Python for the sample data; it matches to all shown digits.
