DC Circuit Solver: Voltages, Currents and Power from a Netlist

Solves a DC circuit of resistors, voltage sources and current sources written as a netlist, giving node voltages, element currents and power.

Use the tool

Why this tool exists

Voltage dividers, ladders and bridges are quick to type as a netlist: V1 in 0 9, R1 in mid 1k, R2 mid 0 2k. The tool solves the whole circuit at once and lists the voltage at every node and the current, voltage drop and power in every element.

It uses modified nodal analysis with Gaussian elimination and partial pivoting, and the power delivered by the sources is compared with the power dissipated in the resistors as a sanity check. The solution was compared with NumPy. Only ideal sources and resistors are supported, and there is no drag-and-drop board: an open switch is simply left out of the netlist, and a lamp is a resistor.

How to use it

  1. Write one element per line: name, node, node, value.
  2. Use node 0 (or gnd) as ground and values like 1k, 2.2k, 5m, 4u or 1meg.
  3. Read node voltages, element currents and the power balance.
  4. Fix any error message, such as a floating node.

Frequently asked questions

What do V, R and I mean?

V is a voltage source, R a resistor, I a current source.

How do I write mega and milli?

Use meg for mega and m for milli. A capital M is refused because it is ambiguous.

Why a negative source current?

The current is counted from the first to the second node inside the element, so a source delivering power shows a negative value.

Can I add capacitors or diodes?

No, only DC steady state with resistors and ideal sources.
