Wayback Machine CDX Analyzer (Snapshots, Status Codes, Content Changes)

Read a CDX listing from the Wayback Machine and find when a page really changed.

Use the tool

Why this tool exists

The Internet Archive's CDX API lists every capture of a URL with timestamp, status and a content digest. Raw, it is a long column of lines. This analyzer groups captures by year and status, identifies the captures where the digest changed (a different body, so a real change), shows error captures that suggest downtime and the longest gap, and links straight to each changed snapshot.

The page makes no request: open the CDX URL in your browser (web.archive.org/cdx/search/cdx?url=...&output=txt) and paste the result. Digests change for trivial reasons such as ads and timestamps, so confirm by viewing the snapshots.

How to use it

  1. Open the CDX API URL for your page in a new tab and copy the text.
  2. Paste it here.
  3. Open the linked snapshots around the dates content changed.

Frequently asked questions

Does it query archive.org?

No. This site never makes requests from tools. Paste the CDX output.

What is the digest?

A hash of the captured response body; a new digest means different bytes.

Can it read JSON output?

Yes, output=json arrays are supported.
