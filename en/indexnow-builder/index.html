IndexNow Request Builder

Create everything needed to ping search engines about new or changed URLs with IndexNow: the key, the file to host, and a ready-to-run request.

Use the tool

Why this tool exists

Paste URLs from one host. The tool generates a random key (or uses yours, 8-128 letters, digits and dashes), shows the key file name and content, builds the JSON body for the bulk endpoint (up to 10,000 URLs) and prints a curl command plus a single-URL GET link. You choose the endpoint (api.indexnow.org or an engine's own).

A 200 or 202 answer only confirms receipt, not indexing. IndexNow is used by Bing, Yandex, Seznam and Naver; Google does not use it. This page only builds the request; it never sends anything.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Paste the changed URLs, all from the same host.
  2. Optionally enter your own key, or let the tool generate one.
  3. Upload the key file to your site root as shown.
  4. Run the curl command (or the GET link) from your terminal.

Frequently asked questions

Does Google support IndexNow?

No. Google has its own mechanisms such as sitemaps and Search Console.

Where does the key file go?

At the root of the host, named KEY.txt, containing just the key, so engines can verify you control the domain.

Can I submit different hosts together?

No. Each request must contain URLs from a single host.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
