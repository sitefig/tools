Eye Break Reminder (20-20-20 Rule Timer)

A timer that cycles between work and short eye breaks, with an on-page prompt, an optional beep and optional desktop notifications.

Use the tool

Why this tool exists

The 20-20-20 rule is a common suggestion for screen users: every 20 minutes, look at something about 20 feet (6 metres) away for 20 seconds. This page counts the work time, tells you when the break starts, counts the break down and then restarts the cycle.

You can change the work and break lengths, turn the beep off, and allow desktop notifications if you want a prompt while another tab is in front. Browsers slow timers in background tabs, so a prompt can come a little late. This is a reminder, not medical advice. Nothing is stored or sent.

How to use it

  1. Set the work minutes and break seconds.
  2. Press Start reminders.
  3. Optionally allow desktop notifications.
  4. Look away when the break prompt appears.

Frequently asked questions

Does it work in the background?

Only while the tab stays open; browsers may delay timers in hidden tabs.

Do I have to allow notifications?

No, the on-page prompt and beep work without them.

Is this medical advice?

No, it is a common guideline in reminder form.

Is anything saved?

No.
