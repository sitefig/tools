Soft 404 Detector (Error Page That Returns 200)

Check whether a page that returns 200 looks like an error page to search engines.

Use the tool

Why this tool exists

A soft 404 is a page that tells visitors "not found" while the server answers 200 OK. Search engines waste crawl budget on them and report them in Search Console. This detector scores the HTML you paste for the usual signs: not-found wording in the title, heading and text, very little content, noindex, a canonical pointing to the home page and meta refresh redirects, then recommends 404, 410, 301 or keeping the page.

Google's own classifier is not public, so treat the verdict as a heuristic. If the server already returns 404 or 410 the tool says so. It cannot request the URL; paste the status and source from your own fetch.

How to use it

  1. Paste the page source, optionally with the HTTP status line.
  2. Set the status and URL if you did not include them.
  3. Read the verdict and the recommended action.

Frequently asked questions

What should I return for removed products?

410 or 404 if gone for good, a 301 to the closest replacement if one exists, and keep 200 only if the page still has useful content.

Is redirecting everything to the home page ok?

Google treats mass redirects to the home page as soft 404s. Redirect to a relevant page.

Can the tool fetch the URL?

No; paste the HTML you retrieved.
