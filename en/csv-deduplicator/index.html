CSV Deduplicator (Remove Duplicate Rows by Key Columns)

Removes duplicate rows from a CSV by comparing one or more key columns, or the whole row, and can show which rows were removed.

Use the tool

Why this tool exists

Exports from CRMs and mailing lists often contain the same person twice with small differences in case or spacing. Comparing only the whole line misses those. Comparing the key column, such as email, finds them.

Choose the key columns by name or number, decide whether the first or last match is kept, and switch case and space handling. You can also view only the removed rows or a list of duplicate groups before you trust the result. Row order of the kept rows is unchanged.

How to use it

  1. Paste the CSV.
  2. Enter key columns by name or 1-based number, or leave empty to compare whole rows.
  3. Choose first or last, and the case and trim options.
  4. Pick cleaned CSV, removed rows or duplicate groups, then copy.

Frequently asked questions

Which row is kept?

The first match by default, or the last if you choose it. Kept rows stay in their original order.

Can I use several key columns?

Yes, separate them with commas. A row is a duplicate only when all key values match.

Are blank values duplicates?

Yes, two rows with an empty key are treated as the same key.

Is anything uploaded?

No, everything runs in your browser.
