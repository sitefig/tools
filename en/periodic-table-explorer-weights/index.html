Periodic Table with IUPAC Atomic Weights, Blocks and Search

Shows the standard 18-column periodic table colored by block or by atomic weight, and details for the elements you search for.

Use the tool

Why this tool exists

A table you can search quickly is useful for homework and for checking an atomic weight. Type Fe, oxygen or 79 and the element is outlined on the table, with its weight, period, group and block listed below.

Weights come from the IUPAC CIAAW abridged table for 2024 and are shown with their uncertainty. Elements without a standard atomic weight are greyed out. Group numbers follow the common layout; because the group 3 question (Lu and Lr versus La and Ac) is still discussed, the f-block rows are shown without a group number. Electron configuration and electronegativity are not included because no source was fetched for them.

How to use it

  1. Type elements to highlight, separated by commas.
  2. Choose to color the table by block or by atomic weight.
  3. Hover a cell to see the name, number and weight.
  4. Read the details list under the table.

Frequently asked questions

Where do the weights come from?

The CIAAW (IUPAC) abridged standard atomic weights 2024, with the link shown on the page.

Why do some elements show a dash?

They have no standard atomic weight because they have no stable isotopes.

Why no electron configuration?

It is not included until it can be taken from a cited source.

Can I print it?

Yes, use your browser print function.
