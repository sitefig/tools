Android Logcat Viewer: Filter by Tag, PID and Priority

Parses logcat lines (threadtime, time, brief) and summarises priorities, tags, processes and crashes.

Use the tool

Why this tool exists

logcat output mixes every app and system service. Filtering by tag or process ID and showing only warnings and above makes it readable.

The summary lists lines containing FATAL EXCEPTION or ANR in. A colour-coded HTML view is available.

How to use it

  1. Run adb logcat -v threadtime > log.txt.
  2. Paste or open the file.
  3. Set a minimum priority and optional tag, PID or text.
  4. Read the summary or open the coloured view.

Frequently asked questions

Which formats work?

threadtime, time and brief. Formats with a UID column are not supported.

What are the priority letters?

V verbose, D debug, I info, W warn, E error, F fatal, S silent.

How do I get a PID?

adb shell pidof com.example.app.

Is my log uploaded?

No. Everything is processed in your browser and nothing is sent. Logs can hold IP addresses and tokens, so the page does not write them into the address bar.
