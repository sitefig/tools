OpenAPI / Swagger Viewer (Readable Outline)

Turn a long API description into a compact outline you can scan: endpoints grouped by path, with parameters, request bodies and response codes.

Use the tool

Why this tool exists

The viewer resolves the structure of an OpenAPI 3.x or Swagger 2.0 document: info, servers or host, security schemes, each operation (method, path, tags, deprecated flag), parameters with location and required marks, request bodies, responses with media types and schema names, and the component schemas with required properties starred. $ref targets are shown by name and not fetched.

It reads the document you paste; it does not validate it (use the OpenAPI validator for that) or call the API.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Paste the spec as JSON or YAML.
  2. Read the outline from top to bottom.
  3. Look for deprecated or undocumented operations.
  4. Use the validator and converters for further work.

Frequently asked questions

Can it load a spec from a URL?

No. Pasting keeps it offline; a browser extension could fetch specs.

Does it support OpenAPI 3.1?

Basic 3.1 documents render, but 3.1-only features such as type arrays are shown simply.

Where are the examples?

Examples are not rendered; this view focuses on structure.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
