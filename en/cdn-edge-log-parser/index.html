CDN Edge Log Parser for Fastly and Akamai (Map Your Own Fields)

A configurable parser: choose the delimiter and name the fields, and it summarises cache and status.

Use the tool

Why this tool exists

CDN log formats are set by you, so no fixed parser fits. Here you list the field names in order and say which one holds the status, cache result and bytes.

A cache value containing HIT counts as a hit and MISS as a miss. PASS and other values are listed on their own.

How to use it

  1. Choose the delimiter used in your log.
  2. List the field names in order.
  3. Name the status, cache, URL and bytes fields.
  4. Paste the log and read the summary.

Frequently asked questions

Where do I find my field order?

In the logging endpoint format of Fastly or the DataStream stream settings of Akamai.

Are quotes handled?

Yes. Quoted values are kept whole.

Which cache values count as hits?

Anything containing HIT, such as HIT, TCP_HIT or REFRESH_HIT.

Is my log uploaded?

No. Parsing happens in your browser and nothing is sent. Logs can hold IP addresses and tokens, so the page does not write them into the address bar.
