Pictogram (Icon Array) Maker for Proportions

Shows a proportion as a grid of icons, with the highlighted ones filled and the rest grey. A fraction fills part of the last icon.

Use the tool

Why this tool exists

Icon arrays make risk and share easier to grasp than percentages, because you can count the icons. Set the total, the highlighted number, the icons per row and pick an icon.

The caption below the grid states the number and percentage in words, so the meaning is not only visual. Pick a total that matches the story, such as 10 or 100, and keep the highlight colour distinct from grey.

How to use it

  1. Set the highlighted count and the total.
  2. Choose icons per row and the icon shape.
  3. Type a caption and pick a colour.
  4. Copy or download the SVG.

Frequently asked questions

Can I use 2.5 of 10?

Yes, the third icon is filled for half.

Which icons are there?

Person, circle, square, heart and star.

Maximum total?

500 icons.

Does it work without a pointer?

Yes, all inputs are normal form fields.
