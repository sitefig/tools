TDMRep JSON Validator (/.well-known/tdmrep.json)

Checks a tdmrep.json file and explains each error.

Use the tool

Why this tool exists

A tdmrep.json file has to be an array, every rule needs a location and a numeric tdm-reservation of 1 or 0, and the first matching rule wins. A wrong value is a protocol error and agents treat the reservation as unset, so a typo can undo your opt-out.

Paste the file and see errors, warnings about ignored policies and rules that an earlier rule always matches first.

How to use it

  1. Paste your tdmrep.json.
  2. Fix errors first, then warnings.
  3. Check the order of rules.
  4. Serve it as application/json.

Frequently asked questions

Is a string like "1" allowed?

No. The value must be the number 1 or 0.

Why does order matter?

The first matching rule is used, so put specific paths first.

Is the policy required?

No.

Is it case sensitive?

Locations are.
