Redis SLOWLOG and MongoDB Slow Query Log Parser

Ranks Redis slow commands and MongoDB slow operations from pasted output.

Use the tool

Why this tool exists

Redis SLOWLOG GET prints nested lists that are hard to scan. The tool groups commands by name and shows total time. KEYS or SMEMBERS on a big key are classic findings.

For MongoDB 4.4 and newer it reads the structured log: namespace, command, plan summary and docs examined. A COLLSCAN plan with many documents examined is flagged for review.

How to use it

  1. Run SLOWLOG GET 128 in redis-cli, or collect mongod logs.
  2. Paste the output.
  3. Set a minimum duration if needed.
  4. Read the ranked groups.

Frequently asked questions

Which units?

SLOWLOG durations are microseconds, shown here in ms. MongoDB durationMillis is ms.

Which Mongo log format?

Structured JSON logs of MongoDB 4.4 and newer.

Is the full command shown?

Only an example per group, cut to 220 characters.

Is my log uploaded?

No. Everything is processed in your browser and nothing is sent. Logs can hold IP addresses and tokens, so the page does not write them into the address bar.
