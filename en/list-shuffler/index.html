List Shuffler (Randomize Line Order)

Paste a list, one item per line, and get it back in a random order.

Use the tool

Why this tool exists

The shuffle is a Fisher-Yates shuffle driven by the browser's cryptographically secure random generator, so every ordering is equally likely. You can keep a number of lines at the top in place, for example a header row, and drop blank lines. Shuffling again gives a new order; there is no seed.

For drawing winners use the raffle picker, and for splitting people into groups use the random team splitter; this tool just reorders.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Paste the list, one item per line.
  2. Optionally keep the first N lines fixed.
  3. Run it and copy the result.
  4. Run again for another order.

Frequently asked questions

Is it truly random?

It uses crypto.getRandomValues with an unbiased algorithm. It is fair for lotteries of low stakes; official draws need audited procedures.

Can I get the same order again?

No. There is no seed, so each run differs.

What about blank lines?

By default they are dropped.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
