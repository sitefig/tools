Font File Inspector: Names, Metrics, Features and Characters

Reads a font file in your browser and shows its family and license strings, metrics, OpenType feature tags, variable axes and the characters it maps. Tick a feature to see it on a sample line.

Use the tool

Why this tool exists

Before you use a font you want to know what it contains: how many glyphs, which languages it can type, whether it has ligatures, small caps or variable axes, and what its license says. The tool parses the sfnt tables itself (name, head, hhea, OS/2, maxp, post, cmap, GSUB, GPOS, fvar) and shows them as text plus a clickable character grid.

WOFF files are unpacked in the browser. WOFF2 uses Brotli, which scripts cannot decode, so those files are not supported here. The tool reads but never changes the file.

How to use it

  1. Choose a .ttf, .otf or .woff file.
  2. Read the report: names, license, metrics, features, tables.
  3. Browse the character grid and click one to copy it.
  4. Tick feature tags to see their effect on the sample line.

Frequently asked questions

Why is WOFF2 not supported?

WOFF2 needs Brotli decoding and browsers do not expose that to scripts. Convert it with a desktop tool first.

What do the metrics mean?

Values are in font units. Divide by units per em to get a ratio of the font size.

Does the feature list show all features?

It lists the feature tags found in GSUB and GPOS. Some are hidden from the toggles, such as kerning pairs and contextual ones, that work automatically.

Is the font uploaded?

No.
