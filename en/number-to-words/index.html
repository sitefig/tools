Number to Words (English)

Writes numbers out in English words, one per line. Choose cardinal, ordinal or dollars-and-cents currency style, and switch on the British "and" if you want it.

Use the tool

Why this tool exists

Cheques, contracts and invoices often need the amount written out in words as well as digits, because words are harder to alter. Teachers, copywriters and developers building templates run into the same need when they have a column of numbers and want text.

This tool handles a whole list at once. Each line is converted separately, so you can paste a column and get a column back. It copes with negatives, decimals and very large values, and it can produce ordinals like twenty-first or currency like forty-two dollars and fifty cents. The British option adds "and" after hundreds. All of it is calculated locally in your browser.

How to use it

  1. Type or paste one number per line.
  2. Choose a style: cardinal, ordinal or currency (dollars).
  3. Tick British "and" if you want "one hundred and five".
  4. Copy the lines of words from the output.

Frequently asked questions

How large a number can it spell out?

Up to about 10 to the power 36, which is the decillion range. Beyond that it returns a "number too large" message for that line. Whole numbers are handled exactly rather than as floating point.

How are decimals treated?

In cardinal mode the digits after the point are read one by one, so 3.14 becomes "three point one four". Ordinals need whole numbers. Currency mode rounds to cents.

Does currency mode support euros or pounds?

No. Currency mode is written for dollars and cents only. You can take the words for the whole number from cardinal mode and add your own currency name.

What happens if a line is not a number?

That line is shown with the note "not a number" and the other lines are still converted. Commas, underscores and spaces inside a number are ignored, so 1,000 works.
