XSD Schema Viewer (Element Tree)

Read an XSD without wading through verbose XML: global elements first, then the named types.

Use the tool

Why this tool exists

The viewer parses the schema strictly, then prints the target namespace, each global element with its nested sequences, choices, elements (type, minOccurs and maxOccurs shown as ranges), attributes (use and default), extensions, and the named complex and simple types including restriction bases and facets such as enumerations, patterns and length limits.

It shows structure only: imports and includes are not resolved, and it does not validate XML documents against the schema.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Paste the .xsd content.
  2. Read the element tree and the named types.
  3. Check required attributes and occurrence limits.
  4. Use the XML validator for well-formedness of documents.

Frequently asked questions

What does [0..*] mean?

minOccurs 0 and unbounded maxOccurs: the element is optional and may repeat.

Does it follow xs:import?

No. Paste each schema separately.

Can it validate an XML document?

No. It is a viewer.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
