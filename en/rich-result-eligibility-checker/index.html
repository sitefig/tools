Rich Result Eligibility Checker

Compares your JSON-LD with the required and recommended properties in Google's structured data documentation for Article, Product, Recipe, Event, Job posting, Video, Review, Local business and more.

Use the tool

Why this tool exists

Google documents which properties a page needs to be eligible for each rich result. Missing a required one means no result; missing a recommended one means a weaker result. Reading eleven documentation pages to find out which is which is slow, so this tool holds the lists and compares them with your markup, nested items included.

The rules were read from the Search Central pages on 2026-10-23 and Google changes them. The output names the documentation page for each type. Eligibility is not a promise: Google decides what to show, and its Rich Results Test is the final check. FAQ and How-to are reported as retired.

How to use it

  1. Paste the JSON-LD or the page HTML.
  2. For each node read the list of missing required properties first.
  3. Add the recommended ones that you can fill truthfully.
  4. Confirm with the Rich Results Test before you deploy.

Frequently asked questions

How current are the rules?

They come from Google pages read on 2026-10-23. The date is printed in the output. Re-check the linked page if something looks off.

What about types it does not know?

They are not listed. Only types with a documented Google feature are checked.

Why does Product show two blocks?

Product snippets and merchant listings have different requirements. The second block applies only if you sell the product.

Does it need the page to be live?

No. It reads the JSON-LD you paste and fetches nothing.
