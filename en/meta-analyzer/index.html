Open Graph & Twitter Card Validator

Paste HTML to validate Open Graph and Twitter Card tags, checking required properties, absolute URLs, https images, length limits and the card type.

Use the tool

Why this tool exists

When a link is shared on social media or in a chat, the preview is built from your Open Graph and Twitter tags. If the title is missing, the image URL is relative or the card type is invalid, the post shows a blank box or the wrong picture, and you only find out after publishing.

This validator reads the tags in the HTML you paste and reports missing required fields (title, type, image, URL), recommended ones, relative or http URLs, over-long titles and descriptions, and a missing or invalid twitter:card. It then lists every OG, Twitter, article and product tag it found. It checks the markup only: it does not fetch the image or ask the platforms, which also cache old scrapes. The check is local to your browser.

How to use it

  1. Copy the HTML source of the page, or just its head section.
  2. Paste it into the input box.
  3. Run the tool and read the validation messages.
  4. Fix the tags, then use the generator and the preview tool to confirm the result.

Frequently asked questions

Does it check that the image exists?

No. It only validates the tag values, for example that the URL is absolute and uses https. It does not download the image or check its size.

Which Twitter card types are valid?

summary, summary_large_image, app and player. Anything else is reported as an error. If twitter tags are missing, platforms fall back to Open Graph, but the card type defaults to summary.

Why is my preview still old on Facebook or X?

Platforms cache link previews. After fixing tags, use each platform's own debugger or scraper tool to refresh the cache. This validator cannot do that for you.

Is my HTML sent anywhere?

No. The validation happens in your browser and your markup is not uploaded. No account, upload or request to a remote service is involved at any point.
