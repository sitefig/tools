LLM Sampling Curve Visualizer

Shows what temperature, top-k, top-p and min-p do to a next-token distribution. You enter token and logit pairs and get probabilities before and after each step, as text bars with entropy.

Use the tool

Why this tool exists

Sampling settings are easy to copy and hard to feel. What does temperature 0.8 really do to a list of candidate words? How many tokens survive top-p 0.9? This tool lets you try it on numbers you control. Enter a few tokens with logits, set the four parameters, and see the softmax probabilities, the effect of temperature, which tokens are filtered out and the final renormalised distribution, along with entropy at each stage. It is a teaching and debugging aid for prompt engineers and developers tuning generation settings. It does not call a model, and real frameworks differ slightly in the order and tie handling of the filters. Everything runs in your browser.

How to use it

  1. Enter tokens with logits, one per line as "token: logit", or paste a plain list of logit numbers.
  2. Set temperature, top-k (0 turns it off), top-p (1 turns it off) and min-p (0 turns it off).
  3. Read the table of probabilities, the kept tokens and the entropy values.

Frequently asked questions

In what order are the filters applied?

Temperature first, then top-k, then top-p, then min-p, with renormalisation after each filter. Some libraries use a different order or handle ties differently, so results can vary.

What does temperature 0 do?

It becomes greedy selection: the highest logit gets all the probability, shared equally between exact ties. Values above 1 flatten the distribution.

What is entropy used for here?

Entropy in bits measures how spread out the distribution is. A drop after temperature or filtering shows that the model has become more predictable.

Does it show real model output?

No. It works only on the logits you enter and does not run a model. Use it to understand the maths, not to predict a specific model's text.
