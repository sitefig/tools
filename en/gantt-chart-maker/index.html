Gantt Chart Maker (Tasks, Durations and Dependencies)

Plans tasks on a timeline. A task has a name, an optional start date, a number of days and optional predecessors; start dates are computed from dependencies.

Use the tool

Why this tool exists

A Gantt chart makes the order of work and the length of the whole plan visible. Give fixed dates to the tasks that have them and let the rest follow their predecessors.

Durations count calendar days, with no weekends or holidays, so use it for rough plans and timelines. Loops and missing predecessors are reported by name. The schedule table lists each start and last day so the plan can be pasted elsewhere.

How to use it

  1. Paste rows: Task, Start (or blank), Days, After (names separated by ;).
  2. Fix start dates where they are known; leave the rest blank.
  3. Read the schedule table for start and end days.
  4. Copy or download the SVG.

Frequently asked questions

Are weekends skipped?

No. Days are calendar days.

What if two predecessors end on different days?

The task starts the day after the latest one ends.

Can tasks overlap?

Yes; give them the same predecessor or the same start.

Is there a critical path?

Not marked, but the longest chain of arrows determines the end date.
