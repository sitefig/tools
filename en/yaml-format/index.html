YAML Formatter

Re-indent and tidy YAML with a 2 or 4 space indent. The file is parsed and written back in a consistent style, which means comments are dropped and anchors are expanded.

Use the tool

Why this tool exists

YAML files edited by several people end up with mixed indentation, list items at different depths and inconsistent quoting. That makes reviews noisy and mistakes easy to miss. Reformatting gives you one consistent layout.

The formatter parses your YAML and writes it out again from the data, so the result is regular by construction. That comes with trade-offs worth knowing: comments are not preserved, and anchors and aliases are replaced by the values they refer to. If you rely on comments, as in most hand-maintained config, copy them back or use the Docker Compose formatter, which keeps them. For multi-document files, documents are written separated by ---. Everything runs in your browser.

How to use it

  1. Paste your YAML into the input box.
  2. Choose an indent of 2 or 4 spaces.
  3. Check the result, remembering that comments are removed and anchors expanded.
  4. Copy the formatted YAML.

Frequently asked questions

Why did my comments disappear?

The tool parses the YAML into data and writes it back, and comments are not part of the data. If you need to keep them, edit by hand or use a formatter that works on text, like the Docker Compose formatter.

What happens to anchors and aliases?

They are expanded. Each alias is replaced by a copy of the anchored value, so the result is longer but means the same thing.

Does it change values?

Values keep their meaning, but their style may change, for instance flow lists become block lists and quoting may be normalised. Compare with a JSON conversion if in doubt.

Does it support multiple documents?

Yes. Documents separated by --- in your input are formatted separately and written back with --- between them.
