Audio Waveform to SVG

Create waveform graphics for podcasts, players and video thumbnails without audio software.

Use the tool

Why this tool exists

The tool decodes the file with the browser's audio decoder, computes the peak level for each bar or point across the track, and writes an SVG with your chosen size, number of bars, style, colour and optional background. The SVG has an accessible label.

Peaks are scaled to the loudest part of the file so quiet tracks still fill the image. Only the first channel is drawn, and formats the browser cannot decode are rejected.

The file is read in your browser and is not uploaded anywhere.

How to use it

  1. Choose an audio file.
  2. Set size, style, colour and number of bars.
  3. Copy or download the SVG.
  4. Embed it in your page with an accessible description.

Frequently asked questions

Which formats are supported?

Whatever your browser can decode: MP3, AAC, OGG, WAV, FLAC and more, depending on the browser.

Can I animate it?

The output is static; CSS or JS can animate the bars.

Is my audio uploaded?

No.

Is my data sent anywhere?

The file is read in your browser and is not uploaded anywhere.
