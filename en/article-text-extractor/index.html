Article Text Extractor (Readability-Style Main Content from HTML)

Strip a page down to its article: title, author, date and the main text, as Markdown or plain text.

Use the tool

Why this tool exists

Readability-style extraction finds the main content block of a page by looking at paragraph length and link density, and drops navigation, sidebars, comments and footers. This tool does that for pasted HTML and also reads the author, publication date and language from meta tags and JSON-LD, estimates reading time and outputs Markdown (headings, lists, quotes, code, links) or plain text.

It uses heuristics on the source you paste: pages that build their text with JavaScript will be empty, and unusual layouts can select the wrong block. Use it to archive your own pages, prepare content for summarising or compare what a crawler sees.

How to use it

  1. Paste the page HTML.
  2. Choose Markdown or plain text.
  3. Copy the extracted article.

Frequently asked questions

Why is the output empty?

The text may be added by JavaScript. Copy the rendered DOM from DevTools instead of the page source.

Does it keep links?

Yes in Markdown mode; untick the option to drop them.

Does it fetch URLs?

No. Paste the HTML.
