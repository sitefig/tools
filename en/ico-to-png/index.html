ICO to PNG Converter (All Icon Sizes)

Extract the images from a favicon or Windows icon.

Use the tool

Why this tool exists

The tool reads the icon directory and every image entry. PNG-compressed entries are saved as they are; bitmap entries are decoded (palettes, 16/24/32-bit colour and the AND transparency mask) and re-encoded as PNG. Decoding of all bit depths was compared pixel by pixel with Pillow.

RLE-compressed or unusual bitmaps are not supported, and cursor hotspots are ignored.

The file is read in your browser and is not uploaded anywhere.

How to use it

  1. Choose an .ico or .cur file.
  2. Read the list of sizes.
  3. Download each PNG.
  4. Create a new favicon set with the favicon generator.

Frequently asked questions

How many images are in an ico?

Often 16, 32, 48 and 256 pixel sizes in one file.

Is transparency kept?

Yes.

Can I make an ico?

Use the favicon generator, which creates .ico from an image.

Is my data sent anywhere?

The file is read in your browser and is not uploaded anywhere.
