Grafana Panel JSON Generator

Skip clicking through the panel editor: describe the panel and paste the JSON into your dashboard.

Use the tool

Why this tool exists

Enter a title, a PromQL expression, legend format, unit, threshold values for warning and critical, the datasource UID and the panel type. The tool writes a panel object with gridPos, targets, fieldConfig (unit and absolute thresholds) and options suitable for current Grafana versions.

Panel schemas change between Grafana versions, so import the JSON and let Grafana migrate it. Make sure the datasource uid matches the one in your instance.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Choose the panel type and enter the query.
  2. Set the unit and thresholds.
  3. In Grafana open Dashboard settings, JSON Model.
  4. Add the object to the panels array with a unique id.

Frequently asked questions

Where do I find the datasource uid?

In Connections, Data sources, in the URL of the datasource page.

Can I use other datasources?

The generated target uses the Prometheus form; adapt it for other plugins.

Why do thresholds start with null?

The first step (base) has no value and applies below the next threshold.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
