Tracker Detector (HTML source)

Paste the HTML source of a page to list third-party hosts and match them against known trackers, analytics, advertising, social, chat and consent services, plus inline code signatures.

Use the tool

Why this tool exists

Before you write a privacy policy, set up a cookie banner or answer a data protection question, you need to know which third parties a page really talks to. Tags are added by marketing, plugins and themes over the years, and nobody remembers them all.

This tool reads the HTML you paste, extracts every external host and groups known ones by category such as advertising, analytics, session replay, tag managers, social widgets, fonts and CDNs. It also looks for inline snippets such as tracking initialisation code. Pasted source only shows what is in the HTML itself: scripts loaded later by other scripts will not appear, so a network capture gives a fuller picture. The analysis runs locally.

How to use it

  1. View the page source in your browser and copy the HTML.
  2. Paste it into the input box.
  3. Optionally enter the first-party domain, otherwise it is read from the canonical or og:url tag.
  4. Run the tool and review the hosts grouped by category.

Frequently asked questions

Does it find every tracker?

No. It only sees hosts and snippets written in the pasted HTML. Trackers that other scripts inject at runtime, or that load after consent, will be missed. A HAR capture gives a fuller list.

How does it know what is first party?

It uses the domain you enter, or the canonical link and og:url in the page. Hosts that share the same base domain are skipped as first party.

Why does it list hosts it cannot identify?

Unknown external hosts are shown separately with a count. They may be your own CDN, an unlisted vendor or a harmless resource, so check them manually.

Is the source code sent to a server?

No. The matching is done in your browser against built-in lists, and the pasted HTML is not uploaded.
