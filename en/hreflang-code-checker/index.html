Hreflang Code Checker (ISO 639-1 and 3166-1)

Checks each hreflang value against the official language, region and script code lists and tells you the correct form, for example en-GB instead of en-UK.

Use the tool

Why this tool exists

Google ignores hreflang values it cannot read, and the common mistakes are all about codes: UK instead of GB, jp instead of ja, a country code on its own, an underscore, a three-letter language, or the numeric region 419. The format check in other tools accepts many of these. This one checks membership in the ISO 639-1 language list, the ISO 3166-1 alpha-2 region list and the ISO 15924 script list.

Rules follow the Google page on localized versions, read 2026-10-23. The check says nothing about whether people in a region really read that language.

How to use it

  1. Paste codes one per line, or whole link tags or code | URL lines.
  2. Read the verdict for each code.
  3. Apply the suggested form where one is given.
  4. Run again until all are OK.

Frequently asked questions

Why is es-419 an error?

It is a UN M.49 region. Google names it as unsupported; use es or a country such as es-MX.

Is lowercase allowed?

Google reads codes case-insensitively. The tool suggests the usual form, de-AT, as a review note.

Why is eu listed as OK?

eu is Basque. The tool warns about this in confusable cases such as be, se and ca when used alone.

Which lists are used?

ISO 639-1, ISO 3166-1 and ISO 15924 from the Debian iso-codes package.
