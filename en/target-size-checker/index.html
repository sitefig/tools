Target Size Checker for WCAG 2.5.8 (24 by 24 CSS Pixels)

Checks touch and click targets against WCAG 2.5.8, including the spacing exception.

Use the tool

Why this tool exists

Small, tightly packed targets are hard to hit with a finger or tremor.

The tool tests each target for 24 by 24 CSS pixels. For smaller ones it applies the spacing exception: a 24 px circle centred on the target must not touch another target or another undersized target circle. Equivalent, inline, user-agent and essential exceptions need your judgement.

How to use it

  1. Enter one target per line: name, width, height, x, y.
  2. Use real sizes from DevTools.
  3. Read the result for each target.
  4. Enlarge or space out the failing ones.

Frequently asked questions

Does padding count?

Yes, the target is the clickable area.

What if I have no positions?

Undersized targets without a position are marked review.

Is this AA?

Yes, 2.5.8 Target Size (Minimum) is Level AA in WCAG 2.2.

Is anything uploaded?

No.
