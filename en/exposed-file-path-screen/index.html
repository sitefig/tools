Exposed File Path Screen (.env, .git, Backups) from URL Lists

Flags file names in a URL list that often mean exposed secrets or source: .env, .git, backups, dumps, keys and admin tools.

Use the tool

Why this tool exists

Many leaks are plain files left on a web server: a .env file, a .git folder, a database dump, a zip backup. They show up in sitemaps, crawl exports and archive lists.

Paste your URLs, paths or sitemap XML and the tool flags names that match common patterns, sorted by severity. A match is a candidate only: open the file on your own site to confirm, then remove it or block the path in the server. The tool makes no requests, so use it only on lists from sites you own or are allowed to test.

How to use it

  1. Export URLs from your sitemap, crawler or access logs.
  2. Paste them into the box.
  3. Check each high and medium item on your own site.
  4. Delete the files or block the paths, and rotate any secret that was exposed.

Frequently asked questions

Does it fetch the URLs?

No. It only reads names.

Is a low item a problem?

Usually not by itself, but dependency manifests and docs can reveal versions.

What should I do if a .env was exposed?

Remove it, then treat every secret in it as leaked and rotate them.
