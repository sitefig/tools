Outlier Detector for a CSV Column (IQR or Z-Score Flag)

Marks values far outside the usual range of a column as low or high and adds an outlier column you can filter on.

Use the tool

Why this tool exists

Outliers can be errors, special cases or the finding. The IQR method flags values beyond 1.5 times the interquartile range from the quartiles, which does not depend on a normal distribution. The z-score method flags values more than a set number of standard deviations from the mean and is thrown off by the very outliers it looks for.

The summary prints the exact limits so the decision is reproducible. Flagging is not removal: check each case before deleting.

How to use it

  1. Paste the CSV and name the numeric column.
  2. Pick IQR or z-score and the threshold.
  3. Read the limits in the summary.
  4. Copy or download the table, or only the flagged rows.

Frequently asked questions

Which quartile method?

Linear interpolation, same as Excel QUARTILE.INC.

Which standard deviation?

Sample standard deviation (n-1).

Non-numeric cells?

They are marked not a number.

Minimum data?

At least 4 numbers.
