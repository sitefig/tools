Mind Map Maker

Build a mind map as a tree: a central idea with branches and sub-branches you can add, rename and delete. The tool exports the structure as a Markdown outline.

Use the tool

Why this tool exists

A mind map is useful for getting thoughts out of your head before they are ordered: the structure of an article, a meeting agenda, the parts of a project. Many mind map apps are heavy, ask you to sign up, or lock your map inside a proprietary format.

This one is deliberately plain. You edit a tree of text fields, adding children with a button and deleting branches you do not need, and below it a Markdown outline updates as you type, which you can paste into a note, wiki or README. The map is saved in this browser only, so nothing is uploaded. It is a text outline, not a drawn diagram with circles and lines.

How to use it

  1. Click the central idea field and replace "Central idea" with your topic.
  2. Click "+ child" on any node to add a branch under it, and type the idea into the new field.
  3. Click "delete" to remove a branch you do not need.
  4. Copy the Markdown outline from the box below the tree with the Copy button.

Frequently asked questions

Is it a visual mind map?

No. It is an indented tree of text fields with a Markdown outline export. There are no drawn bubbles or lines. If you need a diagram, convert the outline to Mermaid or use a drawing tool.

Where is my map saved?

In your browser's local storage on this device only. It is not uploaded and will not sync. Clearing site data, or using a private window, removes it, so copy the outline when it matters.

What does the Markdown look like?

The central idea becomes a top-level heading and each branch becomes a bullet, indented one level per depth. It pastes cleanly into Markdown editors, GitHub and note apps.

Can I have more than one map?

No, there is one map stored per browser. To start another, copy the outline you want to keep, then rename the nodes or delete branches.
