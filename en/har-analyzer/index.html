HAR Privacy Analyzer

Paste the JSON of a HAR file to see third-party domains, known trackers, cookies and their flags, mixed content, large and slow requests and header mismatches.

Use the tool

Why this tool exists

A HAR file is a recording of everything a page loaded. It is the best evidence of which third parties receive requests, what cookies are set and whether anything goes over plain HTTP. It is also dangerous: HAR files can include session cookies, tokens and form data, so uploading one to an unknown online analyser is a bad idea.

This analyser keeps the file in your browser. It groups third-party hosts with request counts and bytes, flags known trackers, lists Set-Cookie headers with flag problems, spots http requests on an https page and highlights requests over your size and time thresholds. Use it for privacy reviews and performance triage. Remove or rotate any secrets before sharing a HAR with anyone.

How to use it

  1. Export a HAR from the Network tab of your browser developer tools.
  2. Paste the HAR JSON into the input box.
  3. Enter the first-party host if the first request is not your site, and set the large and slow thresholds.
  4. Run the tool and read the sections for domains, cookies, mixed content and performance.

Frequently asked questions

Is it safe to paste a HAR file here?

The analysis runs in your browser and nothing is uploaded. HAR files still hold secrets such as cookies and tokens, so only use them on a device you trust and sanitise before sharing.

How are third parties decided?

By comparing the base domain of each request with the first-party host, which you can set. Anything else counts as third party, and a built-in list marks known trackers.

What if my HAR is very large?

Large captures with response bodies can be tens of megabytes and may slow the browser. Export without content, or trim entries, if the page becomes unresponsive.

What do the thresholds do?

Requests above the large size in kilobytes or the slow time in milliseconds are listed separately. The defaults are 500 KB and 1,000 ms, and you can change both.
