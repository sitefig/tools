Accessible HTML Table Builder from CSV with Caption and Scope

Builds an accessible HTML table from pasted CSV with caption and scope attributes.

Use the tool

Why this tool exists

Tables without headers are read cell by cell with no context.

This tool detects the delimiter, handles quoted fields, escapes the content, adds a caption, marks column headers and an optional header column with scope, and can wrap the table in a labelled, focusable scroll region. Complex tables with merged cells need manual markup.

How to use it

  1. Paste CSV or tab-separated data.
  2. Enter a caption.
  3. Choose whether the first column is a header.
  4. Copy the HTML.

Frequently asked questions

Why scope?

It tells assistive technology which cells a header applies to.

Why tabindex on the wrapper?

So keyboard users can scroll a table that overflows.

Can it do merged cells?

No. Use colspan, rowspan and scope="colgroup" by hand.

Is the data sent?

No.
