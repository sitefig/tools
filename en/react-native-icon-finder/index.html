React Native Vector Icons Finder

Type a word and see every matching icon name across the nine icon sets in react-native-vector-icons, with the import line and JSX ready to paste.

Use the tool

Why this tool exists

In React Native the icon you want exists, but you do not know its exact name or which set has it. Searching nine separate glyph lists, each with its own naming style, is slow. This tool searches all the names at once and shows the component and name to use.

It is a name search only. There are no glyph previews, because showing the icons would mean shipping the icon fonts, which this site does not do. The lists come from the react-native-vector-icons package version 10 (MIT licence) and contain names only. For the FontAwesome sets the free icons are included; add the solid or brand prop in your code for those styles. If your project uses a different version of the package, a few names may differ.

How to use it

  1. Type one or more words, such as arrow left.
  2. Optionally choose one icon set.
  3. Look through the matches grouped by set.
  4. Copy the import and JSX line you need.

Frequently asked questions

Why are there no icon images?

Rendering the glyphs needs the icon fonts, and the site ships no third-party code or fonts. Only names are searched.

Which version of the package is this based on?

Version 10.0.1 of react-native-vector-icons. Names in your project may differ slightly if you use another version.

How do I use FontAwesome solid or brand icons?

Import FontAwesome5 or FontAwesome6 and add the solid or brand prop, for example name="github" brand.

Does a multi-word search match all words?

Yes. Every word must appear somewhere in the icon name.
