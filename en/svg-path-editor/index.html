SVG Path Editor

Takes an SVG path data string and lets you translate and scale it, convert it to absolute or relative commands and round the numbers. It lists every point and draws a preview.

Use the tool

Why this tool exists

The d attribute of an SVG path is a compact string of commands that is painful to edit by hand. Nudging a shape ten units to the right, doubling its size, or converting relative commands into absolute ones all mean rewriting every number.

Paste the path, enter translate and scale values, choose absolute or relative output and a number of decimals, and the transformed path is produced with a numbered list of its points and a preview. Horizontal and vertical lines, curves, smooth curves and arcs are all handled, and implicit repeated commands are expanded. Arc radii are scaled with the absolute scale factors. It does not edit shapes visually. The processing runs in your browser.

How to use it

  1. Paste the path data, or the whole d attribute, into the input box.
  2. Enter translate X and Y and scale X and Y if you want to move or resize it.
  3. Choose absolute or relative output and the number of decimals.
  4. Check the preview and copy the new path from the output.

Frequently asked questions

Which commands are supported?

M, L, H, V, C, S, Q, T, A and Z, in both upper and lower case. Numbers following a command without a new letter are treated as repeats of it, with M followed by implicit L.

What is the difference between absolute and relative?

Absolute commands, in capitals, use coordinates from the origin of the drawing. Relative commands, in lower case, move from the current point. The tool converts whichever form you provide.

How does scaling treat arcs?

Arc radii are multiplied by the absolute scale factors, and the other arc parameters are left unchanged. Negative scales that mirror a shape do not flip the arc sweep flags, so check mirrored arcs by eye.

Why does it say a number is missing?

A command did not get all its arguments, for example a cubic curve with only five numbers. The error names the command so you can find the incomplete part of the path.
