Accept-Language Header Parser

Sorts the language ranges in an Accept-Language header by preference and flags invalid q-values and tags.

Use the tool

Why this tool exists

Accept-Language lists the languages a visitor prefers, each with a q-value from 0 to 1. Reading a long header by hand is hard. This tool sorts the ranges, shows q=0 as not acceptable, marks the wildcard and reports malformed values according to RFC 9110.

Leave the input blank in a browser to build a header from navigator.languages. That is an approximation, because browsers choose their own q-values.

How to use it

  1. Paste an Accept-Language value, or leave it blank for your browser.
  2. Read the ranked list.
  3. Fix any invalid q-values.
  4. Use the Locale Negotiation Simulator to see the outcome.

Frequently asked questions

What does q=0 mean?

The language is not acceptable.

What is *?

Any language not otherwise listed.

How are ties ordered?

By their order in the header.

Is the browser header exact?

No, it is rebuilt from navigator.languages.
