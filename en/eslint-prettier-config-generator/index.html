ESLint / Prettier Config Generator

Pick TypeScript, environment and formatting preferences to get an ESLint flat config, a .prettierrc and the npm command to install the packages.

Use the tool

Why this tool exists

ESLint moved to flat config files, and many tutorials online still show the old .eslintrc format, so new projects end up with settings that no longer work. Prettier is simpler, but its options have to match your team's habits, and the two tools need compatible setups.

This generator writes an eslint.config.js using the recommended rules, ignores for dist and node_modules, and globals for Node or the browser. If you tick TypeScript, it adds typescript-eslint. It then writes a .prettierrc with semicolons, quotes, print width, tab width and trailing commas as you choose, and prints the matching install line. The rule set is intentionally small, so grow it as your project needs. Everything is generated in the browser.

How to use it

  1. Select which config you need: both, eslint or prettier.
  2. Tick TypeScript if needed and pick the environment, node or browser.
  3. Choose semicolons, quotes, print width, tab width and trailing commas.
  4. Copy the files and run the install command shown at the bottom.

Frequently asked questions

What is a flat config?

It is the newer ESLint configuration format: a single eslint.config.js file exporting an array of settings objects. It replaces the older .eslintrc files, and recent ESLint versions use it by default.

Does it set up the Prettier plugin for ESLint?

No. The two configs are independent. Run Prettier for formatting and ESLint for code-quality rules. Adding a bridge such as eslint-config-prettier is a separate step if you see conflicts.

Which rules are enabled?

The recommended ESLint set, the TypeScript recommended set if selected, plus no-unused-vars as a warning and eqeqeq as an error. Add or change rules inside the rules object.

What about React or Vue?

Framework plugins are not included. Install the relevant ESLint plugin and add its config to the exported array after the generated entries.
