Calendar Heatmap (GitHub-Style Year of Daily Values)

Shows a year of daily values as a grid of squares, one column per week, shaded by value like a contribution graph.

Use the tool

Why this tool exists

A calendar heatmap shows rhythm: weekends, holidays, streaks and gaps. Paste a date and a value per line and get the year in one picture.

Dates must be written YYYY-MM-DD; other formats are rejected rather than guessed. Repeated dates add up. The year defaults to the latest one in your data, and you can start weeks on Monday or Sunday. A table of the days sits under the chart as a text alternative.

How to use it

  1. Paste lines like 2026-03-14,5.
  2. Optionally set the year, week start and colour.
  3. Check the active days and total in the note.
  4. Copy or download the SVG.

Frequently asked questions

Why only ISO dates?

Formats like 03/04/26 are ambiguous. Normalise them first with the date format normalizer.

What if a date repeats?

The values are added.

How are levels chosen?

Four levels by share of the busiest day, plus an empty level for zero.

Can I show several years?

One year per run. Change the year option for others.
