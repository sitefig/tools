HTML Entities Reference

A searchable table of named and numeric HTML entities. Type a name, a character, a number or a description and see its named, decimal and hexadecimal forms.

Use the tool

Why this tool exists

You need a copyright sign, a non-breaking space or an arrow inside an HTML page, and you cannot remember whether it is the entity with copy in it, or a number. Sometimes you only know what the character looks like, or the code point from a bug report.

This reference lets you search any way round. Type copy, 169, euro or the character itself and the matching rows appear with the named entity, the decimal form and the hex form. The list covers the HTML 4 entities: Latin-1 symbols and accented letters, Greek letters, general punctuation, spaces and joiners. Invisible characters are shown with a dot. It runs entirely in your browser, so no search is sent anywhere.

How to use it

  1. Type a name, character, number or description into the filter box.
  2. Leave it blank to list every entity.
  3. Find the row you need in the table.
  4. Copy the named, decimal or hex form into your HTML.

Frequently asked questions

What can I type in the filter?

A name such as copy, a word from the description such as arrow, a decimal number such as 169, a hex code such as x20ac, a form such as &#169;, or the character itself. Matching is not case sensitive.

Which entities are included?

The classic HTML 4 set: quotation, ampersand, less-than and greater-than, Latin-1 symbols and letters, Greek letters, spaces, joiners, dashes, quotes, bullets and a number of arrows and symbols. It is not the full HTML5 list.

When should I use an entity at all?

You must escape ampersand, less-than and greater-than in HTML text. For other characters, a UTF-8 page can usually contain the character directly. Entities help when you need an invisible character, such as a non-breaking space, to be visible in the source.

Why are some characters shown as a dot?

Spaces, soft hyphens, zero-width characters and direction marks are invisible. A dot stands in for them in the Char column, so you can still find their entities.
