SVG Icon Recolorer: Change Fill and Stroke Colors in Bulk

Recolours the fill and stroke of SVG files in bulk and returns one file or a ZIP.

Use the tool

Why this tool exists

Icon sets often come in one colour. Changing a whole set by hand is slow. The tool rewrites fill and stroke attributes and inline style values, leaves none, gradients and (optionally) currentColor alone, and can add a colour to the root element where there is none.

It works on text, without drawing the icons, so colours set in style blocks or classes are not changed. Check a few results visually. The ZIP is made in your browser.

How to use it

  1. Choose one or more SVG files.
  2. Enter a new fill, stroke or both.
  3. Decide about currentColor and the root element.
  4. Run it and download the file or ZIP.

Frequently asked questions

Which colours are changed?

Values in fill and stroke attributes and in style="..." declarations.

What is skipped?

none, transparent, inherit, url(...) gradients, and currentColor when you untick that option.

Why did nothing change?

The colours may come from a style block or class. Edit the SVG or inline the styles first.

Is the SVG optimised too?

No. Use the SVG Optimizer for that.
