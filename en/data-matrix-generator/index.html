Data Matrix Barcode Generator (ECC 200, SVG)

Make Data Matrix codes for parts, labels and packaging.

Use the tool

Why this tool exists

The encoder writes ECC 200 square symbols: ASCII encodation with digit-pair compression, padding with the standard pseudo-random pad, Reed-Solomon codewords over GF(256) with the 0x12D polynomial, round-robin block interleaving for the larger sizes and the standard "Utah" module placement with finder and clock patterns for the 1 to 36 data regions. All 24 square sizes from 10x10 to 144x144 were generated and decoded with the independent zxing-cpp reader, including digit-heavy, UTF-8 and mixed text.

Only ASCII encodation is used, so very long non-numeric data needs a larger symbol than an encoder that switches to C40, Text or Base 256 would choose. Rectangular symbols and GS1 mode are not offered. Scan a sample before printing in quantity.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Enter the text or digits.
  2. Set the module size and quiet zone.
  3. Copy or download the SVG.
  4. Scan it with a reader before printing.

Frequently asked questions

What is the capacity?

Up to 1,558 codewords in a 144x144 symbol, which is about 1,558 characters or 3,116 digits.

How is it different from a QR code?

Data Matrix is more compact for small items and has a solid L-shaped finder pattern; both are 2D barcodes.

Can I print it small?

Yes, but keep modules large enough for your scanner; test at the final size.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
