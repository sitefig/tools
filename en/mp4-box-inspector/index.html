MP4 / MOV Box Inspector (Codecs, Duration, Fast Start)

Understand why a video starts slowly or what codec a file uses.

Use the tool

Why this tool exists

The inspector walks the ISO base media boxes (ftyp, moov, trak, mdia, stbl, mdat) by reading file slices, so large videos are not loaded into memory. It reports the major brand, duration, per-track type, codec (such as avc1 H.264, hvc1 HEVC, av01, mp4a AAC), video dimensions and duration, the size of the media data and whether moov precedes mdat ("fast start"). Results were compared with ffprobe on test files.

Fragmented MP4 files keep duration in a different place, so a missing duration there is normal. For web delivery, move moov to the start: ffmpeg -i in.mp4 -c copy -movflags +faststart out.mp4.

The file is read in your browser and is not uploaded anywhere.

How to use it

  1. Choose an MP4, M4A or MOV file.
  2. Read the brands, tracks and codecs.
  3. Check the fast start line.
  4. Re-mux with faststart if needed.

Frequently asked questions

What is fast start?

Having the index (moov) before the media data so playback can begin before the download finishes.

Which codec is best for browsers?

H.264 with AAC plays everywhere; AV1 and HEVC support varies.

Does it read MKV or WebM?

No, those use a different container.

Is my data sent anywhere?

The file is read in your browser and is not uploaded anywhere.
