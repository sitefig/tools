Several CSVs to One Excel Workbook (One Sheet Each)

Builds an Excel workbook from several pasted CSV tables. Name each sheet with a first line like -- name: Sales.

Use the tool

Why this tool exists

Excel opens a single CSV as one sheet, so combining several exports into one workbook usually means copy and paste. Separate the tables with a line of three dashes and get one .xlsx with a bold header row on every sheet.

Numbers are written as real numbers so formulas work, while values such as 007 or 00123 stay as text to keep the leading zeros. The file is built in your browser from plain XML and a ZIP container; no macros, no styles beyond the bold header. For a single CSV you can also use the CSV to XLSX tool.

How to use it

  1. Paste the first table, then a line with ---, then the next.
  2. Start a table with -- name: Sheet name to name its sheet.
  3. Pick the delimiter, or leave it on auto, and decide whether numbers are converted.
  4. Download the workbook.

Frequently asked questions

Is the file valid for Excel?

It is a standard .xlsx package. It was checked as a well-formed ZIP and XML; open it in your spreadsheet program to confirm.

Are dates converted?

No. Dates stay text, so nothing is silently reinterpreted.

Sheet name limits?

Names are cut to 31 characters and forbidden characters are replaced with spaces.

Can I upload files?

Paste the text; the tool works on text input only.
