WhatsApp Click-to-Chat Link Generator (wa.me)

Create wa.me links with a prefilled message from phone numbers in international format. Cleans spaces, plus signs and dashes.

Use the tool

Why this tool exists

A wa.me link opens a chat with a number and can fill in a message. It needs the number in full international form, digits only. Spaces, plus signs, brackets and a leading zero break it.

Paste numbers, one per line, and a message. The tool strips the extras, removes a (0) trunk digit, warns if no country code is visible or the length is unusual, and URL-encodes the message. The format is as commonly documented and was not opened here, so click one link to test.

How to use it

  1. Paste the numbers with country code.
  2. Type the prefilled message.
  3. Check any review notes.
  4. Copy the links.

Frequently asked questions

What format does the number need?

Country code then number, digits only, no plus, zeros or brackets.

What if a number starts with 0?

It is a local number. Replace the leading 0 with the country code.

Does it send messages?

No. It only builds links.
