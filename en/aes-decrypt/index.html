AES-GCM Decrypt

Paste the base64 output from the AES-GCM Encrypt tool, enter the password and read the original text. A wrong password or changed data is reported as a failure.

Use the tool

Why this tool exists

You have received an encrypted note and the password through another channel, or you stored a snippet earlier and need it back. This tool reverses the encrypt tool on this site: it reads the version byte, iteration count, salt and nonce from the start of the data, derives the key from your password and decrypts.

AES-GCM is authenticated, so the result is either the exact original or an error. There is no partial output when the password is wrong or a character was altered in transit. That is useful for spotting copy-and-paste damage, such as a missing line or an extra space. Decryption runs in your browser with WebCrypto, so neither the ciphertext nor the password is uploaded.

How to use it

  1. Paste the base64 ciphertext into the input box.
  2. Enter the exact password in the options.
  3. Run the tool and wait a moment while the key is derived.
  4. Read the decrypted text, or check the password and data if you get an error.

Frequently asked questions

Can it decrypt data from other tools?

No. It only reads the format produced by the AES-GCM Encrypt tool on this site. Data from other programs has a different layout and will be rejected as an unrecognised format.

Why do I see decryption failed?

Either the password is wrong, or the data was changed or truncated. GCM authentication cannot tell the two apart, so check both. Whitespace in base64 is ignored, but missing characters are not.

Does it limit iteration counts?

Yes. It accepts counts between 1,000 and 5 million from the header, to prevent absurd values from freezing the page. Data from the companion encrypt tool uses 600,000.

Are the password and text sent anywhere?

No. Decryption is done locally with the browser WebCrypto API. Neither the ciphertext nor the password is uploaded or stored, and closing the tab discards them.
