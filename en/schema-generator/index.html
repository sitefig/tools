Schema.org JSON-LD Generator

Choose a Schema.org type and fill in simple key: value lines to generate JSON-LD for Article, Product, LocalBusiness, FAQPage, Organization, Event, Recipe, HowTo and other types.

Use the tool

Why this tool exists

Structured data tells search engines what a page is about, but writing JSON-LD by hand is tedious and error prone: nested objects, arrays, the right @type for each part. Plugins help only if you use a CMS that supports them.

This generator lets you write flat lines such as author.name or offers.price, and builds the nested objects with the right types for you. Special lines handle FAQ questions, breadcrumb items, HowTo steps and recipe ingredients. Pick a type to load a sample, edit it and copy the script. It supports twelve types, including Video and WebSite search actions. Check the output with the JSON-LD inspector and the official testing tools, because eligibility for rich results is not guaranteed. It runs in your browser.

How to use it

  1. Choose a Schema.org type in the options to load a sample.
  2. Edit the key: value lines with your own data, using dotted names for nested fields.
  3. Run the tool to produce the JSON-LD script.
  4. Paste it into your page and validate it with the inspector and Google's tools.

Frequently asked questions

How do I write nested fields?

Use dots, for example author.name or address.streetAddress. The tool creates the nested objects and assigns sensible types such as Person, PostalAddress or Offer.

How do I add several FAQ items or steps?

Use one line per item. For FAQ write q: Question | Answer. For breadcrumbs write item: Name | URL. For HowTo write step: Name | Text.

Will this give me rich results?

Not necessarily. Markup must match visible page content and meet Google's guidelines, and Google decides when to show rich results. Always test the output.

Is my data uploaded?

No. The JSON-LD is generated in your browser and nothing you enter is sent to a server. You can even load the page and then disconnect from the network before running it.
