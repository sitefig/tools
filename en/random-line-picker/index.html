Random Line Picker (Draw Lines from a List)

Pick one or more random lines from a pasted list, with or without repeats, using your browser secure random numbers.

Use the tool

Why this tool exists

Choosing what to eat, who goes first or which idea to try is easier when something else decides. A random pick also avoids the bias people show when they choose.

Paste a list, set how many lines to draw and whether a line may be drawn twice. The draw uses your browser's secure random numbers without modulo bias, so every line has the same chance. Nothing is uploaded.

How to use it

  1. Paste your list, one item per line.
  2. Set how many lines to pick.
  3. Choose whether repeats are allowed or identical lines count once.
  4. Press run again for a fresh draw.

Frequently asked questions

Is it really random?

It uses crypto.getRandomValues with rejection sampling, so each line is equally likely.

Can I draw the same line twice?

Only if you tick the repeat option. Otherwise each line is drawn at most once.

Can I repeat a draw?

No. For a repeatable, provable draw use the Giveaway Winner Picker with a seed.
