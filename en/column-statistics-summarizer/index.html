Column Statistics Summarizer (Mean, Median, Min, Max, Stdev per Column)

Computes basic statistics for each column of a table in one pass.

Use the tool

Why this tool exists

A quick describe of a new file: which columns are numeric, how many values are missing, what the typical value and spread are. Text columns show the number of distinct values.

The standard deviation is the sample standard deviation (n-1). A column counts as numeric only if every filled cell is a number, so one stray text cell makes the column text; clean it first. Compare with the column profiler for types and the statistics calculator for one list.

How to use it

  1. Paste the CSV with a header.
  2. Set the number of decimals.
  3. Read the summary table.
  4. Copy or download it as CSV.

Frequently asked questions

Why is my column called text?

At least one filled cell is not a number.

Which median?

Linear interpolation between the two middle values.

Are empty cells counted?

They appear in the missing column.

Units or currency symbols?

Not parsed; strip them first.
