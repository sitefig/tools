Remove PDF Metadata

Remove the author, title, creator and other document properties from a PDF, including any XMP metadata packet, and save a clean copy.

Use the tool

Why this tool exists

A PDF can reveal more than its pages: the author's name, the software and version used, the original file name used as a title, creation and modification dates. For a press release, a legal document or a CV sent to many people, that is information you may not want to share.

This tool strips the Info dictionary, where those fields live, and removes XMP metadata packets, the second place that often stores the same details. The visible pages are left as they are. Metadata is only one kind of leaked detail: text inside the document, comments, hidden layers and attachments are not touched, so review the content as well. Use the metadata editor if you want to set specific values rather than clear them. Encrypted files are refused, and the work is done locally.

How to use it

  1. Choose a PDF file.
  2. Run the tool.
  3. Check the summary of the new file.
  4. Download the cleaned PDF and, if you like, inspect it with PDF Info.

Frequently asked questions

What exactly is removed?

The Info dictionary, which holds Title, Author, Subject, Keywords, Creator, Producer and dates, and XMP metadata packets. Page content is unchanged.

Does that make the PDF anonymous?

No. Names, comments, annotations, embedded files and text inside the pages are not touched. File names and the date you save the file can also reveal details, so review the document as a whole.

How can I check the result?

Open the cleaned file in the PDF Info tool, which lists the Info fields. They should show as none found. Your viewer's document properties page should also be empty.

Will it break a digital signature?

Yes. Any rewrite of the file invalidates existing signatures. Remove the metadata first, and sign afterwards if you need a signed document.
