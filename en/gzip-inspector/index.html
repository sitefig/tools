Gzip Inspector (Header, CRC, Ratio)

Check a gzip file's metadata and integrity without a command line.

Use the tool

Why this tool exists

The inspector parses the header fields from RFC 1952: flags, modification time, original file name, comment, extra field, compression level hint and operating system. It then decompresses the data with the browser's DecompressionStream, computes the CRC-32 of the result and compares it and the size with the trailer.

Brotli (.br) files cannot be read because browsers do not expose a Brotli decompressor to pages. Files with several members or sizes over 4 GB report the size field modulo 2^32.

The file is read in your browser and is not uploaded anywhere.

How to use it

  1. Choose a .gz file.
  2. Read the header and integrity result.
  3. Compare the ratio with other compression settings.
  4. Re-create the file if the CRC does not match.

Frequently asked questions

What does a CRC mismatch mean?

The data was corrupted, truncated or modified after compression.

Does it show the original name?

If the compressor stored one. Many tools, such as gzip -n or servers, omit it.

Can it decompress and download?

It verifies and measures; use the gzip decompress tool to get the content.

Is my data sent anywhere?

The file is read in your browser and is not uploaded anywhere.
