HTML Table to JSON

Paste HTML containing one or more tables and get JSON: either an array of objects keyed by the header row, or plain arrays of cell values.

Use the tool

Why this tool exists

Data trapped in an HTML table, on a documentation page, a report or an email, often needs to go into code or a spreadsheet. Selecting the cells and pasting is hit and miss, and a scraper is overkill for a one-off job.

Paste the page source or just the table, and this tool pulls out each table, reads the rows and cells, strips inner tags, decodes entities such as &amp; and tidies whitespace. The first row supplies the keys, duplicate headers are numbered, and numbers can be converted automatically. Merged cells are not expanded and nested tables are not handled specially, so check the output on complex layouts. Nothing leaves your browser.

How to use it

  1. Paste the HTML that contains your table.
  2. Choose which table to use (0 for all), and objects or arrays as the output shape.
  3. Copy the JSON into your code or spreadsheet.

Frequently asked questions

How are the keys chosen?

From the cells of the first row, th or td. Empty headers become column1, column2 and so on, and repeated names get a numeric suffix so no key is lost.

Does it handle colspan and rowspan?

No. Cells are read in order and merged cells are not expanded, so rows with spans can look shifted. Clean such tables in a spreadsheet first.

Can I extract several tables?

Yes. Set the table number to 0 to convert every table into an array of results, or enter 1, 2 and so on for a single table.

Is JavaScript-rendered content included?

Only the HTML you paste is read. If a table is built by JavaScript after the page loads, copy the rendered HTML from your developer tools rather than the raw page source.
