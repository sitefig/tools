Social Share Preview

Enter title, description, URL and image fields to see approximate Facebook, X and LinkedIn link cards side by side, with warnings about missing fields.

Use the tool

Why this tool exists

A link shared with a poor preview gets ignored: no image, a cut-off title or the wrong site name. Platforms each lay cards out differently, so one set of tags looks a little different on Facebook, X and LinkedIn.

This tool draws approximate cards from the fields you type, using each platform's usual image shape and text clipping, so you can judge the title length and the description at a glance before you publish. It does not load the image or fetch your page, and the cards are approximations because platforms change their layouts and cache old scrapes. Warnings tell you if the title or image is missing or the image URL is not absolute. The preview is built in your browser.

How to use it

  1. Edit the key: value fields: title, description, url, image and twitter_card.
  2. Run the tool to draw the three previews.
  3. Check how the title and description are clipped on each card.
  4. Fix the fields or tags, and test the live URL with each platform's own debugger.

Frequently asked questions

Are these previews exact?

No. They approximate common layouts. Platforms change their designs and cache scraped data, so always confirm with the official sharing debuggers after publishing.

Does it load my image?

No. Previews never fetch anything. The image area shows a placeholder with the URL, so it only helps you judge the layout and text.

Which fields does it use?

title, description, url, image and twitter_card. The host name for each card comes from the URL, and the X card layout depends on whether the card is summary or large.

Is my content uploaded?

No. The cards are drawn in your browser and nothing you type is sent anywhere. No account, upload or request to a remote service is involved at any point.
