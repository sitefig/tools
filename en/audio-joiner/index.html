Audio Joiner with Crossfade

Joins two or more audio files into one. Clips with different sample rates are matched, mono clips are copied to both channels, and you can add an equal-power crossfade or a gap between clips.

Use the tool

Why this tool exists

Podcast intros, voice memos, loop takes and music snippets often need to be glued end to end. Doing it in an editor is heavy for a job that takes a second. A crossfade hides the seam between two clips so there is no click or sudden level jump.

The tool decodes every file in the browser, resamples to the rate of the first clip with a windowed-sinc resampler, and writes a 16-bit WAV. Crossfades are equal power, so the loudness stays even through the overlap.

How to use it

  1. Select two or more audio files at once.
  2. Choose the order and set a crossfade or a gap in seconds.
  3. Press Run.
  4. Play the result and download the WAV.

Frequently asked questions

Can I reorder the clips by dragging?

Not here. Use "by file name" (numbers sort naturally) or select the files in the order you want in your file picker.

What if the clips have different sample rates?

They are resampled to the sample rate of the first clip.

Does it re-encode MP3 files?

The output is always an uncompressed WAV. It will be larger than the MP3 inputs.

Why can I not use a crossfade and a gap together?

A gap means silence between clips, so there is nothing to overlap. If you set a gap, the crossfade is ignored.
