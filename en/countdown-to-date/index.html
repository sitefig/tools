Countdown to Date

Pick a target date and time in your local time zone. The tool shows how much time remains in days, hours, minutes and seconds, or how long ago it passed.

Use the tool

Why this tool exists

A launch day, an exam, a holiday or the end of a contract: sometimes you just want to know how long is left. A countdown turns that into something you can quote, such as 42 days or 1,008 hours. This tool compares your chosen local date and time with the current clock and breaks the gap into days, hours, minutes and seconds, and also gives the same span as decimal days and hours. If the target is in the past, it says how long ago it was, which also works for tracking elapsed time since an event. It calculates once when you run it, so run it again to refresh the value. Nothing you enter leaves your device.

How to use it

  1. Pick the target date and time.
  2. Run the tool to read the remaining time in days, hours, minutes and seconds.
  3. Re-run it whenever you want an updated figure.

Frequently asked questions

Which time zone is used?

Your device's local time zone, for both the target and the current time. The target is interpreted as local, so it will not suit an event fixed in another zone.

Does the countdown update by itself?

No, it gives a snapshot when the tool runs. For a live ticking countdown, use the Countdown Timer, which starts from hours, minutes and seconds you enter.

What if the date has already passed?

The tool tells you how long ago the date was, in the same days, hours, minutes and seconds format.

Does it account for daylight saving?

It compares real moments in time using your system's rules, so a clock change between now and the target is included in the elapsed hours.
