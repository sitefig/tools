Landmark Region Outline: banner, nav, main and footer Map

Shows the landmark structure of a page as an outline with warnings.

Use the tool

Why this tool exists

Screen reader users jump between landmarks. A clear structure helps everyone.

The tool applies the HTML rules (header and footer only count at page level, section and form need a name), shows each name, warns on a missing or repeated main, banner or contentinfo, repeated navs without distinct names, and counts text outside any landmark.

How to use it

  1. Paste the page HTML.
  2. Read the outline.
  3. Fix missing or duplicate landmarks.
  4. Add aria-label to repeated regions.

Frequently asked questions

Do I need a main?

Yes, exactly one visible main.

Why must repeated navs have names?

Otherwise users hear "navigation" twice with no way to tell them apart.

Is a skip link outside landmarks a problem?

No, skip links are ignored.

Is the HTML uploaded?

No.
