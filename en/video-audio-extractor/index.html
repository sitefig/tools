Video Audio Extractor: Save the Soundtrack as WAV

Decodes the audio of a video and saves it as a 16-bit WAV file. You can set a start and end time.

Use the tool

Why this tool exists

Browsers can decode audio but cannot encode MP3, so this tool writes WAV, which is simple and lossless. The file is larger than an MP3, but any editor can open it and convert it.

Decoding happens on your device. Long files use memory because the whole track is decoded at once.

How to use it

  1. Choose the video.
  2. Optionally set a start and end time in seconds.
  3. Press Process.
  4. Download the WAV file.

Frequently asked questions

Why not MP3?

There is no MP3 encoder in browsers, and this site ships no third-party code. Convert the WAV on your computer if you need MP3.

How big is the WAV?

About 10 MB per minute for stereo at 44.1 kHz.

Does it work with any video?

If the browser can decode the audio codec. If not, you get a clear message.

Can I trim it?

Yes, use the start and end fields.
