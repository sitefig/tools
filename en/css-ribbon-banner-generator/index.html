CSS Ribbon & Banner Generator

Create a CSS-only ribbon, either a corner sash, a folded-end banner or an arrow banner, with your own text and colours. You get the HTML and CSS along with a live preview.

Use the tool

Why this tool exists

Ribbons mark things like new, sale or beta, and they are one of those effects that look easy but take several tries to get right. A corner sash needs a rotated strip clipped by its container, a folded banner needs small triangles to fake the fold, and an arrow banner needs a clipped end.

This generator writes that markup and CSS for you. Pick the style, type the label, choose the background and text colours and the size, and see the result before you copy it. The output is plain HTML and CSS with no image or script, so it is light and works anywhere. It is generated in your browser, and you can tweak the values afterwards in your own stylesheet.

How to use it

  1. Choose a ribbon style: corner sash, folded-end banner or arrow banner.
  2. Type the label text and pick the ribbon and text colours.
  3. Set the size and look at the live preview.
  4. Copy the HTML and CSS into your page.

Frequently asked questions

Why does my corner sash get cut off?

A sash relies on its parent being positioned and hiding overflow. Make sure the container has position set and overflow hidden, and that it is large enough for the rotated strip.

Is the text accessible?

The ribbon is real text, so screen readers can read it. Check colour contrast between text and ribbon, and avoid putting essential information only in a decorative badge.

Can I use it for several labels on one page?

Yes. Rename the class for each variant, or use CSS variables for the colours. The generated CSS is self-contained, so copy it once and adjust the values per ribbon.
