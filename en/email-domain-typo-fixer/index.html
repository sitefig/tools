Email Domain Typo Fixer (gmial.com, hotmial.com)

Paste addresses and see each domain correction before you import the list.

Use the tool

Why this tool exists

Typed signups often contain domains like gmial.com or outlook.con. Those addresses bounce, and the person never gets your email. Correcting the obvious ones recovers real subscribers.

The fixes come from a built-in list of typos for big providers and common ending mistakes. Review the change list: a rule can be wrong for an unusual real domain. Nothing is uploaded.

How to use it

  1. Paste the addresses.
  2. Read the list of changes.
  3. Turn off applying fixes if you only want the report.
  4. Copy the corrected list.

Frequently asked questions

Can a fix be wrong?

Yes, rarely. That is why every change is listed.

Does it fix local parts?

No, only the domain.

Does it check mailboxes?

No.

Can I add my own typos?

Not in this version.
