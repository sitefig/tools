Tailwind Class Sorter

Sorts Tailwind CSS utility classes into the usual order (layout, box model, typography, effects) with variants like hover: and md: after the base classes. It works on a class list or on HTML.

Use the tool

Why this tool exists

Long class strings grow in whatever order they were typed, which makes diffs noisy and code review slower. Two people style the same element and the lists look completely different. The official Prettier plugin fixes this, but you may not have a build set up, or you may be working in a snippet, a CMS field or a chat message. Paste the markup here and every class="..." or className="..." attribute is reordered; a bare class list works too. Duplicates can be removed. This is a hand-written approximation of the official ordering, so edge cases can differ from the plugin. Your code stays in the browser.

How to use it

  1. Paste a list of classes, or HTML or JSX containing class or className attributes.
  2. Leave "Remove duplicate classes" ticked if you want repeated classes dropped.
  3. Copy the sorted result back into your project.

Frequently asked questions

Does it match prettier-plugin-tailwindcss exactly?

Not always. It uses its own approximation of the official order: layout first, then box model, typography and effects, with variants after. Custom or unknown classes are placed first. Differences appear in rare edge cases.

How are variants handled?

Classes with variants such as hover:, md: or dark: are placed after plain classes, and grouped by variant, then ordered by their base utility. Arbitrary values in square brackets are kept intact.

What about dynamic class names?

Attributes containing a brace expression like className={cond ? "a" : "b"} are left untouched. Only plain strings and simple template literals without placeholders are sorted.

Will it change the meaning of my styles?

Order in the class attribute does not affect CSS precedence in Tailwind, so sorting is safe. Removing duplicates is also safe, but custom CSS that relies on the order of attributes is not covered.
