UUencode Encoder and Decoder (begin / end Blocks)

Encodes data as a uuencoded block and decodes one back, including the begin line and file name.

Use the tool

Why this tool exists

Uuencode is an old way to send binary files over text-only channels such as early email and Usenet. You still meet it in old archives and mailing list posts.

Each line carries up to 45 bytes with a length character first. The tool accepts both the space and the backtick as zero, reads the file name from the begin line and lets you download the decoded bytes.

How to use it

  1. Choose encode or decode.
  2. Paste the text or the whole block including begin and end lines.
  3. For encoding, set the file name and mode in the begin line.
  4. Copy the result or download the decoded file.

Frequently asked questions

Is uuencode secure?

No. It is an encoding, not encryption.

Why is there a backtick in the output?

Modern uuencode writes zero as a backtick so spaces are not lost in transit. Both forms decode.

What about xxencode?

That is a different alphabet and is not supported.

Is my input sent anywhere?

No. Everything runs in your browser and nothing is uploaded.
