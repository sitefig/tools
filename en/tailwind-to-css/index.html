Tailwind Classes to Plain CSS Rules (with hover and responsive variants)

Converts a list of Tailwind utility classes into ordinary CSS rules, including state, breakpoint and dark mode variants.

Use the tool

Why this tool exists

Sometimes you want the CSS a Tailwind class stands for: to move a component out of Tailwind, to learn, or to paste into an email or a CMS field.

This converter handles a documented subset of v4 utilities: layout, spacing, sizing, typography, colours (default OKLCH palette), borders, radius, shadows, opacity and basic transforms. Values were checked against output from the real Tailwind v4 compiler; the compiler writes var(--spacing) calculations where this tool writes the resolved rem value. Classes outside the subset are listed, not guessed.

How to use it

  1. Paste the class list.
  2. Read the generated rules.
  3. Check the list of classes that were not converted.
  4. Copy the CSS.

Frequently asked questions

Which Tailwind version?

Values follow the v4 default theme. Spacing is 0.25rem per step.

Are custom theme values supported?

No. Only the default theme and arbitrary values like w-[300px].

What about hover and md: variants?

They become :hover rules and @media (min-width) blocks. dark: uses prefers-color-scheme.
