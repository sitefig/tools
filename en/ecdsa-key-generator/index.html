ECDSA Key Pair Generator (P-256, P-384, P-521)

Creates an elliptic-curve key pair with your browser's WebCrypto and shows it as PEM and as JWK, with the RFC 7638 thumbprint as key ID.

Use the tool

Why this tool exists

ES256, ES384 and ES512 JWT signing, WebAuthn work and many API signatures use ECDSA keys. This page generates a P-256, P-384 or P-521 pair and gives you the formats tools ask for: PKCS#8 private PEM, SPKI public PEM and both JWKs.

The key is created by the browser and shown only here. It is good for tests, learning and local setups. For production keys use a hardware module, a KMS, or a trusted machine and keep private keys out of web pages. The output matches OpenSSL: the PEM loads with openssl pkey and the public key equals openssl pkey -pubout.

How to use it

  1. Choose the curve and whether the key is for signing or key agreement.
  2. Optionally set a key ID.
  3. Copy the PEM or JWK you need.
  4. Store the private key safely and do not share it.

Frequently asked questions

Which curve should I pick?

P-256 is the common default (ES256). P-384 and P-521 give larger keys and are used when a policy asks for them.

Is the private key sent anywhere?

No. It is generated and shown in your browser only.

What is the thumbprint?

A SHA-256 hash of the required public JWK fields (RFC 7638). It is a stable key identifier and is used as the key ID if you leave it blank.

Can I use these keys for Ed25519 or RSA?

No. Use the Ed25519 or RSA key generator tools for those.
