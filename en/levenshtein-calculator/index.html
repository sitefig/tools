Levenshtein Distance Calculator (Edit Script and Alignment)

Finds the edit distance between two strings and shows one optimal list of edits and an aligned view of both strings.

Use the tool

Why this tool exists

Edit distance counts the fewest single-character changes needed to turn one string into another. It is used for spell checking, record matching, diffing and testing OCR output.

Besides the number, this tool shows which characters are inserted, deleted or substituted and lines the strings up so you can see it. You can switch to Damerau-Levenshtein (the optimal string alignment form, where swapping two neighbours costs one) or to indel distance, where only inserts and deletes are allowed. You can also compare words instead of characters.

How to use it

  1. Enter the two strings.
  2. Choose the distance type and whether to compare characters or words.
  3. Read the distance, similarity and the aligned view.
  4. Follow the edit script step by step if you need it.

Frequently asked questions

Are there several correct edit scripts?

Often yes. The distance is always the same, but a different set of edits can have the same cost. One is shown.

What is the similarity percentage?

One minus the distance divided by the longer length. For indel distance it divides by the sum of both lengths.

What does Damerau add?

A swap of two neighbouring characters counts as one edit, so "ab" to "ba" costs 1 instead of 2. This is the restricted version known as optimal string alignment.

How long can the strings be?

Up to 2000 characters or words each.
