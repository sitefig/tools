Meta Refresh Redirect Detector

Finds meta refresh tags and explains what they do for SEO.

Use the tool

Why this tool exists

A meta refresh can redirect a visitor without a server rule. Google reads an instant refresh as a permanent redirect and a delayed one as temporary, but server-side redirects are more reliable.

The tool shows delay and target and writes an Apache and nginx rule for the page path you enter. A timed redirect can also hurt users: WCAG technique F40 lists it as a failure.

How to use it

  1. Paste the HTML.
  2. Enter the path of the page for the server rules.
  3. Run the tool.
  4. Replace the refresh with the server redirect if you can.

Frequently asked questions

Instant or delayed?

Google treats instant as permanent and delayed as temporary, per its documentation.

Are HTTP Refresh headers found?

No. Only HTML tags can be seen here.

Why prefer a server redirect?

It is faster, clearer to crawlers and does not flash a page.

What if there is no URL?

The page reloads itself; the tool warns about that.
