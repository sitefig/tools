iOS Info.plist Builder

Generates an iOS Info.plist with bundle identifier and versions, orientations, usage-description strings, URL schemes, LSApplicationQueriesSchemes, background modes and App Transport Security exceptions, as valid XML.

Use the tool

Why this tool exists

An iOS app can be rejected or crash at launch because of a missing key in Info.plist. A camera feature needs NSCameraUsageDescription, a custom link scheme needs CFBundleURLTypes, and each background mode and queried app scheme has its own entry. Remembering the exact key names is not realistic. This builder lets you give short aliases such as camera, photos or faceid with the reason text users will see, and writes the matching NS keys. It adds bundle details, supported orientations, URL schemes, LSApplicationQueriesSchemes, UIBackgroundModes and optional ATS exceptions for named domains. The output is valid XML property-list text for you to merge into your project. It runs in your browser.

How to use it

  1. Enter usage descriptions as "alias: reason" lines, for example camera: We use the camera to scan QR codes.
  2. Fill in the display name, bundle identifier, version, build, minimum iOS and URL schemes, background modes or ATS domains.
  3. Copy the plist and merge it into your project's Info.plist.

Frequently asked questions

Which aliases can I use?

Short names such as camera, photos, photos-add, microphone, location, location-always, contacts, calendars, faceid, bluetooth and tracking map to their NS usage-description keys. You can also write a full NS key.

Why do usage descriptions matter?

iOS shows the text to users when asking for permission, and the app is rejected or terminates if the key is missing. Write a clear, honest reason.

What are ATS exceptions?

App Transport Security requires HTTPS by default. Exceptions let named domains use HTTP. Use them only when you must, and prefer fixing the server.

Does it replace Xcode?

No. It generates text for you to merge. Xcode build settings can also define some of these values, so check for conflicts.
