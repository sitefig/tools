Average Order Value (AOV) Calculator With Period Comparison

Calculates average order value from revenue and order count, with units per order and a comparison to a previous period.

Use the tool

Why this tool exists

AOV is simple to compute but easy to compute inconsistently. If one month counts shipping and tax and the next does not, the change means nothing. State what is in revenue and keep it fixed.

Enter revenue and orders, and optionally units and the previous period to see the change in percent. Raising AOV by bundles or free-shipping thresholds can lower conversion, so watch both.

How to use it

  1. Enter revenue and the number of orders.
  2. Optionally add units sold and the previous period.
  3. Read AOV, units per order and the change.

Frequently asked questions

Which revenue should I use?

Pick one definition, such as net of tax and refunds, and use it every time.

Is a higher AOV always better?

No. If conversion drops by more, revenue falls. Track both.

How do I raise AOV?

Common methods are bundles, tiered discounts and free-shipping thresholds. Test each.
