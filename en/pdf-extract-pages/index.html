Extract PDF Pages

Choose the pages you want, using a list such as 1-3,5,7-, and get a new PDF that contains only those pages.

Use the tool

Why this tool exists

You rarely need the whole document. A signature page from a long contract, the one chart from a 60-page report, or the pages of a scanned pack that belong to one person: extracting just those saves attachment size and keeps unrelated content private.

This tool keeps the selected pages and drops the rest. The page list is flexible: single pages, ranges and open-ended ranges like 7- for page seven to the end can be combined with commas. Pages are copied as they are, so quality does not change. If you only want to cut out a few pages and keep the rest, use the Delete PDF Pages tool instead. As with the other editing tools, encrypted PDFs are refused, and bookmarks and form fields are not preserved. Everything runs in your browser.

How to use it

  1. Choose a PDF file.
  2. Enter the pages to keep, for example 1-3,5,7-.
  3. Run the tool.
  4. Check the page count in the summary and download the new PDF.

Frequently asked questions

What page syntax is supported?

Numbers, ranges with a dash and open-ended ranges, combined with commas: 1-3,5,7-. Pages are numbered from 1. A number past the last page or a malformed list produces an error.

Will the pages appear in the order I type them?

Yes. Pages come out in the order you write them, and a page can be repeated, so 5,1-3 puts page five first. The Reorder PDF Pages tool uses the same list syntax with a focus on reordering.

Is the original file changed?

No. A new file is created, named after the original with extract added. The source on your device is untouched.

Why do some features disappear?

Document-level items such as bookmarks, form fields and page labels are not copied. The visible page content, images and fonts are preserved.

Tools often used together

  • Delete PDF PagesRemove selected pages (e.g. 2,4-6) from a PDF.
  • Split PDFSplit a PDF into several files: every N pages, or custom ranges (each comma-separated range becomes its own file).
  • Reorder PDF PagesRearrange pages by an order list such as 3,1,2,4-6 (pages you leave out are dropped, a page may be repeated, 6-4 reverses a run).
  • Merge PDFsCombine several PDFs into one, in the order selected. Works on existing PDFs without re-rendering; bookmarks and form fields are dropped.
  • PDF Page Count and SizesList the number of pages with each page size, rotation and paper format (A4, Letter...).
  • Rotate PDF PagesRotate all pages or a range by 90, 180 or 270 degrees clockwise (adds to any existing rotation).
