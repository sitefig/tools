iOS Crash Report Viewer (.crash and .ips): Crashed Thread First

Reads .ips JSON and older text crash reports and shows the key facts first.

Use the tool

Why this tool exists

Crash reports are long. The things you need first are the exception type, the termination reason and the backtrace of the crashed thread.

This tool formats them, but it does not symbolicate. Frames marked not symbolicated need your dSYM files, which Xcode or atos use.

How to use it

  1. Open the .ips or .crash file or paste its contents.
  2. Read the header and exception.
  3. Read the crashed thread frames.
  4. Tick the option to list other threads.

Frequently asked questions

What is .ips?

The JSON crash report format used by recent iOS and macOS versions.

Why are frames not symbolicated?

The report holds addresses and image offsets. Symbols need the dSYM matching the build.

Is the report uploaded?

No.

Does it fix crashes?

No, it only helps read the report.
