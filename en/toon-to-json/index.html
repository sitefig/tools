TOON to JSON Converter

Turn TOON back into JSON to inspect, validate or use it in code.

Use the tool

Why this tool exists

The decoder reads objects by indentation, header lines such as items[3]{id,name}: with comma, tab or pipe delimiters, inline arrays, "- " list items and quoted strings with escapes. Lengths in headers are checked and errors name the line.

It supports the core forms; nested column groups and keyed tables from the newest spec revisions report a clear "not supported" error rather than guessing. Verified against the reference implementation by round-trip tests.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Paste TOON.
  2. Choose the JSON indentation.
  3. Run to get JSON, or read the error line.
  4. Copy the JSON.

Frequently asked questions

What does [3] in a header mean?

The number of items that follow. If the count is wrong the decoder reports it.

How are strings written?

Plain unless they are empty, look like numbers or keywords, or contain delimiters, colons, quotes or leading dashes; then they are quoted.

Is TOON a standard?

It is an open specification that is still evolving.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
