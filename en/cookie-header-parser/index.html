Cookie and Set-Cookie Header Parser (Name, Value, Attributes)

Parses a Cookie request header into its name and value pairs, and Set-Cookie response headers into the name, value and attributes such as Path, Domain, Expires, Max-Age, Secure, HttpOnly and SameSite.

Use the tool

Why this tool exists

A Cookie header is a single line of name=value pairs, and Set-Cookie lines carry attributes after semicolons. DevTools shows them in a table, but logs and curl output do not.

Paste the header lines and read each cookie on its own, with percent-encoded values decoded and Expires converted to an ISO date. This tool describes; it does not judge. For security findings use the Cookie Flag Analyzer. Cookie values can be session identifiers, so avoid sharing the page link with real ones.

How to use it

  1. Paste Cookie: and Set-Cookie: lines, or the bare header values.
  2. Tick JSON if you want structured output.
  3. Read the name, value and attributes for each cookie.

Frequently asked questions

Can I paste a header without the name?

A line without Cookie: or Set-Cookie: is read as a Set-Cookie value.

Why are values decoded?

Percent-encoded values are shown decoded when valid, to make them readable. The original text is unchanged elsewhere.

Does it check security flags?

No. Use the Cookie Flag Analyzer for that.

Is anything uploaded?

No.
