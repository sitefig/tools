GeoJSON Viewer and Validator (SVG Plot, Stats and Problems)

Checks GeoJSON structure and draws the features without a map service, listing counts, extent, length and area.

Use the tool

Why this tool exists

GeoJSON is easy to get slightly wrong: longitude and latitude swapped, a polygon ring that is not closed, a coordinate out of range. The tool lists such problems and plots the data over country outlines (Natural Earth, public domain) so you can see if it lands on the right continent.

Length and area use spherical formulas and are approximate. Editing is done in the text box: change the JSON and run again. Drawing and dragging on a map needs tiles and is not offered; use the waypoint tool to build GPX from typed points.

How to use it

  1. Paste GeoJSON in the box.
  2. Choose a label property and optionally a numeric property to size points.
  3. Switch the country outlines on or off.
  4. Read the problems and copy the formatted JSON.

Frequently asked questions

Does it fix errors?

No, it reports them.

Is swapped lat/lon detected?

Only when a value falls out of range; a swap with small values is visible on the plot.

Which projection?

A simple equirectangular fit, not Web Mercator.

Limits?

5000 features.

  • CSV Coordinates to Map Plotter (Points on a Country-Outline Map)Plot the rows of a CSV that has latitude and longitude columns as markers on an offline map made of country outlines. Optional label and size columns. Exports SVG. No street map is loaded.
