Sprite Sheet Packer (PNG Atlas with JSON and CSS Map)

Pack images into one sprite sheet with a JSON and CSS map.

Use the tool

Why this tool exists

Choose many images. The tool packs them into rows on one PNG, tallest first, with padding you choose, and gives you a JSON map of each sprite name, position and size plus CSS classes that show a single sprite from the sheet.

It is a simple shelf packer, so it is not the tightest possible layout. Names come from file names, and duplicates are numbered.

How to use it

  1. Choose the images.
  2. Set the maximum width and padding.
  3. Optionally round to powers of two.
  4. Download the PNG and JSON, and copy the CSS.

Frequently asked questions

Which JSON format is it?

A frames map with frame x, y, w, h and sourceSize, close to the common atlas layout. Check your engine's loader.

Why power of two?

Some older GPUs and engines prefer it.

Is the order fixed?

Tallest first, then by name.

Is anything uploaded?

No. The work happens in your browser and the page makes no network request with your input.
