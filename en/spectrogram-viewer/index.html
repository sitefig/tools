Spectrogram Viewer for Audio Files

Computes a short-time Fourier transform of an audio file and draws it as a picture with labelled time and frequency axes, which you can save as PNG.

Use the tool

Why this tool exists

A spectrogram shows what a waveform hides: which frequencies are present and when. It reveals hum lines, hiss, clipping, a low-pass cutoff left by MP3 compression, bird calls, and the harmonics of an instrument.

Choose the window size to trade pitch detail against timing detail: 4096 samples separates close notes, 512 shows fast transients. A logarithmic frequency axis matches how we hear pitch; a linear axis shows high-frequency content better. Brighter colours are louder, over the dynamic range you set.

How to use it

  1. Choose an audio file.
  2. Pick the window size and the frequency axis.
  3. Adjust the dynamic range (80 dB is a good start).
  4. Press Run and save the image.

Frequently asked questions

What window size should I use?

2048 for general use, 4096 for pitch detail, 512 for drums and speech timing.

Why does the top look empty?

Many files have no content above 16 kHz because of MP3 compression or a low sample rate. That cutoff is useful to see.

Is this a live view?

No, it draws the whole file. The live spectrum analyzer shows the microphone in real time.

How long a file can it draw?

Several minutes. The image is capped at about 1400 columns, so long files lose some time detail.
