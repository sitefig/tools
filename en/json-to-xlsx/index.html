JSON to XLSX

Paste a JSON array of objects, or of arrays, and download an Excel .xlsx file with a bold, frozen header row and numbers stored as numbers.

Use the tool

Why this tool exists

APIs and exports give you JSON, but the people who need to read it work in Excel. Opening a CSV generated from JSON can mangle dates and long numbers, and online converters often send the data to a server, which matters for customer lists or internal reports.

This converter writes a real .xlsx workbook locally. For an array of objects, the header row is the union of all keys, so records with different fields still line up, and missing values stay empty. Nested objects and arrays are stored as JSON text in the cell. Numbers become numeric cells, so sums and sorting work, while strings stay text. You can name the sheet and turn off the bold header. The first row is frozen so it stays visible while you scroll through long tables.

How to use it

  1. Paste a JSON array into the input box.
  2. Choose whether to bold the header row and set a sheet name.
  3. Run the tool and check the summary of rows and columns.
  4. Download data.xlsx and open it in Excel or any spreadsheet app.

Frequently asked questions

What JSON shapes are accepted?

An array of objects, where keys become columns, or an array of arrays, where the first row is treated as the header. A single object that is not inside an array is not a table and is rejected.

What happens to nested data?

Objects and arrays inside a record are written into one cell as JSON text. Flatten the data first if you want nested fields as separate columns.

Are numbers and dates handled?

JSON numbers become numeric cells. Dates are plain strings in JSON, so they stay as text rather than becoming Excel dates; format them in the spreadsheet if needed.

Is there a size limit?

None fixed, but the workbook is built in memory, so very large arrays depend on your browser. Excel itself caps a sheet at 1,048,576 rows.
