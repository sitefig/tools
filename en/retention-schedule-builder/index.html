Data Retention Schedule Builder

Formats a retention schedule as a Markdown table or CSV and flags empty justifications, missing periods and open-ended wording.

Use the tool

Why this tool exists

GDPR Art. 5(1)(e) says personal data must not be kept longer than necessary. In practice that needs a written schedule: what you keep, for how long, from when, why, and how it is disposed of.

Paste one category per line and the tool builds the table. It flags rows with no justification, no period, or wording like "as long as necessary" that does not give a fixed period. It does not know legal retention periods: those depend on the country and the type of record, so each one needs checking.

How to use it

  1. Write one category per line: category | period | starts when | justification | disposal.
  2. Choose Markdown or CSV.
  3. Read the review list.
  4. Check each period against the law that applies and save the table.

Frequently asked questions

Does it know legal retention periods?

No. You supply them. It only formats and checks for gaps.

What is a trigger?

The event that starts the clock, such as the end of a contract or of a financial year.

Can I import it into a spreadsheet?

Yes. Choose CSV.
