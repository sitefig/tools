SERP Position CTR Model: Estimate Clicks from Target Rankings

Enter keywords with volume, current position and target position and see the estimated clicks now, at target and the possible gain. The click-through curve is yours to edit.

Use the tool

Why this tool exists

Before you invest in a ranking improvement it helps to know what it could be worth. Moving from position 12 to position 3 on a 5,000-search keyword is a different size of prize than moving from 6 to 4.

The default curve is illustrative, with round numbers and not measured data. Real click-through rates depend on intent, brand, SERP features and ads. Replace the curve with your own Search Console numbers for better estimates. Volume is the monthly average from your keyword tool.

How to use it

  1. Enter one keyword per line with volume, current position and target position.
  2. Edit the CTR curve if you have your own data.
  3. Set the chance of reaching the target positions.
  4. Read the clicks now, at target and expected gain.

Frequently asked questions

Where does the default curve come from?

It is made up for illustration. It is not measured, so replace it with your own.

How do I get my own curve?

Export queries from Search Console and look at average CTR by position. The Search Console Performance Export Analyzer shows it.

What if I do not rank yet?

Leave the current position empty or 0.

Why a chance percentage?

Not every target will be reached, so you can scale the expected gain.
