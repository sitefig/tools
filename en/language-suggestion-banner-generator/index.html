Language Suggestion Banner Generator (No Redirect)

Builds a small script and style block that offers visitors the version in their language, which they can dismiss.

Use the tool

Why this tool exists

Redirecting by IP address or browser language hides versions from crawlers and traps people who want another version. Google says it crawls from different locations without varying the crawler for a site, so it may never see a version served only by location. A banner keeps every URL reachable and lets the visitor choose.

The generated script reads navigator.languages in the visitor's browser, shows a region with a real link and a dismiss button of at least 44 pixels, and remembers the dismissal. Nothing is sent anywhere. Check the colours against your theme.

How to use it

  1. Enter one line per version: code | URL | message | link text.
  2. Set the current page language and the dismiss label.
  3. Copy the block into the end of the body.
  4. Test with the browser set to other languages.

Frequently asked questions

Why not redirect?

A redirect can block crawlers and users from other versions.

Is it accessible?

It uses a labelled region, a real link and a real button. Test with your own setup.

Does it use cookies?

It stores one localStorage flag after dismissal.

Does it still need hreflang?

Yes; the banner is for people, hreflang is for search engines.
