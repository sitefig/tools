CloudTrail Event Viewer: Who Did What, Where and When

Summarises CloudTrail events and lists a few patterns worth a second look.

Use the tool

Why this tool exists

CloudTrail files are large JSON. This page groups events by name, identity, service, region and IP so you can answer who did this and when.

The review list uses four fixed patterns: root identity, failed console login, console login without MFA and AccessDenied-type errors. These are hints, not findings.

How to use it

  1. Open a Records JSON file, or paste JSON lines.
  2. Filter by event name or identity.
  3. Read the summary and the review list.
  4. Switch to the table for each event.

Frequently asked questions

Which file shapes work?

A {"Records": [...]} file, a JSON array, or one event per line. Gzip files are unpacked.

Is the review list a security audit?

No. It is four simple patterns. Use proper tooling for audits.

Why is MFA flagged?

ConsoleLogin events record whether MFA was used in additionalEventData.

Is my log uploaded?

No. Parsing happens in your browser and nothing is sent. Logs can hold IP addresses and tokens, so the page does not write them into the address bar.
