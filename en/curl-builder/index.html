cURL Command Builder

Fill in the method, URL, headers, body, authentication and flags to get a correctly quoted curl command. It can output one line or a multi-line command with backslashes.

Use the tool

Why this tool exists

curl commands are the lingua franca for testing APIs, but quoting JSON bodies in a shell is easy to get wrong, and the flags are hard to remember. Single quotes inside a body, a missing header colon or a stray space can ruin a request.

Enter the method and URL, list headers as Name: value lines and paste the body in its own box. Pick bearer or basic authentication and flags for following redirects, silent mode, response headers, compression, failing on HTTP errors and a timeout. The tool escapes quotes properly and uses --data-raw so the body is sent as written. Avoid putting a real production token into a page you do not trust; this one runs in your browser and sends nothing. To go the other way, use cURL to Code.

How to use it

  1. Choose the method and enter the full URL starting with http or https.
  2. Add headers as Name: value lines and paste the request body if there is one.
  3. Select authentication and flags such as -L, -sS, --compressed or a timeout.
  4. Copy the command, optionally as a multi-line version with backslashes.

Frequently asked questions

How is the body sent?

With --data-raw, which sends the text exactly as typed without treating @ as a file reference. The body is quoted safely for the shell, including any single quotes inside it.

What does the -k option do?

It turns off TLS certificate checking. It is useful for testing local servers with self-signed certificates, but never use it against real services, as it removes protection against interception.

How do I send basic authentication?

Choose basic and enter user:password. The command gets a -u option. For bearer tokens, enter the token and an Authorization header is added.

Can I convert a curl command into code?

Yes, with the cURL to Code tool, which produces fetch, Node, Python or PHP code from a command.

Tools often used together

  • cURL to CodeConvert a curl command to fetch, Node (http/https), Python requests or PHP cURL.
  • fetch() to cURLConvert a JavaScript fetch(url, { method, headers, body }) call (as copied from DevTools or source) into a curl command. Understands JSON.stringify(...) bodies, string and object literals; it never executes your code.
  • HTTP Snippet GeneratorTurn a raw request (METHOD URL, headers, blank line, body) into fetch, curl and Python snippets.
  • cURL to C# / Java / Axios / Guzzle / FaradayConvert a curl command (-X -H -d --data-urlencode --json -F -u -k -L) into C# HttpClient, Java 11 HttpClient, JavaScript axios, PHP Guzzle or Ruby Faraday. Python, fetch, Node and plain PHP live in the main cURL to Code tool; Go and Rust have their own tools. Multipart (-F) is supported for C#, Guzzle and Faraday; Java and axios convert it to a urlencoded body.
  • HTTP Basic Auth Header GeneratorEncode user:password into an Authorization header and snippets.
  • HTTP Raw Message <-> JSON (wire format)Parse a raw HTTP/1.x request or response (start line, headers, body, chunked transfer decoding, Content-Length check, query string, cookies, Basic auth) into structured JSON, or build a correctly framed raw HTTP message (CRLF line endings, Host and Content-Length) from JSON. Useful for debugging proxies, WAF rules, request smuggling cases and hand-written test fixtures.
