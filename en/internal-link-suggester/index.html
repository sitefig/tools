Internal Link Suggester

Give it the text of several pages and it suggests which page should link to which, with the shared terms and a few anchor phrases taken from your own copy.

Use the tool

Why this tool exists

Each page is turned into a TF-IDF vector (words that are frequent on a page but rare across your site count most) and pages are compared with cosine similarity. For every page you get the most similar other pages above a threshold, whether the target is already mentioned in the text, and anchor ideas built from shared terms that actually occur on the source page.

Similarity means overlapping vocabulary, not search intent, so read each suggestion before adding a link. It works best with a few hundred words per page and a site of related topics; with very few pages the weights are not meaningful.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Write each page as a line "=== /url" followed by its text.
  2. Choose how many suggestions per page and the minimum similarity.
  3. Run it and review each suggested link and anchor idea.
  4. Add the links that help the reader, using natural anchor text.

Frequently asked questions

How is similarity calculated?

Cosine similarity between TF-IDF word vectors. Common words are down-weighted, so shared rare terms drive the score.

Does it crawl my site?

No. It only reads the text you paste, which is why no network access is needed.

Can it tell me which links already exist?

It flags suggestions whose URL already appears in the source text, but it does not parse HTML links. Use the link extractor for that.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
