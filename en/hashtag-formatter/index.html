Hashtag Formatter: Words to Clean CamelCase Hashtags

Turn a list of words or phrases into clean hashtags such as #SmallBusinessTips, with CamelCase that screen readers can pronounce.

Use the tool

Why this tool exists

A good hashtag has no spaces or punctuation, and is easier to read and pronounce in CamelCase. #WeAreHiring reads clearly to a screen reader, while #wearehiring does not.

Paste phrases one per line or separated by commas. The tool strips punctuation, joins the words, removes duplicates and skips tags made only of digits, which most platforms do not link. Choose lowercase if you prefer. It does not suggest hashtags: that needs data from a service.

How to use it

  1. Paste phrases, one per line or comma separated.
  2. Choose CamelCase or lowercase.
  3. Choose one line or one per line.
  4. Copy the tags.

Frequently asked questions

Why CamelCase?

Screen readers can pronounce capitalised words, so it is more accessible.

Does it suggest popular hashtags?

No. That needs platform data. It only formats what you give it.

Is there a limit on hashtags?

Platforms set their own, so check each one.
