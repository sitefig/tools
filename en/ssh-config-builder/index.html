SSH Config Builder: ~/.ssh/config Host Entries

Builds Host blocks for ~/.ssh/config from simple comma separated lines, with optional shared keep-alive settings.

Use the tool

Why this tool exists

A good ssh config saves typing and avoids offering every key to every server. Writing the blocks by hand is easy to get wrong when you have many hosts or jump hosts.

Enter alias, host name, user, port, identity file and jump host per line. The output was checked with ssh -G, which reads the generated file and prints the settings it will use.

How to use it

  1. Write one host per line: alias, hostname, user, port, key, jump host.
  2. Choose IdentitiesOnly, keep-alive and AddKeysToAgent options.
  3. Copy the output.
  4. Append it to ~/.ssh/config and test with ssh -G alias.

Frequently asked questions

What does IdentitiesOnly do?

It makes ssh offer only the key you name, instead of every key in the agent.

How do I use a jump host?

Put the alias of the jump host in the last column. It becomes ProxyJump.

Is the key file read?

No. Only the path text is written.

Is anything uploaded?

No.
