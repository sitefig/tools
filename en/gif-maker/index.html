GIF Maker

Select several images and combine them into one animated GIF. Choose the frame delay, the maximum width and whether it loops forever.

Use the tool

Why this tool exists

A short animated GIF is still the easiest way to show a before and after, a step-by-step walkthrough or a few product shots in a place that does not accept video, such as an email, a README or a support ticket. Online GIF makers often upload your pictures, add a watermark or restrict the number of frames.

This maker builds the file in your browser with its own GIF89a encoder. Frames are used in the order you select them, resized to fit the first image's proportions and placed on a white background so transparent areas do not turn black. Colours are reduced to a single 256-colour palette shared by all frames, which keeps files small but can band on photos. Nothing is uploaded, and the result is a normal .gif download.

How to use it

  1. Choose two or more images; they become frames in the order selected.
  2. Set the frame delay in milliseconds and the maximum width in pixels.
  3. Tick Loop forever if the animation should repeat.
  4. Run the tool and download animation.gif.

Frequently asked questions

What order are the frames in?

The order in which your files are selected. If the order is wrong, select them again one at a time in the order you want, or rename the files so they sort correctly in the picker.

Why do photos look grainy?

GIF allows only 256 colours, and this encoder uses one palette for every frame. Illustrations, screenshots and logos look fine, while photographs with gradients can show banding.

Which size does the GIF use?

The width is the smaller of your setting and the first image's width, and the height follows its proportions. Other images are fitted inside that frame without stretching, centred on white.

How long can the animation be?

There is no fixed frame limit, but file size grows with frames and dimensions, and the work runs in your browser's memory. Keep width modest for long animations. The shortest delay is 20 ms.
