JSON / CSV Grid Editor

Paste or open a JSON array of objects or a CSV file, edit it in a spreadsheet-like grid, add or delete rows and columns, sort by a column, and copy or download the result as CSV or JSON.

Use the tool

Why this tool exists

Editing a few cells in a large JSON or CSV file is awkward in a text editor. Quotes get lost, a stray comma breaks a row, and finding the right line in a long array takes patience. Opening a full spreadsheet application can be heavy and may change how numbers and dates are stored.

This grid shows your data as rows and columns, so you can fix a value, rename a header, add a column or sort and then export in the format you need. Numbers and booleans stay typed in the JSON output instead of becoming strings. The data never leaves your browser, which makes it safe for customer lists, test data and exports you would rather not upload to an online service.

How to use it

  1. Paste JSON (an array of objects) or CSV into the input, or open a file.
  2. Click a cell to edit it, and use the controls to add or delete rows and columns or rename a header.
  3. Click a column header to sort by that column.
  4. Copy or download the data as CSV or JSON.

Frequently asked questions

What JSON shape does it accept?

An array of objects, where each object becomes a row and its keys become columns. Deeply nested objects do not fit a flat grid well, so flatten them first with the JSON flatten tool.

Are numbers kept as numbers?

Yes. In JSON output, values that look like numbers or booleans are written as numbers and booleans rather than strings. In CSV everything is text, as the format has no types.

Is there a size limit?

There is no fixed limit, but a grid with many thousands of rows depends on your browser's memory and speed. For very large files, a command-line tool or a database import is a better fit.
