scrypt Key Derivation

Enter a password and a salt, then set N, r, p and the output length. The tool derives a key with scrypt and prints it as hex.

Use the tool

Why this tool exists

scrypt is a memory-hard password-based key derivation function, used for wallet encryption, some login systems and encrypted file formats. Its three cost parameters are easy to mix up, and the memory it needs, 128 times N times r bytes, can surprise you: a setting that works in a library on a server can freeze a browser tab. This page lets you try values, check them against the RFC 7914 test vectors and see the result in hex. The memory is capped at 64 MiB, and the computation yields to the page so it stays responsive. The implementation is hand-written and unaudited, so use it to learn and to verify, not to protect real passwords. Input stays in your browser.

How to use it

  1. Enter the password and the salt as text.
  2. Set N (a power of 2), r and p, plus the output length in bytes.
  3. Run the tool and copy the derived key in hex.

Frequently asked questions

What do N, r and p mean?

N is the CPU and memory cost and must be a power of two. r is the block size, and p is the parallelism. Memory used is about 128 times N times r bytes.

Why does it refuse some values?

Memory above 64 MiB is rejected to protect your browser, so lower N or r. N must also be a power of two and at least 2.

Which test vector do the defaults match?

The defaults, password 'password', salt 'NaCl', N=1024, r=8, p=16 and 64 bytes, are one of the examples in RFC 7914.

Should I use this for real passwords?

Do not enter real passwords or live secrets into a page you do not fully trust. It is intended for testing and learning, and the code has not been audited.
