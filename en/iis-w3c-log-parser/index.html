IIS W3C Log Parser (#Fields Header to Table)

Maps every IIS log line to the columns named in the #Fields header and summarises the result.

Use the tool

Why this tool exists

IIS log files change their columns when logging settings change, so a fixed parser breaks. This tool reads the #Fields line and uses it, including when the header appears again in the file.

The summary covers status codes, top URLs, client IPs and request time. IIS writes UTC by default.

How to use it

  1. Paste the log including the # header lines, or choose files.
  2. Pick the view: summary, table, CSV or JSON.
  3. Filter by status or choose columns.
  4. Copy the result or narrow it with the filters.

Frequently asked questions

Why do I need the # lines?

The #Fields line names the columns. Without it the lines cannot be mapped.

What if some lines do not match?

They are skipped and the result says how many. Lines before the first #Fields line are skipped.

Which unit is time-taken?

Milliseconds in IIS logs.

Is my log uploaded?

No. Parsing happens in your browser and nothing is sent. Logs can hold IP addresses and tokens, so the page does not write them into the address bar.
