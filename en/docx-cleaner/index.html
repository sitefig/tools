Word Document Cleaner (Remove Metadata, Comments, Tracked Changes)

Send a Word file without leaking who edited it, what was deleted or what colleagues commented.

Use the tool

Why this tool exists

The cleaner rewrites the .docx: it clears author, last modified by, title, subject, keywords, description and revision in the core properties, company, manager, template and editing time in the extended properties, deletes the comments parts and their references, accepts all tracked changes (deleted text disappears and insertions stay), strips rsid attributes, and removes the thumbnail and custom properties. It also sets Word's "remove personal information on save". Output was opened with python-docx and LibreOffice to confirm the content and that the metadata and changes are gone.

Metadata can also live in headers, footers, hidden text, embedded objects, images and the file name; this tool does not touch those. Open the cleaned file in Word and use Inspect Document for a final check.

The file is read in your browser and is not uploaded anywhere.

How to use it

  1. Choose a .docx file.
  2. Tick what to remove.
  3. Download the cleaned copy.
  4. Review it in Word before sending.

Frequently asked questions

Does it reject tracked changes?

No, it accepts them: deleted text is removed and inserted text stays.

Is it safe for legal documents?

Review the result carefully; keep the original and check with Word's Inspect Document.

Will formatting change?

The content is unchanged apart from removed revision marks and metadata.

Is my data sent anywhere?

The file is read in your browser and is not uploaded anywhere.
