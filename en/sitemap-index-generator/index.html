Sitemap Splitter and Index Generator

Splits a URL list into several sitemap files and writes the sitemap index that points to them. You download everything as one ZIP.

Use the tool

Why this tool exists

A single sitemap may hold 50,000 URLs and 50 MB uncompressed. Bigger sites need several files and an index, and writing that by hand is slow and easy to get wrong.

This tool cuts the list by count and by bytes, escapes the URLs, names the files and builds the index with the base URL you give. It does not know your server, so you still upload the files yourself. Everything runs locally.

How to use it

  1. Paste one absolute URL per line.
  2. Enter the base URL where the sitemap files will be hosted.
  3. Set the maximum URLs per file if you want smaller parts.
  4. Download the ZIP, upload the files and submit only the index.

Frequently asked questions

What are the limits?

Per sitemap.org, 50,000 URLs and 50 MB (52,428,800 bytes) uncompressed per file. An index may list up to 50,000 sitemaps.

Should I gzip the files?

You may, but the limit applies to the uncompressed size. This tool writes plain XML.

Why does it warn about hosts?

A sitemap normally may only list URLs on the host it is served from, unless ownership is verified.

Is lastmod in the files?

Only the index entries get a lastmod. Per-URL dates need the CSV or XML tools.
