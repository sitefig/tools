Multiplication Table Trainer with Timed Drills

Drills multiplication facts for the tables you choose, with an optional timer, and ends with your score and the facts you missed most.

Use the tool

Why this tool exists

Fluency in times tables comes from short, regular practice. Pick the tables (2 to 12), the number of questions and, if you want pressure, a time limit of 30 seconds to 2 minutes.

Each question is random, you type the answer and press Enter. The end summary lists your score, time and the facts you got wrong. The page is built for keyboards and screen readers: the question is a labeled field and results are announced. Nothing is stored or sent.

How to use it

  1. Tick the tables to practise.
  2. Choose a time limit and number of questions.
  3. Press Start, type each answer and press Enter.
  4. Read the summary of missed facts.

Frequently asked questions

Does it save my progress?

No, nothing is stored.

Can I practise only the 7 times table?

Yes, tick only 7.

Is there a timer?

Yes, optional.

Does it work on a phone?

Yes, with the numeric keypad.
