Box and Whisker Plot Maker (Quartiles and Outliers)

Draws a box plot per column: median line, quartile box, Tukey whiskers and outlier dots, with a five-number summary table.

Use the tool

Why this tool exists

Box plots compare spread and centre across groups at a glance. Here the quartiles use linear interpolation, the same as Excel QUARTILE.INC and R type 7, and the table shows the exact numbers so you can check them.

Whiskers run to the most extreme value within 1.5 times the interquartile range of the box; points beyond that are drawn as outliers. That is a convention, not a verdict: an outlier may be a data error or the most interesting row.

How to use it

  1. Paste a header row of group names and the numbers below each.
  2. Choose vertical or horizontal boxes.
  3. Check the summary table for min, quartiles, median, max and whisker ends.
  4. Copy or download the SVG.

Frequently asked questions

Which quartile method?

Linear interpolation (Excel QUARTILE.INC, R type 7). Other methods give slightly different quartiles for small samples.

Do groups need equal length?

No. Empty cells are ignored.

How are outliers decided?

Values more than 1.5 IQR beyond the box.

Verified?

Quartiles match Python statistics.quantiles with the inclusive method for the sample data.
