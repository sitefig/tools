Character Counter with Custom Limits (160, 280, 500)

Count characters as you paste and see how many are left against one or more limits you choose, such as 160 for SMS or 280 for a post.

Use the tool

Why this tool exists

Many fields have a hard limit: an SMS, a meta description, a button label, a post. Counting by eye fails, and word processors count differently from the platform you paste into.

This counter shows characters the way people see them, plus code points, UTF-16 length and UTF-8 bytes, so you can tell why two tools disagree. You can set several limits at once and see the room left on each. Nothing leaves your browser.

How to use it

  1. Paste or type your text.
  2. Enter one or more limits, separated by commas.
  3. Read the remaining characters for each limit.
  4. Tick the trim option if spaces at the ends should not count.

Frequently asked questions

Why do emoji count differently in other tools?

An emoji is one character to a reader but two or more UTF-16 units and several bytes. This tool shows all the counts so you can compare.

Does this count SMS segments?

No. SMS splits messages at 160 characters in the GSM alphabet and 70 once any other character appears, and long messages use smaller parts. Use it as a first check.

Is my text uploaded?

No. The counting runs in your browser.
