Multi-Log Merger: Interleave Several Logs by Timestamp

Merges pasted logs and files by the first timestamp in each line and tags the source.

Use the tool

Why this tool exists

When a request crosses services, the story is spread over several files. Merging by time shows the order of events.

Lines without a timestamp stay with the line before them, so stack traces are not separated. All sources must use comparable clocks; if they do not, normalise them first.

How to use it

  1. Paste two logs, or choose several files.
  2. Set the zone for times without one.
  3. Keep source tags on.
  4. Read or copy the merged view.

Frequently asked questions

How is order decided?

By the first timestamp in each line, then by input order.

What about clock skew?

It is not corrected. Different server clocks give a wrong order.

How many files?

Any number, memory permitting.

Is my log uploaded?

No. Everything is processed in your browser and nothing is sent. Logs can hold IP addresses and tokens, so the page does not write them into the address bar.
