SQL Keyword Uppercaser

Changes the case of SQL keywords, and optionally functions and data types, to UPPERCASE or lowercase, while leaving string literals, quoted identifiers, comments and your own table and column names untouched.

Use the tool

Why this tool exists

Many teams settle on upper-case keywords so queries scan quickly, but queries pasted from logs, ORMs or old code come in every style. A plain find-and-replace to upper-case the whole query would ruin string values, identifiers and comments. This tool changes only what it recognises as keywords, and can include built-in function names and data types. Strings, quoted identifiers and comments are left alone, so a word like "select me" inside a literal stays as it is. It does not reformat or indent, only the case, so it fits as a quick clean-up before a commit or review. You can also go the other way and lower-case everything. It runs in your browser.

How to use it

  1. Paste your SQL into the input box.
  2. Choose UPPERCASE or lowercase for keywords, and tick whether functions and data types should change too.
  3. Copy the result back into your editor or script.

Frequently asked questions

What is left unchanged?

String literals, quoted identifiers, comments, and any name that is not a recognised keyword, function or type, such as your table and column names.

Does it reformat the query?

No. Only the letter case of recognised words changes. For layout and indentation, use the SQL formatter on this site.

What if a column shares a name with a keyword?

An unquoted word that matches a keyword list entry will change case. Quote the identifier if you need it kept as written.

Does it understand every dialect?

It uses a general list of common keywords, functions and types, so dialect-specific words may be missed. Check the result before committing.
