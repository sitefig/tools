Printable Math Worksheet Generator with Answer Key

Generates printable arithmetic worksheets with the operation, number range and problem count you choose, plus an answer-key page.

Use the tool

Why this tool exists

Practice sheets are easiest when they match the lesson: only sums to 20, or the 7 times table, or division with no remainders. Set the range, the operation (or a mix) and the number of problems and get a clean page with a name and date line.

The second page has the answers. Subtraction never goes negative and division always comes out exact. The same seed gives the same worksheet, so you can recreate it, and a new seed makes a new one. The answers were checked against an independent calculation. Use your browser print dialog and choose Save as PDF to get a file.

How to use it

  1. Pick the operation and the smallest and largest number.
  2. Set the number of problems and columns, and a title.
  3. Change the seed for a different set.
  4. Print the sheet, or save it as a PDF from the print dialog.

Frequently asked questions

Does it make a PDF?

It makes a printable page. Choose Save as PDF in your browser print dialog.

Are the answers correct?

Yes, they were verified independently.

Can I get the same worksheet again?

Yes, use the same seed and settings.

What is mixed?

A rotation of all four operations.
