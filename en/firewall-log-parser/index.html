Firewall Log Parser: iptables, UFW and pfSense filterlog

Turns firewall log lines into columns and summaries of actions, sources and destination ports.

Use the tool

Why this tool exists

Firewall logs are dense KEY=value or comma lists. Seeing which source and which port are blocked most helps tune rules.

UFW and iptables lines are read by their SRC, DST and port fields. pfSense filterlog lines are read by position as in the pfSense source code. IPv6 and ICMP details are only partly shown.

How to use it

  1. Paste the kernel log lines or filterlog lines.
  2. Filter by action.
  3. Read top sources and destination ports.
  4. Switch to the table for each line.

Frequently asked questions

Which formats are supported?

iptables LOG and UFW lines with SRC and DST, and pfSense filterlog CSV.

Where does pfSense field order come from?

From the pfSense source file syslog.inc.

Does it block anything?

No. It only reads text.

Is my log uploaded?

No. Everything is processed in your browser and nothing is sent. Logs can hold IP addresses and tokens, so the page does not write them into the address bar.
