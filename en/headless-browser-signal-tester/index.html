Headless Browser Signal Tester (What Bot Detectors See)

Reads the signals simple bot detectors check in your browser and says which look automated.

Use the tool

Why this tool exists

Bot detection starts with simple checks: does the browser report webdriver, does the user agent say Headless, are there plugins and languages, is there a real window size, what graphics renderer is used.

The page reads these from your own browser and explains each. A clean result proves nothing: modern automation hides most of these and detectors use many more signals. A flagged result can be a false alarm, for example with privacy extensions or unusual setups. Nothing is sent anywhere.

How to use it

  1. Open the page in the browser you want to test.
  2. Read the table of signals.
  3. Compare a normal and an automated browser.
  4. Use it to debug false positives on your site.

Frequently asked questions

Is my data sent?

No. Everything is read locally.

Does a clean result mean I look human?

No. Detectors use timing, behaviour and network signals too.

Why does a real browser sometimes flag?

Privacy extensions, containers and software rendering can trigger signals.

Is this for evading detection?

It shows what is checked; it does not help hide it.
