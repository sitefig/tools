Parallel Coordinates Plot with Range Filters

Shows multi-column data as lines across vertical axes. Filters highlight matching rows and fade the rest.

Use the tool

Why this tool exists

Parallel coordinates help you explore tables with many numeric columns: which rows are high on one measure and low on another. The first axis order matters, so reorder columns in your data to compare neighbours.

Instead of dragging a brush on an axis, you type filters such as mpg: 20-30; weight: -3000. The matching ranges appear as yellow bars on the axes. This keeps the tool usable without a pointer. Text columns are used to colour lines.

How to use it

  1. Paste a table with a header row.
  2. Type filters as column: min-max, separated by ;.
  3. Choose a column to colour lines by.
  4. Copy or download the SVG.

Frequently asked questions

How do I write an open range?

Leave one side empty: mpg: 20- or weight: -3000.

Which columns become axes?

Columns where every filled cell is a number.

How many rows?

Up to 1000.

Can axes be reordered?

Reorder the columns in your data.
