OpenPGP Armor / Packet Inspector

Paste an ASCII-armored PGP block, or hex of binary packets. The tool checks the CRC-24, lists the packets and shows algorithms, key sizes, user IDs, signature details and fingerprints.

Use the tool

Why this tool exists

A PGP key block is a wall of base64, and the questions you have about it are practical: whose key is this, what algorithm does it use, when was it made, does it expire, and what is its fingerprint? Command-line tools such as gpg answer them but need installing and a keyring. This inspector parses the packets directly in your browser. It lists public keys, subkeys, user IDs, signatures and their subpackets, including key flags, creation and expiry times, and preferences, and computes v4 (SHA-1) and v6 (SHA-256) fingerprints and key IDs. It does not verify signatures, check trust or decrypt anything, and secret key blocks should never be pasted into a web page. Only public material is safe to inspect here.

How to use it

  1. Paste the full armored block, including the BEGIN and END lines, or paste hex.
  2. Run the tool.
  3. Read the CRC check, the numbered packet list and the fingerprints.

Frequently asked questions

Does the tool verify signatures or trust?

No. It only parses and describes the data. It does not check that a signature is valid, that a key is trusted or that a user ID belongs to a real person.

What does the CRC-24 check tell me?

It tells you whether the armor was copied intact. A mismatch suggests a damaged paste, such as lost characters or changed line endings. It is not a security check.

Is it safe to paste a private key?

No. Do not paste secret keys into any web page. Although the tool runs locally and reports only whether secret material is protected, public key blocks are the intended use.

Which fingerprints can it compute?

Version 4 keys (SHA-1) and version 6 keys (SHA-256). Version 3 keys are flagged as obsolete and version 5 fingerprints are not computed.
