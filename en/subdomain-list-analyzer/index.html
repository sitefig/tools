Subdomain List Analyzer (Dedupe, Group, Flag Risky Names)

Clean a messy list of hostnames, group it by registered domain and spot the names that deserve a security review.

Use the tool

Why this tool exists

Subdomain lists from Certificate Transparency, amass, subfinder or DNS zone exports come with wildcards, duplicates, URLs and case differences. This tool normalises them, groups them by registered domain, shows how deep the names go and flags words that often mark exposed internals: admin consoles, staging and test environments, VPNs, CI systems, internal tools, backups and databases.

It is an attack-surface inventory aid for your own domains. Keyword matches are hints, not findings, and the grouping uses a short built-in list of two-level suffixes rather than the full Public Suffix List. It performs no DNS lookups: dangling records (names pointing to deleted cloud services) need a resolver to confirm.

How to use it

  1. Paste hostnames, one per line (URLs and wildcards are cleaned).
  2. Keep "Flag interesting names" on for the review list.
  3. Export the grouped list and check each flagged name with your DNS and asset records.

Frequently asked questions

Where do I get a list?

From crt.sh, your DNS provider export, a zone transfer you are allowed to do, or tools such as amass and subfinder.

Is this scanning anything?

No. It only processes the text you paste.

What is a subdomain takeover?

A DNS record that still points to a deleted cloud resource, which an attacker can claim. Find them by resolving each flagged name.
