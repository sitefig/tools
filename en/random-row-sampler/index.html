Random Row Sampler (Seeded Sample from a CSV)

Selects random rows without replacement and keeps their original order, with an optional seed.

Use the tool

Why this tool exists

Spot-checking a big file is faster on a sample. A fixed seed gives the same rows for the same input, which is useful when you must show how a sample was drawn. Leave the seed empty for a fresh draw each time.

Sampling is simple random sampling without replacement using a Fisher-Yates shuffle; it is not stratified, so small groups can be missed. The summary states the seed used.

How to use it

  1. Paste the CSV with a header.
  2. Set a sample size or a percentage.
  3. Enter a seed to make it repeatable, or leave blank.
  4. Copy or download the sample.

Frequently asked questions

Is it truly random?

The shuffle uses a seeded pseudo-random generator, fine for sampling but not for security.

Does it keep the header?

Yes.

What if the sample is bigger than the file?

You get all the rows.

Stratified sampling?

Not available.
