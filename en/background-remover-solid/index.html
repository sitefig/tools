Background Remover for Plain Backgrounds (No AI)

Cut out a white or flat-colour background in your browser, with no upload and no model.

Use the tool

Why this tool exists

The tool finds the dominant colour along the image edges (or uses one you give), then floods inward from the edges through pixels within the tolerance of that colour and makes them transparent. Only regions connected to the edge are removed, so enclosed areas of the same colour, such as the inside of a letter O, stay. Edge pixels can be softened for a cleaner outline. The result is a PNG with an alpha channel.

This is not an AI cut-out tool: it cannot separate a person from a busy photo background. If parts of the subject disappear, lower the tolerance; if a halo remains, raise it.

The file is read in your browser and is not uploaded anywhere.

How to use it

  1. Choose an image.
  2. Set the tolerance and (optionally) the background colour.
  3. Run it and download the PNG.
  4. Retry with another tolerance if needed.

Frequently asked questions

Does it work on photos?

Only when the background is uniform, such as a studio backdrop.

Why does a hole stay opaque?

Regions not connected to the edge are kept on purpose.

Is there a limit?

Images above about 36 megapixels are rejected.

Is my data sent anywhere?

The file is read in your browser and is not uploaded anywhere.
