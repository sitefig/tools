Writing Prompt Generator by Genre

Get random creative writing prompts by genre: horror, romance, science fiction, fantasy, mystery, drama, humour or historical.

Use the tool

Why this tool exists

A blank page is easier to start when a prompt gives you a person, a place and a problem.

Pick a genre or let the tool choose. Each prompt joins one of eight characters, eight settings and eight complications, so each genre offers 512 combinations. Add a seed text to get the same list again. Everything is generated in your browser.

How to use it

  1. Choose a genre or any.
  2. Set how many prompts you want.
  3. Optionally enter a seed to repeat the list.
  4. Pick one and write for ten minutes.

Frequently asked questions

Are the prompts original?

They are combinations of short original elements written for this tool.

Can I get the same prompts again?

Yes, enter the same seed text.

May I use them in published work?

Yes. They are ideas, not text to copy.
