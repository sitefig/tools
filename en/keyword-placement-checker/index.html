Keyword Placement & Content Score Checker

Paste a page (HTML or plain text) and a target keyword to see whether it appears in the places search engines and readers look first.

Use the tool

Why this tool exists

The checker looks at the title, meta description, H1, number of H1s, subheadings, image alt text and file names, the first 100 words, the URL, keyword count and density, keyword stuffing and body length, then gives a weighted pass score. With plain text only the on-page checks apply.

It measures placement, not quality: there is no ideal keyword density, and exact-match checks miss synonyms and variants that readers value. Use the score as a checklist, then judge whether the page truly answers the query.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Paste the page source (best) or article text.
  2. Enter the target keyword and the page URL if you want the URL check.
  3. Run it and work through any FAIL lines.
  4. Re-read the page for the reader, not just the checker.

Frequently asked questions

What is a good keyword density?

There is no target. Use the phrase naturally; anything above about 3% on a long page starts to read as stuffing.

Why does a short page fail the length check?

The check uses a rule of thumb of 300 words for an article. Some pages, such as product pages, are fine shorter.

Does it work for multi-word keywords?

Yes. It matches the whole phrase in order, ignoring case and hyphens.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
