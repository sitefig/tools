Network Graph Visualizer (Force-Directed Layout from an Edge List)

Draws a network from pairs of connected names. A force simulation places connected nodes close and unconnected ones apart; a table lists degrees.

Use the tool

Why this tool exists

Edge lists come from exports of links, emails, dependencies and social data. Seeing them as a graph shows clusters, bridges and isolated groups quickly.

The layout is a Fruchterman-Reingold style simulation with a fixed seed, so the same input draws the same picture, and you can change the seed for another arrangement. Direction and repeated edges are ignored. Beyond a few hundred nodes any force layout becomes a hairball; filter the list first.

How to use it

  1. Paste one connection per line: a,b or a -> b.
  2. Turn labels on or off, change the seed for another layout.
  3. Read the degree table for the most connected nodes.
  4. Copy or download the SVG.

Frequently asked questions

Are edges directed?

No, direction is ignored in the picture.

What do colours mean?

Each connected component has its own colour.

Why do two runs look different with another seed?

The simulation starts from a different random start; both layouts show the same graph.

Limits?

Up to 300 nodes and 1500 edges.
