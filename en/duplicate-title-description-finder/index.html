Duplicate Title and Meta Description Finder (Crawl CSV)

Finds duplicate titles and descriptions in a crawl export.

Use the tool

Why this tool exists

Duplicate titles are one of the most common crawl findings, and a crawler lists them row by row. Grouping them shows the pattern, such as paginated or filtered pages.

It finds Screaming Frog style headers (Address, Title 1, Meta Description 1) and common alternatives, or you can name the columns. Case and spacing can be ignored. Empty values are counted but not grouped.

How to use it

  1. Paste the crawl CSV with its header row.
  2. Name the columns if they are not found.
  3. Run the tool.
  4. Download the groups as CSV.

Frequently asked questions

Which columns are found?

Address or URL, Title or Title 1, Meta Description or Meta Description 1.

Are empty titles duplicates?

No. They are counted separately.

Is the CSV uploaded?

No.

How big can the file be?

As large as your browser can paste; very large files may be slow.
