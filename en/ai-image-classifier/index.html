AI Image Classifier (MobileNetV2, 1000 ImageNet Classes)

A small neural network, MobileNetV2, tells you which of 1000 everyday object classes your picture most resembles.

Use the tool

Why this tool exists

Image classifiers label what is in a picture. MobileNetV2 is built to be small enough for phones: 3.5 million parameters and a 7 MB file, which makes it practical to run fully in a browser tab with no upload. Typical uses are sorting photo collections, quick alt-text ideas and learning how convolutional networks behave.

It knows only the 1000 ImageNet classes (many dog breeds, tools, vehicles, foods, animals, household objects). It has no "none of these" class, no concept of people or text, and it always answers with the closest class, so low percentages mean it is guessing. The weights are timm mobilenetv2_100.ra_in1k (Apache-2.0); our JavaScript engine matches PyTorch on test tensors to about 0.004 in the logits.

How to use it

  1. Choose an image file.
  2. Run the tool; the first run downloads the 7 MB model once.
  3. Read the top five classes with probabilities.

Frequently asked questions

Can it identify people or read text?

No. It only distinguishes the 1000 ImageNet object classes and will still pick one for anything else.

Why is the answer odd for my photo?

The centre 87% of the picture is analysed at 224 by 224 pixels. Busy scenes, unusual angles and objects outside the 1000 classes confuse it.

Is my image uploaded?

No. It is decoded and analysed in your browser tab.
