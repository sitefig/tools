Speakable Schema Builder

Generates speakable JSON-LD that points to the sections of a page suited to text-to-speech, using CSS selectors or XPath.

Use the tool

Why this tool exists

Speakable tells voice assistants which parts of a page to read aloud. Google's documentation allows either cssSelector or xPath, not both, and the tool enforces that. It also repeats the guidance: mark key points, not the whole article, aim for about 20 to 30 seconds per section, and leave out datelines, captions and source credits.

Google lists the feature as beta for news content in English on U.S. Google Home devices. Treat it as optional.

How to use it

  1. Enter the page name and URL.
  2. Add css: lines or xpath: lines, not both.
  3. Choose WebPage, Article or NewsArticle.
  4. Copy the script tag.

Frequently asked questions

Which should I use, CSS or XPath?

CSS selectors are easier to maintain. Use one kind per block.

Is speakable widely supported?

Google describes it as beta and limited to some markets. Other voice assistants may differ.

What should I mark?

Headline and summary sentences that make sense when heard alone.

Can I use several selectors?

Yes, repeat the line.
