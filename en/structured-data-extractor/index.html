Structured Data Extractor

Finds JSON-LD scripts, microdata items and RDFa items in pasted HTML and lists each with its type, properties and a copyable JSON-LD version.

Use the tool

Why this tool exists

Pages often mix formats, and testing tools show them in different places. This tool lists every item it finds, labelled by format, as an indented tree followed by the same item as JSON-LD. Invalid JSON-LD blocks are reported with the line and column.

Nothing is fetched: paste the HTML you copied from the page source or the elements panel. Items that scripts add after loading need the rendered HTML.

How to use it

  1. Copy the HTML from view-source or DevTools.
  2. Paste it in and add a base URL if you want absolute links.
  3. Read the tree for each item.
  4. Copy any item as JSON-LD.

Frequently asked questions

Can it read a live URL?

No. A web page cannot fetch other sites. Paste the HTML.

What if a script adds the markup later?

Copy the rendered HTML from DevTools rather than view-source.

Does it merge duplicates?

No, use the @graph merger for that.

Which formats are covered?

JSON-LD, microdata and a subset of RDFa.
