Link Extractor (internal / external)

Paste HTML and a base URL to list every link as internal, external or other, with its anchor text and nofollow, ugc or sponsored status, plus warnings on weak anchors.

Use the tool

Why this tool exists

A link audit starts with knowing what links a page contains. For internal linking you want descriptive anchors that point to the pages you care about, and for outbound links you want to know which are nofollow, which open in a new tab without rel protection and which still use http on an https site.

This extractor reads the anchor tags in the HTML you paste, resolves them against the base URL you enter or the canonical link in the page, and classifies each one. It gives counts for internal, external and other links such as mailto and tel, and warns about empty anchors, generic text like "click here", insecure links and internal nofollow. Nothing is fetched, so it does not check whether the targets actually work.

How to use it

  1. Paste the page HTML into the first box.
  2. Enter the page's base URL in the second box, or leave it to be taken from the canonical link.
  3. Run the tool to classify the links.
  4. Review the warnings and the link table, then improve weak anchors and attributes.

Frequently asked questions

How does it decide what is internal?

It compares the host of each link with the base URL host, ignoring a leading www. Subdomains count as external, so check them manually if you treat them as part of the same site.

Does it check for broken links?

No. It works only on the pasted HTML and does not request any URL. Use a crawler or a status checker to test whether targets respond.

Does it handle relative links?

Yes. Relative links are resolved against the base URL you give. If the base is missing it tries the canonical link, and if that is also absent it asks you for one.

Is my HTML uploaded?

No. The extraction runs in your browser and your markup stays on your device. Closing the tab discards the input, so nothing is kept on this site.
