Log Timestamp Normalizer: Mixed Formats to ISO 8601

Finds the timestamp in each line and rewrites it in ISO 8601 in a time zone you choose.

Use the tool

Why this tool exists

Merging logs from several systems is painful when each writes time differently. Normalising first makes sorting and comparison work.

Formats: ISO 8601, Apache, RFC 2822, syslog, logcat, yyyy/mm/dd, epoch seconds and milliseconds. Day-first dates such as 03/04/2024 are not guessed. Conversions were checked against Python.

How to use it

  1. Paste the log lines.
  2. Set the zone for times that have none.
  3. Choose the output zone.
  4. Copy the converted lines.

Frequently asked questions

Which time is changed?

Only the first timestamp in each line.

What if a line has no time?

It is left as it was and counted.

Why is the year wrong for syslog?

Syslog lines have no year. Set it in the option.

Is my log uploaded?

No. Everything is processed in your browser and nothing is sent. Logs can hold IP addresses and tokens, so the page does not write them into the address bar.
