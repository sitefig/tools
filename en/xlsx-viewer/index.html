XLSX to CSV Viewer

Open an .xlsx workbook, see the list of sheets and read any one of them as CSV text that you can copy elsewhere.

Use the tool

Why this tool exists

Sometimes you only need the data from a spreadsheet: to paste into a script, load into a database or check what a colleague sent. Without Excel installed, or on a locked-down device, opening an .xlsx can be surprisingly hard, and uploading it to a viewer site exposes whatever is inside.

This viewer reads the workbook on your device. It unpacks the file, finds the sheets, resolves shared strings and prints the chosen sheet as CSV, with an optional header listing every sheet name. It shows the values Excel last saved for formulas rather than recalculating them. It does not interpret cell formats, so dates appear as serial numbers, and only one sheet is shown at a time. For complex workbooks with charts or macros, use a full spreadsheet application.

How to use it

  1. Choose an .xlsx file.
  2. Set the sheet number to read; the default is the first sheet.
  3. Keep Prefix with sheet list ticked to see all sheet names.
  4. Run the tool and copy the CSV output.

Frequently asked questions

Why do dates show as numbers?

Excel stores dates as serial numbers, and the cell format decides how they look. This viewer does not interpret formats, so 45000 appears instead of a date. Convert serials in your next step.

Are formulas recalculated?

No. The tool shows the cached result that Excel stored when the file was saved. If a file was generated by software that did not store values, formula cells may appear empty.

Which files does it support?

Modern .xlsx workbooks only. Older .xls files, .xlsb and password-protected workbooks are not supported, and you will see a message that the workbook structure is missing.

How do I read a different sheet?

Change the sheet number. With the sheet list shown at the top, the line marked shown tells you which one is displayed. Numbers beyond the last sheet select the last one.
