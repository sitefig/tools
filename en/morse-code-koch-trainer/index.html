Morse Code Trainer: Copy by Ear with the Koch Method

Plays groups of five random Morse characters from the set you have learned so far; you type them, and you add a new character at a time.

Use the tool

Why this tool exists

The Koch method starts with just two characters at full speed and adds one at a time, so you learn to hear the sound of each letter rather than counting dots. Set the level, speed and pitch, press Play, and type the five characters.

The character order and the 90 percent rule of thumb for moving on are the commonly used ones, written from memory and not checked against a published source. The Morse table itself was compared with the Morse translator on this site. Timing follows the standard: a dash is three dots, with one dot between elements and three between letters. The level is remembered in this browser if storage is allowed.

How to use it

  1. Set how many characters you have learned and your speed.
  2. Press Play 5 new characters and listen.
  3. Type what you heard and press Check.
  4. Raise the level when your accuracy is high.

Frequently asked questions

Why start at 15 words per minute?

The Koch method uses a fast character speed from the start; lower it if you need to.

Is the order verified?

No. It is the order commonly cited, written from memory.

Can I hear a text I type?

Use the Morse code audio generator.

Is my progress saved?

The level only, in this browser.
