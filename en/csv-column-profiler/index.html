CSV Column Profiler (Types, Nulls, Unique, Min/Max)

Get a quick data-quality summary of a CSV before importing it.

Use the tool

Why this tool exists

Each column is analysed for filled and empty cells, number of distinct values, and a type (integer, number, boolean, date or text). Numeric columns show min, max, mean and median; text columns show length range; dates show the earliest and latest and invalid dates (like 2024-02-30) are listed. The three most common values with counts appear for every column.

Types are inferred from the values present, so a column of IDs with leading zeros counts as integer. For large files use a data tool; this works in memory in the page.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Paste the CSV with a header row.
  2. Run the profiler.
  3. Look for unexpected types, many empties or invalid dates.
  4. Clean the data before import.

Frequently asked questions

How is a date detected?

Values that look like YYYY-MM-DD (optionally with time) and are real calendar dates.

Are empty strings counted as null?

Yes, empty cells count as empty.

Can it handle big files?

It works in memory in your browser, so very large files may be slow.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
