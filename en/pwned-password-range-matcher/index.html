Pwned Password Range Matcher (k-anonymity, Offline)

Check a password against the Have I Been Pwned list the privacy-preserving way, without this page ever sending anything.

Use the tool

Why this tool exists

Step 1: enter the password; the tool computes its SHA-1 hash in your browser and shows the first five characters. Open the address it prints (api.pwnedpasswords.com/range/PREFIX), which returns a list of hash suffixes with breach counts. Step 2: paste that list in the second box and run again; the tool searches for your suffix locally.

Only the five-character prefix ever needs to leave your computer, and this page sends nothing at all. A match means the password appeared in known breaches and should not be used anywhere. No match does not make a password strong: use the strength checker too.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Type the password and run the tool to get the prefix and lookup address.
  2. Open the address and copy the whole response.
  3. Paste the response into the second box and run again.
  4. If it is found, change that password everywhere it is used.

Frequently asked questions

Why is this safer than typing the password into a site?

You control every network request. Only a 5-character hash prefix goes out, and it matches hundreds of other passwords.

Is SHA-1 insecure?

For this lookup it is only an identifier, not protection. The list is indexed by SHA-1.

Does it check my email address?

No. This is for passwords only.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
