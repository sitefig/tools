PDF Redaction (Black Out Areas Permanently)

Remove names, numbers or signatures from a PDF so they cannot be recovered.

Use the tool

Why this tool exists

Boxes are given as "page x y width height" in percent of the page, with "all" for every page. The tool renders each page, paints the boxes and rebuilds a PDF from the images, so the original text, hidden layers, form fields, annotations and metadata are not carried over. That is what makes the redaction permanent, unlike a box drawn over text in an editor.

Always open the result and check every page. Text becomes a picture, so the file is no longer searchable. Positions are measured from the top-left corner.

The file is read in your browser and is not uploaded anywhere.

How to use it

  1. Choose the PDF.
  2. List the boxes, one per line.
  3. Download and review the redacted copy.
  4. Share only the redacted file.

Frequently asked questions

Why flatten the pages?

Covering text with a shape leaves the text in the file. Rendering to an image removes it.

How do I find coordinates?

Estimate the position as a percentage of the page; run, check, adjust.

Is the original changed?

No, a new file is created.

Is my data sent anywhere?

The file is read in your browser and is not uploaded anywhere.
