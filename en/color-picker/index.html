Color Picker with HEX, RGB, HSL and OKLCH Values

Uses your browser colour picker plus a text field to show one colour in HEX, RGB, HSL and OKLCH, each with a copy button.

Use the tool

Why this tool exists

Design tools, CSS and code want different formats. Pick a colour with the native picker, or type any HEX, rgb(), hsl() or oklch() value, and see the others at once.

OKLCH is the format for perceptually even colour work in modern CSS. The numbers come from the Oklab matrices and were checked against the Color Converter on this site.

How to use it

  1. Click the colour box and choose a colour, or type a value in the text field.
  2. Read HEX, RGB, HSL and OKLCH below the swatch.
  3. Press Copy next to the format you need.
  4. Use the Color Converter for CMYK or CSS names.

Frequently asked questions

Which input formats can I type?

HEX (3, 4, 6 or 8 digits), rgb(), hsl() and oklch().

Why does OKLCH show a hue for grey?

For colours with almost no chroma the hue is meaningless, so it shows 0.

Can I pick from the screen?

Not here. Use the Color Picker from Image for an image, or the EyeDropper API in your browser tools.

Is my colour stored?

No.
