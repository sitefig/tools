Batch Image Optimizer (Compress Many Images to a ZIP)

Compress many images at once and download one ZIP.

Use the tool

Why this tool exists

Drop in a set of images, pick JPEG or WebP, one quality and a maximum width. Every image is re-encoded in your browser and the results come back in one ZIP with a report of the savings. A tick box keeps the original when the new file would not be smaller.

Re-encoding removes EXIF metadata, which is good for privacy and bad if you need the camera data. Quality 70 to 80 is a good start for photos.

How to use it

  1. Choose the images.
  2. Pick the format, quality and maximum width.
  3. Decide whether to keep originals that would grow.
  4. Download the ZIP and read the report.

Frequently asked questions

Is the quality lost?

JPEG and WebP are lossy. Check a few results by eye before using a whole batch.

Why is a file unchanged?

If the new file is not smaller and you ticked Keep, the original goes into the ZIP.

Is there a file limit?

Memory is the limit. Very large batches may be slow in a small browser tab.

Is anything uploaded?

No. The work happens in your browser and the page makes no network request with your input.
