Typography Unit Converter: Points, Picas, Pixels and Millimetres

Converts print and screen type sizes between points, picas, pixels, millimetres, centimetres, inches and twips at a DPI you set.

Use the tool

Why this tool exists

Designers work in points, browsers in pixels and printers in millimetres. A 12 pt font is 4.23 mm and 16 px at 96 DPI.

Set the DPI to match your target and read all units. It uses the 1/72 inch desktop publishing point.

How to use it

  1. Enter the size.
  2. Choose its unit.
  3. Set the DPI for pixel results.

Frequently asked questions

How many px is 12 pt?

16 px at 96 DPI (CSS).

What is a pica?

12 points, one sixth of an inch.

Which point size is used?

The 1/72 inch point used by PostScript, PDF and CSS, not the older traditional point.
