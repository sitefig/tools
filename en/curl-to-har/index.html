cURL to HAR

Converts a curl command into a HAR 1.2 request entry containing the method, URL, headers, query string, cookies and post data. No response is recorded.

Use the tool

Why this tool exists

Some tools can only import a HAR file: load testers, API mockers, replay tools and certain documentation generators. HAR is what browsers export from the network tab, but if you only have a curl command from a ticket or an API guide, you have no HAR. This converter builds one request entry from the command, with the method, URL, headers, parsed query parameters, cookies and any request body, wrapped in a valid HAR 1.2 structure. It does not make the request, so there is no response data, timings or sizes: the entry is a request template. Parsing is done in your browser, so tokens in your command are not sent anywhere.

How to use it

  1. Paste a curl command into the input box.
  2. Run the conversion to produce the HAR JSON.
  3. Save the output as a .har file and import it into your tool, adding responses there if needed.

Frequently asked questions

Does the HAR include a response?

No. The command is only parsed, never run, so there is no response, status, timing or size. Tools that need a response will have to fill it in or ignore it.

What parts of the request are included?

Method, URL, headers, query string parameters, cookies and the request body (post data), as in a HAR 1.2 request entry.

Can I convert several commands?

This tool converts one command at a time. For several requests, use the cURL to Postman converter, which handles multiple commands, or run this tool once per command.

Is it valid for browsers' DevTools import?

It follows the HAR 1.2 shape, but DevTools may expect response fields. If an import complains, try a tool made for request templates.
