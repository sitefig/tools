CSS Spring Easing Generator (linear() Function)

Get bouncy, natural animations in plain CSS without a JavaScript animation library.

Use the tool

Why this tool exists

The generator solves the damped spring equation exactly (underdamped, critically damped and overdamped cases), samples it at the number of points you choose, finds the time to settle within 0.1% and writes a linear(...) easing and a transition ready to paste. The curve was compared with a numerical integration of the spring for several parameter sets.

linear() with many stops is supported in current browsers; older ones ignore the declaration, so keep a plain ease-out before it. Large overshoot on opacity values is clamped by the browser, so use springs for transforms.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Set mass, stiffness and damping (170 and 14 is a lively default).
  2. Choose how many sample points.
  3. Copy the transition line.
  4. Add a fallback easing before it.

Frequently asked questions

What do the parameters mean?

Stiffness pulls toward the target, damping slows oscillation, mass makes it more sluggish.

How many points do I need?

30 to 60 gives a smooth curve; more bloats the CSS.

Can I get no bounce?

Raise damping until the damping ratio is 1 or more.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
