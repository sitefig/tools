Log to CSV Converter (Access Logs, logfmt, JSON Lines, Custom Regex)

Converts several common log formats to CSV with the columns you pick.

Use the tool

Why this tool exists

Spreadsheets and SQL tools want columns. This tool parses the log and writes CSV with proper quoting, so user agents with commas survive.

For a custom regex, named groups become columns. Use the SQL on CSV tool or the XLSX converter on the result. Lines that do not match are skipped without a note, so compare line counts.

How to use it

  1. Paste the log or choose a file.
  2. Pick the format and, if needed, enter a format string or regex.
  3. Optionally list the columns to keep.
  4. Copy or download the CSV.

Frequently asked questions

Can I get XLSX?

Paste the CSV into the CSV to XLSX tool.

Can I query it with SQL?

Yes, paste the CSV into the SQL on CSV tool. It is not DuckDB, but runs common SELECT queries.

Why are lines missing?

Lines that do not match the format are dropped.

Is my log uploaded?

No. Everything is processed in your browser and nothing is sent. Logs can hold IP addresses and tokens, so the page does not write them into the address bar.

Tools often used together

  • SQL on CSV / JSON (in-browser SQL)Run SQL against pasted CSV or JSON. Box 1: tables separated by a line of ---, each CSV (first row = header) or a JSON array of objects, optionally starting with "-- name: users"; they become t1, t2, ... (and the name). You can also put CREATE TABLE / INSERT statements in either box. Box 2: statements separated by ;. Supported: SELECT with expressions, aliases, DISTINCT, WHERE (AND OR NOT, comparisons, LIKE, GLOB, IN, BETWEEN, IS [NOT] NULL, EXISTS), INNER/LEFT/RIGHT/FULL/CROSS JOIN with ON or USING, GROUP BY/HAVING, COUNT SUM AVG MIN MAX TOTAL GROUP_CONCAT (DISTINCT ok), ORDER BY (aliases, ordinals, NULLS FIRST/LAST), LIMIT/OFFSET, subqueries (FROM, IN, EXISTS, scalar, correlated), WITH (non-recursive), UNION [ALL]/INTERSECT/EXCEPT, CASE, CAST, string and math functions, CREATE TABLE [AS], CREATE VIEW, INSERT, UPDATE, DELETE, DROP. Differences from SQLite: "/" is always true division, numeric-looking text compares as a number, empty CSV cells are NULL, no constraint enforcement (PRIMARY KEY/UNIQUE/NOT NULL), no window functions, recursive CTEs, triggers or date functions. Output is a text table plus CSV; nothing leaves your browser.
  • CSV to XLSXConvert CSV text to an Excel .xlsx file. Numbers become numeric cells (leading-zero values like 007 stay text).
  • CSV ViewerView CSV as a sortable, filterable table. Open a file or paste text.
  • Apache and Nginx Access Log Parser (Common and Combined Format Table)Turn Common or Combined Log Format lines into a table with IP, time, method, path, status, bytes, referrer and user agent. Filter by text, regex, status or method, sort, and export CSV or JSON.
  • Nginx log_format and Apache LogFormat to Regex ConverterPaste a log_format or LogFormat directive and get a regular expression with named groups for JavaScript and Python, plus a test against a sample line.
  • Logfmt Parser: key=value Log Lines to JSON or TableConvert logfmt lines (key=value, quoted values) from Heroku, Go and other services into JSON, a table or CSV. Numbers and booleans can be typed.
