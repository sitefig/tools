cloud-init User Data Generator (#cloud-config)

Provision a fresh VM with a sane baseline from its user data.

Use the tool

Why this tool exists

Enter hostname, an admin user and public SSH key, packages and the commands to run once. The output creates the user with sudo and no password, disables password and root SSH login (and writes a drop-in sshd config), installs packages, sets the timezone and optionally updates packages on first boot, then restarts SSH.

Check the SSH key before booting: with password login disabled a wrong key locks you out. User data runs once on first boot on most clouds, and command lines run as root.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Fill in host, user and your public key.
  2. List packages and first-boot commands.
  3. Paste the output as user data when creating the server.
  4. Log in with your key.

Frequently asked questions

Is the key secret?

No, only the public key is used.

Why disable password login?

It removes the most common brute-force attack path.

Which clouds support cloud-init?

Most: AWS, Azure, Google Cloud, DigitalOcean, Hetzner and OpenStack.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
