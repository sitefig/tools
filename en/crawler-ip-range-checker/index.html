Crawler IP Range Checker (Googlebot, Bingbot, GPTBot JSON Lists)

Checks whether IPv4 and IPv6 addresses fall inside the ranges of a JSON file or CIDR list you paste.

Use the tool

Why this tool exists

A user-agent claiming to be Googlebot proves nothing. The operators publish the IP ranges of their crawlers as JSON, and a request from outside them is not the real bot.

Download the current file yourself, paste it with your IPs, and see which are in range. The tool reads the prefix fields of the JSON and any CIDR line, for IPv4 and IPv6. It makes no network requests, so you need a fresh copy of the list.

How to use it

  1. Download the operator's JSON file.
  2. Paste it in the first box.
  3. Paste the IPs from your log.
  4. Read which are in range.

Frequently asked questions

Which files does it accept?

Any text that contains CIDR ranges or IPs, including Google, Bing and OpenAI JSON files.

Why not fetch the lists for me?

That is a network request, which this site does not make.

Is in range proof enough?

It is strong evidence. Reverse DNS is the second check.

The sample ranges are real?

No, they are documentation addresses.
