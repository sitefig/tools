Image to Text (OCR)

Choose one or more images and get the printed English text back as plain text you can copy or download. The recogniser runs locally on your device, so the pictures never leave it.

Use the tool

Why this tool exists

Text trapped in a screenshot, a phone photo of a page or a scanned letter is awkward to reuse: you cannot search it, quote it or paste it into a form. Most online OCR services want the image uploaded to a server first, which is a poor fit for invoices, contracts, ID documents or anything confidential.

This tool runs a Tesseract-style LSTM recogniser inside your browser tab. The model file is a small download from this site, the pixels stay on your machine, and nothing needs an account. It targets clean printed English text: screenshots, scanned pages, slides and photos of documents. It is not built for handwriting, vertical text or complex magazine layouts, and it says so rather than guessing quietly.

How to use it

  1. Choose one or more images (PNG, JPEG, WebP or similar) with the file picker.
  2. Leave the options on auto, or set invert, threshold, scale and deskew if the result looks wrong.
  3. Read the recognised text in the output area, tick per-line confidence to spot doubtful lines.
  4. Copy the text or download it as a .txt file.

Frequently asked questions

Is my image uploaded anywhere?

No. The recogniser and its model run in your browser tab. The only network request is the one-off download of the model file from this site. Your images are read from disk by the page and never sent to a server.

Which languages and layouts does it support?

English with Latin script only, and horizontal text. It auto-corrects small skew up to about four degrees, handles light text on a dark background, and reads simple columns. Tables come out as lines of text, not as a grid.

Why are some characters wrong or missing?

Very small text (under about 10 pixels high), heavy blur, low contrast and 1-bit images are the weak spots. Try the scale-up option, switch the threshold to adaptive, or take the screenshot at a higher zoom level and run it again.

How fast is it and does it block the page?

A dense page of text takes a few seconds on a recent computer, using a small SIMD WebAssembly kernel when the browser supports it and a slower fallback otherwise. The page stays usable between batches of lines but is busy while recognising.
