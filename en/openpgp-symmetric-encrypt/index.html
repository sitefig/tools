OpenPGP Passphrase Encrypt / Decrypt (gpg --symmetric Compatible)

Send a secret to someone with a shared passphrase, in a format every GnuPG installation can open.

Use the tool

Why this tool exists

Encryption derives an AES-256 key from the passphrase with the iterated, salted S2K (SHA-256), writes the symmetric-key packet, a literal data packet and an encrypted-and-integrity-protected packet (SEIPD v1 with an MDC) and wraps everything in PGP armor with a CRC-24. Messages made here decrypt with gpg --decrypt, and messages from gpg --symmetric (AES-128/192/256, ZIP or ZLIB compression) decrypt here.

The passphrase is the only protection: anyone with the message can guess passphrases offline, so use a long one. Public-key messages and the newer AEAD format are not supported.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Choose encrypt or decrypt.
  2. Paste the text or the PGP MESSAGE block and the passphrase.
  3. Copy the armored message to send.
  4. Share the passphrase through a different channel.

Frequently asked questions

Can GnuPG read it?

Yes: gpg --decrypt message.asc. This was tested in both directions.

Does it hide the message length or metadata?

No. OpenPGP leaks approximate size and the existence of the message.

Is the passphrase uploaded?

No. Everything runs in your browser.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.

Tools often used together

  • AES-GCM EncryptEncrypt text with a password: PBKDF2-SHA256 (600k iterations) + AES-256-GCM via WebCrypto. Output is base64: version | iterations | salt | iv | ciphertext.
  • AES-GCM DecryptDecrypt output from the AES-GCM Encrypt tool with the same password. Authentication failure means wrong password or tampered data.
  • OpenPGP Armor / Packet InspectorPaste an ASCII-armored PGP key, signature or message: checks the CRC-24, lists packets (algorithms, curves, key sizes, creation time, user IDs, signature subpackets) and computes v4 (SHA-1) / v6 (SHA-256) fingerprints. Nothing is verified or decrypted.
  • PBKDF2 Key DerivationDerive a key from a password with PBKDF2 (WebCrypto) using SHA-1/256/384/512; output as hex and Base64.
  • Password GeneratorCryptographically random passwords (crypto.getRandomValues, no modulo bias). Guarantees each selected class appears.
  • Passphrase GeneratorPronounceable syllable-based passphrases from crypto.getRandomValues. Entropy is computed exactly from the syllable space.
