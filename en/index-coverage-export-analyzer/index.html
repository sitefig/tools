Search Console Page Indexing Export Analyzer

Summarises CSV exports from the Search Console page indexing report.

Use the tool

Why this tool exists

The report lists reasons pages are not indexed, but the pages are in separate exports and hard to compare. Grouping by folder shows which part of the site is hit.

Paste one or more exports. Add a line like "# Crawled - currently not indexed" before an export that has no reason column. A summary table with Reason and Pages columns is also read. The tool groups only; it does not explain statuses.

How to use it

  1. Export the URL lists from Search Console as CSV.
  2. Paste them, each after a # reason line.
  3. Set the folder depth.
  4. Read the reasons and the most affected folders.

Frequently asked questions

Which columns are needed?

A URL (or Address) column, or Reason and Pages columns for a summary.

Does it log in to Search Console?

No. You paste exports.

Does it say why a status happened?

No. Read Google help for each reason.

Is my data uploaded?

No.
