Venn Diagram Maker (2 or 3 Sets with Labels in Each Region)

Draws overlapping circles for two or three sets and places your text into each region using simple codes like 12 for the overlap of sets 1 and 2.

Use the tool

Why this tool exists

Venn diagrams compare what is shared and what is not. You write the set names once, then one line per region.

The circles are equal in size and do not reflect how many items each region has; it is a layout diagram, not a proportional one. Four-set diagrams are not supported. A text version of every region is in the table below.

How to use it

  1. Write the set names on the first line, separated by |.
  2. Add lines like 1: text, 12: shared item, 123: centre.
  3. Separate several items in a region with ;.
  4. Copy or download the SVG.

Frequently asked questions

What do the numbers mean?

Digits are set positions: 1 is the first set, 12 is the overlap of 1 and 2 only.

Is there a 4-set version?

No.

Are areas proportional?

No, circles are equal.

Can I leave regions empty?

Yes.
