Random Date Generator

Creates random dates or timestamps between a start and an end, in the format you need.

Use the tool

Why this tool exists

Test data, seed files and demos need dates that vary but stay in range. Set a start and an end, choose a format, and get as many values as you want. All times are UTC.

Date-only formats pick a random day, so every day in the range has the same chance. Time formats pick a random millisecond. You can skip weekends, sort the list, and avoid duplicates. The random source is the browser's cryptographic one, without modulo bias.

How to use it

  1. Enter a start and end date.
  2. Choose a format and a count.
  3. Tick weekdays only, sorted or no duplicates if needed.
  4. Copy the list.

Frequently asked questions

Is the end date included?

Yes. A date-only end covers the whole day.

What time zone is used?

UTC. Convert if you need local time.

Why does it say only some values fit?

When duplicates are off or weekends are skipped, the range may hold fewer values than you asked for.

Can I get the same dates again?

No. The values are random each time, with no seed.
