Content-Language Header Builder

Writes the Content-Language header and its equivalents from valid language tags.

Use the tool

Why this tool exists

Content-Language states the language of the audience the content is meant for. It is not Accept-Language, which is what a browser requests. The tool checks your tags against the ISO lists and outputs the header, the meta http-equiv equivalent, the html lang attribute and server config lines.

Google says it does not use hreflang or lang to detect language and does not list Content-Language as a signal. For Bing, community and older sources say it reads the meta tag or header; I could not confirm that on Bing's current official documentation, and the tool says so.

How to use it

  1. Enter one or more language tags.
  2. Copy the header, meta tag or server line you need.
  3. Set html lang as well.
  4. Test the header with curl -I.

Frequently asked questions

Does Google use it?

Google does not list it as a signal; use hreflang for alternates.

Does Bing use it?

Sources say yes, but this was not verified on official documentation.

Can I list several languages?

Yes, for content meant for readers of all of them.

Is it the same as lang?

No, lang is for browsers and assistive technology.
