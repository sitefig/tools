Heading Structure Analyzer

Paste HTML to see its H1 to H6 outline as a tree and find a missing or repeated H1, skipped levels, empty headings, over-long headings and duplicate text.

Use the tool

Why this tool exists

Headings are how people skim a page and how screen readers and search engines understand its structure. They also go wrong quietly. A theme jumps from H1 to H4 for styling, a page ends up with three H1s after a template change, or a heading is empty because an image failed to load.

This analyser pulls every heading out of your HTML, shows the outline with indentation and counts how many of each level there are. It reports a missing H1, more than one H1, a first heading that is not H1, skipped levels, empty headings, headings over 70 characters and repeated heading text. These are guidelines rather than hard rules, since HTML5 allows several H1s in sectioning content. The analysis happens in your browser.

How to use it

  1. Copy the HTML source of the page and paste it into the input box.
  2. Run the tool to extract all headings.
  3. Read the issues list for missing H1, skipped levels and empty headings.
  4. Use the outline view to check the page reads logically, then fix the markup.

Frequently asked questions

Is more than one H1 always wrong?

Not always. HTML allows it, and Google handles it. But a single clear H1 is the safer convention for most pages, so the tool reports extra H1s as a warning.

Why does skipping levels matter?

Jumping from H2 to H4 leaves a gap in the outline that screen reader users rely on. Use the heading level for structure and CSS for appearance.

Does it read headings added by JavaScript?

Only if they are in the HTML you paste. For client-rendered pages, copy the rendered DOM from developer tools rather than the page source.

Is my page sent anywhere?

No. The extraction runs locally in your browser and nothing is uploaded. It also means the page works for drafts and private sites you would not want to share.
