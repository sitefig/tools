Case Sensitivity URL Checker: URLs That Differ Only by Letter Case

Groups URLs that are equal when case is ignored, so you can pick one lowercase form and redirect the rest.

Use the tool

Why this tool exists

On many servers /Shop and /shop are different pages. If both are linked, crawled or indexed, the same content lives at two URLs. This tool finds those pairs in a crawl or log export.

Whether a case variant is a separate page depends on your server, so test one pair with curl -I before acting. Host names are case-insensitive by definition, so a host-only difference needs no fix.

How to use it

  1. Paste a URL list from a crawl, sitemap or log.
  2. Choose whether the query string case matters.
  3. Review the groups.
  4. Redirect the variants to one lowercase URL.

Frequently asked questions

Why do case duplicates happen?

Hand-typed links, links from other sites, and CMS or rewrite rules that ignore case.

What is the fix?

Pick one lowercase form, redirect the others with a 301 and use the same form in canonical tags and sitemaps.

Do trailing slashes count?

You can treat them as the same so variants that differ in both are still grouped.

Does it request the URLs?

No, it only compares the text.
