Color Temperature Visualizer: Kelvin to RGB

Shows the colour of a black body radiator for a Kelvin value between 1000 and 15000, with HEX, RGB and CIE chromaticity.

Use the tool

Why this tool exists

Lights are described in Kelvin: low values are warm and orange, high values are cool and blue. The tool uses Krystek's rational approximation of the Planckian locus and converts it to sRGB, then scales the brightest channel to 255.

The chromaticity matches published values near 6500 K (x 0.3135, y 0.3235) and 2856 K. Real screens and lamps differ, so use it as a guide for white balance and lighting choices.

How to use it

  1. Move the slider or type a Kelvin value.
  2. Read the swatch, HEX, RGB and chromaticity.
  3. Compare with the reference table.
  4. Copy the HEX if needed.

Frequently asked questions

Is 6500 K pure white?

On screens it is the standard white point, but a black body at 6500 K looks very slightly pink on sRGB.

How accurate is it?

It is an approximation, valid about 1000 to 15000 K.

Is it the same as camera white balance?

It is related, but cameras use tint and sensor curves too.

Why scale to 255?

Only the colour matters here, not the brightness.
