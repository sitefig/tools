Plus Code (Open Location Code) Encoder, Decoder and Short-Code Recovery

Encodes and decodes Open Location Codes, including the 11 to 15 digit refinements, and recovers short codes near a reference point.

Use the tool

Why this tool exists

Plus Codes give any place a short address without street names. The tool follows the published specification: a 20 character alphabet, five latitude and longitude pairs and an optional grid refinement. Codes were compared with the openlocationcode Python library on 300 random points.

A short code such as 9G8F+6W drops the first characters and is only meaningful near a place. Give a reference location within roughly 50 km to recover the full code. Decoding returns the centre and the corners of the cell, with its size in metres.

How to use it

  1. Paste a Plus Code to decode it, or a latitude and longitude to encode.
  2. For a short code, enter a nearby reference as lat, lon.
  3. Pick the code length for encoding; 10 is about 14 by 14 m.
  4. Copy the result.

Frequently asked questions

What length should I use?

10 digits is the usual precision, about 14 metres; each added digit narrows it further.

What does a 0 mean?

Padding in short-area codes such as 8FVC0000+.

Is it related to what3words?

No. Plus Codes are an open standard with no database or licence.

Can it find a place by name?

No. That needs a geocoding service; this tool only converts coordinates.
