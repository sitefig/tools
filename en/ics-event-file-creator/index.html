ICS Calendar Event File Creator with Reminder

Builds a standards-style iCalendar (.ics) file for one event, with an optional reminder and all-day option, and lets you download it.

Use the tool

Why this tool exists

An .ics file opens in any calendar app. Fill the form and get a file to send or attach.

Times are converted from your chosen time zone to UTC, so there is no timezone block to break. Text is escaped and lines are folded as the spec requires. The output was parsed with the Python icalendar library.

How to use it

  1. Enter title, date and times.
  2. Set the time zone, location and reminder.
  3. Download the .ics file.

Frequently asked questions

Which time zone is used?

The IANA zone you type, then converted to UTC.

Does it handle repeats?

No, one event. Use the recurring date generator for a list.

Is the file private?

It is built in your browser and never uploaded.
