Response Time Percentile Calculator per Endpoint (p50, p90, p95, p99)

Groups requests by route and computes latency percentiles with the nearest-rank method.

Use the tool

Why this tool exists

Averages hide slow requests. Percentiles show how bad the slow ones are. The tool groups by endpoint, optionally merging /items/12 and /items/13 into /items/:id.

The log must record the duration: add $request_time to nginx or %D to Apache. Results were checked against a Python nearest-rank calculation.

How to use it

  1. Add the duration to your log format.
  2. Paste the log lines.
  3. Set the unit and whether to merge IDs.
  4. Sort by p95, p99 or count.

Frequently asked questions

Which percentile method?

Nearest rank: the smallest value with at least p percent of values at or below it.

What if my log has a different layout?

Use the regex option with a named group rt, and optionally path.

What unit does nginx use?

$request_time is in seconds with millisecond resolution; Apache %D is microseconds.

Is my log uploaded?

No. Everything is processed in your browser and nothing is sent. Logs can hold IP addresses and tokens, so the page does not write them into the address bar.
