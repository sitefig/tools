systemd Journal Export Viewer (journalctl -o json)

Reads journalctl -o json lines and shows counts per unit and priority, top repeated messages and a table of entries.

Use the tool

Why this tool exists

journalctl can export every field as JSON, which is complete but long. This tool shows which units are noisy and how bad their worst priority is.

Timestamps come from __REALTIME_TIMESTAMP in microseconds and are shown in UTC. Messages stored as byte arrays are decoded as UTF-8.

How to use it

  1. Run journalctl -o json --since "1 hour ago" > j.json.
  2. Paste the output or choose the file.
  3. Filter by unit, priority or text.
  4. Read the summary or switch to the table.

Frequently asked questions

Which priorities exist?

emerg, alert, crit, err, warning, notice, info, debug (0 to 7).

Why are some messages numbers?

journald stores binary or non-UTF8 messages as byte arrays. They are decoded here.

What if some lines do not match?

They are skipped and the result says how many. Lines that are not JSON are counted.

Is my log uploaded?

No. Parsing happens in your browser and nothing is sent. Logs can hold IP addresses and tokens, so the page does not write them into the address bar.
