Log Level Histogram: DEBUG, INFO, WARN, ERROR Counts Over Time

Counts lines per log level for each minute, hour or day, with a bar per bucket.

Use the tool

Why this tool exists

A spike in ERROR lines is easier to see as a table with bars than in the raw file. The tool finds the first timestamp in each line (ISO, Apache, syslog or epoch) and the first level word.

Continuation lines such as stack traces carry no level and are not counted. Times without a zone are read as the zone you set.

How to use it

  1. Paste the log.
  2. Choose a bucket size or leave auto.
  3. Set the zone for times without one.
  4. Read the table.

Frequently asked questions

Which levels are found?

TRACE, DEBUG, INFO, NOTICE, WARN, ERROR and FATAL, plus close synonyms.

What about syslog times with no year?

Set the year option or the current year is used.

Why are some buckets empty?

The range between first and last line is filled with zero rows.

Is my log uploaded?

No. Everything is processed in your browser and nothing is sent. Logs can hold IP addresses and tokens, so the page does not write them into the address bar.
