URL Length Checker: Sitemap, Apache and Nginx Limits

Lists URLs by length in characters and bytes, with path depth and parameter counts, and flags those over the sitemap limit, near default server limits or your own guideline.

Use the tool

Why this tool exists

Very long URLs are usually a sign of parameter or session ID problems. Some also break real limits: a sitemap entry must be shorter than 2,048 characters, Apache refuses request lines over 8,190 bytes by default and Nginx returns 414 when the request line does not fit its 8k buffer.

Google does not publish a maximum URL length for Search that I could verify, so the "own guideline" setting is your style rule, not a ranking threshold. Browser and CDN limits are not checked.

How to use it

  1. Paste your URLs.
  2. Set your own guideline if you have one (0 turns it off).
  3. Read the table sorted from longest to shortest.
  4. Investigate long URLs with many parameters first.

Frequently asked questions

Is there an ideal URL length?

No official one. Short readable URLs are easier to share and to check, but length is not a known ranking factor.

Characters or bytes?

Servers count bytes, so a URL with non-ASCII characters is longer in bytes. Percent-encoded forms count three characters per byte.

Where do the limits come from?

sitemaps.org protocol, the Apache LimitRequestLine and Nginx large_client_header_buffers documentation.

What about old browsers?

Limits of old browsers are not covered here.
