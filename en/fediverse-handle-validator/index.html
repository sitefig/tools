Fediverse Handle Validator and WebFinger URL Builder (Mastodon)

Check that a Mastodon or fediverse handle like @user@example.social is well formed, normalise it, and build its profile and WebFinger URLs without looking anything up.

Use the tool

Why this tool exists

A fediverse handle has two parts, a username and a server. A typo in either points to the wrong account, or to none.

Paste handles or profile URLs. The tool checks the form, normalises the host, and builds the profile URL and the WebFinger lookup URL. Nothing is contacted, so it cannot say that the account exists. Open the WebFinger link in a browser to see the server's answer.

How to use it

  1. Paste handles or profile URLs, one per line.
  2. Read the form check for each.
  3. Open the WebFinger URL yourself to look up the account.
  4. Fix invalid lines.

Frequently asked questions

Does it check the account exists?

No. It checks the form. A browser visit to the WebFinger URL does the lookup.

Are usernames case sensitive?

Usually not.

Does it work for non-Mastodon servers?

The handle form is shared, but the profile URL pattern may differ.
