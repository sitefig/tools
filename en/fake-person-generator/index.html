Fake Person Generator

Generate fictional people for testing: a name, an example.com email, a 555-01xx phone number, a birth date, a made-up address and a company.

Use the tool

Why this tool exists

Forms, CRMs, onboarding flows and email templates need sample people, but using real names and addresses in a demo or a bug report is a privacy problem. Random strings, on the other hand, look wrong and hide layout issues such as long surnames.

This generator produces records that are obviously fictional. Emails use the reserved example.com domain, phone numbers sit in the +1-555-01xx block reserved for fiction, and addresses use invented towns and street names with a fake ZZ region. The seed makes the set repeatable, so screenshots and tests stay stable. Choose JSON for code or plain text for pasting into a document. Nothing is fetched from a server.

How to use it

  1. Set how many people you need, from 1 to 500.
  2. Enter a seed so you can reproduce the same list later.
  3. Choose JSON or Text as the format.
  4. Copy the output into your test data.

Frequently asked questions

Can these people be real?

A name like Alex Smith is common, so a coincidental match is possible, but the emails, phones and addresses are built from reserved or invented values. They are not meant to identify anyone.

Why example.com and 555-01xx?

example.com is reserved for documentation, so mail never reaches a real inbox. The 555-0100 to 555-0199 range is set aside for fictional use in North America, which keeps test records from dialling real people.

Does it generate national ID numbers or card numbers?

No. It only creates name, email, phone, birth date, address and company. For card-shaped test numbers use the mock credit card generator, which is clearly marked as test data.

Is the list repeatable?

Yes. The same seed and count return the same people. Change the seed for a new list. This is useful for stable screenshots and snapshot tests.
