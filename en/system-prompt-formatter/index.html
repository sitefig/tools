System Prompt Formatter

Restructures a free-form system prompt into labelled sections: role, context, instructions, constraints, output format and examples, written with XML tags, Markdown headings or plain labels.

Use the tool

Why this tool exists

System prompts tend to grow by accretion: a line about tone here, a rule added after a bug there, an example pasted at the end. Eventually nobody can see what the model has been told. Splitting the prompt into named sections makes it easier to read, edit and review, and many people find models follow clearly delimited prompts more reliably. This tool sorts each line or paragraph into a section, using your existing headings or tags where present and keyword rules where not, then writes the result in the style you choose. It does not rewrite your wording, and its sorting is heuristic, so read the output and move any misplaced line. Your prompt stays in the browser.

How to use it

  1. Paste your existing system prompt into the input box.
  2. Choose XML tags, Markdown headings or plain labels as the output style.
  3. Check that each line landed in the right section, move any misplaced ones and copy the prompt.

Frequently asked questions

How does it decide which section a line belongs to?

If your prompt already has headings or tags it uses them. Otherwise keyword rules decide: "You are" means role, example markers mean examples, words like never or avoid mean constraints, format words mean output format.

Does it change my wording?

No. Lines are kept as written, only removing list markers and regrouping. Instructions and constraints with several lines become bullet lists.

Why did a line end up in the wrong section?

Rules are simple and a line can match more than one. Always review the result and move lines by hand. The default bucket is instructions.

Which style should I pick?

XML tags suit prompts with long pasted content because the boundaries are explicit. Markdown headings read well for humans. Both are valid; use what your team can maintain.
