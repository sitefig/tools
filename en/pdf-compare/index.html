PDF Compare (Visual Difference Between Two PDFs)

See exactly what changed between two revisions of a document.

Use the tool

Why this tool exists

Select both PDFs together (original first). Each pair of pages is rendered at the same size and compared pixel by pixel with an adjustable threshold. The result is a PNG per page showing differences in red over a faded copy of the original, and a summary with the percentage of changed pixels and the areas with the most change.

This is a visual comparison, so it works for scans and any layout but cannot tell text edits from layout shifts: inserting a paragraph moves everything below it and lights up the rest of the page.

The file is read in your browser and is not uploaded anywhere.

How to use it

  1. Select two PDFs at once.
  2. Choose pages, resolution and threshold.
  3. Review the diff images.
  4. Use a text compare when you only need wording changes.

Frequently asked questions

Can it compare text only?

No, it compares appearance.

What does the threshold do?

Pixel colour differences below it are ignored.

Do page counts have to match?

Pages are compared by number; extra pages are reported.

Is my data sent anywhere?

The file is read in your browser and is not uploaded anywhere.
