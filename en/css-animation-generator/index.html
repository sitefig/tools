CSS Animation Generator

Writes CSS keyframes and an animation declaration from ready-made presets like fade-in, slide-up, bounce, shake, flip, wobble and heartbeat. You set duration, delay, timing, iteration and fill mode.

Use the tool

Why this tool exists

Small motion cues make an interface feel alive, but writing keyframes from memory is a chore and tuning timing by trial and error means constant reloads. Most of what people need, such as a fade, a slide, a bounce or a shake, is a standard recipe.

Choose a preset, set the duration, delay, easing curve, iteration count and fill mode, and watch the sample box animate. The output includes both the keyframes block and a class that applies the animation, ready to paste. Use animation sparingly, since constant movement is distracting and can cause problems for people with vestibular disorders. Respect the reduced motion setting in your own stylesheet. Everything runs in your browser.

How to use it

  1. Choose a preset animation from the list.
  2. Set the duration, delay, timing function and iteration count.
  3. Choose the fill mode and watch the preview box.
  4. Copy the keyframes and the animation rule.

Frequently asked questions

What do the iteration and fill options mean?

Iteration is how many times it plays, or infinite for a loop. Fill mode decides which styles apply before and after the animation: none, forwards keeps the end state, backwards applies the first frame during the delay, both combines them.

How do I respect reduced motion?

Wrap your animation in a media query for prefers-reduced-motion: no-preference, or turn it off inside a reduce query. The generated CSS does not add this for you.

Can I use my own keyframes?

This tool uses its fixed presets. Copy the output and edit the percentages and properties by hand to build a custom animation.

Which properties are safe to animate?

Transform and opacity are the cheapest because browsers can animate them without re-laying out the page. Animating width, height or margins is more expensive. The presets here stick to transform and opacity.
