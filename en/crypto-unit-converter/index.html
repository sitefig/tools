Ethereum Unit Converter (wei / gwei / ether)

Enter an amount and pick its unit to see the exact value in wei, gwei, ether and the other Ethereum units, or in satoshi and BTC for Bitcoin.

Use the tool

Why this tool exists

Ethereum amounts live in wei, an integer one eighteen-zeroth of an ether, while gas prices are quoted in gwei and wallets show ether. Mixing them up by a factor of a billion is an easy mistake, and floating-point arithmetic in a spreadsheet or JavaScript loses digits on numbers this large.

This converter uses BigInt arithmetic, so every digit is exact. Type 1.5 ether, or 30 gwei, and read the value in every unit. The same approach works for Bitcoin, where one BTC is 100 million satoshi. Values with more decimals than the unit allows are rejected rather than rounded, which catches a pasted number that is in the wrong unit. It converts units only and knows nothing about prices.

How to use it

  1. Enter a non-negative amount. Underscores and commas are ignored.
  2. Choose the unit you entered it in.
  3. Read the equivalent values in the other units.

Frequently asked questions

Why not use a normal calculator?

Wei amounts run to 18 digits or more, beyond what ordinary floating-point numbers hold exactly. BigInt arithmetic keeps every digit, so nothing is silently rounded.

What is a gwei?

One billionth of an ether, or 10^9 wei. Gas prices are normally quoted in gwei because wei is too small and ether too large for everyday fees.

Why did I get an error about decimal places?

Each unit has a fixed number of decimals, for example 18 for ether and 9 for gwei. An amount with more digits than that cannot be a whole number of wei.

Does it show currency prices?

No. It converts between units of the same coin only, and does not look up exchange rates or use the network.
