MongoDB Query Builder (find, filter, sort, projection)

Write a MongoDB filter from readable lines and get both the find call and the equivalent aggregation.

Use the tool

Why this tool exists

Conditions are written as "field operator value" with =, !=, >, >=, <, <=, in, nin, regex and exists. Values are parsed as JSON where possible. The tool merges operators on the same field, adds a projection and sort and prints the find command, the equivalent aggregate pipeline and the filter as JSON.

When user input goes into a filter object, check its type: an attacker can send {"$ne": ""} where a string is expected (operator injection).

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Choose the collection.
  2. Write conditions, one per line.
  3. Set projection, sort and limit.
  4. Copy the mongosh command.

Frequently asked questions

What is operator injection?

Passing an object with $-operators in place of a value to change the query logic. Validate that values are plain strings or numbers.

Can it write updates?

No, only read queries.

Does it connect to a database?

No; it only writes the command.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.

Tools often used together

  • SQL to MongoDB QueryTranslate SQL into MongoDB shell syntax: SELECT -> find() with filter, projection, sort, skip, limit (or distinct); GROUP BY / aggregates / simple JOINs -> aggregate pipeline ($match, $lookup, $group, $project, $sort); INSERT VALUES -> insertOne/insertMany; UPDATE -> updateMany with $set/$inc; DELETE -> deleteMany. LIKE becomes a regex. Subqueries, UNION and CTEs are not supported.
  • MongoDB Query to SQLTranslate MongoDB shell queries to SQL: find/findOne with filters ($and, $or, $in, $gt..., $regex -> LIKE/REGEXP, $exists), projection, sort/skip/limit, countDocuments, distinct, insertOne/Many, updateOne/Many ($set, $inc, $unset), deleteOne/Many and simple aggregate pipelines ($match, $group, $sort, $limit, $project, $lookup). The query is parsed, never executed.
  • MongoDB Aggregation Pipeline BuilderFill in $match, $unwind, $lookup, $group, $sort, $project, $skip, $limit and get a pipeline for mongosh, Node, PyMongo or plain JSON.
  • BSON Hex / Base64 to JSON (MongoDB Extended JSON) and BackDecode a BSON document from hex or base64 into MongoDB Extended JSON ($oid, $date, $numberLong, $binary), or encode such JSON to BSON bytes.
  • MongoDB ObjectId ParserDecode ObjectIds into creation time, random value and counter; one per line.
  • JSON FormatterPretty-print JSON with custom indent and optional key sorting; errors show line and column.
