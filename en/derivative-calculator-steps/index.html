Symbolic Derivative Calculator with Rule-by-Rule Steps

Computes the symbolic derivative of a function of x, lists the rule applied at each level of the expression and gives the simplified result.

Use the tool

Why this tool exists

A derivative has a clear recipe, and the useful part for a student is knowing which rule applies where. The tool walks down the expression and names the sum, product, quotient, power, exponential or chain rule at each node, then prints the result.

The answer is simplified only with simple arithmetic, such as dropping times one and adding zero, so it may look longer than a hand-simplified result. It is checked against an independent computer algebra system on many functions. Derivatives assume radians. You can ask for up to the fourth derivative and for the value at a point.

How to use it

  1. Type a function of x, for example x^2 * sin(x) or exp(3x)/x.
  2. Set the order if you want a higher derivative.
  3. Optionally enter an x value to get the numeric value there.
  4. Read the steps and the final result.

Frequently asked questions

Which functions are supported?

Sums, products, quotients, powers (including x^x), sin, cos, tan, their inverses and hyperbolic forms, exp, ln, log, log2, sqrt, cbrt and abs.

Is the result fully simplified?

Not always. It is correct but only lightly simplified.

Can it do partial derivatives?

No, only one variable, x.

Why does abs() have a warning?

The derivative of abs(x) does not exist at zero. The formula given is valid elsewhere.
