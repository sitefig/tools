Image Sitemap Generator

Turns lines of page URL and image URLs into an image sitemap.

Use the tool

Why this tool exists

Image sitemaps help search engines find images that scripts or galleries hide. The markup needs the image namespace and one image:image per image.

Google supports image:loc only now. The older title, caption, geo and license tags are no longer documented, so this tool does not write them.

How to use it

  1. Write one page per line: page URL, then image URLs separated by |.
  2. Run the tool.
  3. Check the XML.
  4. Save it as sitemap-images.xml and submit it.

Frequently asked questions

How many images per page?

Up to 1,000 image tags per URL.

Can images be on another domain?

Yes, if both domains are verified in Search Console.

Why no captions?

Google no longer documents image:caption, title, geo_location or license.

Does robots.txt matter?

Yes. Do not block images you want indexed.
