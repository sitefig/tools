Ear Training: Identify Intervals, Chords and Scales by Ear

Plays a random interval, chord or scale from a random starting note and asks you to name it, then tracks your accuracy for each type.

Use the tool

Why this tool exists

Ear training is repetition with feedback. Choose intervals, chords or scales, press play, and pick the name from the buttons. Melodic mode plays notes one after another, harmonic mode plays them together.

Sounds are generated with the Web Audio API in equal temperament with A4 at 440 Hz. Your accuracy per type is saved in this browser so you can see which ones to work on; if storage is blocked it still works for the session. The tool needs sound on.

How to use it

  1. Choose intervals, chords or scales.
  2. Press Play a new sound and listen.
  3. Pick the answer; hear it again if needed.
  4. Check the accuracy list.

Frequently asked questions

What is included?

12 intervals, 7 chord types and 6 scales and modes.

Is my progress saved?

In this browser if storage is allowed.

Why triangle waves?

They are softer than square waves; you can change the sound.

Can I use headphones?

Yes.
