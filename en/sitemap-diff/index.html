Sitemap Diff (Added, Removed, Changed URLs)

Compares an old and a new sitemap and lists what was added, removed and changed.

Use the tool

Why this tool exists

After a migration or redesign you want to know which URLs came or went. Eyeballing two big XML files does not work.

Paste two sitemaps, or one sitemap and a plain URL list from a crawl, logs or an archive export, and the tool shows the difference. That second use finds pages missing from the sitemap. It only compares text you paste.

How to use it

  1. Paste the old sitemap or URL list in the first box.
  2. Paste the new one in the second box.
  3. Tick the option to ignore trailing slashes if needed.
  4. Review added, removed and changed lists.

Frequently asked questions

Can I compare a sitemap to a URL list?

Yes. Plain lists work as either side.

What counts as changed?

A different lastmod, changefreq, priority or image count for the same URL.

Does it fetch archives?

No. Paste the list yourself.

Are URLs normalised?

Only if you tick the option for trailing slash and host case.
