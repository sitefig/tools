Palindrome Checker

Checks each line of text and marks it YES or NO depending on whether it reads the same backwards. Strict mode keeps case, spaces and punctuation in the comparison.

Use the tool

Why this tool exists

Palindromes pop up in programming interviews, word puzzles, school exercises and naming games. The famous phrase examples only work once you throw away punctuation and spaces, which is exactly the step people forget when testing them by hand or in a quick script.

Paste several candidates, one per line, and each gets its own verdict. The default mode compares only letters and digits, ignoring case and accents, so "A man, a plan, a canal: Panama" passes. Strict mode compares every character as typed, which is closer to what a coding exercise usually asks for. Nothing leaves your browser, so you can test answers for a puzzle or assignment privately.

How to use it

  1. Enter a word or phrase on each line.
  2. Tick Strict if case, spaces and punctuation must also match.
  3. Read the YES or NO verdict printed in front of each line.
  4. Copy the results if you need them elsewhere.

Frequently asked questions

What does the normal mode ignore?

Case, spaces, punctuation and accents. Only letters and digits are compared, so "No lemon, no melon" is a palindrome. Empty lines are skipped.

What changes in strict mode?

Every character counts, including capital letters, spaces and punctuation, so "Racecar" fails because R and r differ. Emoji and combined characters are treated as single units rather than being split.

Is a single letter a palindrome?

Yes, a single letter or digit reads the same both ways and is reported as YES. A line with no letters or digits left after cleaning is reported as NO.

Can I check many lines at once?

Yes. Each non-empty line is judged separately and the result keeps your original text next to the verdict, so you can paste a long list and scan down it.
