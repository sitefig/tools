QR Code Reader: Decode a QR Image in Your Browser

Scan a QR code from an image file without uploading it or using a phone.

Use the tool

Why this tool exists

The decoder is written from scratch: it thresholds the image adaptively, finds the three finder patterns by their 1:1:3:1:1 run ratios, estimates the grid and samples modules (rotated and inverted codes are handled), reads the format information, removes the mask, de-interleaves the blocks, repairs damaged codewords with Reed-Solomon error correction and decodes numeric, alphanumeric, byte (UTF-8 or Latin-1), ECI and Kanji segments. It was tested against codes produced by an independent encoder (zxing-cpp) at all four correction levels, versions 1 to 30+, rotations, blur, noise, JPEG compression and deliberate damage.

It reads one code per image and assumes little perspective distortion: photos taken at a steep angle may fail. Always check a decoded web address before opening it, because QR codes are used for phishing.

The file is read in your browser and is not uploaded anywhere.

How to use it

  1. Choose an image with a QR code.
  2. Read the decoded text and the code details.
  3. Check URLs before opening them.
  4. Try a sharper, straighter or larger image if it fails.

Frequently asked questions

Does it use the camera?

No, it reads image files.

Why did it fail?

Steep perspective, glare, a cropped quiet zone or a very small code can prevent detection.

Which codes are supported?

QR Code (Model 2) only, not Data Matrix or barcodes.

Is my data sent anywhere?

The file is read in your browser and is not uploaded anywhere.
