PDF Grayscale Converter

Adds a gray layer in the Saturation blend mode to each page, so colors drop out and brightness stays. Text and vector art remain sharp and searchable.

Use the tool

Why this tool exists

Printing a color document in black and white saves ink, and gray often reads better than a printer's own conversion of red or green text. Rasterising every page would do it but turns text into pictures. Painting a full-page gray rectangle with the PDF Saturation blend mode removes the saturation of everything below it and keeps its brightness.

We checked a rendered page: the original had strong colors and the converted page had zero spread between its red, green and blue channels. The limits are stated plainly. The color data is still in the file, so the size does not shrink, and old RIPs or print workflows that flatten transparency may ignore the effect. For strict black-and-white printing, also use your printer's gray setting.

How to use it

  1. Choose a color PDF.
  2. Press Run.
  3. Download the grayscale PDF.
  4. Check it in your viewer before printing.

Frequently asked questions

Does the file get smaller?

No. The original color data stays; only a gray layer is added.

Is the text still selectable?

Yes. Nothing is rasterised.

Will every printer respect it?

Modern viewers and printer drivers do. A few older print systems ignore transparency blend modes.

Can I get true gray color data?

Not with this method. A desktop tool that converts colors in place is needed for that.
