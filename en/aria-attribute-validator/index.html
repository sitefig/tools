ARIA Validator: Roles, States, Properties and Required Attributes

Validates roles and aria-* attributes in HTML against WAI-ARIA 1.2.

Use the tool

Why this tool exists

ARIA used wrongly is worse than none. Many mistakes are typos or attributes a role does not allow.

The data comes from the WAI-ARIA 1.2 Recommendation of 6 June 2023: roles, supported and required attributes with inheritance, value types and prohibited naming. It also checks ID references and aria-hidden on focusable elements. It does not know which HTML elements may take which role.

How to use it

  1. Paste the HTML.
  2. Fix errors first.
  3. Treat review items as hints; scripts may satisfy them later.
  4. Prefer native elements where you can.

Frequently asked questions

Which version of ARIA?

1.2. Newer draft attributes are noted as info.

Does it check DPUB roles?

No. doc- and graphics- roles are noted but not checked.

Why is a role flagged as redundant?

The element already has that role, for example role="button" on a button.

Is the HTML uploaded?

No.
