Handwriting Tracing Worksheet Maker (Dotted Letters, Printable)

Creates a printable handwriting worksheet with dotted letters to trace on baseline and midline guides, followed by blank practice lines.

Use the tool

Why this tool exists

Children learn letter shapes by tracing before writing alone. Enter the letters or words to practice and the sheet shows each line as dotted outlines on ruled guide lines, with empty lines below to copy it.

The letters use the sans-serif, serif or monospace font of your device, because a school-style font cannot be assumed. Use the size setting to make the letters bigger for young writers. Print the sheet or save it as a PDF from your browser.

How to use it

  1. Type one line of text per row to trace.
  2. Choose a letter style, size and the number of blank rows.
  3. Check the preview.
  4. Print or save as PDF.

Frequently asked questions

Can I get a school handwriting font?

No fonts are loaded, so only the system fonts are used.

How many lines fit?

Up to 14 lines.

Can I use other alphabets?

Yes, if your device has a font for them.

Is anything uploaded?

No.
