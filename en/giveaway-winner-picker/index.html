Giveaway Winner Picker (with Backups and Audit Hash)

Draw winners and backup winners from a list of entrants, remove duplicates, and keep a hash of the list so the draw can be shown to be fair.

Use the tool

Why this tool exists

A giveaway needs a draw people can trust. Duplicate entries, excluded accounts and the question 'was it fair?' cause most of the trouble.

This tool removes duplicates, drops names you exclude, draws winners and ordered backups, and prints the SHA-256 of the cleaned entrant list. With a public seed announced after entries close, anyone can repeat the draw and get the same result. Without a seed it uses secure random numbers. Check the rules of the platform and your country before running a giveaway.

How to use it

  1. Paste the entrants, one per line.
  2. Optionally paste names to exclude, such as staff.
  3. Set the number of winners and backups, and a seed if you want a repeatable draw.
  4. Publish the list hash, the seed and the result.

Frequently asked questions

What does the hash prove?

That the list used is the same one you later publish. Anyone can hash the cleaned list and compare.

Why announce the seed afterwards?

If the seed is known before entries close, someone could add names until a seed favours them.

Does this follow giveaway law?

It only draws names. Platform rules and local law differ, so check them yourself.
