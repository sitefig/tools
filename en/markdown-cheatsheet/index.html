Markdown Cheatsheet

A one-page reference for common Markdown syntax. Each row shows the element, the source you type and how it renders, covering headings, emphasis, links, lists, code, tables and more.

Use the tool

Why this tool exists

Most people know a handful of Markdown rules and forget the rest the moment they need them. How do you write a task list, add a title to a link, or make a table align right? Searching returns long guides when you want a quick answer.

This cheatsheet is a single table. The middle column shows exactly what to type and the right column shows what you get, rendered by the same converter used in the Markdown to HTML tool. It covers headings, bold, italic, strikethrough, inline code, links, images, autolinks, reference links, block quotes, lists, task lists, code fences, rules, tables, line breaks and escapes. It works offline after loading.

How to use it

  1. Open the page and scan the table for the element you need.
  2. Copy the syntax from the middle column.
  3. Compare the rendered result in the right column.
  4. Try your own text in the Markdown preview tool.

Frequently asked questions

Which Markdown flavour does it show?

CommonMark with common GitHub extensions: tables, task lists and strikethrough. Platform-specific extras, such as footnotes, emoji shortcodes or callout blocks, are not covered because they differ between sites.

Why does my Markdown look different on another site?

Markdown has several dialects. Details like line breaks, nested list indentation and raw HTML handling vary, so a document can render differently in a forum, a wiki or a static site generator.

How do I show a literal asterisk or backtick?

Put a backslash in front of it, as in the Escape row of the table. Inside inline code you can also wrap the code in a longer run of backticks.

Can I edit the examples?

Not on this page. To experiment, paste the syntax into the Markdown preview tool and change it there.
