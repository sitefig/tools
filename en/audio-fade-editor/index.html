Audio Fade In and Fade Out Editor

Applies a fade at the start and a fade at the end of an audio file, with a choice of curve, and saves the result as WAV.

Use the tool

Why this tool exists

A hard start or stop makes clicks, and a song that ends mid-note sounds unfinished. A fade fixes both. The shape matters: a straight line in amplitude sounds as if it drops late, while a logarithmic curve sounds even because the ear judges level on a log scale.

Pick linear for sound effects, cosine for a smooth S-shape, equal power when blending clips, and logarithmic for natural music fades. The fade lengths are in seconds and the file length does not change.

How to use it

  1. Choose an audio file.
  2. Enter the fade-in and fade-out lengths in seconds.
  3. Pick a curve.
  4. Press Run and download the WAV.

Frequently asked questions

Which curve sounds most natural?

Logarithmic for music endings. It starts at -40 dB and rises evenly to the ear.

Can I fade only one end?

Yes, set the other length to 0.

Does the file get shorter?

No. The fades happen inside the existing length.

What about crossfades?

Use the audio joiner, which overlaps two clips with an equal-power crossfade.
