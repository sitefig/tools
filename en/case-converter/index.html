Case Converter

Convert text between UPPER, lower, Title, Sentence, camelCase, PascalCase, snake_case, kebab-case, CONSTANT_CASE, dot.case and aLtErNaTiNg case, or see all of them at once.

Use the tool

Why this tool exists

Developers rename variables between conventions, editors fix headings typed in capitals, and writers need title case that skips small words like "of" and "the". Retyping or fixing by hand is tedious and error prone, and a word processor only covers upper, lower and title case.

This converter handles all of them. For the identifier styles, camel, Pascal, snake, kebab, constant and dot case, each line is converted separately, so you can paste a list of names. The tool splits words on spaces, punctuation, underscores and changes in capitalisation. Title case leaves short words in lower case, except at the start and end. Choose one style or all, to compare the results. Conversion happens in your browser.

How to use it

  1. Paste your text into the input box.
  2. Pick the target case in the options, or leave it on all to see every style.
  3. Run the tool.
  4. Copy the version you need.

Frequently asked questions

Are identifiers converted line by line?

Yes. For camel, Pascal, snake, kebab, constant and dot case, each line becomes one identifier. For the other styles the text is converted as a whole.

How does title case treat small words?

Words such as a, of and the stay lower case unless they are the first or last word. Style guides vary, so check the result against the guide you follow.

What happens to accents and non-English letters?

Letters from any script are handled using Unicode rules, so accented characters change case correctly. Camel and snake style splitting works best with Latin text.

Is my text uploaded?

No. The text is processed in your browser and is not uploaded, stored or sent to a server, so it is fine to use with drafts, lists and private notes.
