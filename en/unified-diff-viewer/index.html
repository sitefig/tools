Git Diff Viewer: Unified Diff or Patch Side by Side

Renders unified diffs and .patch files as side-by-side columns or a single unified view, with line numbers and an added and removed count.

Use the tool

Why this tool exists

Raw diff text is hard to read once a change touches many lines. A side-by-side view shows the old and new line next to each other so you can review quickly, for example a patch someone sent by email.

The parser reads git diff, git show and plain unified diffs. It pairs removed and added lines inside a hunk. It does not recompute the diff, so what you see is exactly what the patch says. Word-level highlights are not drawn; use the two-text diff tools for that.

How to use it

  1. Paste the output of git diff, git show or a .patch file.
  2. Choose side by side or unified layout.
  3. Scroll through the files and hunks.
  4. Check the status line for the number of added and removed lines.

Frequently asked questions

Which formats work?

Unified diffs as made by git diff, git show, git format-patch and diff -u. Context diffs and binary patches are not supported.

Does it show word-level changes?

No. It shows whole-line changes. For inline word highlights use the text diff tools on this site.

Are the counts right?

They were compared with git diff --numstat on a test repository and matched.

Is the patch uploaded?

No. It is parsed and shown in your browser.
