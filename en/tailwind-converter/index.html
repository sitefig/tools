CSS to Tailwind Converter

Turns CSS declarations into Tailwind utility classes, with an arbitrary-value fallback for anything unusual, and converts common Tailwind classes back into plain CSS.

Use the tool

Why this tool exists

Moving an existing stylesheet to Tailwind means translating each declaration into a utility name: padding 8px 16px becomes py-2 px-4, font-size 18px becomes text-lg. Looking each one up in the documentation is slow, and going the other way, reading a long class list to work out the CSS, is just as tedious.

Paste declarations, with or without a selector block, to get the equivalent classes. About eighty common properties are mapped, and values that do not match the default scale fall back to arbitrary values in square brackets, so nothing is silently dropped. In reverse mode, paste classes to get CSS. Variants, palette colours and unsupported classes are listed as not converted. It uses the default Tailwind scale and runs in your browser.

How to use it

  1. Choose a direction: css-to-tailwind or tailwind-to-css.
  2. Paste CSS declarations or a list of Tailwind classes.
  3. Read the generated class attribute or CSS.
  4. Review any items flagged as not converted.

Frequently asked questions

What happens to values Tailwind does not have?

They become arbitrary values such as w-[137px] or [transition:opacity_0.2s]. The result is valid Tailwind, but you might prefer to add a value to your theme instead.

Which Tailwind features are not reversed?

Variants such as hover: and md:, palette colours such as blue-500, and anything outside the supported subset are reported as not converted. Only a core set of utilities, spacing, sizing and arbitrary values are handled.

Does it assume the default theme?

Yes. Spacing, font sizes, radii and so on follow the default Tailwind scale, with 1 spacing unit equal to 4 pixels and rem values treated as 16 pixels. A customised theme may differ.

Can I paste a whole rule with a selector?

Yes. If the input contains braces, the declarations inside each block are collected and converted together. Comments are removed first. Selectors are ignored.

Tools often used together

  • CSS box-shadow to Tailwind ClassConvert a CSS box-shadow value (including multiple layers, inset, rgba / hex colours) to a Tailwind arbitrary-value class (shadow-[0_4px_6px_-1px_rgba(0,0,0,0.1)]) and detect when it exactly equals a built-in preset of Tailwind v3 or v4 (shadow-md, shadow-lg, ...). Also gives the theme extension for tailwind.config.js and the v4 @theme variable.
  • Tailwind Classes to Inline CSS (HTML, subset)Convert Tailwind utility classes in HTML class="..." attributes into inline style="..." attributes (useful for HTML email and embeds). Supported subset: display, position, flexbox / grid basics, spacing (p, m, gap, inset, negative, arbitrary [..] values), width / height, typography, borders, radius, shadows, opacity, black / white / transparent / arbitrary colours and common layout helpers. NOT supported: the Tailwind colour palette (e.g. blue-500), responsive and state variants (md:, hover:), dark mode, space-x / divide: those classes are kept in the class attribute and listed.
  • Tailwind CSS v3 to v4 MigratorRewrite class names and CSS directives for the Tailwind v4 upgrade: renamed utilities (shadow -> shadow-sm, rounded -> rounded-sm, blur, ring -> ring-3, outline-none -> outline-hidden, bg-gradient-to-* -> bg-linear-to-*, flex-shrink/grow -> shrink/grow), the important modifier moved to the end (!flex -> flex!), @tailwind directives -> @import "tailwindcss", @layer utilities -> @utility, and a report of changes that cannot be automated (opacity utilities, default border colour, config file). Paste HTML, JSX or CSS; based on the official upgrade guide, so review the diff.
  • Tailwind Spacing Scale GeneratorGenerate a custom spacing scale for Tailwind: choose a base unit (4px grid, 8pt grid, or any), a linear, doubling, modular (ratio) or Fibonacci progression, and get Tailwind v4 @theme variables, a v3 theme.extend.spacing block, plain CSS custom properties and a px / rem table.
  • Tailwind Class SorterSort Tailwind CSS utility classes into the conventional order (layout, box model, typography, effects ... with variants like hover:/md:/dark: after base classes), similar to prettier-plugin-tailwindcss. Hand-written approximation of the official ordering: unknown/custom classes come first, results can differ in rare edge cases.
  • CSS to SCSS ConverterConvert plain CSS to nested SCSS: selectors that extend an earlier selector (descendant, child, sibling, :hover / ::after pseudo, .class, [attr]) are nested with & where appropriate, @media / @supports blocks are kept, and colours used two or more times can be pulled into $color-N variables. Comma-separated selector lists are left untouched. Review the result: nesting depends on rule order.
