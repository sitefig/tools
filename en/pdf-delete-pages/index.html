Delete PDF Pages

Enter the pages to remove, such as 2,4-6, and download a new PDF without them. The rest stays exactly as it was.

Use the tool

Why this tool exists

A blank page at the end of a scan, a cover sheet that should not be shared or an outdated appendix: removing pages is one of the most common PDF edits. Opening a full editor for it, or uploading a confidential file to a web service, is more than the task deserves.

This tool drops the pages you list and keeps all the others in their original order, without re-rendering them. The list can mix single pages and ranges, and open-ended ranges like 7- remove everything from page seven onwards. It will not let you delete every page. If you know exactly which pages to keep instead, the Extract PDF Pages tool is quicker. Encrypted files are refused, and bookmarks and form fields are not carried over. Processing happens in your browser.

How to use it

  1. Choose a PDF file.
  2. Enter the pages to delete, for example 2,4-6.
  3. Run the tool.
  4. Check the new page count and download the file.

Frequently asked questions

Can I delete the last page without knowing the count?

Use an open-ended range. Typing 7- removes page seven and all following pages. To remove just the last page, check the page count first with the page count tool.

Does deleting pages shrink the file?

Usually yes, because unused images, fonts and content are not copied into the new file. The saving depends on how much those pages contained.

Is the content really removed?

The new file does not contain the deleted pages or anything only they used. The original file on your device is unchanged, so keep a backup before sharing the edited one.

What if I list every page?

A PDF needs at least one page, so the tool shows an error instead of producing an empty file. Adjust the list so at least one page remains.
