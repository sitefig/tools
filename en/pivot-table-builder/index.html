Pivot Table Builder (Rows, Columns, Sum, Count, Average)

Builds a pivot table from a CSV: choose the row field, an optional column field and the value to summarise.

Use the tool

Why this tool exists

A pivot answers questions like revenue by region and product in one table. Instead of dragging fields, you type their names, which works with a keyboard and is easy to repeat.

Values that are not numbers are skipped and counted, except with count. Totals are added for rows and columns; averages in the total cells are averages of all values, not of the cells shown. For several measures run the tool once per measure.

How to use it

  1. Paste the CSV with a header.
  2. Type the row field, column field (optional) and the value field.
  3. Choose sum, count, average, min or max.
  4. Copy or download the pivot as CSV.

Frequently asked questions

Can I use two row fields?

Not yet. Merge the two columns first with the column merger.

What is in empty cells?

Combinations with no rows are left empty.

Are totals averages of averages?

No. They are computed over all underlying values.

Large tables?

It is held in memory; tens of thousands of rows are fine.
