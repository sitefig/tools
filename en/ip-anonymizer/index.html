IP Address Anonymizer (Truncate IPv4 and IPv6)

Truncates every IPv4 and IPv6 address in your text to a prefix you choose and leaves the rest of the line unchanged.

Use the tool

Why this tool exists

Server logs, analytics exports and support tickets often hold full IP addresses. Cutting the last part is a common way to reduce what you keep, for example the last octet of IPv4 and the last 80 bits of IPv6.

This tool finds addresses in any text, including whole log lines, and zeroes the host bits. It handles compressed IPv6 and IPv4-mapped addresses. The results were checked against Python's ipaddress module on random addresses. A truncated address can still be personal data in some cases, so treat this as one step in a retention plan.

How to use it

  1. Paste addresses or log lines.
  2. Choose how many bits to keep for IPv4 (default 24) and IPv6 (default 48).
  3. Run it and copy the result.
  4. Use the result for storage, and delete the originals.

Frequently asked questions

What do the defaults mean?

/24 for IPv4 and /48 for IPv6. Pick what your policy and risk review say.

Is a truncated IP still personal data?

It can be, for example in a small network. It is much less identifying.

What about version numbers like 1.2.3.4?

They look like IPv4 and are changed too. Check the output.
