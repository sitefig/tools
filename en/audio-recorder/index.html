Voice Recorder (Record Audio to a File)

Capture a quick voice memo without installing an app.

Use the tool

Why this tool exists

The recorder uses the browser's MediaRecorder to capture microphone audio, shows the elapsed time, allows pause and resume, plays the result and offers a download in the format the browser records (usually WebM/Opus, Ogg or M4A). The stream stops when you finish or leave the page.

Browsers choose the format, so the file type varies. Convert it with the audio converter if you need WAV.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Press Start recording and allow the microphone.
  2. Pause or stop when done.
  3. Play it back.
  4. Download the recording.

Frequently asked questions

What format is the file?

Whatever your browser supports; Chrome and Firefox use WebM or Ogg Opus, Safari uses MP4/AAC.

Is there a time limit?

No fixed limit, but long recordings use memory.

Does it work offline?

Yes, once the page is loaded.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
