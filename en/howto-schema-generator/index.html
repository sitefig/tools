HowTo Schema Generator

Builds HowTo markup with steps (name, text, image, URL), tools, supplies and total time, with the duration written in ISO 8601.

Use the tool

Why this tool exists

The tool is honest about the main fact: Google removed how-to rich results in 2023 and no longer shows them. The markup is still valid Schema.org and other software may read it, so the generator stays, but the output says plainly that it gives no Google result.

Times are converted for you: type 15 min or 1h 30m and get PT15M or PT1H30M. Each step line takes a name, the instruction text, and optionally an image and a step URL, separated by vertical bars.

How to use it

  1. Enter the name, description and total time.
  2. Add tool: and supply: lines.
  3. Add one step: line per step: name | text | image | URL.
  4. Copy the script tag if you still want the markup.

Frequently asked questions

Will this give me a rich result?

Not in Google Search. The feature was removed in September 2023.

Why keep generating it?

Valid HowTo data can still help other tools and assistants. Decide for yourself whether it is worth the page weight.

How is total time written?

As an ISO 8601 duration such as PT1H30M, converted from what you type.

Are images required for steps?

No. They are optional.
