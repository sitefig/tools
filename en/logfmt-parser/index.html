Logfmt Parser: key=value Log Lines to JSON or Table

Parses key=value logfmt lines into objects and prints them as JSON, JSON lines, a table or CSV.

Use the tool

Why this tool exists

Logfmt is compact for people but awkward for tools. Converting it to JSON or CSV lets you use jq, spreadsheets or other viewers.

Quoted values with escapes are supported. Numbers and true or false can be converted to types. Words without an equals sign are ignored unless you ask to keep them.

How to use it

  1. Paste logfmt lines or choose a file.
  2. Choose the output format.
  3. Turn typing of numbers on or off.
  4. Copy the result.

Frequently asked questions

Are bare words kept?

Only if you tick the option. They become key=true.

Does it handle a prefix before the pairs?

Words before the first pair are ignored, so syslog-style prefixes do not break it.

Are numbers converted?

By default yes. Long digit strings stay text so IDs are not damaged.

Is my log uploaded?

No. Parsing happens in your browser and nothing is sent. Logs can hold IP addresses and tokens, so the page does not write them into the address bar.
