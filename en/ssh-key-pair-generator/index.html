SSH Key Pair Generator (Ed25519, ECDSA, RSA)

Create an SSH key for servers, Git hosting or CI without installing anything.

Use the tool

Why this tool exists

Pick Ed25519, ECDSA (P-256 or P-384) or RSA (3072 or 4096 bits) and an optional comment. WebCrypto generates the key, and the page writes the public key line, the SHA-256 fingerprint and the private key in the OpenSSH format. All four key types were verified with ssh-keygen -y and ssh-keygen -l, which derived the same public keys and fingerprints.

The private key is not passphrase-protected; add one with ssh-keygen -p. A key made in a web page is only as trustworthy as the page and device, so for high-value keys generate them on the machine that will keep them.

The file is read in your browser and is not uploaded anywhere.

How to use it

  1. Choose the key type and comment.
  2. Copy the public key line and the private key.
  3. Save the private key with permissions 600 and add the public key to authorized_keys.
  4. Protect it with ssh-keygen -p -f FILE.

Frequently asked questions

Which type is best?

Ed25519 is small, fast and widely supported; use RSA 3072+ only for old systems.

Is it safe to generate keys in a browser?

The key is made locally with the browser's crypto, but the safest place for important keys is the device that will use them.

Can I add a passphrase here?

No. Run ssh-keygen -p afterwards.

Is my data sent anywhere?

The file is read in your browser and is not uploaded anywhere.
