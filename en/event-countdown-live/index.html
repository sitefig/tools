Live Event Countdown with Shareable Link

Counts down live to an event in days, hours, minutes and seconds and keeps the settings in the page link so you can share it.

Use the tool

Why this tool exists

Share a launch, trip or exam date with a link that shows the remaining time. The link holds the event name, date and time, nothing else.

The time is read in the viewer's local time zone, so people in other zones see the same wall-clock moment in their own zone.

How to use it

  1. Enter an event name, date and time.
  2. Watch the countdown.
  3. Press Copy share link.

Frequently asked questions

Which time zone is used?

The viewer's own, so a 09:00 event is 09:00 for each viewer.

What happens after the date?

It shows how long ago the event was.

Is anything sent to a server?

No. The link carries the settings in the address.
