HSTS Header Generator with Preload Eligibility Check

Generates the Strict-Transport-Security header and checks max-age, includeSubDomains and preload against the preload list header rules.

Use the tool

Why this tool exists

HSTS tells browsers to use HTTPS only for your site. A long max-age protects returning visitors, includeSubDomains extends it, and preload asks browsers to build the rule in.

This tool writes the header with nginx and Apache lines and says whether the header part of the hstspreload.org rules is met: at least one year, includeSubDomains and preload. The other rules (valid certificate, redirect, all subdomains on HTTPS) cannot be checked from a header. Preload is hard to undo.

How to use it

  1. Set max-age and tick the options.
  2. Copy the header or the server line.
  3. Roll out with a short max-age first, then raise it.
  4. Submit to the preload list only when every subdomain works over HTTPS.

Frequently asked questions

Why start with a short max-age?

A mistake with a long max-age locks visitors out of HTTP for that long.

Can I remove preload later?

It is slow. Removal can take months to reach users.

Does it check my site?

No. It generates a header from your choices.
