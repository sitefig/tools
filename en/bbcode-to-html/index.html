BBCode to HTML Converter with Safe Links and Preview

Converts common BBCode tags to HTML, escaping text and keeping only safe link and image URLs.

Use the tool

Why this tool exists

Old forums and CMS exports store posts as BBCode. Converting them with search and replace is risky, because the text can contain HTML and unsafe URLs.

This converter escapes all text, builds a tree so nested and unclosed tags are handled, keeps only http, https, mailto and ftp links and http or https images, and lists problems such as unclosed tags. Unknown tags stay as literal text. Output links get rel="nofollow ugc".

How to use it

  1. Paste the BBCode.
  2. Review the preview and the notes comment.
  3. Copy the HTML.
  4. Fix unclosed tags in the source if the notes list any.

Frequently asked questions

Which tags work?

b, i, u, s, url, email, img, quote, code, list with [*], color, size, center, left, right.

Are javascript: links removed?

Yes. The link is dropped and the text kept.

Can it go the other way?

Use the BBCode to Markdown tool, or Markdown to BBCode.

Tools often used together

  • BBCode to MarkdownConvert forum BBCode to Markdown: [b] [i] [s] [u] (as HTML <u>), [url], [img], [quote], [code], [list] with [*] items (bullet or numbered), [size] / [color] / [center] wrappers (dropped, content kept) and [hr]. Unknown tags are left as-is.
  • Markdown to BBCodeConvert Markdown to BBCode for forums (phpBB, vBulletin, XenForo...): headings -> [size][b], bold / italic / strikethrough, links, images, inline and fenced code -> [code], block quotes -> [quote], bullet and numbered lists -> [list][*], horizontal rules. Tables and raw HTML are passed through as text.
  • HTML Tag StripperRemove tags, scripts, styles and comments; decode entities.
  • HTML Sanitizer: Strip Scripts, Event Handlers and Unsafe URLsClean untrusted HTML with a strict allow-list: scripts, styles, forms, event handlers and javascript: URLs are removed, and every removal is listed with its line number.
  • Markdown to HTMLCommonMark/GFM-style converter: tables, task lists, fences, nested lists. HTML is escaped by default.
  • HTML to MarkdownConvert HTML (headings, lists, tables, links, code) to Markdown using the browser parser.
