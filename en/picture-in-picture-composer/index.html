Picture-in-Picture Composer: Put One Video Inside Another

Overlays a second video in a corner of a main video. Choose the corner, width, margin and border colour.

Use the tool

Why this tool exists

A webcam clip over a screen recording is the classic use. Both videos play together and are recorded as one. The main video sets the length and the inset disappears when it ends.

Nothing is uploaded. The file is decoded by your browser and re-encoded, so quality drops a little and the result is WebM (or MP4 where your browser can record it). It records in real time, so a 60 second clip takes about a minute and the tab must stay visible. The inset sound is muted by default so it does not clash with the main audio.

How to use it

  1. Choose the main video and the inset video.
  2. Pick the corner, size, margin and border.
  3. Set the inset volume if you want it audible.
  4. Process and download.

Frequently asked questions

How do I sync the two videos?

They start together. Trim either one first with the Video Trimmer if they need an offset.

Can I use a webcam recording?

Yes, record it with the Webcam Recorder, then use the file here.

What if the inset is longer?

It stops when the main video ends.

Is the inset round?

No, it is a rectangle with an optional border.
