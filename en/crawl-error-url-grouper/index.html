Crawl Error URL Grouper: Find Patterns in 404 and Error URL Lists

Paste a list of error URLs and see them grouped by pattern (digits and slugs replaced), folder, file type, query parameter names or reason. The biggest group shows what to fix first.

Use the tool

Why this tool exists

A list of 3,000 404 URLs is rarely 3,000 problems. It is usually a handful of causes: a deleted section, a changed URL pattern or a broken link template. Grouping shows them.

The default pattern view replaces numbers with {n}, long hex or UUID values with {id} and hyphenated words with {slug}, so /products/12345 and /products/12399 become one group. It is a grouping aid. It does not check whether the URLs really return errors.

How to use it

  1. Paste URLs, each optionally followed by a reason or status.
  2. Choose how to group.
  3. Start with the largest group.
  4. Redirect, fix the link or return 410 depending on the cause.

Frequently asked questions

What formats work?

A plain URL list, or lines with a URL plus text such as a status or a Search Console reason.

What is a pattern?

The path with variable parts replaced, so similar URLs share one label.

Should I redirect every 404?

No. Redirect when a close replacement exists. Let truly removed pages stay 404 or 410.

Does it work with Search Console exports?

Yes, paste the URL column, optionally with the reason.
