Remove Duplicate Lines

Paste a list and remove repeated lines, keep only lines that occur once, or list only the lines that appear more than once. Case and surrounding spaces are optional to ignore.

Use the tool

Why this tool exists

Mailing lists, keyword exports, log excerpts and URL lists all pick up duplicates. Removing them by hand is slow, and spreadsheets need several steps to do it. Sometimes you want the opposite: just the lines that repeat, to see what is being duplicated.

This tool has three modes. Keep first removes later copies and leaves each line once in its original order. Only unique drops every line that appears more than once. Only duplicates shows each repeated line once. You choose whether comparison is case sensitive and whether to ignore spaces around lines, which is on by default. The original line, not the trimmed one, is kept in the output. It runs in your browser.

How to use it

  1. Paste your list into the input box, one item per line.
  2. Choose the mode: keep first, only unique or only duplicates.
  3. Set case sensitivity and whether to ignore surrounding spaces.
  4. Run the tool and copy the result.

Frequently asked questions

Which copy is kept in keep first mode?

The first occurrence of each line, in its original position and exact form, including its original spacing and capitalisation. Later matches are removed.

What is the difference between only unique and keep first?

Keep first keeps one copy of every line. Only unique keeps only lines that were never repeated, so anything that had duplicates disappears completely.

How do I count how many times each line occurs?

Use the duplicate line counter tool on this site, which reports how many times each line occurs. This tool only filters lines and does not show any counts.

Is my list uploaded?

No. The text is processed in your browser and is not uploaded, stored or sent to a server, so it is fine to use with drafts, lists and private notes.
