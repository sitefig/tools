Permissions-Policy Header Generator

Writes a Permissions-Policy header from the features you want to disable and allow, with nginx and Apache lines.

Use the tool

Why this tool exists

A Permissions-Policy header lets your page and its iframes use only the browser features you allow. Switching off camera, microphone, geolocation and similar features you do not need limits the damage if a script or an embed misbehaves.

List the features to disable and, if needed, the ones to allow for your own origin or named origins. The tool checks names against the directive list on MDN as read on 23 October 2026 and warns about names it does not know. Browser support differs by feature.

How to use it

  1. List features to disable, one per line.
  2. Add allowed features as feature = self https://origin.
  3. Copy the header or the server line.
  4. Test your pages to see nothing needed was blocked.

Frequently asked questions

What does () mean?

No origin may use the feature, including your own page.

Does it replace Feature-Policy?

Yes. Feature-Policy is the old name and is obsolete.

Why do I see an unknown name warning?

The name is not in the MDN list read on 23 October 2026. It may be new, experimental or a typo.
