Prompt Injection Scanner (Untrusted Text Check)

Check text you are about to feed to an AI assistant for the usual tricks used to hijack it.

Use the tool

Why this tool exists

The scanner looks for phrases that override instructions, ask for the system prompt, assign a new persona, imitate chat delimiters (<system>, [INST]), embed markdown images or links that carry data to another site, tell the model to hide actions from the user, lure it into dangerous tool calls, encode instructions, and for invisible Unicode tag characters and zero-width controls. It gives a risk level and the matched text.

This catches only well-known phrasings. Injection can be paraphrased, translated or hidden in images, so a clean result proves nothing. Real defences are architectural: treat model output as untrusted, restrict tool permissions and require confirmation for sensitive actions.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Paste the untrusted text.
  2. Run the scan.
  3. Review each match; remove or quarantine the content.
  4. Apply least privilege to any tools the model can call.

Frequently asked questions

What is prompt injection?

Text that tries to make a model follow the attacker's instructions instead of yours, often hidden in documents or web pages the model reads.

Can this prevent it?

No. It is a heuristic check; prevention needs design changes.

Why flag hidden Unicode?

Characters in the tag block are invisible to people but can be read by models.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
