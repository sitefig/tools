Base85 Converter: Ascii85 and Z85 Encode and Decode

Converts text or hex bytes to Ascii85 or Z85 and back.

Use the tool

Why this tool exists

Base85 packs four bytes into five characters, so it is about 25 percent bigger than the data, against 33 percent for Base64. Ascii85 appears in PostScript and PDF streams. Z85 is a variant from ZeroMQ that avoids quotes and backslashes so it can sit in source code.

Ascii85 handles any length and uses z for four zero bytes. Z85 needs a multiple of four bytes and has no padding. The tool checks both rules and tells you when input breaks them.

How to use it

  1. Choose encode or decode and the variant.
  2. Paste text, or switch the plain side to hex bytes for binary data.
  3. Tick the delimiter option if you need <~ and ~> around Ascii85.
  4. Copy the result.

Frequently asked questions

Which variant should I use?

Ascii85 for PDF and PostScript data. Z85 only when a ZeroMQ-style system asks for it.

Why does Z85 refuse my text?

Z85 works on blocks of four bytes. Pad your data to a multiple of four.

Is this RFC 1924 Base85?

No. RFC 1924 and Python's b85 use another alphabet.

Is my input sent anywhere?

No. Everything runs in your browser and nothing is uploaded.
