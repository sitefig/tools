Duplicate Photo Finder (Group Visually Similar Photos)

Find groups of photos that look alike.

Use the tool

Why this tool exists

Select many photos (use Select All in the file dialog for a folder). The page hashes each one and groups the ones within your distance threshold, then marks the largest in each group as the one to keep.

Nothing is deleted or changed. Groups are built by chaining, so a long chain of small changes can join pictures that are not close to each other. Review each group.

How to use it

  1. Select the photos.
  2. Pick the hash and threshold.
  3. Read the groups.
  4. Decide yourself which to keep.

Frequently asked questions

Can it pick a folder?

Browsers let you select all files in a folder in the file dialog. This page uses that, not a folder picker.

How many photos can it handle?

Up to 600 at once.

Will it delete anything?

No. It only lists groups.

Is anything uploaded?

No. The work happens in your browser and the page makes no network request with your input.
