Protobuf Raw Decoder (Wire Format Without a Schema)

Reads the protobuf wire format and prints each field with its number, wire type and a guess at the value.

Use the tool

Why this tool exists

Protobuf data carries field numbers and wire types but no names. When you only have captured bytes, you can still read a lot from them: varints, fixed numbers, strings and nested messages.

The tool shows each field with several readings, such as unsigned and zigzag for varints, and decides between string, nested message and raw bytes by testing the content. These are guesses. A varint may be an enum or a bool, and a nested message may also be valid text.

How to use it

  1. Paste the bytes as hex or Base64.
  2. Leave the input type on auto, or force one.
  3. Read the field tree.
  4. Compare the guesses with your .proto file if you have one.

Frequently asked questions

Why is a field shown as a string and as a message?

Some bytes are valid in both readings. The tool notes it.

Are groups supported?

No. Wire types 3 and 4 are deprecated and give an error.

Can it decode gRPC frames?

Remove the 5-byte frame header first.

Is my input sent anywhere?

No. Everything runs in your browser and nothing is uploaded.
