MessagePack & CBOR Decoder / Encoder

Inspect binary payloads from APIs, queues and IoT devices without writing code.

Use the tool

Why this tool exists

Paste hex (with or without spaces or 0x) or base64 and choose MessagePack or CBOR. The decoder handles integers of all sizes, floats (including CBOR half precision), strings, binary, arrays, maps, extension types, CBOR tags and indefinite-length items. Byte strings appear as {"$binary"/"$bytes": hex}. The encoder turns JSON into the shortest standard encodings.

Both directions were cross-checked with the @msgpack/msgpack and cbor-x libraries. Values beyond JSON, such as big integers and undefined, appear as small marker objects.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Choose the format and direction.
  2. Paste hex, base64 or JSON.
  3. Read the decoded JSON or copy the encoded hex.
  4. Compare sizes with the JSON text.

Frequently asked questions

How do I know which format it is?

MessagePack maps start with 0x80-0x8f or 0xde/0xdf; CBOR maps with 0xa0-0xbf. Try both if unsure.

What are $ext and $tag?

Markers for MessagePack extension types and CBOR tags, which JSON cannot express.

Are Date objects supported?

Timestamp extensions appear as ext/tag objects; they are not converted to dates.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
