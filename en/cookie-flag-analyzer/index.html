Cookie Flag Analyzer

Paste Set-Cookie header lines to check the Secure, HttpOnly and SameSite flags, __Host- and __Secure- prefix rules, lifetime, scope and known tracking cookies.

Use the tool

Why this tool exists

Cookie flags decide whether a stolen script, a network eavesdropper or another site can reach a session cookie. A missing HttpOnly lets injected JavaScript read it, a missing Secure sends it over plain HTTP, and a loose SameSite setting invites cross-site request abuse. These mistakes are easy to make and hard to see in the browser.

This analyser parses each Set-Cookie line you paste, lists its flags and attributes and reports issues ranked from high to low severity. It checks the rules for cookie name prefixes, long lifetimes and broad Domain scope, and recognises common tracking cookies. Values are shortened in the output. You can say whether the site uses HTTPS, as some checks depend on it. Everything runs locally.

How to use it

  1. Copy the Set-Cookie header lines from your browser developer tools or from curl output.
  2. Paste them into the input box, one per line.
  3. Tick or untick the option that says the site is served over HTTPS.
  4. Run the tool and fix the high-severity issues first.

Frequently asked questions

What does each flag protect against?

Secure keeps the cookie off plain HTTP, HttpOnly hides it from JavaScript, and SameSite limits sending it on cross-site requests. Together they reduce theft and request forgery risks.

What are the __Host- and __Secure- prefixes?

They are name prefixes that browsers enforce. __Secure- requires the Secure flag. __Host- also requires Path=/ and no Domain attribute, which locks the cookie to the exact host.

Does it need the Cookie header too?

No. It reads Set-Cookie response headers only, the lines that create or update cookies. Request Cookie headers contain no flags, so there is nothing to check in them.

Are my cookies uploaded?

No. The text is analysed in your browser and not sent anywhere. Even so, do not paste live session cookies you still use.
