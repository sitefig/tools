Sitemap Priority and Changefreq Distribution

Counts priority and changefreq values and draws them as bars.

Use the tool

Why this tool exists

If every URL has priority 0.5 or the same changefreq, the values say nothing. Google ignores both anyway, but other tools and engines may read them.

The chart makes a flat distribution obvious. Use it as a quick audit of what a CMS plugin wrote.

How to use it

  1. Paste the sitemap XML.
  2. Run the tool.
  3. Read the two charts.
  4. Decide whether to set real values or drop the fields.

Frequently asked questions

Does Google use priority?

Google states it ignores priority and changefreq.

Why check then?

Other consumers of the file may use them, and defaults show a lazy generator.

Is the chart an image?

No, it is text bars you can copy.

Are missing values counted?

Yes, as (none).
