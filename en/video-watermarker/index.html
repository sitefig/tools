Video Watermarker: Add a Logo or Text Overlay

Overlays text or an image logo on every frame of a video. You set the corner, size, opacity and margin.

Use the tool

Why this tool exists

A watermark discourages casual reuse and brands your clips. The overlay is drawn on each frame as the video is recorded, so it becomes part of the picture.

Nothing is uploaded. The file is decoded by your browser and re-encoded, so quality drops a little and the result is WebM (or MP4 where your browser can record it). It records in real time, so a 60 second clip takes about a minute and the tab must stay visible. A visible watermark can be cropped out, so it is a deterrent, not protection.

How to use it

  1. Choose the video.
  2. Type the watermark text or choose a logo image (the logo wins if both are set).
  3. Set position, size and opacity.
  4. Process and download.

Frequently asked questions

Which image formats work for a logo?

Any your browser can open: PNG, JPG, WebP, SVG. Use a transparent PNG for best results.

Can the watermark be removed?

Not easily, but a determined person can crop or paint over it.

Can I animate it?

No. It stays in one place.

Does it work on images too?

Use the Image Watermark tool for pictures.
