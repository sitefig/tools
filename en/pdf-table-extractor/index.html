PDF Table Extractor to CSV

Looks at where text sits on each page, finds blocks of rows with several cells, works out the columns from the gaps between them and writes each table as a CSV file.

Use the tool

Why this tool exists

Copying a table out of a PDF usually pastes one long column. The PDF has no real table object, only words placed at coordinates, so a tool has to rebuild the structure. This one treats a line with two or more widely separated cells as a table row, joins consecutive rows into a table and takes the empty vertical bands as column boundaries.

It is a heuristic and the page says so. It works well on invoices, statements and data tables with clear spacing. It ignores ruling lines, turns wrapped cells into extra rows and can merge columns under a heading that spans them. Always check the output. Scanned tables need OCR first.

How to use it

  1. Choose a PDF.
  2. Optionally set pages, the cell gap and the smallest table size.
  3. Press Run to see a preview of each table.
  4. Download the CSV files.

Frequently asked questions

No table was found. Why?

The text may be a scan, or the columns may be too close together. Lower the "gap that separates two cells" value, for example to 0.6.

Cells are split in the wrong places.

Raise the cell gap so words in one cell stay together, or lower it to separate close columns.

Does it read tables with borders?

It uses only text positions, so borders do not help or hurt. Cells that wrap onto several lines become separate rows.

Can I open the CSV in a spreadsheet?

Yes. Cells with commas or quotes are escaped as standard CSV.
