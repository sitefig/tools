Alt Text Quality Checker: Filenames, Redundant Words and Missing Alt

Reviews alt text in pasted HTML for common quality problems.

Use the tool

Why this tool exists

Alt text fails in predictable ways: missing, a file name, or a vague word.

The tool checks img, area and image inputs, flags empty alt inside links with no other text, repeated captions, and very long text, and leaves empty alt alone on decorative images. It cannot judge whether the description is right, only whether it looks like a typical mistake.

How to use it

  1. Paste the HTML.
  2. Set the length limit if you want.
  3. Read each finding with its line.
  4. Rewrite alt to say what the image does here.

Frequently asked questions

Is empty alt wrong?

No, it is correct for decorative images. It is an error only when it leaves a link with no name.

Why a 125 character limit?

It is a common rule of thumb, not a WCAG rule. Put long descriptions in the page text.

Does it check SVG or CSS images?

No, only img, area and image inputs.

Is the HTML uploaded?

No.
