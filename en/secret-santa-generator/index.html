Secret Santa Generator (Draw Names With Exclusions)

Run the draw for a gift exchange in seconds, without a website that stores everyone's names.

Use the tool

Why this tool exists

The generator shuffles the list with a secure random source and retries until the result is a valid derangement: every person gives to exactly one person and receives from exactly one, nobody draws themselves and none of your exclusion pairs (such as partners) match in either direction. It tells you when no valid draw exists, for example when the exclusions leave too few options.

The organiser sees the full list unless you untick the option. To keep it secret, send each person only their own line; a draw run again will differ. Names must be unique, so add an initial for two people with the same name.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Enter the names, one per line.
  2. Add exclusions as pairs like Alice-Bob; Carol-Dan.
  3. Run the draw.
  4. Send each person only their own line.

Frequently asked questions

Can someone draw themselves?

No. The tool only accepts draws in which nobody is matched with themselves.

Why does it say no valid draw exists?

Too many exclusions for the group size. With three people, excluding one pair already leaves no valid draw.

Is it truly random?

It uses the browser's secure random numbers and an unbiased shuffle.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
