Mixed Content Finder (http:// in HTTPS Pages)

Finds insecure http:// references in the HTML of an HTTPS page and sorts them by type.

Use the tool

Why this tool exists

When an HTTPS page loads a script, stylesheet or image over plain HTTP, browsers block or warn. Active content such as scripts and iframes is blocked; passive content such as images may be upgraded or flagged.

Paste the page source and the tool lists every http:// reference with its line number, split into active, passive and review items. Plain links are listed separately because they are not mixed content. It reads static HTML only: resources added by scripts are not seen. The best fix is to change the URL to https.

How to use it

  1. Open view-source on your page and copy the HTML.
  2. Paste it into the box.
  3. Fix the active items first, then the passive ones.
  4. Re-test in the browser console for blocked content.

Frequently asked questions

Why are some images only warned about?

Browsers treat images as passive content and may upgrade or warn instead of blocking.

Should I use upgrade-insecure-requests?

It patches the problem but hides it. Fix the URLs.

Why are links separate?

A link to an http page is a navigation, not a subresource load.
