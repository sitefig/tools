Hreflang Matrix Builder (CSV to Tags, Header, Sitemap)

Turns a spreadsheet of page versions into complete hreflang sets, in the format you choose, with an optional x-default taken from one column.

Use the tool

Why this tool exists

On a large site you keep translations in a spreadsheet: each row a page, each column a locale. This tool takes that table as CSV, checks the column codes, requires absolute URLs and builds the full set for every version. A row with a blank cell simply omits that version.

Choose which column should double as x-default, or leave it empty. The sitemap output has one url element per version, each with every alternate, as Google describes.

How to use it

  1. Paste or type the CSV with locale codes in the header row.
  2. Choose the format and the x-default column.
  3. Read the notes for bad codes or short rows.
  4. Copy the output.

Frequently asked questions

Can a page exist in only some locales?

Yes, leave the cell blank. Rows with fewer than two versions are skipped.

Which delimiters work?

Comma, semicolon or tab, detected from the header line.

Is there a size limit?

Only what your browser can handle; large sitemaps should be split.

Does it check the pages exist?

No, it cannot fetch them. Use the CSV audit with crawl data for that.
