Hreflang Audit from a CSV Export

Reads a CSV of hreflang annotations with optional status and canonical columns and groups every problem by type with the affected URLs.

Use the tool

Why this tool exists

Large sites cannot be checked page by page. Export the annotations from your crawler as url, hreflang, href rows and add the status and canonical columns if you have them. The audit then finds missing self-references, one-way links, targets that do not return 200, targets canonicalised elsewhere, codes outside the ISO lists, repeated codes pointing at different URLs and missing x-default.

Only pages present in the url column can be checked for return links, status and canonical; others are listed as not in the export. Nothing leaves your browser, which matters for unreleased sites.

How to use it

  1. Export hreflang rows from your crawler into CSV with the named columns.
  2. Paste the CSV.
  3. Read the issues, errors first.
  4. Fix them and re-crawl.

Frequently asked questions

Which columns are needed?

url, hreflang and href. Optional: status and canonical.

Does it accept wide crawler exports?

No. It needs one row per annotation.

What does "not in the export" mean?

The target was never listed as a source page, so its return links could not be checked.

Is there a row limit?

Only your browser memory; the report shows the first 40 per issue.
