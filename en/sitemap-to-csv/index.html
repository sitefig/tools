Sitemap to CSV Converter

Turns a sitemap into a CSV you can open in a spreadsheet.

Use the tool

Why this tool exists

A spreadsheet makes it easy to filter sections, sort by date and share lists. Sitemaps are XML, which is not.

Columns for images, videos, hreflang alternates and news fields appear only when the sitemap has them. Fields with commas or quotes are escaped correctly.

How to use it

  1. Paste the sitemap XML.
  2. Run the tool.
  3. Copy the CSV or download it.
  4. Open it in a spreadsheet.

Frequently asked questions

Does it handle sitemap indexes?

Yes, the child sitemaps are listed as rows.

How are alternates written?

As lang=url pairs separated by spaces.

Is the order kept?

Yes, file order.

Can I go back to XML?

Yes, with the CSV to Sitemap Converter.

Tools often used together

  • CSV to Sitemap ConverterTurn a spreadsheet export (URL, date, changefreq, priority columns) into a valid sitemap.xml. Dates are converted to W3C format.
  • Sitemap URL ExtractorPull all <loc> URLs out of sitemap XML.
  • Sitemap ValidatorCheck limits, duplicates, bad URLs, dates and values in pasted sitemap XML.
  • Sitemap URL Pattern and Structure AnalyzerGroup sitemap URLs by folder and URL template to see site structure, section sizes, parameter variations and very deep paths.
  • XML to JSONConvert XML to JSON: attributes get a prefix, repeated elements become arrays, text goes to #text.
