Live Audio Spectrum Analyzer

Draws the frequency spectrum of your microphone or of a file as it plays, with a logarithmic frequency axis and a readout of the strongest frequency and its note.

Use the tool

Why this tool exists

A spectrum shows which frequencies are loud right now. It helps you find the pitch of a tone, spot feedback ringing, check a room for hum, and see what an equalizer is doing. Microphone input is processed live and is not echoed to your speakers, so there is no feedback loop.

The analyser uses the browser's FFT with the size you choose: larger sizes resolve close frequencies better but react slower. Automatic gain control, echo cancellation and noise suppression are switched off so the display shows what the microphone really hears.

How to use it

  1. Choose Microphone or Audio file as the source.
  2. Pick an FFT size and the smoothing.
  3. Press Start and allow microphone access if asked.
  4. Press Stop when you are done.

Frequently asked questions

Is my voice recorded or uploaded?

No. The audio is analysed in memory and never stored or sent.

Why does the peak jump around?

Real sounds have many harmonics and the strongest one can change. Raise the smoothing or use a larger FFT size.

How accurate is the peak frequency?

Within a fraction of a hertz for a clean tone at FFT size 8192 or more, thanks to interpolation.

Can I test it without a microphone?

Yes, choose Audio file and play any recording.
