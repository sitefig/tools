Hreflang Cluster Visualizer

Shows which pages link to which in an hreflang set and highlights the links with no return link.

Use the tool

Why this tool exists

The hardest hreflang rule to check by eye is the return link: if page A points to B, B must point back. This diagram draws each annotation as an arrow between pages. A one-way arrow is dashed and red and appears in a list below the picture, so the information is not carried by colour alone.

Pages that have annotations but none pointing at themselves are marked with an orange outline and a label. The graph shows up to 40 pages; the audit tool covers larger sets.

How to use it

  1. Paste the CSV of annotations.
  2. Read the summary and the picture description.
  3. Check the list of missing return links.
  4. Add the missing annotations.

Frequently asked questions

What is a one-way link?

An annotation A to B where B does not list A.

Why dashed lines?

So the problem is visible without relying on colour.

Can it show hundreds of pages?

It draws the first 40.

What input does it need?

url, hreflang, href columns.
