Missing Value Filler (Constant, Mean, Median, Forward Fill)

Replaces empty cells column by column using the method you choose, with one default and overrides for single columns.

Use the tool

Why this tool exists

Gaps in data break charts and averages. Filling with a mean or the last value is a modelling choice, so the tool tells you how many cells were changed in each column and which method it used.

Mean and median need numbers; forward and backward fill work for text as well, and leave leading or trailing gaps empty if there is nothing to copy. Writing overrides such as temp: mean; city: forward lets you mix methods. Filled values are guesses; keep the original file.

How to use it

  1. Paste the CSV with a header.
  2. Choose a default method.
  3. Add overrides like temp: mean; city: forward.
  4. Copy or download the filled CSV.

Frequently asked questions

What counts as empty?

A cell with nothing or only spaces.

Can I fill with a fixed word?

Yes, choose constant and type it, or use const=VALUE in an override.

Is the mean rounded?

To six significant digits.

Does it modify non-empty cells?

Never.
