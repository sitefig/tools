Property List (plist) to JSON and Back

Read and edit plist files as JSON, then turn them back into a valid XML property list.

Use the tool

Why this tool exists

Dictionaries, arrays, strings, integers, reals, booleans, dates and data elements are mapped to JSON; dates become {"$date": ISO string} and binary data {"$data": base64} so that the conversion back is lossless. JSON null has no plist equivalent and is rejected. The output was checked against Python's plistlib in both directions.

Only XML plists are supported. Convert binary plists first with plutil -convert xml1.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Choose plist to JSON or JSON to plist.
  2. Paste the document.
  3. Edit the JSON if needed and convert back.
  4. Save as .plist and test in Xcode or with plutil -lint.

Frequently asked questions

Can it read binary plists?

No. Run plutil -convert xml1 first.

How are dates stored?

As ISO 8601 text in a {"$date": ...} object.

Why is null rejected?

Property lists have no null type.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
