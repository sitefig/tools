Simple Logo Maker: Shape, Initials and Name to SVG and PNG

Combines one of eight geometric shapes, optional letters inside it and your brand name in a layout you choose, and exports SVG code and a PNG.

Use the tool

Why this tool exists

A quick logo for a side project or a placeholder. Pick a shape, set the colours, choose a font family and a layout: icon left, icon above, icon only or name only. The text colour inside the icon is chosen for contrast.

Fonts are the generic system families because the SVG does not embed fonts, so the look changes on other devices. For a final brand, convert text to outlines in a design tool. There is no icon library here, only simple shapes.

How to use it

  1. Type your brand name.
  2. Pick a shape, letters, layout and font family.
  3. Set icon, text and background colours.
  4. Copy the SVG or download the PNG.

Frequently asked questions

Can I use my own icon?

Not in this tool. Put your icon into the SVG code or use a design tool.

Why does the font look different on another computer?

Fonts are not embedded in the SVG. Use outlines for final artwork.

Is the logo trademark safe?

No check is made. Search for similar marks before using a logo commercially.

What is the PNG scale?

A multiplier of the SVG size.
