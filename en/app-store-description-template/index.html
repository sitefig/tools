App Store Description Template

Fill in your app name, tagline, features, audience and call to action to get listing text for the App Store and Google Play, with character counts against common limits.

Use the tool

Why this tool exists

Store listings have hard limits: a 30-character name and subtitle on iOS, a 100-character keyword field and an 80-character short description on Google Play. Writing a lovely sentence that turns out to be 12 characters too long is a waste of an afternoon.

This template arranges your answers into a listing: name, subtitle, keyword string, short description and a full description with a features list and call to action, each with a count such as 24/30 and OVER when it exceeds the limit. It is a draft to rewrite in your own voice. Limits change, so confirm the current ones in App Store Connect and Google Play Console.

How to use it

  1. Enter the app name, tagline and a one-sentence description of what it does.
  2. List key features, comma separated, and describe who the app is for.
  3. Add iOS keywords separated by commas, and a closing call to action.
  4. Check each character count, fix anything marked OVER and copy the text.

Frequently asked questions

Which limits does it check?

App name 30, iOS subtitle 30, iOS keywords 100, Google Play short description 80 and full description 4000 characters. These are values at the time of writing, so confirm them with the stores.

How is the short description made?

It is the first 80 characters of your one-sentence description, cut mechanically. Rewrite it by hand so it reads well and ends on a whole word.

Do I repeat keywords in the description on iOS?

The keyword field is a separate, hidden field, so words there do not need repeating. Avoid duplicating the app name or category words, which are already indexed. Check the guidelines for current advice.

Does it follow store policies?

No. It only formats and counts. Avoid claims you cannot support, and read each store's rules on metadata, which prohibit things such as competitor names and misleading text.
