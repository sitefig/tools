WireGuard Config Generator (Server + Peers, Keys Included)

Set up a WireGuard VPN faster: get a server config and one config per client, with keys created in your browser.

Use the tool

Why this tool exists

Enter a /24 subnet, the server endpoint, the number of clients, DNS and routing. The page generates X25519 keys with a hand-written implementation of RFC 7748 (checked against the RFC test vector and against the wg tool, which derived the same public keys), optional preshared keys and files for wg0.conf and each client with sequential addresses.

Copy each file to its machine over a secure channel and do not keep spare copies. The server also needs IP forwarding and a NAT rule for clients to reach the internet.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Enter the subnet, endpoint and number of clients.
  2. Choose full tunnel or split tunnel and DNS.
  3. Copy the server config to /etc/wireguard/wg0.conf and each client file to its device.
  4. Run wg-quick up wg0.

Frequently asked questions

Are the keys safe?

They are random and created locally. Treat the output like any secret and avoid sharing it.

What is a preshared key?

An extra symmetric key mixed in for added protection against future quantum attacks on key exchange.

How do clients get internet access?

Enable ip_forward on the server and add a masquerade rule for the outgoing interface.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
