Molecule Viewer for PDB and XYZ Files (Ball-and-Stick, Space-Filling)

Draws a molecule from pasted PDB or XYZ coordinates in ball-and-stick, sticks or space-filling style, which you turn with azimuth and elevation.

Use the tool

Why this tool exists

Structure files are plain text. Paste the ATOM lines of a PDB file or an XYZ block and the page draws the atoms with the usual CPK colors, depth-sorted so nearer atoms cover farther ones.

Bonds come from CONECT records when the file has them, otherwise they are guessed from distances (under 1.9 angstrom, or 1.25 to hydrogen), and the page says which. Space-filling radii use Bondi van der Waals radii for H, C, N, O, F, P, S and Cl, as listed in a public table, and 1.8 angstrom for other elements. SMILES input is not supported because it needs a 3D structure generator. The picture is static; you turn it by changing the angles.

How to use it

  1. Paste a PDB or XYZ file.
  2. Choose ball-and-stick, sticks or space-filling.
  3. Change azimuth and elevation to turn the molecule.
  4. Read the atom and bond counts under the picture.

Frequently asked questions

Can I load a SMILES string?

No. SMILES has no coordinates and generating 3D coordinates is not included.

How many atoms can it draw?

Up to 4000.

Are bonds always right?

Not when guessed. Use a file with CONECT records for exact bonds.

Is my file uploaded?

No, it is drawn in your browser.
