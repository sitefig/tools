MTA-STS and TLS-RPT Record Checker

Checks the DNS records and the policy file that make up MTA-STS and TLS reporting.

Use the tool

Why this tool exists

MTA-STS tells sending mail servers to use TLS when delivering to your domain. It needs a TXT record, a policy file served over HTTPS and, ideally, a TLS-RPT record so you receive reports about failures.

Paste the records and the policy file and the tool checks the version, id, mode, mx lines, max_age and report address against RFC 8461 and RFC 8460. It cannot test the HTTPS side or fetch anything. Move from testing to enforce once reports look clean.

How to use it

  1. Copy the _mta-sts and _smtp._tls TXT records.
  2. Copy the mta-sts.txt policy.
  3. Paste both and read the review list.
  4. Switch mode from testing to enforce when ready.

Frequently asked questions

What does testing mode do?

Failures are reported but delivery is not stopped.

Why does the id matter?

Senders use it to know when to refetch your policy. Change it whenever the policy changes.

Does it fetch my policy?

No. Paste the text.
