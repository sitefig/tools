Resistor Colour Code Calculator (4, 5, 6 Band & SMD)

Read a resistor or find the colours for a value you need.

Use the tool

Why this tool exists

Enter the band colours (4, 5 or 6 bands, with gold and silver multipliers and tolerance) to get the value, tolerance range and temperature coefficient; enter a value such as 4.7k to get the 4-band and 5-band colour sequences; or enter a 3 or 4 digit SMD code (103) or an R-notation code (4R7). Results were checked against standard code tables.

Colours can be misread under some lighting and bands can be faded, so confirm with a multimeter before relying on a part.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Type colours separated by spaces, or a value, or an SMD code.
  2. Read the ohm value and tolerance.
  3. Check with a multimeter.
  4. Choose a standard E-series value where possible.

Frequently asked questions

Which band is first?

The one closest to an edge; the tolerance band is usually gold or silver and separated by a larger gap.

What is 103?

10 followed by 3 zeros: 10 kilohms.

What does R mean in 4R7?

A decimal point: 4.7 ohms.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
