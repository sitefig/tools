Password Strength Checker

Paste a password to see its estimated entropy, the weak patterns found in it and how long different attackers would need. Everything is calculated on this page.

Use the tool

Why this tool exists

A password that looks complicated can still be weak. Substituting @ for a, adding 1! to a dictionary word or walking across the keyboard are patterns that cracking tools try first. A simple length-and-symbols rule does not catch them.

This checker compares your password against common-password lists, l33t substitutions, keyboard walks, sequences and repeats, then estimates entropy after those patterns are taken into account. It shows crack-time estimates for several attack speeds, from a throttled online login to a large offline cluster. Use it to learn why a password is weak, not as a certificate. The figures are heuristic estimates, and you should still avoid pasting a live password into any page you do not trust.

How to use it

  1. Type or paste a password into the box.
  2. Run the tool to see the verdict and entropy.
  3. Read the list of patterns found and the crack-time table.
  4. Follow the advice shown, or generate a stronger password with the generator.

Frequently asked questions

Is my password sent anywhere?

No. The analysis runs in your browser and nothing is uploaded. Even so, prefer testing a similar password rather than one you use for a real account, in case of browser extensions or shared devices.

How accurate are the crack-time estimates?

They are rough. They assume average-case guessing at fixed speeds, and real attackers depend on the hashing method used by the site. Treat them as a comparison between passwords, not a guarantee.

Why did a long password score badly?

Patterns reduce entropy. A long phrase made of common words, a keyboard walk or repeated blocks is far easier to guess than random characters of the same length.

What is a good score?

Aim for the Strong or Very strong verdict, roughly 60 bits or more after pattern analysis. For important accounts use a random password from a manager and turn on two-factor authentication.
