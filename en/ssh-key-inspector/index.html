SSH Public Key Inspector

Paste an OpenSSH public key line and see its key type, bit size, comment and the SHA-256 and MD5 fingerprints that ssh-keygen -l would print.

Use the tool

Why this tool exists

Public keys in authorized_keys files, deploy key lists and cloud consoles are long Base64 strings that all look alike. When you are asked to confirm a fingerprint, or you need to check which key is which, you want the same value that ssh-keygen shows.

This inspector decodes the key blob inside the line, checks that its internal type matches the label, estimates the RSA modulus size and calculates both fingerprints locally. It handles ssh-rsa, ssh-ed25519 and ECDSA lines. Public keys are not secret, but do not paste private keys into any website. The fingerprint tells you whether two lines are the same key, not whether the key is trustworthy.

How to use it

  1. Paste one or more public key lines, in the form type, Base64 data and an optional comment.
  2. Read the type, size, comment and the SHA256 and MD5 fingerprints.
  3. Compare them with the value shown by your server, GitHub or cloud console.

Frequently asked questions

Which fingerprint should I compare?

The SHA256 form is the current default in OpenSSH and is shown by most services. The older colon-separated MD5 form is included for systems that still display it.

Can I paste a private key?

Please do not. This tool needs only the public key line, which starts with ssh-rsa, ssh-ed25519 or ecdsa-sha2. Keep private keys out of web pages.

Why does it say the key blob type does not match?

The label at the start of the line and the type stored inside the Base64 data must agree. A mismatch usually means the line was edited or truncated when copied.

Does it check whether a key is strong?

It shows the size, such as RSA bits, but gives no verdict. As a guide, use Ed25519 or RSA of at least 3072 bits for new keys.
