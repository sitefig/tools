Terraform Plan Viewer (terraform show -json)

Reads the JSON from terraform show -json and lists each resource with its action and the attributes that change. Sensitive values are hidden.

Use the tool

Why this tool exists

A long plan is hard to review in a pull request. This page turns the machine-readable plan into a short list: counts, one line per resource and the changed attribute names.

It compares before and after values from the JSON, so its grouping can differ from the text plan. Values marked sensitive are never printed, and values unknown until apply are labelled as such.

How to use it

  1. Run terraform plan -out tfplan, then terraform show -json tfplan > plan.json.
  2. Paste the JSON or choose the file.
  3. Read the totals and the per-resource list.
  4. Use Terraform itself for the final decision.

Frequently asked questions

Can the plan contain secrets?

Plan files can. The page hides values marked sensitive and runs offline, but treat the file as private anyway.

Why does a replace show as -/+?

Terraform destroys and creates the resource. The order depends on create_before_destroy.

Does it run Terraform?

No. It only reads the JSON.

Are drift changes shown?

Only a count of resource_drift entries.
