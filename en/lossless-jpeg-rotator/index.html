Lossless JPEG Rotator (Change EXIF Orientation, No Re-encoding)

Rotate or flip JPEGs by changing the orientation tag only.

Use the tool

Why this tool exists

Choose a turn or a mirror. The tool changes the EXIF orientation value and leaves the compressed picture data alone, so there is no quality loss. It combines your turn with any orientation already in the file and adds a small EXIF block if there is none.

Browsers and phones obey the tag. Some old software and upload forms ignore it. If yours does, rotate the pixels with the Image Rotate & Flip tool instead.

How to use it

  1. Choose one or more JPEGs.
  2. Pick the turn or mirror.
  3. Download the files.
  4. Open them in the app you care about to check.

Frequently asked questions

Is it really lossless?

Yes. The image bytes are copied unchanged.

Why does it look unrotated in some apps?

Those apps ignore the orientation tag.

Does it work on PNG?

No. Only JPEG.

Is anything uploaded?

No. The work happens in your browser and the page makes no network request with your input.
