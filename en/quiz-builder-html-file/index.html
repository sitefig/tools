Multiple-Choice Quiz Builder (Self-Contained HTML Quiz File)

Turns a simple text format into a self-contained HTML quiz file with scoring and feedback, which works offline on any device.

Use the tool

Why this tool exists

Quiz sites want accounts and store your questions. Here you write the quiz as plain text, with Q: for a question, a dash for a wrong option and a star for a correct one, and download a single HTML file.

The file contains the questions, a small script and nothing else, so you can email it, put it on a website or a USB stick. Questions with more than one correct option become check boxes. The answers are inside the file, so anyone who views the source can read them: it is for practice, not for exams. This tool shares by file, not by a web link.

How to use it

  1. Write each question with Q: and options starting with - or *.
  2. Separate questions with a blank line, and add Title: on the first line if you like.
  3. Check the preview list.
  4. Download the HTML file and send or host it.

Frequently asked questions

Can I get a share link?

No link is made; share the file. Anyone can open it in a browser.

Can answers be hidden from students?

No. They are in the file, so this is not secure.

Does the quiz save scores?

No, scores are shown on the page only.

Can options be shuffled?

Yes, tick the shuffle box.
