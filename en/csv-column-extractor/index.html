CSV Column Extractor

Selects, reorders or removes columns from a CSV by header name, column number or range, with optional de-duplication and CSV, line or JSON output.

Use the tool

Why this tool exists

Exports from CRMs, shops and analytics tools usually contain far more columns than you need. Opening a 40-column file in a spreadsheet just to copy two of them is slow, and it is a risk when the file holds personal data. With this tool you type the columns you want, such as "email,country" or "1,3-5", and get only those back. You can invert the choice to drop columns instead, keep the original header or not, and remove duplicate rows to get a unique list. The one-value-per-line output is handy for pasting email addresses into another system. It all happens in your browser, so the file contents are not sent anywhere.

How to use it

  1. Paste your CSV and set the delimiter (comma, semicolon, tab or pipe).
  2. Type the columns as names or numbers, separated by commas. Ranges such as 2-4 work. Choose keep or drop.
  3. Tick duplicate removal if needed, choose CSV, one value per line or JSON, and copy the result.

Frequently asked questions

Can I mix names and numbers?

Yes. Each item is first matched against the header names, then read as a range like 2-4, then as a 1-based column number. The order you type is the order of the output columns when you keep them.

What if there is no header row?

Untick "First row is header". Columns are then numbered 1, 2, 3 and so on, and all rows are treated as data. JSON output then uses those numbers as keys.

How are quotes and line breaks handled?

The parser follows the usual CSV quoting rules: quoted fields, doubled quotes and line breaks inside quotes are read correctly, and output cells are quoted again where needed. An unterminated quote gives an error.

What does one value per line do with several columns?

When more than one column is selected, the values of each row are joined with a space on one line. For clean lists, select a single column.
