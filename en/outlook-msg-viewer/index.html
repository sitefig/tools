Outlook .msg Viewer (Headers, Body, Attachments)

Read a saved Outlook message on any computer, and pull out its attachments, without installing Outlook.

Use the tool

Why this tool exists

An .msg file is an OLE compound file (the same container as old .doc files) holding MAPI properties. This viewer reads the container itself (versions 3 and 4, FAT, mini-FAT and DIFAT), finds the property streams and decodes subject, sender, To, Cc and Bcc recipients, sent and received times, transport headers, the plain text body, the HTML body and the compressed RTF body (LZFu decompression, converted roughly to text when no plain body exists). Attachments are listed with size and type, and you can download any one by number.

It was tested against extract-msg on messages built with an independent compound file writer: subjects, addresses, recipients, dates, bodies and the SHA-1 of every attachment matched, for both container versions and for a compressed-RTF-only message. HTML is shown in a sandboxed frame with a content-security policy that blocks remote images and scripts.

Limits: encrypted or rights-protected messages, digitally signed messages, embedded .msg attachments (listed but not exported), TNEF attachments, and calendar, contact and task items (only their standard fields appear, because named properties are not resolved). Everything stays in your browser.

How to use it

  1. Choose the .msg file.
  2. Read the headers, body and attachment list.
  3. To save an attachment, enter its number in the download field.
  4. Use the EML viewer for .eml files.

Frequently asked questions

Can I save attachments?

Yes. Enter the attachment number shown in the list. Embedded messages and OLE objects are listed but cannot be exported here.

Why does the sender show an odd address?

Messages inside Exchange often store an internal address (type EX) instead of an SMTP address. When there is no SMTP address in the file, the viewer shows what is stored.

Does it load remote images in HTML mail?

No. Remote content and scripts are blocked in the preview.

Does it work offline?

Yes, once the page has loaded. The file never leaves your browser.

Can it open .oft templates or .pst archives?

No. Only single .msg messages. A .pst is a different, much larger format.
