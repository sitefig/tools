Password Generator

Create random passwords of the length and character mix you choose. They come from the browser secure random generator, and each selected character type is guaranteed to appear.

Use the tool

Why this tool exists

Reused or guessable passwords are how most accounts get taken over. You need a fresh, long, random one every time you register a service, rotate a database credential or set up a router. Making one up in your head tends to produce patterns an attacker already tries.

This generator uses the browser secure random source and avoids modulo bias, so every symbol is equally likely. You choose length, how many to produce and which classes to include, and you can drop look-alike characters such as O, 0, I and l when someone has to type it by hand. The page shows the approximate entropy. Nothing is transmitted, so the passwords exist only on your screen.

How to use it

  1. Set the password length and how many passwords you want.
  2. Tick the character types to include: lowercase, uppercase, digits and symbols.
  3. Tick the look-alike option if the password will be typed by hand.
  4. Run the tool and copy a password straight into your password manager.

Frequently asked questions

How random are these passwords?

They use crypto.getRandomValues, the browser cryptographic random generator, with rejection sampling to avoid modulo bias. Each selected character class is guaranteed at least once, then the rest is filled randomly and shuffled.

How long should a password be?

For accounts stored in a password manager, 20 characters or more is a good default. The page shows approximate entropy in bits. Length is limited to 512 characters and the maximum count is 200.

Are the passwords stored or sent anywhere?

No. They are generated in your browser and not uploaded or logged by this page. Still, copy one into a password manager promptly and close the tab.

Why can I not select zero character types?

A password needs at least one set of characters. The tool also needs a length at least as large as the number of selected types so each can appear.
