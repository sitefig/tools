Bot Trap URL Generator (Honeypot Path, robots.txt and Log Filter)

Generates a hard-to-guess trap path with the robots.txt line, hidden link and grep commands to find visitors.

Use the tool

Why this tool exists

A bot trap is a URL that no human sees and no polite crawler visits. If something requests it, it ignored robots.txt and followed a hidden link.

The tool derives a path from your seed, gives the Disallow rule, a hidden link that screen readers and keyboards skip, and commands to list visitors from your logs. Do not ban on one hit without checking, since scanners and proxies can trigger it.

How to use it

  1. Enter a seed word and folder name.
  2. Add the Disallow rule to robots.txt.
  3. Place the hidden link in a template.
  4. Check the log for visitors.

Frequently asked questions

Is the path secret?

No. It comes from a simple hash and is visible in robots.txt.

Is the hidden link accessible?

It uses display:none, so it is hidden from sighted users, keyboards and screen readers.

Should I auto-ban?

Review first. Link preview tools and scanners can hit it.

What should the trap return?

Something harmless, like a 404.
