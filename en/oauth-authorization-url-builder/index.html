OAuth 2.0 Authorization URL Builder

Builds the authorization request URL for the authorization code or implicit flow. It encodes the parameters, can generate a random state, nonce and a PKCE code challenge, and lists each parameter.

Use the tool

Why this tool exists

Authorization URLs fail on small things: an unencoded redirect URI, a missing scope separator, no state, a PKCE challenge that does not match the verifier. The error pages are often vague.

This tool assembles the URL with correct encoding and random values from the browser crypto API. If it generates a PKCE verifier it shows it once. Keep it, you need it at the token request. Client secrets do not belong in this URL and the tool has no field for them.

How to use it

  1. Enter the authorization endpoint, client_id and redirect URI.
  2. Choose the response type and scopes.
  3. Leave state blank for a random one, and tick PKCE for the code flow.
  4. Copy the URL and keep the code verifier.

Frequently asked questions

Does it send the URL anywhere?

No. It only builds text. You open the URL yourself.

Why is PKCE ignored for some response types?

PKCE protects the authorization code flow. For other flows there is no code to protect.

Do I need a nonce?

OpenID Connect flows that return an ID token directly need one. The tool warns when it is missing.

Where do I put the client secret?

Not in this URL. It goes in the token request, from a server.
