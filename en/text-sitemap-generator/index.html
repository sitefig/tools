Text Sitemap Generator

Cleans a URL list into the text sitemap format.

Use the tool

Why this tool exists

A text sitemap is the simplest format: one URL per line and nothing else. Google accepts it up to 50,000 URLs and 50 MB.

This tool removes duplicates, fragments, and encodes spaces and non-ASCII characters. If a line is not an absolute http(s) URL it stops and tells you which one, because the file may contain nothing but URLs.

How to use it

  1. Paste your URLs.
  2. Keep fragment removal on unless you need it.
  3. Run the tool.
  4. Save the result as sitemap.txt.

Frequently asked questions

Why does it stop on a bad line?

The text format allows only URLs. A stray word would break the file.

Is encoding UTF-8?

Yes, and URLs are percent-encoded.

What about more than 50,000 URLs?

Split the list with the sitemap splitter.

Can I add dates?

No. Use the XML format for lastmod.
