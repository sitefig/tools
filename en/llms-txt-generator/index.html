llms.txt Generator

Write a title, summary and sections of links, and get a correctly formatted llms.txt file: a markdown index of your most useful pages for AI assistants to read.

Use the tool

Why this tool exists

The llms.txt idea is a plain markdown file at the root of a site that tells AI assistants what the site is and which pages matter most, in a form that is easy to read without crawling the whole site. It is a proposal and not a standard, and no search engine or AI company guarantees that it will read it.

This generator saves you the formatting. Enter a title, a one-line summary and optional details, then sections with lines of name, URL and a short description. It outputs the heading, the quote block summary and a list of links under each section heading. A section called Optional marks lower-priority pages. Save the result as llms.txt in your site root. Nothing is sent anywhere, because the file is produced in your browser.

How to use it

  1. Fill in title, summary and details at the top of the box.
  2. Add sections with a line starting ## and then one link per line in the form name | url | description.
  3. Run the tool to produce the formatted file.
  4. Save the result as llms.txt and place it at the root of your site.

Frequently asked questions

Do AI assistants actually use llms.txt?

There is no guarantee. It is a community proposal, and support varies between tools. It costs little to add, but do not expect a measurable effect on search or AI answers.

What does the Optional section mean?

In the proposal, a section named Optional lists secondary links that can be skipped when a short context is needed. Put background material there and your essentials in the main sections.

What is the link line format?

Use name | url | description, with the description optional. The tool writes it as a markdown list item with the name linked to the URL, followed by a colon and the description.

Is my content sent to a server?

No. The calculation runs in your browser and nothing you paste is uploaded, stored or sent to a server, so drafts and confidential copy are safe to check.
