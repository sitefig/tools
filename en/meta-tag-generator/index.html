Meta Tag Generator

Fill in simple key: value lines to produce the head tags for a page: charset, viewport, title, description, canonical, robots, author, theme colour and favicon, with length warnings.

Use the tool

Why this tool exists

Every page needs a handful of tags in its head, and getting them slightly wrong is common: a title that is too long, a description missing, a canonical typed with a stray space, a robots value with a typo. Writing them from memory each time invites mistakes.

This generator takes lines such as title, description, canonical and robots, escapes the values so quotes do not break the HTML and prints the matching tags. It always adds charset and viewport, and warns when the title goes over 60 characters or the description over 160. The language is shown as an html tag note, since lang belongs on the opening html element. It is a convenience for writing markup, and the output is built locally in your browser.

How to use it

  1. Edit the key: value lines, for example title, description, canonical, robots and lang.
  2. Add author, keywords, theme_color or favicon if you need them.
  3. Run the tool to produce the head tags and any warnings.
  4. Copy the tags into the head of your page and set lang on the html tag.

Frequently asked questions

Which fields does it understand?

title, description, canonical, robots, author, keywords, theme_color, favicon, charset and lang. Unknown keys are ignored, and charset defaults to utf-8.

Are title and description length limits strict?

No. The tool warns above 60 and 160 characters, which are common guidelines. Google truncates by pixel width, so use the SERP snippet preview to see the likely result.

Should I add the keywords tag?

Search engines ignore it, so it is optional. The tool supports it only because some systems still read it.

Does it store my text?

No. The tags are generated in your browser and nothing you type is uploaded. It also means the page works for drafts and private sites you would not want to share.
