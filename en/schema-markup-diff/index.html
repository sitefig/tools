Schema Markup Diff

Lists what changed between two JSON-LD blocks: properties added, removed or changed, by path.

Use the tool

Why this tool exists

When a theme update or a release changes your structured data, a text diff is noisy because key order and formatting change. This tool parses both versions and compares the values, so only real changes appear. Objects inside lists are matched by @id when every item has one; otherwise by position.

A single value and a one-item list are reported as different, because consumers can treat them differently.

How to use it

  1. Paste the old markup on the left and the new one on the right.
  2. Read the plus, minus and tilde lines.
  3. Check the paths of changed values.
  4. Fix unintended changes.

Frequently asked questions

Does key order matter?

No.

How are arrays compared?

By @id if all items have one, else by position.

Can I paste whole pages?

Yes, the ld+json scripts are extracted.

Does it understand @graph?

It compares the structure as written; use matching @id values for stable results.
