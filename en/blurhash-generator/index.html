BlurHash Generator (Compact Image Placeholder String)

Make a BlurHash placeholder string from an image.

Use the tool

Why this tool exists

Choose an image and the number of components. The page returns the BlurHash, a short string you can store with the picture, and a preview of the blur it decodes to. More components keep more detail and make a longer string. 4 by 3 is the usual choice.

The image is shrunk to 64 pixels first, which is enough for a blur. The encoder was checked against the reference C implementation for several component counts.

How to use it

  1. Choose an image.
  2. Set the horizontal and vertical components.
  3. Copy the hash.
  4. Store the aspect ratio with it.

Frequently asked questions

How do I use the hash?

Decode it on the client with any BlurHash decoder at the picture's aspect ratio and show it until the real image loads.

Why is it so short?

It keeps only a handful of low-frequency colour components.

Is it private?

Yes. The picture stays in your browser.

Is anything uploaded?

No. The work happens in your browser and the page makes no network request with your input.
