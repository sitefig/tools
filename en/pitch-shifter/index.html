Pitch Shifter (Semitones, Same Tempo)

Shifts the pitch of an audio file up or down by semitones and cents while keeping the length the same, then saves a WAV file.

Use the tool

Why this tool exists

Singers move a backing track into their range, players transpose a song for a capo or a different instrument, and producers fix a sample that is a little flat. The pitch has to change while the tempo stays put.

The tool time-stretches the clip by the opposite ratio with WSOLA, then resamples it so it plays back at the original length. This is a classic and simple method. It sounds good for shifts of a few semitones. Voices shifted by much more than four semitones start to sound unnatural because the formants move too.

How to use it

  1. Choose an audio file.
  2. Enter the semitones (positive is higher) and optional cents.
  3. Press Run.
  4. Listen to the result and download the WAV.

Frequently asked questions

How many semitones is a full tone?

Two. A shift of 12 semitones is one octave.

Why does the length stay the same?

The tool stretches the audio by the inverse ratio first, then resamples, so the two changes cancel in length.

Can it fix a slightly out-of-tune recording?

For a whole-file offset, yes: use cents, for example +20. It cannot correct individual notes.

Does it keep stereo?

Yes. Both channels use the same alignment so the stereo image stays stable.
