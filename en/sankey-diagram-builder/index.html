Sankey Diagram Builder (Flows from Source, Target, Amount)

Draws a Sankey diagram from rows of source, target and amount. Bands are as wide as the flow, nodes are as tall as the larger of what comes in or goes out.

Use the tool

Why this tool exists

Sankey diagrams show where a total goes: budgets, energy, traffic sources, user journeys. Paste the flows and the layout is automatic, with columns assigned by path length from the sources.

Flows must not loop back, since a Sankey needs a direction; cycles are reported. If a node receives more than it sends the difference shows as a taller node, which is also useful for spotting leaks. Dense diagrams with many crossing bands are better simplified first.

How to use it

  1. Type one flow per line: source, target, amount.
  2. Add a title and a unit text.
  3. Check the table below the diagram against your input.
  4. Copy or download the SVG.

Frequently asked questions

What if my flows form a cycle?

You get an error naming the problem. Break the cycle or split the node.

Are node colours meaningful?

They only help tell nodes apart.

How many flows?

Up to 300.

Can nodes be dragged?

No. The layout is automatic; edit the input order to influence it.
