Font Format Converter: TTF or OTF to WOFF with @font-face CSS

Converts between desktop font files and WOFF, the compressed web font format, and writes a matching @font-face CSS rule.

Use the tool

Why this tool exists

WOFF is the original zlib-compressed wrapper for fonts. Each table is compressed on its own and the font data is unchanged, so the conversion is lossless and reversible. The test font used here shrank to about half its size.

WOFF2 compresses better but needs a Brotli encoder, which the browser does not offer and this site does not ship, so it is not offered. WOFF is supported by all current browsers. Check the font license before converting or self-hosting.

How to use it

  1. Choose a TTF, OTF or WOFF file.
  2. Pick WOFF or unpacked output.
  3. Run the tool and download the font.
  4. Copy the @font-face rule into your CSS.

Frequently asked questions

Why no WOFF2?

Browsers cannot produce Brotli output for scripts. WOFF gives a smaller file than TTF but larger than WOFF2.

Does it change glyphs?

No. Tables are copied byte for byte. Round trip checks showed identical tables.

May I convert any font?

Only if the license allows it. Some licenses forbid web embedding.

Can it subset the font?

Use the Font Subsetter to cut unused glyphs first.
