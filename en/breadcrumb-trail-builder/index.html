Breadcrumb Trail Builder (HTML and JSON-LD)

Builds a breadcrumb nav and the JSON-LD from a URL.

Use the tool

Why this tool exists

Breadcrumbs help visitors and can appear in search results when marked up. The visible trail and the markup must match.

The names come from the URL segments, so check them and rename the ones that are not right. The last item is the current page and does not need a link or an item URL.

How to use it

  1. Paste the page URL.
  2. List renames as segment = Label.
  3. Choose the home label.
  4. Copy the HTML and JSON-LD.

Frequently asked questions

Is the last item linked?

Not by default; the current page is marked with aria-current.

Is the markup valid?

It follows the schema.org BreadcrumbList shape. Test it in a rich results tool.

Do names come from page titles?

No, from URL segments.

Can I add levels?

Edit the URL or paste the output and adjust.
