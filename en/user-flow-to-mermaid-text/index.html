User Flow to Mermaid Text

Write your user flow as an indented list and get Mermaid flowchart code. Prefix a step with "? " for a decision and with "(label) " for a labelled edge.

Use the tool

Why this tool exists

User flows are easier to agree on when they are drawn, but dragging boxes around in a diagram editor is slow, and editing one later is slower. A text outline is quick to write and easy to review in a pull request.

This converter reads an outline where each indent level is a step deeper in the flow, and writes Mermaid flowchart TD source. Questions become diamond decision nodes, and labels like (yes) or (no) go on the arrows. Steps that repeat the same name become one node, so branches can join again. Paste the output into any Mermaid renderer, including the Mermaid Renderer on this site. Your text is not uploaded.

How to use it

  1. Write one step per line and indent by two spaces (or a tab) for each level deeper.
  2. Start a line with "? " for a decision, and with "(label) " to label the arrow into that step.
  3. Run the tool to get the flowchart TD source.
  4. Copy the code into a Mermaid renderer to see the diagram.

Frequently asked questions

How do I make branches that join again?

Reuse the same step text on each branch. Steps with identical text, ignoring case, are merged into one node, so two paths ending in "Dashboard" lead to the same box.

What does an indentation error mean?

You jumped more than one level at once, for example from no indent to four spaces. Each step may be at most one level deeper than the line above.

Can I make cycles or arbitrary links?

Not directly. The outline describes a tree with merges, so a step links only to its parent. For arbitrary connections, write the Mermaid syntax by hand.

Where do I view the diagram?

Paste the output into the Mermaid Renderer on this site, or into GitHub Markdown, Notion or any tool that supports Mermaid.
