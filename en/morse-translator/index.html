Morse Code Translator

Type a message to get Morse code, or paste dots and dashes to read it as text. Letters are separated by a space and words by " / ".

Use the tool

Why this tool exists

Morse code still appears in puzzle games, escape rooms, amateur radio exercises, scouting events and the odd hidden message. Decoding it from a printed chart is slow, and one misread dot changes the whole word.

This translator uses the international Morse alphabet for letters, digits and common punctuation such as full stop, comma, question mark, slash and @. Writing a message, you get dots and dashes with clear gaps. Reading one, it accepts a slash, a pipe or a wide gap between words, and tolerates typographic dots and dashes. Characters it does not know come out as a question mark.

How to use it

  1. Choose the direction: text to morse or morse to text.
  2. Type or paste your message. For Morse, separate letters with spaces and words with " / ".
  3. Read the translation in the output box.
  4. Copy the result and share it.

Frequently asked questions

How should I separate letters and words?

Use a single space between letters and a slash with spaces around it between words, for example ".... .. / - .... . .-. .". A pipe or three or more spaces also work as a word gap when decoding.

What characters are supported?

Letters A to Z, digits 0 to 9 and common punctuation: . , ? ' ! / ( ) & : ; = + - _ " $ @. Accented letters and other scripts are not part of this table, so they appear as ?.

Does it play the sound?

No, this page only translates text. If you want to hear it, the Morse Code Audio tool turns text into beeps.

Why do I see question marks in my result?

A question mark marks a character the table does not contain, or a Morse group that is not a valid code, often caused by a typo in the dots and dashes.
