Graphviz DOT Renderer (lite)

Write Graphviz DOT and get an SVG graph drawn offline in your browser. It supports common nodes, edges, shapes, styles, labels and clusters, with its own layout rather than the real Graphviz engine.

Use the tool

Why this tool exists

DOT is a convenient text format for dependency graphs, state machines and architecture sketches, but the real Graphviz needs installing or a server-side render. When you only want to check a small graph while writing documentation, or you are somewhere you cannot install software, a quick in-page renderer is enough.

This one handles the commonly used subset: directed and undirected graphs, rankdir, default attributes, chains, node sets, shapes, styles, colours, arrow and label options, and cluster subgraphs. Layout attributes such as splines, ratio and nodesep are ignored, HTML labels and ports are not supported, and positions differ from real Graphviz. Choose curved, orthogonal or straight edges. Nothing is sent over the network.

How to use it

  1. Type or paste DOT source, starting with digraph or graph.
  2. Choose the edge style: curved, orthogonal or straight.
  3. Check the rendered graph and fix any syntax message.
  4. Export or copy the SVG, and use the real Graphviz if you need exact layout.

Frequently asked questions

Why does my graph look different from real Graphviz?

This tool uses its own layered layout and ignores layout attributes such as nodesep, ratio and size. The structure and labels are the same, but positions and spacing will not match.

Which DOT features are unsupported?

HTML-like labels, record shapes with ports, compass points and most layout tuning attributes. Cluster subgraphs, common shapes and styles are supported, and unsupported attributes are ignored.

Does it work offline?

Yes. Once the page has loaded, rendering uses code in the page and makes no network request, so your graph text is not uploaded.
