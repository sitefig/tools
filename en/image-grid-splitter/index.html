Image Grid Splitter (Instagram Grid, Tiles)

Split one large picture into pieces for a multi-post grid.

Use the tool

Why this tool exists

Choose columns and rows (up to 100 tiles), whether to crop the image to square tiles and the output format. Tiles are cut with the canvas, centred when cropping, and numbered either in reading order or in posting order (highest number first, so the grid reads correctly on a profile).

Check the platform's current aspect ratios, since grids and crops change. High-resolution tiles keep the original sharpness; tiny tiles from a small image will look soft.

The file is read in your browser and is not uploaded anywhere.

How to use it

  1. Choose the image.
  2. Set columns and rows.
  3. Pick square crop and format.
  4. Post the tiles in numeric order.

Frequently asked questions

Which numbering should I use?

Posting order for profile grids: post tile 9 first, tile 1 last.

What size should the source be?

About 1080 pixels per tile gives sharp results.

Can I add gaps?

Not in this version.

Is my data sent anywhere?

The file is read in your browser and is not uploaded anywhere.
