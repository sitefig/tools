Server-Timing Header Parser with Duration Bars

Parses Server-Timing headers into a table of metrics, descriptions and durations.

Use the tool

Why this tool exists

Server-Timing lets the server explain where time went, but the raw header is hard to scan.

The parser splits metrics and parameters, handles quoted descriptions, checks metric names, reports invalid durations and draws a small bar per metric. Metrics may overlap, so the sum is a hint, not the response time.

How to use it

  1. Copy the Server-Timing header value from DevTools or curl -I.
  2. Paste it, several header lines are fine.
  3. Read the table and warnings.
  4. Fix names or durations on the server.

Frequently asked questions

Where do I see it in the browser?

DevTools Network, select the request, open the Timing tab.

Can scripts read it?

Yes for same-origin responses, or cross-origin with Timing-Allow-Origin.

Is it safe to expose internals?

No secrets: anyone can read the header.

Is the header uploaded?

No.
