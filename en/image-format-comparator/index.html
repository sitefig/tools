Image Format Comparator (JPEG, WebP, AVIF and PNG Side by Side)

Compare JPEG, WebP, AVIF and PNG for the same picture.

Use the tool

Why this tool exists

Choose an image and a quality. The page encodes it in each format your browser can write and shows the pictures side by side with file size and PSNR against the original. AVIF appears only if your browser can encode it; most cannot yet.

PSNR is a number, not a judgement of looks. Always view the pictures. Transparency is flattened to white for the comparison.

How to use it

  1. Choose an image.
  2. Set the quality.
  3. Optionally scale it down first.
  4. Compare size and appearance.

Frequently asked questions

Why is AVIF missing?

Browsers decode AVIF widely but few can encode it from a canvas.

What is PSNR?

A measure of pixel difference from the original, in dB. Higher means closer. Above 40 dB is very close.

Is the result the best the format can do?

No. Browser encoders are quick, not the most efficient. Dedicated tools can do better.

Is anything uploaded?

No. The work happens in your browser and the page makes no network request with your input.
