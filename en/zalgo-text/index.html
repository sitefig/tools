Zalgo (Glitch) Text

Adds random combining marks above, through and below each letter to create the corrupted look known as Zalgo text. You can set intensity, pick directions and use a seed for a repeatable result.

Use the tool

Why this tool exists

Zalgo text is the dripping, glitched lettering you see in horror memes, game names and creepy posts. It is made by piling Unicode combining marks onto ordinary letters, and nobody types that by hand.

Here you choose how wild it gets, from mini to max, and which directions are used: marks above, through the middle, or below. A seed makes the pattern repeatable, so the same input always gives the same output. Without a seed, each click is different. Heavy Zalgo can overflow lines, break layouts and bother screen readers, so use it for fun rather than anything people must read. It is generated locally in your browser.

How to use it

  1. Type the text you want to corrupt.
  2. Pick an intensity: mini, normal or max.
  3. Tick or untick Up, Middle and Down, and add a seed if you want repeatable output.
  4. Copy the glitched text from the output.

Frequently asked questions

Why does the output change each time?

Without a seed the marks are chosen randomly. Type any word into the Seed box to get the same result for the same input every time.

Why does it spill over other lines?

Combining marks are drawn above and below the letter without adding line height, so tall stacks overlap neighbouring text. Use the mini level, or switch off Up or Down, to reduce the overflow.

Will it work on every site?

Some platforms strip or limit combining marks, and others cap the length of names. The text is still ordinary Unicode, so it can usually be pasted, but the look depends on the font and the site.

Can I reverse Zalgo text?

This tool only adds marks. To clean text, use the Unicode normalizer and tick Strip diacritics, which removes combining marks and leaves the base letters.
