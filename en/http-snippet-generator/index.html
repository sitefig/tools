HTTP Snippet Generator

Paste a raw request, with the method and URL first, then headers, a blank line and the body, to get curl, fetch and Python code.

Use the tool

Why this tool exists

API documentation, support tickets and browser devtools show requests as plain text, but you usually want code you can run. Rewriting the headers and quoting the body by hand is slow, and quotes in a JSON body easily break a shell command.

This tool reads the first line as METHOD URL, treats each following line as a header until the first blank line, and takes the rest as the body. It then writes a curl command with safe single-quote escaping, a fetch call with headers and body, and a Python snippet that uses only the standard library. It is a quick way to move between those forms when testing an endpoint or sharing a reproduction. The parsing happens in your browser, so tokens in the request stay on your device.

How to use it

  1. Type the request: the first line is METHOD URL.
  2. Add one Header: value line per header, then a blank line and the body.
  3. Run the tool.
  4. Copy the curl, fetch or Python version.

Frequently asked questions

What request format does it expect?

A first line such as POST https://api.example.com/items, then header lines in Name: value form, then an empty line and the body. The URL must be a full address, not just a path.

How are quotes in the body handled?

For curl, single quotes inside the body are escaped so the shell command stays valid. The fetch and Python snippets use JSON string quoting. Check very unusual characters before you run the command.

Does it send the request?

No. It only generates code. Nothing is sent from this page, so you can paste requests containing tokens without them leaving your browser, though you should still avoid sharing live secrets.

Which other languages does it cover?

Only curl, fetch and Python here. If you start from a curl command and need other languages, the curl converter tools on this site cover Go, Rust, PHP and more.

Tools often used together

  • cURL to CodeConvert a curl command to fetch, Node (http/https), Python requests or PHP cURL.
  • cURL to C# / Java / Axios / Guzzle / FaradayConvert a curl command (-X -H -d --data-urlencode --json -F -u -k -L) into C# HttpClient, Java 11 HttpClient, JavaScript axios, PHP Guzzle or Ruby Faraday. Python, fetch, Node and plain PHP live in the main cURL to Code tool; Go and Rust have their own tools. Multipart (-F) is supported for C#, Guzzle and Faraday; Java and axios convert it to a urlencoded body.
  • fetch() to cURLConvert a JavaScript fetch(url, { method, headers, body }) call (as copied from DevTools or source) into a curl command. Understands JSON.stringify(...) bodies, string and object literals; it never executes your code.
  • cURL Command BuilderFill in method, URL, headers, body, auth and flags to get a correctly quoted curl command.
  • HTTP Raw Message <-> JSON (wire format)Parse a raw HTTP/1.x request or response (start line, headers, body, chunked transfer decoding, Content-Length check, query string, cookies, Basic auth) into structured JSON, or build a correctly framed raw HTTP message (CRLF line endings, Host and Content-Length) from JSON. Useful for debugging proxies, WAF rules, request smuggling cases and hand-written test fixtures.
  • HTTP Headers to JSONConvert raw HTTP request/response headers (or a status line plus headers) to a JSON object; repeated headers become arrays.
