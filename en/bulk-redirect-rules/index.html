Bulk Redirect Rule Generator: Apache, Nginx, Cloudflare, Netlify, Vercel

Paste old and new URLs, pick a platform and copy ready rules. Supports Apache Redirect, RedirectMatch and RewriteRule, Nginx location blocks and map, Cloudflare Bulk Redirects CSV, Netlify _redirects and vercel.json.

Use the tool

Why this tool exists

A site migration can mean thousands of redirects, and every platform wants a different format. Typing them by hand invites typos, duplicate sources and chains. This tool reads one simple list and writes the format you need, and it warns about self-redirects, duplicate sources, chains and rows a platform cannot express, such as query strings in a Cloudflare source.

The Apache outputs were tested against a running apache2 2.4. Cloudflare and Netlify formats follow their documentation. Vercel escaping could not be checked against a live deployment. Always test on staging: one wrong rule can redirect the whole site.

How to use it

  1. Paste one pair per line: old URL, then new URL. Add 301, 302, 307 or 308 at the end of a line to override the default.
  2. Choose the output format and the default status code.
  3. For Cloudflare, enter your domain if the old URLs are only paths.
  4. Copy the rules, read the Review list and test on staging.

Frequently asked questions

What is the difference between Redirect and RedirectMatch?

Redirect matches a path prefix, so /old also redirects /old/anything. RedirectMatch with ^/old$ matches only the exact path. Pick the exact form when you do not want the prefix behaviour.

How are query strings handled?

Apache RewriteRule, Nginx location and Netlify rules can match a specific query string. Redirect, RedirectMatch, Cloudflare and Vercel sources match the path only, so those rows are skipped with a note.

Which format for thousands of rows?

Nginx map and Cloudflare Bulk Redirects are built for long lists. Long lists in vercel.json are better placed in a bulk redirects file.

Does it check that redirects work?

No. It only writes rules. Test with curl -I and fix chains with the Redirect Map Flattener.
