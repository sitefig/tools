Markdown Preview

Shows your Markdown as rendered HTML as you type, inside a sandboxed frame. Scripts do not run, and raw HTML is escaped unless you allow it.

Use the tool

Why this tool exists

Before you commit a README, post a comment or publish a changelog it helps to see how the Markdown will actually look. A missing blank line breaks a list, a stray pipe ruins a table, and an unclosed code fence swallows the rest of the page.

This preview renders your text with the same engine as the Markdown to HTML tool and shows it in a sandboxed frame, so even if the source contains script tags they cannot run. Raw HTML is escaped by default, which shows you what a stricter platform would do. Turn it on to test how your own HTML blocks look. It works offline once the page has loaded, and your text is not uploaded.

How to use it

  1. Paste or write your Markdown in the input box.
  2. Look at the rendered preview, which updates with your text.
  3. Tick Allow raw inline HTML to see how embedded HTML renders.
  4. Fix formatting problems in the source and watch the preview change.

Frequently asked questions

Is it safe to preview untrusted Markdown?

The preview sits in a sandboxed frame, so scripts never run, even if the Markdown contains script tags and you have allowed raw HTML. Links are also filtered for javascript addresses.

Will it match how GitHub renders my file?

Closely for common syntax such as tables, task lists and fenced code. It is not an exact copy of any one platform, so features like emoji shortcodes or mentions are not rendered here.

Why does my HTML not appear?

Raw HTML is escaped by default and shown as plain text. Tick Allow raw inline HTML to render it. Many comment systems do the same and strip HTML, so the default is a useful check.

Can I get the HTML itself?

Use the Markdown to HTML tool, which gives the converted code to copy. The preview shows only the rendered result.
