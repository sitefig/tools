Test Identifier Generator (IBAN, IMEI, ISIN, LEI, VIN, ISBN and more)

Get realistic but fake numbers to test input validation, parsers and databases.

Use the tool

Why this tool exists

Each generator builds a value in the right format with the correct check digit: mod-97 for IBAN and LEI, Luhn for IMEI and ISIN, the weighted VIN check digit, the ABA 3-7-1 checksum, ISBN-13 and ISSN checks, the Dutch 11-test, the GSTIN base-36 check, UPS 1Z and UPU S10 parcel checks. Output was validated with the python-stdnum library (and independent checks for VIN and tracking numbers).

The values are random and unissued but could coincide with real identifiers by chance; use them only for software testing. IBANs have valid length and mod-97 digits, but national account check digits inside the BBAN are not computed.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Choose an identifier type.
  2. Set how many.
  3. Copy the list into your tests.
  4. Never use generated values for real transactions.

Frequently asked questions

Are these real accounts?

No. They are random numbers that pass format and check-digit tests.

Why do some national validators reject my IBAN?

Some countries add their own check digits inside the account number, which this tool does not compute.

What about credit card numbers?

Use the mock credit card generator, which covers card brands and expiry dates.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
