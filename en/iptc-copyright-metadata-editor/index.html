IPTC Caption, Keywords and Copyright Editor for JPEG (Batch)

Read and write caption, keywords and copyright in JPEGs.

Use the tool

Why this tool exists

Fill in the fields you want and choose JPEG files. The tool writes IPTC caption, headline, title, keywords, creator, credit, source and copyright, and adds a small XMP block (creator, rights, license link) when the file has none. Leave every field empty to just read what the files hold.

Empty fields keep what is there. The picture data is copied byte for byte. Copyright metadata states a claim. It does not stop copying, and anyone can strip it.

How to use it

  1. Choose the JPEGs.
  2. Fill in the fields.
  3. Optionally add a license URL.
  4. Download the updated files.

Frequently asked questions

Will search engines read it?

Google can read IPTC creator, credit and copyright for image results. Visibility is not guaranteed.

Does it overwrite existing XMP?

No. If the file already has XMP, it is left unchanged and the report says so.

Does it work for PNG?

No. JPEG only.

Is anything uploaded?

No. The work happens in your browser and the page makes no network request with your input.
