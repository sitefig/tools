Pre-Consent Request Finder (HAR)

Finds tracker requests and tracking-looking cookies in a HAR file recorded before any consent click, in time order.

Use the tool

Why this tool exists

The most common banner failure is simple: tags fire before the visitor has chosen anything. You can see it by recording a HAR on first visit in a clean browser profile and not touching the banner.

This tool reads that HAR and lists requests to known tracker domains, other third-party requests that send the visitor's IP, and cookies set by responses whose names look like analytics or marketing cookies. It cannot tell when you clicked the banner, so only feed it a HAR where you did not. HAR files can hold secrets, so keep them private.

How to use it

  1. Open a private window, open dev tools Network tab, load your site and do not touch the banner.
  2. Export the HAR and paste its JSON.
  3. Set the first-party domain if the first request is not on your site.
  4. Read the lists and fix tags that fire too early.

Frequently asked questions

Why are some cookies missing?

Cookies set by JavaScript (document.cookie) do not appear in a HAR.

Is a tag manager request a violation?

Not by itself. It is shown because it often loads trackers. Check what it loads.

Is my HAR uploaded?

No. It is read in your browser.
