Add Line Numbers

Add line numbers to pasted text. Choose the starting number, the separator, whether to right-align the numbers and whether to skip empty lines.

Use the tool

Why this tool exists

Numbered lines are useful when you quote code in a review, refer to a clause in a contract, share a log excerpt in a ticket or prepare a script. Most plain text editors do not show numbers you can copy, so the numbers are lost when you paste.

This tool puts a number at the start of every line of the text you paste. You can start from any number, set the separator, such as a colon and a space, or a tab, and right-align the numbers so the text lines up when the count passes 9 or 99. If you skip empty lines, they are left blank and not numbered, and the numbering continues on the next line with text. Everything is done in your browser.

How to use it

  1. Paste your text into the input box.
  2. Set the starting number and the separator, for example a colon and a space.
  3. Choose right-aligned numbers and whether to skip empty lines.
  4. Run the tool and copy the numbered text.

Frequently asked questions

Can I start numbering from a number other than 1?

Yes. Set the start value in the options, for example 100 to continue from an earlier section. Zero and negative start values also work.

What does skip empty lines do?

Empty lines are left unnumbered and do not use up a number, so the numbers continue in sequence on the lines that have text.

How do I remove line numbers later?

Use the find and replace tool with a regex such as ^\s*\d+: to strip them, adjusting the separator to match what you used.

Is my text uploaded?

No. The text is processed in your browser and is not uploaded, stored or sent to a server, so it is fine to use with drafts, lists and private notes.
