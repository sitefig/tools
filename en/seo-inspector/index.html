SEO Page Inspector

Paste a page's HTML source to get a prioritised on-page SEO report covering title, meta description, canonical, robots, viewport, headings, images, social tags, structured data and thin content.

Use the tool

Why this tool exists

When a page does not rank or looks wrong in search results, the cause is often a basic tag: a missing title, a noindex left over from staging, a canonical pointing somewhere else or no H1. Spotting that in a long source file is slow, and many online auditors want you to hand over a URL or an account.

This inspector reads the HTML you paste and lists problems as errors, warnings and notes in order of importance. It checks the title and description length, canonical and robots tags, viewport, language and charset, headings, image alt text, Open Graph and Twitter tags, JSON-LD, favicon, empty links and the amount of visible text. It works on one page of source at a time and does not fetch anything, so it cannot see how the page renders after JavaScript runs.

How to use it

  1. Open the page, view the source and copy all the HTML.
  2. Paste it into the input box.
  3. Run the tool to produce the report.
  4. Fix the errors first, then the warnings, and run it again to confirm.

Frequently asked questions

Does it fetch my page?

No. You paste the source and it analyses only that text in your browser. It cannot see content added later by JavaScript, so paste the rendered DOM from developer tools if your page needs it.

What counts as an error here?

Problems that usually block search visibility or basic usability, such as a missing title or H1, a noindex robots tag, multiple canonicals or a missing viewport. Warnings and notes are less urgent.

Is it a full SEO audit?

No. It covers on-page markup only. It does not check links to other pages, speed, backlinks, indexing status or content quality, so use it alongside other checks.

Is my HTML uploaded?

No. The analysis runs locally in your browser and your source code is not sent to any server.
