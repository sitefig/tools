Waypoint List to GPX Route or Track File

Writes a GPX 1.1 file from a typed list of points, as a route, a track or plain named waypoints.

Use the tool

Why this tool exists

Planning a route usually means clicking on a map, which needs map tiles. If you know the points, you can type them and get the GPX file directly, ready for a GPS unit or a hiking app.

Routes are meant to be navigated, tracks record where you went. The tool can also write the same points as named waypoints. It shows the great-circle length between points, which is shorter than any real path. The file was parsed with gpxpy to verify structure.

How to use it

  1. Type one point per line: lat, lon, name.
  2. Choose route, track or waypoints only.
  3. Name the route and decide on extra waypoints.
  4. Download the .gpx file.

Frequently asked questions

Does it route along roads?

No, the line goes straight between your points.

Can I add elevation?

Not in this version.

Which GPX version?

1.1.

How many points?

Up to 5000.
