Radar (Spider) Chart Maker for Comparing Items

Draws a radar (spider) chart. Each row is an item, each column an attribute, and each item becomes a polygon on shared axes.

Use the tool

Why this tool exists

Radar charts compare a few items on several scores, such as products against criteria or skills across a team. All axes share one scale, set automatically or by you, so polygons are comparable.

Radar charts are easy to misread: area grows with the square of scores, and the order of axes changes the shape. Use them for 3 to 8 attributes and 2 to 4 items, and keep the table as the exact reference.

How to use it

  1. Paste a header row of attributes and one row of scores per item.
  2. Set an axis maximum if scores share a known scale such as 10.
  3. Choose whether polygons are filled.
  4. Copy or download the SVG.

Frequently asked questions

How many attributes?

Between 3 and 24.

Can scores be negative?

Yes, the centre then represents the lowest value.

Should I normalise first?

Yes if attributes use different units.

Does axis order matter?

It changes the polygon shape, so keep it consistent between charts.
