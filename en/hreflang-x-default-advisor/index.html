Hreflang x-default Advisor

Explains which page should be your x-default for your setup and generates the tag set with it added.

Use the tool

Why this tool exists

x-default names the page for visitors whose language matches none of your versions. Google says it was designed for language selector pages, and also works as a general fallback. The right target depends on your setup, and the tool explains each case: a selector page, a global page, a home page that redirects by browser language, or no fallback at all.

The generated set includes x-default and a reminder that every version, including the x-default page, must carry the complete set.

How to use it

  1. Enter your versions as code | URL lines.
  2. Choose your setup and optionally enter the x-default URL.
  3. Read the advice.
  4. Copy the tags into every version.

Frequently asked questions

Is x-default required?

No, Google calls it recommended.

Can x-default be the same URL as a language?

Yes, a version can carry both codes.

What about auto-redirecting home pages?

Keep plain links to every version; Google does not vary its crawler by location.

Does it need a language code?

No, the x-default page is for unmatched users, so its language is irrelevant.
