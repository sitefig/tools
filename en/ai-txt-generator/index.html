ai.txt Generator (AI Training Permissions by File Type)

Generates an ai.txt with robots.txt-style rules per file extension for the media types you choose.

Use the tool

Why this tool exists

ai.txt is a proposal by Spawning to tell AI developers which file types on a site may be used for training. It looks like robots.txt and works per extension.

The specification page could not be loaded while building this tool, so the syntax is from memory and marked unverified in the output. No AI company is documented to read ai.txt, so robots.txt and the TDM headers are more likely to be honoured. Treat the file as an extra signal at best.

How to use it

  1. Set allow or disallow for each media type.
  2. Add extra extensions to block.
  3. Copy the output and save it as /ai.txt.
  4. Back it up with robots.txt rules.

Frequently asked questions

Does any AI company read ai.txt?

None is documented to do so.

Is the syntax verified?

No, the output says so.

Is it a standard?

No, it is a proposal.

What else should I use?

robots.txt tokens for AI crawlers, TDM headers or the aipref drafts.
