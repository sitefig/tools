Mind Map Builder from an Indented Outline (SVG)

Draws a mind map from an indented list. Each branch from the centre gets its own colour, and you can collapse levels deeper than a number you choose.

Use the tool

Why this tool exists

Outlines are how most people draft ideas; a map makes the structure visible. Paste an indented list and get a tree growing to the right, with curved links and colours per main branch.

Collapsing is done with the levels option, which replaces the click-to-fold of an interactive map and is therefore usable with a keyboard. Collapsed nodes show a plus count of what is hidden. The outline is also listed in the table as a text version.

How to use it

  1. Write the root, then indent children by two spaces.
  2. Use bullets or numbers if you like; they are ignored.
  3. Set levels to show to collapse deeper branches.
  4. Copy or download the SVG.

Frequently asked questions

How do I nest?

Indent by two spaces (or a tab) per level.

Several top-level lines?

They are placed under a generic "Map" root.

Can I export Markdown?

The mind map maker tool exports an outline; this one draws the picture.

Size limits?

Up to 400 nodes.
