JSON Diff

Compare an original and a changed JSON document and get a list of added, removed and changed values, each with its path. Key order does not matter.

Use the tool

Why this tool exists

A text diff of two JSON files is often useless: reformatting or a different key order lights up every line. What you want to know is which values really changed. This happens when you compare API responses between environments, review a changed config, or check what a migration did to a document.

The tool parses both inputs and walks them together, reporting each difference with its path, such as $.address.city. Added values are marked +, removed ones -, changed ones ~. Objects are compared by key, so reordering is ignored. Arrays are compared item by item by position. Both documents stay in your browser and are not uploaded.

How to use it

  1. Paste the original JSON in the first box.
  2. Paste the changed JSON in the second box.
  3. Read the list of differences, each with a path and the old and new value.
  4. Fix any syntax error shown, then compare again.

Frequently asked questions

How are arrays compared?

By position. If an item is inserted at the start, later items appear as changed. That is accurate, but sort or normalise arrays first if their order should not matter.

Does key order matter?

No. Objects are compared key by key, so the same data in a different order reports no difference.

What do the symbols mean?

A plus sign marks a value added in the changed document, a minus sign marks one removed, and a tilde marks a value that exists in both but differs, shown as old to new.

What if both documents are equal?

The tool says No differences: the documents are equivalent. That includes the case where they differ only in whitespace or key order.
