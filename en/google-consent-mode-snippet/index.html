Google Consent Mode v2 Snippet Builder

Generates the Google Consent Mode v2 default and update code with all four main signals, optional regions, wait_for_update and ads_data_redaction.

Use the tool

Why this tool exists

Google tags need to know the visitor's consent state before they load. Consent Mode v2 added two signals, ad_user_data and ad_personalization, next to ad_storage and analytics_storage.

This tool writes the default call, the update function for your banner to call, and the optional settings. The default must run before the Google tag or Tag Manager loads, otherwise the tag starts without it. The code does not collect consent: that is the job of your consent banner.

How to use it

  1. Choose the default for each signal. Denied is the usual starting point in the EU.
  2. Set a region list if the default should only apply to some places.
  3. Copy the script above your Google tag snippet.
  4. Call updateConsent from your banner when the visitor chooses.

Frequently asked questions

Does this make me compliant?

No. It passes a state to Google tags. You still need a valid consent banner and a lawful basis.

What does wait_for_update do?

It tells tags to wait that many milliseconds for an update call before sending data, so a stored choice can arrive first.

Can I check it works?

Yes. Paste a request URL into the Consent Mode Decoder to see the gcs and gcd values.
