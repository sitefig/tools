Email Name and Address Formatter ("Name <email>" List)

Paste rows of names and addresses and get a single separated list for a mail client.

Use the tool

Why this tool exists

Mail clients expect "Name" <address> pairs. Pasting columns from a spreadsheet gives tabs and mixed formats, and names with commas or dots need quotes to stay valid.

Quoting follows RFC 5322: names with specials such as comma, dot, quote, @ or brackets are quoted, and quotes inside are escaped. Non-ASCII names can be encoded as RFC 2047 encoded words. Use semicolons for Outlook.

How to use it

  1. Paste one row per person.
  2. Choose the separator.
  3. Turn on encoding for non-ASCII names if your tool needs it.
  4. Copy the list into To or BCC.

Frequently asked questions

Which row formats work?

"Name, email", Name<TAB>email, Name <email> and plain addresses.

Why use semicolons?

Older Outlook settings use semicolons between addresses.

Is BCC private?

Yes, but check your tool: put addresses in BCC, not To.

Does it validate addresses?

Basic syntax only.
