Sitemap Size and Limit Checker

Counts URLs and bytes in a pasted sitemap and compares them with the protocol limits.

Use the tool

Why this tool exists

Search engines stop reading a sitemap that is too big. It is easy to cross a limit without noticing, especially with many long URLs.

This page shows how close you are to each limit and how many files a split would need. Size is measured on the pasted text, so line endings in the real file can change the number slightly.

How to use it

  1. Paste the sitemap XML or a URL list.
  2. Read the URL count and size against each limit.
  3. Check the number of files needed.
  4. If it is over, use the splitter tool.

Frequently asked questions

Which limits are used?

50,000 URLs and 52,428,800 bytes uncompressed, from sitemaps.org.

Does gzip help?

No. The limit is on the uncompressed size.

Does it handle sitemap indexes?

Yes. It counts the sitemaps in the index against the 50,000 sitemap limit.

Is my file uploaded?

No, it is processed in your browser.
