Silence Remover for Audio

Finds stretches of audio quieter than a threshold and cuts or shortens them, then exports the tightened file as WAV.

Use the tool

Why this tool exists

Voice memos, lecture recordings and screen-recorded narration are full of pauses. Removing the long ones makes them faster to listen to without changing the voice, unlike speeding up the whole file.

Level is measured in 10 ms blocks across all channels. A gap counts only if it stays below the threshold for longer than your minimum length. By default each cut leaves 150 ms of silence so speech still breathes, and each join has a 2 ms fade to avoid clicks. If room noise is above the threshold, nothing is cut, so raise the threshold in that case.

How to use it

  1. Choose a recording.
  2. Set the threshold (try -45 dB) and the shortest gap to cut (500 ms).
  3. Set how much silence to leave at each cut.
  4. Press Run and compare the new length with the old.

Frequently asked questions

Nothing was cut. Why?

The pauses are probably louder than the threshold because of room noise. Raise the threshold, for example to -35 dBFS.

Does it cut quiet words?

Very soft sounds below the threshold can be treated as silence, but only if they last longer than the minimum gap.

Can I remove all silence entirely?

Set "leave this much silence" to 0. Speech sounds hurried that way.

Will it click at the joins?

Each join has a short 2 ms fade, which prevents clicks in normal material.
