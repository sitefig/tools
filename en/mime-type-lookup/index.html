MIME Type Lookup

Look up the MIME type for an extension like .webp, or work out the extension for a type like application/json. The list covers common web, image, audio, video, font and document formats.

Use the tool

Why this tool exists

A wrong Content-Type is a classic cause of broken downloads and silent failures: fonts that do not load, scripts blocked by nosniff, a PDF that opens as text, a WebAssembly file that cannot be streamed. Remembering the exact type for every extension is unrealistic.

This lookup lists around a hundred extensions with the MIME type and a short description. Type an extension, part of a type or a word like "video" and the list narrows. Use it when setting up a web server, an upload validator or a storage bucket. It lists common types, so for anything exotic check the IANA registry.

How to use it

  1. Open the tool to see the whole list.
  2. Type an extension such as .woff2, or part of a MIME type such as image/ or json.
  3. Read the matching rows, which show extension, MIME type and description.
  4. Copy the MIME type into your server configuration or upload rules.

Frequently asked questions

Is the correct JavaScript type text/javascript?

Yes. The current standard type is text/javascript. The older application/javascript and application/x-javascript are obsolete aliases that you may still see, and servers should send text/javascript.

Why do some extensions map to several types?

Some formats have a registered type plus older aliases, and a few extensions are shared. For example .pem appears as a certificate type and as a generic PEM file. Choose the one your client expects.

What should I send for an unknown file?

Use application/octet-stream, which means arbitrary binary data. Browsers will usually offer to download it. Send a specific type whenever you know it, so the file opens properly.

Does it cover every type?

No, it covers the common ones, roughly a hundred. The official registry kept by IANA lists many more, including vendor-specific types.
