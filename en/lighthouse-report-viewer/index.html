Lighthouse JSON Report Viewer: Scores, Metrics and Failing Audits

Reads a Lighthouse JSON report and lists category scores, lab metrics, opportunities with estimated savings and the audits that failed, grouped by category.

Use the tool

Why this tool exists

A Lighthouse report.json is hard to read by eye. It holds hundreds of audits, and the HTML viewer needs the original tool or a hosted page.

This page reads the file in your browser and keeps only what you act on: scores with bands, the weighted metrics, savings in milliseconds and bytes, and each failing audit with its item count. It also accepts a PageSpeed Insights API response, because that wraps the same report. Nothing is uploaded. The result is one lab run, so scores move between runs.

How to use it

  1. Run Lighthouse and save the JSON (the CLI flag --output=json, or Save as JSON in the report menu).
  2. Paste the file contents into the box.
  3. Pick one category or leave it on all.
  4. Tick "List passing audits too" if you want the full list.

Frequently asked questions

Can I paste a PageSpeed Insights API response?

Yes. The report sits under lighthouseResult and the tool unwraps it.

Why does my score differ from PageSpeed Insights?

Each run is a separate lab test with its own network and CPU variance, and PSI uses different hardware. Compare several runs.

What are the score bands?

Lighthouse treats 90 and above as good, 50 to 89 as needs work, and below 50 as poor.

Is the report sent anywhere?

No. It is parsed in your browser.
