AES-GCM Encrypt

Encrypt a piece of text with a password. The tool derives a key with PBKDF2-SHA256 (600,000 iterations), encrypts with AES-256-GCM and gives you one base64 string.

Use the tool

Why this tool exists

Sometimes you need to pass a short secret through a channel you do not trust: a note in a ticket, an email, a shared document. Encrypting it with a password first means the channel only ever sees ciphertext.

This tool uses the browser WebCrypto API, so there is no custom cryptography. A random salt and nonce are generated for every run, the key comes from your password through PBKDF2 with 600,000 iterations, and AES-GCM adds authentication so tampering is detected. The output is a single base64 string that carries a version byte, the iteration count, salt and nonce, ready for the matching decrypt tool. It is a convenience for short text, not a replacement for a vetted file encryption tool.

How to use it

  1. Enter the text to encrypt in the input box.
  2. Type a strong password in the options. The default password is only a placeholder, so change it.
  3. Run the tool to produce the base64 ciphertext.
  4. Copy the output and share the password through a different channel.

Frequently asked questions

How is the output structured?

Base64 of a version byte, the iteration count, a 16-byte salt, a 12-byte IV and the ciphertext. Header bytes are authenticated. A fresh salt and IV are used each time, so the same input gives different output.

Is it safe to use for important secrets?

It uses standard primitives, but safety depends on your password. A weak password can be guessed offline. This is not audited software, so for high-stakes data use a reviewed tool.

What if I forget the password?

The text cannot be recovered. There is no reset and no copy on any server. Keep the password in a password manager.

Is my text uploaded?

No. Encryption runs in your browser through WebCrypto, and neither the text nor the password is sent anywhere. Closing the tab discards both from the page.
