Robots Meta Tag Generator (noindex, max-snippet, max-image-preview)

Builds the robots meta tag you need, plus the same rules as an X-Robots-Tag header, using the directives Google documents.

Use the tool

Why this tool exists

The robots meta tag controls indexing and previews per page, but the syntax is easy to get wrong: max-snippet takes a number, max-image-preview takes none, standard or large, and unavailable_after wants a date.

Pick the directives and get the tag and the header form. The tool warns about combinations that do nothing, such as indexifembedded without noindex, and notes that noarchive is ignored by Google. A page blocked in robots.txt never shows its tag to crawlers.

How to use it

  1. Choose the crawler and indexing options.
  2. Add snippet or preview limits if needed.
  3. Copy the meta tag into the page head or the header into your server.
  4. Make sure the page is not blocked in robots.txt.

Frequently asked questions

Meta tag or header?

Use the header for non-HTML files such as PDFs. For HTML pages either works.

What does max-snippet:-1 mean?

No limit: the search engine chooses the length.

Does noindex work if robots.txt blocks the page?

No. The crawler never fetches the page, so it never sees the tag.

Is noarchive still used?

Google lists it as ignored for Search; other engines may honour it.
