Word (.docx) to HTML & Text Viewer

Read or extract the text of a Word document on any device and copy clean HTML.

Use the tool

Why this tool exists

A .docx is a ZIP of XML files. The viewer unzips it in the browser, reads word/document.xml, the relationships (for links and images) and the numbering definitions, then writes HTML for paragraphs with Heading and Title styles, bold, italic, underline, strikethrough, super- and subscripts, bulleted and numbered lists, tables, hyperlinks and embedded images. Output was compared with python-docx text on generated documents.

It shows content, not page layout: columns, text boxes, headers and footers, comments and exact fonts are not reproduced, and legacy .doc files are not supported.

The file is read in your browser and is not uploaded anywhere.

How to use it

  1. Choose a .docx file.
  2. Pick preview with HTML source or plain text.
  3. Copy the HTML or text you need.
  4. Check complex layouts in Word.

Frequently asked questions

Does it handle .doc files?

No, only the modern .docx format.

Are images included?

Yes, small images are embedded as data URIs in the HTML.

Is the file uploaded?

No.

Is my data sent anywhere?

The file is read in your browser and is not uploaded anywhere.
