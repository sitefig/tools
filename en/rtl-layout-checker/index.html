RTL Layout and Bidi Checker for Arabic and Hebrew HTML

Reviews pasted Arabic or Hebrew HTML for missing dir attributes, invalid values, embedded left-to-right runs and physical left and right styles.

Use the tool

Why this tool exists

Right-to-left pages break in small ways: punctuation lands on the wrong side of an English brand name, a phone number reads backwards, a margin stays on the left. The tool reads the HTML source, checks that dir="rtl" accompanies RTL languages, flags invalid dir values, finds URLs, numbers and Latin words inside RTL text, and notes inline styles that use left and right.

It is a source-level heuristic. It cannot see your CSS files, the rendered result or text added by scripts, so findings are labelled REVIEW. A native reader checking the rendered page is the real test.

How to use it

  1. Paste the HTML of the page or a fragment.
  2. Read the errors and review notes.
  3. Wrap embedded LTR text in bdi or a span with dir="ltr".
  4. Use logical CSS properties.

Frequently asked questions

Which languages count as RTL?

Arabic, Hebrew, Persian, Urdu, Pashto, Sindhi, Uyghur, Yiddish, Dhivehi and Central Kurdish.

What is bdi?

An element that isolates its text from the surrounding direction.

Does it look at CSS files?

No, only the HTML you paste.

Is it a full accessibility audit?

No.
