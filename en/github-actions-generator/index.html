GitHub Actions CI Generator

Choose a language, matrix versions, runners and branches to get a CI workflow YAML that checks out code, sets up the toolchain, caches dependencies and runs tests.

Use the tool

Why this tool exists

Every new repository needs a basic CI workflow, and writing the YAML from memory means looking up the right setup action, the matrix key and how caching is switched on. A small indentation slip stops the workflow from loading at all.

This generator builds a working file for Node, Python, Go and Rust. It sets up a test job that runs on push and pull request for the branches you list, expands a matrix of language versions and runners, and turns on dependency caching where the setup action supports it. Rust gets an explicit cache step. The build and test commands are the common defaults, such as npm ci and pytest, so edit them to fit your project. Output is created locally in the browser.

How to use it

  1. Select the language: node, python, go or rust.
  2. Enter matrix versions separated by commas, or leave it blank for defaults.
  3. Set runners and branches, and keep Cache dependencies ticked if you want caching.
  4. Copy the YAML into .github/workflows/ci.yml.

Frequently asked questions

What are the default versions?

Node 18, 20 and 22; Python 3.10, 3.11 and 3.12; Go 1.21 and 1.22; Rust stable and beta. Enter your own comma-separated list if you support different releases.

Which commands does the workflow run?

Node runs npm ci, an optional build and npm test. Python installs requirements.txt and runs pytest. Go runs build and test, and Rust runs cargo build and cargo test. Edit the run lines for your own scripts.

How does caching work?

Node and Python use the built-in cache option of their setup actions, Go uses its own cache setting, and Rust uses an actions/cache step keyed on Cargo.lock. Untick the option to disable all of it.

Does it deploy anything?

No. It only builds and tests. Deployment, secrets and release steps depend on your target and are best added as separate jobs after the tests pass.
