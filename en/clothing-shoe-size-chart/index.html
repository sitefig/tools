Clothing & Shoe Size Chart

Choose Shoes or Clothing (tops) to see a reference table. Shoe tables convert US, UK and EU sizes with foot length in centimetres; the clothing table lists chest measurements.

Use the tool

Why this tool exists

Ordering clothes from an overseas shop usually means decoding a size chart. A US 9 is a UK 8.5 for men and a 42 in European sizes, but the same number means something else for women, and brands cut differently again. This page puts a compact set of common conversions in one place, with foot length in centimetres, which is the most reliable thing to measure. The clothing table gives chest ranges in centimetres and inches alongside XS to XXL and rough EU and US numbers. It is a generic reference table only, not a fit guarantee, so always check the shop's own chart if it has one. The page needs no uploads and works offline once loaded.

How to use it

  1. Select the chart: Shoes or Clothing (tops).
  2. Run the tool to show the table.
  3. Find your size in one system and read across to the others.

Frequently asked questions

How accurate are the conversions?

They are approximate. Brands, countries and styles differ by half a size or more. Use the table as a guide and prefer the retailer's own size chart or your measured foot length.

How should I measure my foot?

Stand on paper, mark the heel and the longest toe, and measure the distance in centimetres. Measure in the evening, when feet are largest, and compare with the foot length column.

Is the clothing chart for men or women?

It is an approximate chart for men's tops. Women's and children's sizing varies more between brands and is not covered.

Does the chart include half sizes?

Only the sizes listed. In between, choose the nearer size or check the brand's chart. The table is deliberately short and readable.
