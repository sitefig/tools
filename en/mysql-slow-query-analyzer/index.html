MySQL Slow Query Log Analyzer (Group by Fingerprint)

Groups slow log entries by fingerprint and ranks them.

Use the tool

Why this tool exists

One slow query pattern may run thousands of times. Total time per pattern shows where the server spends its time.

For each pattern the tool shows count, total, average and maximum time, lock time and rows examined versus rows sent. Examining far more rows than returned is a sign of a missing index.

How to use it

  1. Enable the slow query log and collect it.
  2. Paste the log or open the file.
  3. Choose ranking by total, average, max or count.
  4. Read the patterns and examples.

Frequently asked questions

What is a fingerprint?

The query with literals replaced by ? and lists collapsed, in lower case.

Does it replace pt-query-digest?

No. It is a simplified take for pasted logs.

Which log forms work?

The text slow log with # Query_time lines.

Is my log uploaded?

No. Everything is processed in your browser and nothing is sent. Logs can hold IP addresses and tokens, so the page does not write them into the address bar.
