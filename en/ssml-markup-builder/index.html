SSML Builder: Speech Markup for Voice Assistants and TTS

Prepare text-to-speech input for Alexa, Google, Azure or Polly with correct markup.

Use the tool

Why this tool exists

Write plain text with a blank line between paragraphs, *word* for emphasis, [pause 500ms] for pauses and [spell 4471] for character-by-character reading. The tool escapes XML, wraps paragraphs in <p>, inserts <break> between them, applies a prosody element for rate and pitch, an optional voice and the language, and verifies the result with an XML parser.

Speech platforms accept different subsets of SSML and some require their own extensions, so test in your target service. The tool does not speak the result; the text-to-speech tool uses the browser's own voices.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Write the text with markers.
  2. Choose language, voice, rate and pitch.
  3. Copy the SSML.
  4. Paste it into your speech service console.

Frequently asked questions

What does <break> do?

It inserts a pause of a given length.

How do I spell out a code?

Use [spell ABC], which becomes say-as interpret-as="characters".

Does it work in every service?

The core elements are widely supported; vendor extensions are not generated.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
