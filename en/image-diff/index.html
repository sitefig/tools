Image Diff

Load two images and see the pixels that differ highlighted in red, with the share of changed pixels shown above the result.

Use the tool

Why this tool exists

Visual changes are hard to spot by eye: a shifted button, a different shade, a missing icon. Designers comparing exports, developers checking screenshots after a CSS change and testers reviewing a visual regression all need an objective answer to what changed and by how much.

This tool draws the second image over the first at the first image's size and compares them pixel by pixel. Any pixel that differs by more than your tolerance in red, green, blue or alpha is painted red, and unchanged areas are shown faded, so the differences stand out. A percentage tells you how large the change is. Raise the tolerance to ignore tiny compression noise. Both images stay in your browser; nothing is uploaded.

How to use it

  1. Choose Image A, the reference image.
  2. Choose Image B, the image to compare.
  3. Adjust the tolerance, from 0 to 255, to ignore small colour differences.
  4. Read the percentage changed and inspect the red areas in the result.

Frequently asked questions

What does tolerance mean?

It is the largest difference in any colour channel that still counts as unchanged. The default of 16 hides faint JPEG noise. Set it to 0 to flag every tiny difference.

What if the images have different sizes?

The second image is resized to match the first, and the tool says so. Because resizing blurs detail, results are most meaningful when both images have the same dimensions.

Will JPEG compression cause false differences?

Yes, lossy compression changes pixels slightly even when the picture looks the same. Compare PNG screenshots where you can, or raise the tolerance to filter out the noise.

Does it detect moved elements?

No. It compares pixels at the same position, so an element that shifted by a few pixels will show as changes at both its old and new place. It does not track movement.
