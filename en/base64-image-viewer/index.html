Base64 Image Viewer

Paste a data URI or a raw Base64 string and see the image it contains. The tool detects the file type from the bytes, shows a preview and lets you download the file.

Use the tool

Why this tool exists

Images hide inside CSS, HTML emails, JSON responses and log files as long Base64 strings, and a wall of characters tells you nothing. You often need to confirm that an API really returned the picture you expect, or to pull an embedded logo back out as a normal file.

This viewer decodes the string locally and shows the image straight away. If the data URI has no usable type, it checks the first bytes for known image signatures. The preview and download are built in your browser, so private screenshots or customer images are not uploaded.

How to use it

  1. Paste a full data URI such as data:image/png;base64,... or just the raw Base64 string.
  2. Run the tool to decode it and preview the image.
  3. Check that the picture looks right.
  4. Download the image as a file with the suggested name and extension.

Frequently asked questions

Which image types are recognised?

PNG, JPEG, GIF, WebP, BMP, ICO and SVG. If the data URI declares an image type, that is used. Otherwise the tool reads the first bytes for the format signature.

Why do I get "Could not detect an image type"?

The decoded bytes do not start like any supported image format. The string may be truncated, may be a different kind of file such as a PDF, or may have extra characters at the start. Check the source.

Does the file leave my device?

No. Decoding, preview and download all happen inside your browser tab, so private images and screenshots stay on your own computer.

Can I go the other way and turn an image into Base64?

Yes, the Image to Base64 tool creates a data URI from a picture file. Keep in mind that Base64 makes the data about a third larger, so it suits small icons rather than big photos.
