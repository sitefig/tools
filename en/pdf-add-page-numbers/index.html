Add Page Numbers to PDF

Add page numbers to an existing PDF. Choose the position, the format such as Page {n} of {N}, the first number, font size and which pages to number.

Use the tool

Why this tool exists

Merged files, scans and exported chapters often arrive without page numbers, which makes referring to a page in a meeting or a legal review awkward. Word processors add numbers when you write a document, but not after the PDF exists.

This tool stamps numbers onto the finished pages. Pick one of six positions along the top or bottom edge, write a format using {n} for the current number and {N} for the total, and set the first number, so a chapter can start at 15. You can also limit the numbering to a range, for example to skip a cover page. It respects page rotation and crop offsets, so numbers land where you expect on rotated pages. Text is set in Helvetica, and characters outside the Western set show as a question mark.

How to use it

  1. Choose a PDF file.
  2. Pick a position and write the format, for example Page {n} of {N}.
  3. Set the first number, font size, margin, bold, and the pages to number if you want a subset.
  4. Run the tool and download the numbered PDF.

Frequently asked questions

What do {n} and {N} mean?

{n} is replaced with the page's own number, and {N} with the total number of pages. The default format Page {n} of {N} gives Page 3 of 12. Use just {n} for a bare number.

Can I skip the cover page?

Yes. Enter a range in the pages field, such as 2-, to number from page two onwards. Set the first number to 1 if you want page two to be shown as 1.

Will the numbers cover existing text?

They are drawn on top of the page, near the edge. If your page has content in the margin, increase the margin value or choose another position. The crop box and rotation are taken into account.

Can I change the font?

Only the size and bold setting. The text uses Helvetica, a standard PDF font, so no font files are embedded and the file size barely grows.
