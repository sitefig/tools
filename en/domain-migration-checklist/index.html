Domain Migration SEO Checklist: Redirects, Search Console, Sitemaps

An interactive checklist for moving a site to a new domain or URL structure, in four stages: prepare, map URLs, launch and after launch. Tick items off, copy as Markdown.

Use the tool

Why this tool exists

Site moves go wrong when a small step is forgotten: a robots.txt that still blocks everything, a missing Search Console property, redirects that chain or point to the home page. A checklist makes the order clear.

The steps follow Google Search Central's guide for site moves with URL changes, read in October 2026. Your site may need more, and the guide may change. Ticks are stored in this browser only and are never sent anywhere.

How to use it

  1. Work through the four groups from the top.
  2. Tick each step as you finish it.
  3. Use Copy as Markdown to paste the list into a ticket.
  4. Press Reset all to start a new migration.

Frequently asked questions

Do I need the Change of Address tool for HTTPS?

No. Google says it is only for domain moves, not for http to https, www changes or path changes.

How long should I keep redirects?

At least a year, according to Google.

Where is my progress stored?

In your browser's local storage. Clearing site data removes it.

Is this the full migration plan?

No. It covers the search-related steps. Add your own technical and content tasks.
