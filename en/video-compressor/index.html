Video Compressor: Lower Bitrate and Resolution to Shrink a File

Lowers the resolution and bitrate of a video so the file is small enough to send. You see an estimated size before you start and the real size after.

Use the tool

Why this tool exists

File size is bitrate times duration. This tool lets you set both ends: a target height and a video bitrate in kbit/s, and it shows the arithmetic as an estimate for a one minute clip. That makes it easy to reach a limit such as 25 MB for email.

Nothing is uploaded. The file is decoded by your browser and re-encoded, so quality drops a little and the result is WebM (or MP4 where your browser can record it). It records in real time, so a 60 second clip takes about a minute and the tab must stay visible. If the result is bigger than the source, the source was already well compressed, so lower the bitrate or the height more.

How to use it

  1. Choose the video file.
  2. Pick an output height and a bitrate. 720p at 1200 kbit/s is a common starting point.
  3. Press Process and keep the tab visible.
  4. Check the size shown, then download. Repeat with lower numbers if needed.

Frequently asked questions

How do I hit a size limit?

Size in MB is about (video kbit/s + audio kbit/s) x seconds / 8 / 1024. Solve for the bitrate you can afford.

Why is my output larger than the original?

Browser encoders are less efficient than the encoder that made your file. Lower the bitrate or the height.

Can I remove the audio to save space?

Yes, untick Keep audio. Audio is small, about 64 kbit/s here.

Is the bitrate exact?

It is a target for the browser encoder. Real files vary around it.
