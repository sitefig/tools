PDF OCR: Make a Scanned PDF Searchable

Renders each scanned page, recognises the printed English text with the on-device OCR engine and adds the text as an invisible layer on top of the original page.

Use the tool

Why this tool exists

A scanned PDF is only pictures. You cannot search it, select a sentence or let a screen reader read it. Adding a hidden text layer fixes that and leaves the page looking exactly as it did. The original page content is kept untouched.

OCR is slow and imperfect, so pages are limited to 60 per run and a resolution of 200 DPI is the default. Lines are placed from their recognised position and stretched to the measured width, so selecting text highlights roughly the right area rather than exact words. English printed text only; handwriting and other scripts are not recognised. The recognised text is also shown so you can copy it.

How to use it

  1. Choose a scanned PDF.
  2. Set the pages if you only need some.
  3. Press Run; the first run downloads the OCR model once.
  4. Download the searchable PDF or copy the recognised text.

Frequently asked questions

Does it replace the scan?

No. Pages keep their image; the text layer is added invisibly on top.

How accurate is it?

Good on clean printed English text at 200 DPI or more. Poor scans, small print and tables lower the accuracy; the page report shows a confidence percentage.

Can it read other languages?

Not yet. The model is English (Latin script) only.

Why skip pages that already have text?

Adding OCR text over real text would duplicate it. Untick the option to force OCR.
