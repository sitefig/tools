Ethereum EIP-55 Checksum Address

Paste Ethereum addresses, one per line. The tool returns each in EIP-55 checksum form and tells you whether the case in your input was a valid checksum.

Use the tool

Why this tool exists

Ethereum addresses are 20 bytes written as 40 hex digits, and a single wrong character sends funds to the wrong place. EIP-55 hides a checksum in the capitalisation of the letters, so a typo in a mixed-case address can be detected without changing its length. Wallets and block explorers show the checksummed form, but logs, databases and old documentation often hold all-lowercase addresses. This tool converts a list to the checksum form and flags any mixed-case address whose capitalisation does not match, which usually means a typo or a mangled copy. It uses Keccak-256, run locally in your browser. It checks format only; it cannot tell you whether an address is a contract, is funded or belongs to the person you think.

How to use it

  1. Paste one Ethereum address per line, with or without the 0x prefix.
  2. Run the tool.
  3. Read each checksummed address and its status: valid, invalid or no checksum in the input.

Frequently asked questions

How does the EIP-55 checksum work?

The lowercase address is hashed with Keccak-256. Each letter is uppercased if the matching hex digit of the hash is 8 or higher. The pattern of capitals is the checksum.

What does 'no checksum in input' mean?

The input was all lowercase or all uppercase, so there was no checksum to verify. The tool still outputs the correct checksummed form.

What does CHECKSUM INVALID mean?

The address had mixed case that does not match the correct pattern. Either a character was mistyped or the capitalisation was altered. Recheck the source before sending funds.

Does it validate the address on-chain?

No. It checks only length, hex characters and the checksum. It cannot tell if the address exists, holds funds or is a contract.
