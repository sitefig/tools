Repeated Word Finder (Same Word Used Too Close Together)

Find words that come back within a few words or sentences of each other, ignoring common little words, and mark them in your text.

Use the tool

Why this tool exists

Repeating a word within a sentence or two is one of the first things a reader notices and an editor flags. It is hard to see in your own writing.

Set a window in words, a minimum word length and whether to skip common words. The tool marks every word that recurs inside the window and lists the closest gaps. Key terms and names are fine to repeat, so use it as a prompt.

How to use it

  1. Paste your draft.
  2. Set the window, for example 40 words.
  3. Set the minimum word length.
  4. Read the marked repeats and decide which to change.

Frequently asked questions

How is this different from the Duplicate Words Finder?

That tool finds accidental doubles like 'the the'. This finds words reused close together.

Which words are ignored?

A built-in list of common function words, if the option is ticked.

Is a repeat always a problem?

No. Names, terms and deliberate echoes are fine.
