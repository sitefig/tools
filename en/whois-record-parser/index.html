WHOIS Record Parser (Domain and IP, Expiry and Status Explained)

Turn raw WHOIS text into a readable summary with the expiry countdown, domain age and the meaning of each EPP status.

Use the tool

Why this tool exists

WHOIS output is long, inconsistent between registries and full of codes such as clientTransferProhibited. This parser extracts the registrar, creation, update and expiry dates, name servers and statuses from pasted text (domain or IP records), calculates domain age and days to expiry and explains each status: which are normal locks, which mean the domain does not resolve (hold, redemption, pending delete).

The page cannot query WHOIS servers, so run `whois example.com` or use a lookup site and paste the result. Registries format fields differently and modern records hide registrant data, so a missing field may exist in the raw text. Set the "today" option to check how a record looked on another date.

How to use it

  1. Run whois (or copy a lookup result) and paste the text.
  2. Optionally set a fixed date for the age and expiry calculation.
  3. Read the summary, the status explanations and the checks at the bottom.

Frequently asked questions

Does this look up the domain for me?

No. A web page cannot reach WHOIS servers. Paste a record you obtained yourself.

What does clientTransferProhibited mean?

The registrar has locked the domain against transfers. It is normal and recommended.

Why is the registrant hidden?

Since GDPR most registries redact personal data. Contact the registrar abuse address for issues.
