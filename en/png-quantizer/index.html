PNG Quantizer (Shrink PNG Files with a Reduced Colour Palette)

Shrink PNG files by reducing them to fewer colours.

Use the tool

Why this tool exists

Choose a colour count from 2 to 256. The tool builds a palette with median cut, maps every pixel to the nearest entry, optionally dithers, and saves an indexed PNG with transparency kept. If a file would not get smaller, the original can be kept.

Logos, icons and screenshots usually survive 64 colours well. Photos can band at low counts, so check by eye.

How to use it

  1. Choose PNG files.
  2. Set the number of colours.
  3. Decide on dithering.
  4. Compare the sizes and download.

Frequently asked questions

Is it lossy?

Yes. Colours are merged. Pick the count that still looks right.

Is transparency kept?

Yes, including partial transparency, within the palette limit.

Why use dithering?

It hides banding in gradients but makes the file larger.

Is anything uploaded?

No. The work happens in your browser and the page makes no network request with your input.
