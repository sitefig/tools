Roof Pitch Calculator

Enter rise, run and building span. The tool returns the pitch as x:12, the angle, the slope percentage, the rafter length factor and approximate rafter length and ridge height.

Use the tool

Why this tool exists

Roofers talk about a 6:12 pitch, planners may specify degrees, and a drawing might give a percentage. They all describe the same slope, and converting between them by hand means a bit of trigonometry. This calculator takes the rise and run you measured or drew and shows every form, then uses the building span to work out the rafter length without overhang and how high the ridge sits above the wall plate. It is useful for ordering timber, checking whether a roof will suit a certain covering or sketching a loft conversion. The span, rise and run only need to share a unit. It is a geometric estimate for a symmetrical gable roof, not a structural design.

How to use it

  1. Enter the rise and the run in the same unit, for example 6 and 12.
  2. Enter the building span or width, using the same unit.
  3. Read the pitch, angle, slope percentage, rafter length and ridge height.

Frequently asked questions

What does a 6:12 pitch mean?

The roof rises 6 units for every 12 units of horizontal run. That is a slope of 50% and an angle of about 26.57 degrees.

Is the rafter length the full cut length?

No. It is the sloping length from the wall plate to the ridge without overhang, ridge board allowance or birdsmouth cuts. Add those separately when you cut timber.

Does the span have to use the same unit?

Yes, the rafter length and ridge height are returned in whatever unit you use for span, so keep them consistent.

Can I use it for a lean-to roof?

The pitch, angle and slope values apply to any single slope. The rafter and ridge figures assume a symmetrical gable, so for a lean-to use the full span instead of half.
