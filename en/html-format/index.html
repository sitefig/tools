HTML Formatter

Beautify HTML with consistent indentation and line wrapping. Inline style and script blocks are formatted too, and pre blocks are left exactly as written.

Use the tool

Why this tool exists

View-source on a production page, or HTML pasted from an email template or a CMS export, is often a single dense line. Finding the unclosed div or the stray attribute in that is miserable. A formatter turns it into something you can read and diff.

The tool indents nested elements, puts block elements on their own lines, wraps long lines at the width you set, and formats the CSS and JavaScript inside style and script tags. Content of pre elements is preserved so that intentional spacing is not damaged. Missing closing tags for elements such as li are tolerated, as in a browser. It is a pragmatic formatter, not a full HTML5 parser, so check unusual markup. Nothing is uploaded.

How to use it

  1. Paste your HTML into the input box.
  2. Choose the indent: 2, 4 or 8 spaces, or a tab.
  3. Set the line width at which long lines wrap.
  4. Copy the formatted HTML.

Frequently asked questions

Is whitespace inside pre and text content changed?

Content inside pre elements is kept exactly as written. In normal text, whitespace is collapsed the way browsers treat it, so line wrapping does not change what visitors see.

Does it format CSS and JavaScript inside the page?

Yes. Inline style and script blocks are beautified with the same logic as the CSS and JavaScript formatters, and are indented to match the HTML around them.

Can it fix broken HTML?

Not really. It tolerates some missing end tags, like unclosed li elements, but it does not repair structure or check validity. Use a validator for that.

Will formatting change how the page looks?

It should not for normal pages. Whitespace between inline elements can matter in rare cases, so compare the page before and after when layout is sensitive.
