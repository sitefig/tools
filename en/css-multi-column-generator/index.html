CSS Multi-Column Layout Generator (columns, gap, rule)

Configures CSS multi-column layout and previews sample text reflowing as you change the values.

Use the tool

Why this tool exists

Multi-column layout flows one block of text into several columns, like a newspaper. The shorthand mixes count and width in ways that are easy to get wrong.

This tool writes the right property for what you set (column-count, column-width or the columns shorthand), adds a column-rule, and optionally a heading that spans all columns and a helper to stop cards splitting across columns. Long text in columns can hurt reading on small screens, so test on a phone.

How to use it

  1. Set a count, a width, or both. Zero means automatic.
  2. Choose gap and rule style.
  3. Tick the helper classes you want.
  4. Copy the CSS.

Frequently asked questions

Count or width?

Width is more responsive: the browser fits as many columns as it can. Count is fixed.

What does column-fill do?

balance evens the columns; auto fills one before the next, which needs a fixed height.

Is it accessible?

Reading down and then up again on a short screen is tiring. Prefer one column on narrow viewports.
