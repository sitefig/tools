Text Repeater

Create long repeated strings for testing, fill-in text or formatting experiments.

Use the tool

Why this tool exists

Enter the text, the number of repetitions and a separator. Use \n and \t in the custom separator for line breaks and tabs. The result is limited to five million characters to keep your browser responsive.

For realistic placeholder text use the lorem ipsum or random text generators instead.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Type or paste the text to repeat.
  2. Set the count and separator.
  3. Copy the result.
  4. Use shorter counts for quick tests.

Frequently asked questions

What is the limit?

100,000 repetitions or five million characters, whichever comes first.

How do I repeat with new lines?

Choose "new line" as the separator.

Is it useful for load tests?

It can create large payloads, but dedicated tools suit real load testing.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
