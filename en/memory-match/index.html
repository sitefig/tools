Memory Match

Flip two cards at a time to find matching pairs. There are eight pairs on a 4 by 4 board, and your goal is to clear them in as few moves as possible.

Use the tool

Why this tool exists

Memory games are a simple way to exercise short-term recall, and a quick one to play while a build runs or a file uploads. This one has sixteen cards, eight emoji pairs, and a move counter so you can try to beat your own record.

Cards are shuffled on every new game. A pair that does not match flips back after under a second, which is your chance to remember where each symbol is. The best result, the lowest number of moves, is kept in this browser only. There is no timer, account or advertising, and the game works on touch screens and with a mouse.

How to use it

  1. Click or tap a card to flip it, then flip a second card.
  2. If the two match, they stay face up. If not, they flip back after a moment.
  3. Remember where each symbol was and clear all eight pairs while keeping the move count low.
  4. Press "New game" to reshuffle and try for a better score.

Frequently asked questions

How is the score counted?

Each time you flip two cards counts as one move. The fewer moves you need to find all eight pairs, the better. The lowest total is stored as your best.

Where is my best score stored?

In your browser's local storage on this device only. It is not sent anywhere. Clearing site data or using a private window removes it.

What is the lowest possible score?

Eight moves, which would need every pair found on the first try and so takes luck. With good recall you will usually need noticeably more, so set yourself a personal target and try to beat it.

Can I change the board size?

No. The board is fixed at 16 cards with 8 emoji pairs, so every game is directly comparable with your saved best score. Press New game to reshuffle the cards.
