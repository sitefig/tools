Entity Extractor (Emails, Dates, Money, Names - Rules)

Find the structured facts hiding in a block of text and list them by type.

Use the tool

Why this tool exists

Regular expressions pick out emails, URLs, phone numbers, dates in several formats, currency amounts, percentages, hashtags, @mentions and reference numbers such as #4471. Runs of capitalised words that are not month names are listed as likely names and organisations.

It matches patterns only. Names are guessed from capital letters, so sentence starts can slip in, and unusual number formats are missed. For named-entity recognition of unseen text you need a language model, which this page does not use.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Paste the text.
  2. Run it.
  3. Copy the lists you need.
  4. Check the names list by eye.

Frequently asked questions

Is this named-entity recognition?

It is a rule-based extractor. It finds patterned entities reliably and names only heuristically.

Which date formats are supported?

ISO dates, "March 3, 2026", "3 March 2026" and numeric day/month/year strings.

Is the text uploaded?

No. It is processed in the page.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
