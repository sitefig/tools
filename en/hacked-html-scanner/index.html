Hacked Page / Injected Code Scanner

Look through a page's source for the classic traces of a compromise: invisible spam links, hidden iframes, obfuscated scripts, forced redirects and miner libraries.

Use the tool

Why this tool exists

The scanner applies a list of patterns to the source and reports each hit with its line number and severity: eval of decoded data, long escape sequences, zero-size or hidden iframes, links hidden off-screen, meta refresh redirects, scripts from bare IP addresses or throwaway top-level domains, long base64 blobs and pharma or casino spam words.

Patterns produce false positives (some analytics and consent scripts use similar tricks) and miss anything cloaked or served only to crawlers, so a clean result proves nothing. Use hits as leads: check recently changed files, plugins and admin accounts, restore from a clean backup, rotate credentials and use Search Console's security reports.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Open the page, view source and copy it all.
  2. Paste it and run the scan.
  3. Investigate each HIGH and MEDIUM hit in your files or database.
  4. Clean up, secure the site and request a review if Google flagged it.

Frequently asked questions

Can it prove my site is clean?

No. Attackers cloak content by user agent or visitor and the scan sees only what you paste.

Why was my analytics code flagged?

Some legitimate scripts use eval, base64 or hidden elements. Judge each hit in context.

What should I do first after a hack?

Take the site offline or restrict access if needed, change all passwords and keys, restore from a known-good backup and patch the entry point.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
