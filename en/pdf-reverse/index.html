Reverse PDF Page Order

Flip a PDF so the last page comes first and the first page comes last. No settings needed: choose the file and run the tool.

Use the tool

Why this tool exists

Reversed page order is common when a scanner stacks pages face down, when you scan the back of a double-sided stack, or when a document was printed in the order it came off the printer. Fixing a 50-page file by dragging pages one by one is nobody's idea of fun.

This tool reverses the whole document in a single step. It takes the file, rearranges the pages and writes a new PDF named after the original, without re-rendering the content, so text and images remain unchanged. It is the quickest option for a full reversal. If you need only part of the document reversed, or want to mix other changes in, use the Reorder PDF Pages tool with a reversed range. Encrypted PDFs are refused, and bookmarks and form fields are not preserved.

How to use it

  1. Choose a PDF file.
  2. Run the tool.
  3. Check the page count in the summary.
  4. Download the reversed PDF.

Frequently asked questions

Does it need any options?

No. The whole document is reversed. If you want only part of it reversed, use the Reorder PDF Pages tool and write the range backwards, for example 1-2,8-3,9-.

Is the quality affected?

No. Pages are copied without being re-rendered, so text stays selectable and images keep their quality. Only the order changes.

Will page numbers printed on the pages change?

No. Numbers that are part of the page content stay as they were, so a reversed file shows them counting down. Use the page number tool afterwards to stamp new ones.

Can I undo it?

Run the tool again on the new file to reverse it back. Your original file is not touched, so you can also just keep it.

  • Merge PDFsCombine several PDFs into one, in the order selected. Works on existing PDFs without re-rendering; bookmarks and form fields are dropped.
  • Split PDFSplit a PDF into several files: every N pages, or custom ranges (each comma-separated range becomes its own file).
