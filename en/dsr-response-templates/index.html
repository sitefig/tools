Data Subject Request Response Template Generator

Writes the reply a company sends to a data subject request: fulfilled, partly refused, refused, identity check or extension.

Use the tool

Why this tool exists

When a person exercises a GDPR right, the company must reply within a month and say clearly what it did. Writing a good reply each time is slow, and the wording for a refusal or an extension matters.

This tool builds a draft for six request types and five outcomes, with the article numbers and the complaint information that a refusal needs. Bracketed parts need your own details. It is a template, not legal advice.

How to use it

  1. Choose the request type and the outcome.
  2. Fill in company, requester, date, contact and reason.
  3. Copy the draft and replace the [brackets].
  4. Send it within the deadline and keep a record.

Frequently asked questions

What deadline applies?

One month, extendable by two months for complex or numerous requests (Art. 12(3)). Use the Deadline Calculator.

Do I need to check identity?

Only if you have reasonable doubts (Art. 12(6)). Ask for the minimum needed.

Which tool writes the request itself?

The GDPR Erasure / Access Request Letter tool, which is for the person making the request.
