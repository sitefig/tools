Keyword Intent Classifier

Paste a list of keywords and get a search intent label for each one: informational, commercial, transactional or navigational, along with the word that triggered it.

Use the tool

Why this tool exists

Search intent decides which kind of page can rank: a guide for "how to start a blog", a comparison for "best crm software", a product or pricing page for "buy running shoes". Sorting hundreds of keywords by hand before planning content is tedious.

This classifier checks each keyword against lists of signal words, such as buy, price, best, vs, login and how. The first rule that fits sets the label, and the matching signal is shown so you can judge it. Keywords with no signal are tagged "informational?" as a default. It is a quick first pass, not a model of how Google reads queries, so check ambiguous ones in the search results.

How to use it

  1. Paste your keywords, one per line.
  2. Run the classifier.
  3. Read the table with the keyword, its intent and the signal that triggered it.
  4. Check the summary counts, and look at keywords labelled with a question mark by hand.

Frequently asked questions

How are conflicts resolved?

Rules are checked in a fixed order: transactional, navigational, commercial, then informational. A keyword like "best price" is labelled transactional because that rule comes first.

Is it accurate?

It is a keyword-pattern heuristic written in English. It misses context, other languages and unusual phrasing. Treat it as a way to sort a long list quickly, then verify important keywords against real search results.

What does "informational?" mean?

No signal word matched, so the tool defaulted to informational. Look at those keywords yourself; many are product or brand queries.

Does it use an AI model or send data anywhere?

No. It uses a fixed set of word patterns in your browser, so results are repeatable and the list is not uploaded.
