JSON Minifier

Strip every unnecessary space and line break from JSON to get the smallest valid text. The input is checked first, so invalid JSON is reported instead of silently mangled.

Use the tool

Why this tool exists

Pretty-printed JSON is pleasant to read but wasteful to send. When you embed a payload in a URL, a test fixture, an environment variable or a single-line log entry, you want the compact form. Minifying by hand is risky because deleting spaces inside strings changes the data.

This tool parses the JSON first and then writes it back without any whitespace, so string contents are untouched and syntax errors are caught before you copy anything. It does not rename keys or change values. It is also handy to confirm that a file you are about to commit is valid. The work stays in your browser and nothing is uploaded.

How to use it

  1. Paste formatted JSON into the input box.
  2. Read the minified single-line result in the output.
  3. If an error appears, fix the syntax at the line and column shown.
  4. Copy the result into your code, config or request.

Frequently asked questions

Does minifying change my data?

No values change. Only whitespace outside strings is removed. Spaces inside string values are kept exactly as they are, and numbers, booleans and nulls stay the same.

Will it fix invalid JSON?

No. It validates first and reports the error with line and column. Trailing commas, comments and single quotes are not valid JSON and must be fixed before minifying.

How much smaller will it get?

It depends on the indentation. Deeply indented, pretty-printed files often shrink a lot, while already compact JSON barely changes. Transfer size is also reduced further by gzip on your server.

Is the minified output safe to share?

It contains the same data as the input, so it is as sensitive as the original. The tool itself runs locally in your browser and does not upload your text.
