Subscription Cost Tracker (Monthly and Yearly Total)

Turns a list of subscriptions with different billing cycles into monthly and yearly totals.

Use the tool

Why this tool exists

Small recurring charges add up. Putting weekly, monthly, quarterly and yearly prices on the same monthly scale shows which ones cost most.

Set a highlight limit to flag items worth reviewing. Nothing is saved: copy your list if you want to keep it.

How to use it

  1. Write one line per subscription: name, price, cycle.
  2. Optionally set a highlight limit.
  3. Read totals and ranking.

Frequently asked questions

Which cycles work?

Weekly, monthly, quarterly, half-yearly and yearly.

Is my list stored?

Nothing you type leaves your browser.

Does it include tax?

Only if the price you enter does.
