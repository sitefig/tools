ASN.1 / DER Decoder (PEM, Hex, Base64)

Look inside any ASN.1 structure: certificates, private keys, CSRs, PKCS containers.

Use the tool

Why this tool exists

The decoder reads definite-length BER/DER, prints each element with its offset, depth, header length and content length, names universal types, converts OIDs to dotted form (with names for common algorithms, extensions and attributes), decodes strings and UTCTime/GeneralizedTime and opens OCTET STRING and BIT STRING contents when they hold more DER. Every element that openssl asn1parse lists for a test certificate also appears here.

Indefinite lengths (BER only) and very unusual tags are not supported. Nothing leaves the page, which matters when you paste private keys.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Paste a PEM block, hex or base64.
  2. Read the tree; indentation shows nesting.
  3. Match OIDs and offsets with the specification you are debugging.
  4. Use the certificate viewer for a friendlier summary of certificates.

Frequently asked questions

How is this different from the X.509 viewer?

It shows the raw ASN.1 structure of any DER data, not only certificates.

What do the d, hl and l columns mean?

Depth, header length and content length, like openssl asn1parse.

Is it safe to paste a private key?

The decoding is local, but treat any key you paste into a browser carefully.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
