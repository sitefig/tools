Noise Texture Generator: Tileable Grain PNG

Creates a square transparent PNG filled with random grain, colour noise or sparse speckles that tiles without seams.

Use the tool

Why this tool exists

A touch of grain makes gradients look richer and hides banding. Every pixel here is random and independent, so the tile repeats without a visible edge. Opacity controls how strong the overlay is, density how many pixels are filled.

The seed makes a result repeatable. Use the PNG as a CSS background over a colour or gradient. Large tiles and high opacity increase file size.

How to use it

  1. Choose the tile size and noise type.
  2. Set density, opacity and tint.
  3. Run it and preview the tile.
  4. Download the PNG and use it as a repeating background.

Frequently asked questions

Is it really seamless?

Yes. Pixels are independent, so there is no pattern to break at the edges.

How big should the tile be?

256 pixels is usually enough because noise has no structure.

Can I get SVG noise?

No. This tool writes PNG pixels.

What does the seed do?

The same seed and settings give the same image.
