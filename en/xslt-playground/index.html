XSLT Playground (Transform XML in Your Browser)

Runs an XSLT 1.0 stylesheet on pasted XML and shows the output text or markup.

Use the tool

Why this tool exists

XSLT is still used to turn XML feeds, sitemaps and exports into other formats. Testing a stylesheet usually means a command line tool or an IDE.

This page uses the XSLT processor built into your browser. Paste the XML and the stylesheet, and read the result. Malformed XML or a rejected stylesheet gives an error message. Only XSLT 1.0 is supported by browsers; functions from XSLT 2 or 3 will fail. Output may differ slightly between browsers.

How to use it

  1. Paste the XML in the first box.
  2. Paste the stylesheet in the second.
  3. Read the transformed output.
  4. Edit the stylesheet and run again.

Frequently asked questions

Which XSLT version?

1.0, the version browsers implement.

Why does my stylesheet fail?

It may use XSLT 2 or 3 functions, or have a mistake. The message from the browser is shown.

Does it fetch other files?

No. xsl:import and document() are not fetched.

Is the XML uploaded?

No.
