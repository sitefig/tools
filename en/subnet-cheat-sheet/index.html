IPv4 Subnet Mask Cheat Sheet (CIDR Table)

Look up a netmask or host count without calculating it.

Use the tool

Why this tool exists

The table lists each prefix length with its dotted subnet mask, wildcard (inverse) mask, total addresses and usable hosts (addresses minus network and broadcast, except /31 point-to-point and /32 host routes). Values were checked against Python's ipaddress module. You can narrow the range of prefixes.

It covers IPv4 only. For specific networks use the subnet calculator.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Choose the prefix range.
  2. Read the row you need.
  3. Use the wildcard mask for ACLs and OSPF statements.
  4. Open the subnet calculator for a specific network.

Frequently asked questions

What is a wildcard mask?

The inverse of the subnet mask, used in some router ACL syntaxes.

Why minus 2?

The first address is the network and the last the broadcast.

What is /31 for?

Point-to-point links, defined in RFC 3021.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
