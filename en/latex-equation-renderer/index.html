LaTeX Equation Renderer to SVG (TeX Layout Rules)

Renders a LaTeX math formula as an SVG image using a layout engine written for the task, following TeX's spacing and placement rules, and lets you copy or download the SVG.

Use the tool

Why this tool exists

A formula for a slide, a document or a web page is often easier as a picture than as MathJax or a LaTeX install. This tool lays the formula out with the rules from the TeXbook: inter-atom spacing, script shifts, fraction clearances, radicals, limits on large operators and delimiter sizes, using glyph sizes measured from Computer Modern.

The layout was compared with real LaTeX (width, height and depth of 195 formulas in display and text style): 97% were within 0.02 em on all three, and the mean width error was under 0.01 em. The glyphs themselves are text in your system fonts (Latin Modern Math, STIX, Cambria, Times), so letter shapes differ from Computer Modern and spacing can be slightly off when a different font is used. Supported: fractions, binomials, scripts, roots, sums and integrals, functions, Greek and common symbols, fonts such as \mathbb, accents, over and underbraces, \left and \right, matrices, cases, aligned, \text and spacing commands. No macros, packages, colours or numbering.

How to use it

  1. Type the formula without dollar signs, or paste one wrapped in $...$ or \[...\].
  2. Pick display or text style and a size.
  3. Check the preview; an error names the command it does not know.
  4. Copy the SVG markup or download equation.svg.

Frequently asked questions

Why do letters look different from LaTeX output?

The SVG uses text in a math font that your system has. Install Latin Modern Math or STIX Two Math for the closest look. Spacing is computed from Computer Modern widths.

Which commands are not supported?

Custom macros, \newcommand, packages such as tikz or chemfig, \tag, \color, \cancel, multi-line equation numbering and any text-mode formatting outside \text.

Is the layout accurate?

It was measured against LaTeX for 195 formulas. Most matched within 0.02 em in width, height and depth. Cases such as \underset next to an operator and kerning inside \text words differ slightly.

Can I use the SVG in a document?

Yes. The SVG is self-contained and scales without loss. It refers to system fonts by name, so convert text to outlines in your editor if the target machine may lack them.
