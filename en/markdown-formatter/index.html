Markdown Formatter: Lists, Headings, Tables and Blank Lines

Tidies Markdown lists, headings, tables and blank lines without touching code blocks.

Use the tool

Why this tool exists

Markdown from many authors mixes list markers, odd heading spacing and ragged tables. The tool picks one bullet marker, renumbers ordered lists, tidies # headings, pads tables to equal column widths with their alignment, puts blank lines around blocks and removes trailing spaces except hard line breaks.

As a check, real Markdown files were formatted and rendered again with a CommonMark parser: 498 of 500 rendered to the same HTML, and 99 of 100 in a second set. The differences were mixed bullet markers at one level, which now join one list, and a code block with no closing fence. Review the output.

How to use it

  1. Paste Markdown.
  2. Pick the bullet marker.
  3. Choose whether to renumber lists and align tables.
  4. Copy the result.

Frequently asked questions

Does it change how the page renders?

Rarely. Mixed bullet markers at the same level become one list.

What about wide characters in tables?

Column width uses string length, so East Asian text may look uneven.

Does it rewrap paragraphs?

No.

Is my input sent anywhere?

No. Everything runs in your browser and nothing is uploaded.
