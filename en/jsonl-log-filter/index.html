JSON Lines Log Filter: Flatten Fields and Filter by Any Key

Flattens JSON log records to dotted keys and filters them with simple key conditions.

Use the tool

Why this tool exists

Structured logs are easy to write and awkward to read. This tool flattens nested fields and lets you ask questions such as level=error;ctx.ms>1000 without jq.

It picks time, level and message columns first. The NDJSON viewer is better for plain sorting and CSV; this one is for filtering and summaries.

How to use it

  1. Paste JSON lines or choose a file.
  2. Write filters separated by semicolons.
  3. Choose columns and sorting if needed.
  4. Read the level summary and the matching rows.

Frequently asked questions

Which operators work?

= != ~ (contains) !~ > < >= <=. Numbers compare as numbers when both sides are numeric.

How are nested keys named?

With dots, like ctx.ms. Arrays of simple values are joined with commas.

What if some lines do not match?

They are skipped and the result says how many. Lines that are not JSON are counted and skipped.

Is my log uploaded?

No. Parsing happens in your browser and nothing is sent. Logs can hold IP addresses and tokens, so the page does not write them into the address bar.
