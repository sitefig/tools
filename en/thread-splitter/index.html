Thread Splitter: Long Text into Numbered Posts

Split a long text into numbered posts of a set length for X, Threads or Bluesky, breaking at sentence ends and keeping every post under the limit.

Use the tool

Why this tool exists

Long ideas need a thread, but cutting one by hand is fiddly: each post needs room for its number and must not end mid-sentence.

Set the limit and the numbering style. The tool reserves space for the number, packs whole sentences into each post, keeps paragraph breaks where it can and splits only a sentence that is too long. With the X option, links count 23 and emoji 2. Links are never broken.

How to use it

  1. Paste the long text.
  2. Set the limit per post and the numbering.
  3. Keep the X counting option on for X.
  4. Copy each post in order.

Frequently asked questions

Where does it break?

At sentence ends. A sentence longer than the limit is split at a word.

How is the numbering counted?

Space for 1/5 style numbers is reserved in each post.

Does it post for me?

No. It only formats text.
