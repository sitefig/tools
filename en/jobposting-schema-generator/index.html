JobPosting Schema Generator

Creates JobPosting markup with location or remote settings, base salary range per hour, day, week, month or year, employment type and expiry date.

Use the tool

Why this tool exists

Google's job posting rules have enumerated values that are easy to misspell: FULL_TIME, PART_TIME, CONTRACTOR and so on, and salary units in capitals. The tool rejects values outside the documented lists, checks the currency, and makes sure the salary range is not reversed.

Remote jobs use jobLocationType TELECOMMUTE with the countries where applicants may live; on-site jobs need a work address. The documentation says only employers may publish baseSalary and that expired jobs must be removed or expired with validThrough; both are repeated in the notes.

How to use it

  1. Enter the title, description, dates and employer.
  2. Add the work address, or set remote: yes with applicantCountry lines.
  3. Add salaryMin, salaryMax, salaryCurrency and salaryUnit if you publish pay.
  4. Copy the script tag onto the job page.

Frequently asked questions

Which employment types are valid?

FULL_TIME, PART_TIME, CONTRACTOR, TEMPORARY, INTERN, VOLUNTEER, PER_DIEM and OTHER.

How do I mark a remote job?

Set remote: yes and add applicantCountry: lines. The tool writes jobLocationType TELECOMMUTE.

Can the description contain HTML?

Yes, basic HTML is allowed by Google; it is escaped correctly in the JSON.

What happens when a job closes?

Remove the page or set validThrough to a past date, as Google describes.
