Pagination Link and Canonical Checker

Checks the head of each page in a paginated series for common mistakes.

Use the tool

Why this tool exists

A common mistake is a canonical on every paged URL that points to page one. Google advises against that and wants each page to have its own canonical.

Google no longer uses rel=prev/next as an indexing signal, though other engines may. The tool checks canonicals, prev/next reciprocity, fragment links and noindex across the pages you paste. Page numbers are guessed from common URL patterns.

How to use it

  1. Paste each page after a URL: line, separated by ---.
  2. Include at least two pages for reciprocity checks.
  3. Run the tool.
  4. Fix errors, then review the warnings.

Frequently asked questions

Does Google use rel=prev/next?

No longer, per its documentation. Other engines may.

Why not canonical to page 1?

Each page has different content, so each needs its own canonical.

Why avoid fragments?

Google ignores fragment identifiers.

Does it crawl?

No. Paste the pages.
