PDF Flattener (Annotations and Form Fields)

Draws the appearance of every comment, highlight, stamp and form field into the page content and removes the editable objects.

Use the tool

Why this tool exists

A filled form or a reviewed document still carries separate annotation objects that a recipient can change, hide or delete. Flattening turns them into ordinary page content, so what you see is what everyone gets. It also fixes viewers that do not draw annotations on print.

The tool uses the appearance streams already stored in the file and places them exactly as a viewer would; on a test file the flattened page rendered pixel for pixel like the original with annotations. Fields with no stored appearance cannot be drawn and are reported. Links can be kept. The form itself is removed, so fields are no longer fillable.

How to use it

  1. Choose a PDF with comments or filled form fields.
  2. Keep "keep clickable links" ticked if you want to retain links.
  3. Press Run.
  4. Download the flattened PDF.

Frequently asked questions

Is flattening reversible?

No. Keep the original if you may need to edit the annotations later.

Why were some fields removed?

They had no appearance stream, which happens when a program relies on the viewer to draw them. Open the file in the form filler first and save with values.

Does it make the text unselectable?

No. Page text stays text; flattened annotation text depends on how it was drawn.

What about hidden annotations?

Annotations marked hidden are removed rather than drawn.
