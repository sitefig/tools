Palette Exporter: Adobe ASE, GIMP GPL, CSS Variables and Tailwind

Takes a named list of colours and exports it as Adobe Swatch Exchange (.ase), a GIMP palette (.gpl), CSS custom properties, a Tailwind colors block or JSON.

Use the tool

Why this tool exists

Moving a palette between design tools and code is tedious. Paste lines such as "Brand #4f8cff" and pick a format. The ASE file follows the published block layout with RGB float values and can be imported by Adobe apps. GPL is the plain text format of GIMP and Inkscape.

The ASE file was checked by parsing it back, not by opening it in Adobe software. Colours are RGB only.

How to use it

  1. Enter one colour per line, with an optional name first.
  2. Pick the format and a palette name.
  3. Run the tool.
  4. Copy the code or download the file.

Frequently asked questions

Does it export CMYK?

No, ASE entries are RGB.

Can I import the ASE into Photoshop?

It is meant for that, but this tool was not tested in Adobe software. Tell us if it fails.

What are the CSS names?

The name you give, lower-cased with dashes.

Which Tailwind version?

The config extends theme.colors, usable in v3 style configs.
