JSON-LD Inspector

Extract JSON-LD blocks from pasted HTML or raw JSON-LD, parse them, list the Schema.org types and flag missing properties, bad dates and price problems.

Use the tool

Why this tool exists

Structured data helps search engines understand a page and can unlock rich results, but one stray comma or a missing required property quietly breaks it. Copying markup from a template and editing it by hand is where most errors come from.

This inspector finds every application/ld+json script in the HTML you paste, or accepts a raw JSON-LD object. It parses each block, reports invalid JSON with the error, checks that the context is schema.org, lists the types it finds, including those inside a graph, and checks required fields for common types, absolute URLs, valid publication dates and price with currency on offers. It is a sanity check and not Google's Rich Results Test, which uses more rules. All of it happens in your browser.

How to use it

  1. Paste the page HTML, or just a JSON-LD object, into the input box.
  2. Run the tool to extract and parse the blocks.
  3. Read the types found and the list of warnings and errors for each block.
  4. Fix the markup and run it again, then confirm with Google's own testing tools.

Frequently asked questions

Which types does it check?

It has built-in required-property checks for common types such as Article, Product, LocalBusiness, FAQPage, Organization, Event and Recipe. Other types are listed with a note that no checks exist.

Does passing mean I will get rich results?

No. Rich results depend on eligibility rules, content quality and Google's own decisions. This tool only catches structural and obvious property problems.

Can it read microdata or RDFa?

No. It only reads JSON-LD, either in script tags or pasted directly as JSON. You can even load the page and then disconnect from the network before running it.

Is my markup uploaded?

No. Parsing and checks run in your browser and nothing is sent to a server. It also means the page works for drafts and private sites you would not want to share.
