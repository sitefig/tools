Text to PDF

Paste plain text and download it as a multi-page PDF, choosing page size, orientation, font, margins, an optional header and page numbers.

Use the tool

Why this tool exists

Notes, logs, code snippets and email text often need to become a PDF: to attach to a ticket, archive a conversation or print neatly. Word processors add formatting you do not want, and online converters want the text uploaded.

This tool lays out your text directly. It wraps long lines to the page width, starts new pages automatically and keeps blank lines. You can pick A4 or Letter, portrait or landscape, and one of three standard fonts: Helvetica, Times or Courier, the last being fixed-width and good for code. Add a header line and number the pages as n or Page n of N. Because only standard PDF fonts are used, characters outside the Western European set show as question marks. Everything is made on your device.

How to use it

  1. Paste or type the text into the box.
  2. Choose page size, orientation, font, size and margin.
  3. Add a header and choose a page-number style if you want them.
  4. Run the tool and download the PDF.

Frequently asked questions

Which characters are supported?

The standard PDF fonts cover Western European characters. Letters outside that range, such as Cyrillic, Greek, Chinese or emoji, are replaced by a question mark because no font is embedded.

Does it keep my line breaks?

Yes. Each line of your text stays a line, long lines are wrapped to the page width, and blank lines are preserved. Tabs are converted to four spaces.

Can I use bold or colours?

No. This tool outputs plain text in a single font and size. For headings and lists, try the Markdown to PDF tool instead.

Is the PDF searchable?

Yes. The text is stored as real text with standard fonts, so you can select and search it in any viewer. It is not an image.
