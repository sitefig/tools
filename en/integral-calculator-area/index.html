Integral Calculator: Antiderivative, Definite Integral and Shaded Area

Gives the antiderivative when the built-in rules can find it, the value of a definite integral with a numeric cross-check, and a plot of the shaded area.

Use the tool

Why this tool exists

The value of a definite integral is the signed area under a curve. This tool computes it numerically with adaptive Simpson integration, and when it can find an antiderivative it also evaluates F(b) - F(a) and compares the two values. If they disagree it warns you, which usually means a singularity inside the interval.

The antiderivative table covers polynomials, sums, constant multiples, powers of a linear term, sin, cos, exp, sinh, cosh, tan, sqrt, ln of a linear term, c/(ax+b) and c/(ax^2+k). It does not do integration by parts or substitution, so x*sin(x) gets a numeric value but no formula. Every antiderivative is checked by differentiating it numerically before it is shown.

How to use it

  1. Type the function of x.
  2. Enter the lower and upper limits, or clear them for an indefinite integral.
  3. Read the antiderivative, the numeric value and the check.
  4. Look at the shaded plot to see which parts count as negative.

Frequently asked questions

Why is there no formula for my integral?

The built-in table is limited. A numeric value is still given when you enter limits.

How precise is the number?

The target tolerance is 1e-10. Smooth functions usually reach it.

Does it handle improper integrals?

No. Limits must be finite and the function finite on the interval.

What does the + C mean?

Any constant can be added to an antiderivative without changing its derivative.
