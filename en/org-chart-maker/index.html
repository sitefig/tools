Org Chart Maker from a CSV of People and Managers

Reads people and their managers and draws the reporting tree with names and titles, with a table of levels.

Use the tool

Why this tool exists

Most HR exports are already a list of people with a manager column. Paste it and get the chart without redrawing boxes.

Several people without a manager become several roots side by side. A manager who is not in the list, a duplicate name or a reporting loop produces a clear error naming the person, which also makes it a quick data check before you import the file elsewhere.

How to use it

  1. Paste rows: name, manager, title (header optional).
  2. Leave the manager empty for the top person.
  3. Fix any named error and run again.
  4. Copy or download the SVG.

Frequently asked questions

Can there be several top people?

Yes, each starts its own tree.

What if two people share a name?

Make names unique, for example by adding an initial.

Is the chart wide for big teams?

Yes. Width grows with the number of people at the bottom level.

Is the data private?

Yes, it never leaves the page.
