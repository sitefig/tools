Keyword Permutation Generator: Combine Word Lists

Put your modifiers, products and locations in separate blocks and get every combination, optionally in every column order. Copy the list into your keyword tool.

Use the tool

Why this tool exists

Keyword research often starts with combining modifiers ("buy", "cheap"), products and places. Doing it by hand or in a spreadsheet is slow. This writes every combination at once.

The result is a list of candidate searches, not proof that anyone searches for them. Check them against a keyword tool or your Search Console data. To avoid freezing the browser the tool stops at 50,000 combinations.

How to use it

  1. Write each list as one item per line.
  2. Put a blank line between lists (two to four lists).
  3. Choose the joiner and whether to use every column order.
  4. Copy the result into your keyword tool.

Frequently asked questions

How many combinations will I get?

The product of the list sizes, times the number of column orders if you tick that box.

Can I join without spaces?

Yes, set the joiner to nothing, for example for domain name ideas.

Why not search volumes?

Volumes need a data provider. This tool only generates the list.

Will duplicates be removed?

Yes, identical results are listed once.
