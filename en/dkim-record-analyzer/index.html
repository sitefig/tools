DKIM Record Analyzer (Key Type and RSA Key Length)

Parses a DKIM public key record, measures the RSA key length from the DER data and flags weak or revoked keys.

Use the tool

Why this tool exists

A DKIM record holds the public key that receivers use to check your signatures. Common problems are a key that is too short, a record cut off during copy and paste, a revoked key (empty p=) and a domain left in testing mode.

Paste the TXT value and the tool joins split strings, decodes the key and shows the RSA modulus size. It was checked against keys made with OpenSSL. It reads text only: it does not fetch DNS or verify any signature.

How to use it

  1. Run dig TXT selector._domainkey.yourdomain.
  2. Paste the value, with or without quotes.
  3. Read the key type, size and review list.
  4. Replace keys under 2048 bits when you can.

Frequently asked questions

What is a good key size?

2048 bits for RSA. 1024 is the minimum allowed for signers by RFC 8301 and is considered weak.

What does an empty p= mean?

The key is revoked and signatures with that selector fail.

Does it support Ed25519?

It identifies the key and checks the length. RFC 8463 defines the type.
