WCAG 2.2 Success Criteria Explorer and Reference

A searchable list of all WCAG 2.2 success criteria with level, opening text and a link to the W3C explanation.

Use the tool

Why this tool exists

You often need to find the criterion for a problem quickly.

The data comes from the W3C WCAG 2.2 Recommendation. Filter by A, AA or AAA, by principle, or to the nine criteria new in 2.2. Only the opening sentence is shown, so read the full text before judging a pass.

How to use it

  1. Type words or a number.
  2. Pick the level and principle.
  3. Tick "new in 2.2" for recent additions.
  4. Open the Understanding link for detail.

Frequently asked questions

How many criteria are there?

86, with 4.1.1 Parsing removed in 2.2.

Which are new?

2.4.11, 2.4.12, 2.4.13, 2.5.7, 2.5.8, 3.2.6, 3.3.7, 3.3.8 and 3.3.9.

Is the full text here?

No, only the first sentence.

Does it use the network?

No.
