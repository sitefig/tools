Third-Party Script Cost by Vendor (from a HAR or Lighthouse Report)

Maps the third-party requests in a HAR file to known vendors and categories, or reads the Lighthouse third-party summary, to show what each vendor costs.

Use the tool

Why this tool exists

Tag managers, chat widgets and ad scripts add up, and nobody owns the total. A per-vendor table makes the conversation easier.

For a HAR file the tool uses a hand-made list of well-known domains and reports requests, bytes and request time per vendor and category. The main-thread cost is not in a HAR, so if you paste a Lighthouse report instead, the tool shows the transfer size, main thread time and blocking time that Lighthouse measured. Unknown domains show as unclassified.

How to use it

  1. Export a HAR file or a Lighthouse JSON report.
  2. Paste it into the box.
  3. Read the vendor table sorted by bytes.
  4. Check the category totals to find what to remove or delay.

Frequently asked questions

How complete is the vendor list?

It has about 90 entries for common vendors. Anything else is listed as unclassified with its site name.

Does it measure CPU cost?

Only through the Lighthouse report. A HAR has network data only.

Why is a CDN listed as a vendor?

Public CDNs and font hosts are third-party requests too, so they are shown with their own category.

Is the data uploaded?

No.
