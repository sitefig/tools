Data URI Inspector: Type, Size and Decoded Preview

Breaks a data URI into type, encoding and payload and checks that the declared type matches the bytes.

Use the tool

Why this tool exists

Data URIs hide files inside strings in HTML, CSS and emails. It is hard to tell what one holds or how big it is.

The tool decodes the payload, reports the size and the Base64 overhead, sniffs the real type from the first bytes and flags a mismatch for review. Images show a preview. Types that can run script, such as HTML and SVG, carry a warning.

How to use it

  1. Paste the data: URI, a url(...) value or an attribute value.
  2. Read the type, charset and size.
  3. Check any mismatch note.
  4. Download the decoded image if one is shown.

Frequently asked questions

Is it safe to paste untrusted data?

Yes. Nothing is executed. Images are shown with an img element only.

Why is the size larger than the file?

Base64 adds about a third.

Does it need the base64 flag?

No. Percent-encoded payloads are decoded too.

Is my input sent anywhere?

No. Everything runs in your browser and nothing is uploaded.
