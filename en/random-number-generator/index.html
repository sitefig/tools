Random Number Generator (Integers and Decimals)

Generates random whole numbers or decimals between a minimum and a maximum using the browser's cryptographic random source.

Use the tool

Why this tool exists

Pick numbers for a sample, a test, a draw or a spreadsheet. Integers are drawn without modulo bias, and big ranges work because the maths uses exact large integers. Decimals use 53 random bits scaled to your range and rounded to the places you choose.

You can ask for unique values, sort the list and choose the separator. The result also shows the count, sum and mean so you can check it. Because it is a true random source with no seed, the same settings give different numbers each time.

How to use it

  1. Set the minimum and maximum.
  2. Choose integers or decimals and the count.
  3. Tick unique or sorted if needed.
  4. Copy the numbers.

Frequently asked questions

Is this secure random?

It uses crypto.getRandomValues, which is suitable for most uses including picking winners. Do not use it where a law or contest rule requires a certified method.

Are both ends included?

For integers yes. For decimals the range is closed at both ends after rounding.

Can I repeat a draw?

No. There is no seed, so results cannot be reproduced.

What is the biggest range?

Integers can be very large. Decimals are limited by double precision.
