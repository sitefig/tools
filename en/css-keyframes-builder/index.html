CSS @keyframes Builder from Keyframe Lines

Builds a @keyframes block from simple lines like "50%: opacity: 1; transform: scale(1.1)" and adds the animation shorthand and a reduced-motion override.

Use the tool

Why this tool exists

Preset animation tools are fine until you need your own steps. Writing @keyframes by hand is mostly typing braces.

Here each keyframe is one line. The tool sorts them by percentage, checks the syntax, merges lines for the same percentage, and outputs the animation shorthand with your timing, direction and fill mode. It also adds a prefers-reduced-motion block so the animation can be switched off for users who ask for that.

How to use it

  1. Write one keyframe per line: percent, a colon, then declarations.
  2. Set name, duration, easing, iterations, direction and fill mode.
  3. Watch the preview box.
  4. Copy the CSS.

Frequently asked questions

Can I use from and to?

Yes. Use from, to or percentages, and comma-separate several keys such as "0%, 100%: opacity: 0".

Why a reduced-motion block?

Some people get discomfort from motion. The block turns the animation off when their system asks for that.

Does it check property names?

No. It checks the structure, not whether each property is animatable.
