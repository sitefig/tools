Image Filters

Applies grayscale, sepia, brightness, contrast, saturation, hue rotation, blur and invert to your images using canvas filters, then saves them as PNG, JPEG or WebP.

Use the tool

Why this tool exists

Sometimes you only need a quick adjustment: a black-and-white version of a logo, a brightened screenshot, a blurred background or an inverted diagram for dark mode. Opening a full photo editor is overkill, and online filter sites often upload your picture.

Set the percentage for each effect, leave the rest at their defaults and run it. The filters are combined in one pass and the result is saved as a new file. They rely on the canvas filter feature of your browser, which older versions of Safari do not support, in which case the output may look unchanged. If you only want the CSS for a web page, use the CSS filter generator instead. Nothing leaves your device.

How to use it

  1. Choose one or more image files.
  2. Set the filter amounts, for example grayscale 100 for black and white.
  3. Pick the output format and quality.
  4. Run it and download the filtered images.

Frequently asked questions

What are the default values?

Brightness, contrast and saturate are 100 percent, which means no change. Grayscale, sepia, invert, blur and hue are 0. Only the settings you change affect the picture.

Why does nothing change in my browser?

The tool uses the canvas filter property, which older Safari versions do not support. Try a current Chrome, Edge, Firefox or a recent Safari.

Are the effects applied in a fixed order?

Yes: grayscale, sepia, brightness, contrast, saturate, hue rotation, blur, then invert, all in a single pass. A different order would give slightly different results.

Is it lossy?

The effects are applied to the pixels and the file is encoded again, so a JPEG or WebP output uses lossy compression. PNG output is lossless.
