Schema @graph Merger

Combines separate JSON-LD blocks into a single @graph, assigns @id values from a base URL and merges duplicates of the same entity.

Use the tool

Why this tool exists

Plugins and themes each add their own JSON-LD, and the same Organization appears three times with different details. This tool puts them in one @graph. Nodes with the same @id, or the same type and URL or name, are merged; lists are joined, objects merged, and when two blocks disagree on a single value the first is kept and the conflict is listed.

With a base URL, nodes without an @id get one like https://example.com/#organization, and nested copies of an entity are replaced by a reference to it.

How to use it

  1. Paste all the blocks or the page HTML.
  2. Enter your site's base URL.
  3. Read the notes about merged nodes and conflicts.
  4. Replace the old scripts with the merged one.

Frequently asked questions

What decides that two nodes are the same?

The same @id, or the same first @type with the same URL or name.

What about conflicts?

The first value is kept and each conflict is listed for review.

Are properties lost?

Properties from all copies are kept unless they conflict.

Should I check the result?

Yes, run the syntax validator and the eligibility checker on it.
