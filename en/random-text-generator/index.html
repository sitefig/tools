Random Text Generator (Words, Sentences, Paragraphs, Characters)

Create filler text or random strings with a secure random source.

Use the tool

Why this tool exists

Words are drawn from a list of 250 common English nouns; sentences and paragraphs are built from them with capitals and full stops, so the text reads like language without meaning. Character mode picks from letters, letters and digits, digits, hex or a symbol set.

The character mode is good for test data but is not meant for passwords; use the password generator, which has strength guidance.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Choose words, sentences, paragraphs or characters.
  2. Set how many.
  3. Pick the character set if needed.
  4. Copy the result.

Frequently asked questions

Is this like lorem ipsum?

Similar purpose, but it uses real English words rather than Latin-style filler.

Is it secure random?

Yes, it uses crypto.getRandomValues.

Can I get the same text twice?

No, there is no seed.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
