Invisible Character & Homoglyph Detector

Scan text for zero-width, bidirectional-control and other invisible characters, and for Cyrillic or Greek look-alike letters mixed into Latin words. Strip them or fix them.

Use the tool

Why this tool exists

Text can hide things you cannot see. Zero-width characters can watermark a document so a leak can be traced, bidirectional controls can make code or a file name display differently from what it contains, and a Cyrillic "а" in "paypal" makes a spoofed link look genuine. Invisible characters also break searches, passwords and comparisons in confusing ways.

This detector lists every invisible or control character with its line, column and Unicode code point, finds words that mix scripts, and shows look-alike characters from other alphabets. You can then output cleaned text, or cleaned text with look-alikes converted to Latin letters. Some legitimate text, such as Cyrillic or Arabic, uses these scripts, so review before replacing. Processing is local.

How to use it

  1. Paste the suspect text into the input box.
  2. Choose the output: report, cleaned text, or cleaned text with homoglyphs converted to Latin.
  3. Tick the option to keep unusual spaces if you do not want them replaced by normal spaces.
  4. Run the tool and review the findings or copy the cleaned text.

Frequently asked questions

What counts as an invisible character?

Zero-width spaces and joiners, byte order marks, bidirectional controls, soft hyphens, unusual spaces, tag characters, variation selectors and control codes. Each is listed by type and position.

Will cleaning damage legitimate text?

It can. Joiners and variation selectors matter in some scripts and emoji, and homoglyph conversion would change real Cyrillic or Greek words. Check the report first and use the cleaned output only where it fits.

What is a Trojan Source risk?

Bidirectional control characters can reorder how source code is displayed, so what a reviewer sees differs from what the compiler reads. The tool warns when it finds them.

Is the text uploaded?

No. Everything runs in your browser and your text is not sent to any server, which matters if you are checking a confidential or watermarked document.
