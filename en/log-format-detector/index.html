Log Format Auto-Detector: Which Parser Fits These Lines?

Matches each line against known log formats, shows shares and names the tool to open next.

Use the tool

Why this tool exists

When you get a log file from someone else, the first question is what format it is. This tool tests each line against about thirty patterns, including cloud JSON logs identified by their keys.

The first matching pattern wins, so ambiguous lines may be assigned to a generic format. It reads the first 5000 lines.

How to use it

  1. Paste a sample of the log.
  2. Read the best guess and the table.
  3. Open the suggested tool.
  4. Check unmatched lines if there are any.

Frequently asked questions

How many formats?

About twenty line patterns plus JSON shape detection for CloudTrail, Cloudflare, Traefik, Caddy, Google Cloud, Azure, journald, MongoDB and Vercel.

What if nothing matches?

Use the log pattern miner to see the shapes in the file.

Are the tool ids pages here?

Yes. They are tool ids on this site.

Is my log uploaded?

No. Everything is processed in your browser and nothing is sent. Logs can hold IP addresses and tokens, so the page does not write them into the address bar.
