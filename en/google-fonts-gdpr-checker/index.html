Google Fonts Loading Checker (Self-Hosting Guide)

Finds Google Fonts links, imports and preconnects in pasted source and gives a self-hosting plan.

Use the tool

Why this tool exists

Loading fonts from fonts.googleapis.com makes each visitor's browser contact Google, which sends the IP address to a third party. Some European courts and authorities have treated this as a data protection problem, and many sites now host the font files themselves.

Paste your HTML or CSS and the tool lists each Google Fonts URL, the families and weights, and a step plan with @font-face stubs. It only sees the text you paste, so fonts loaded by scripts or plugins need a look at the Network tab.

How to use it

  1. Paste the head of your page or your CSS.
  2. Read the list of remote URLs and families.
  3. Download the font files, host them on your domain and add the @font-face rules.
  4. Remove the Google links and update your CSP.

Frequently asked questions

Is Google Fonts illegal?

There is no single answer. Some courts and authorities objected; others did not. Self-hosting avoids the question.

Are the fonts free to host myself?

Google Fonts are open source licensed, mostly under the SIL Open Font License. Check each font's licence.

Will it find fonts loaded by JavaScript?

No. Check the Network tab for fonts.gstatic.com.
