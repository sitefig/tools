Password Protect PDF

Encrypt a PDF so it asks for a password to open, and set what readers may do with it. The password never leaves your browser.

Use the tool

Why this tool exists

Sending a contract, a payslip or a scan by email is easier when the file asks for a password. This tool applies the PDF standard security handler: AES-256 (revision 6, the modern default), AES-128 or the old RC4 128-bit scheme for very old readers.

The user password is what a reader types to open the file. The owner password controls the permission flags: printing, copying text, editing and annotating. Leave the owner password blank and a random one is used, which makes the flags impossible to lift with a password but does not stop software that simply ignores them. Honest limit: permission flags are advisory. A viewer that respects them will block printing; a tool that does not will not. Only the open password is real protection.

You can leave the open password empty to set restrictions only. There is no recovery: if you lose the password, the file cannot be opened. The encryption itself runs in your browser with platform crypto APIs; the file and the password are never uploaded.

How to use it

  1. Choose a PDF that is not already encrypted.
  2. Type the password needed to open it and, optionally, a separate owner password.
  3. Pick AES-256 unless you need an older reader, and tick or untick the permissions.
  4. Download the protected file and test it by opening it with the password.

Frequently asked questions

Which encryption should I choose?

AES-256 is the strongest and is understood by current viewers (Acrobat, Preview, Chrome, Firefox, poppler, MuPDF). AES-128 works with readers from about 2005. RC4-128 is only there for very old software and is weak.

Are the permission flags secure?

No. They are a request to the viewer. Many tools ignore them, and anyone who can open the file can usually remove them. Use the open password for real protection.

How strong is the password protection?

The encryption is sound, the weak point is the password. For AES-256 the password is hashed with the iterated ISO 32000-2 algorithm, but a short or common password can still be guessed. Use a long passphrase, for example from the password generator.

Can I protect a file that is already encrypted?

Not directly. Remove the old password first, then protect again. This avoids mixing up two passwords.

What happens to signatures, forms and bookmarks?

Forms, bookmarks and links are kept. The file is rewritten, so any digital signature becomes invalid. Metadata is encrypted too.
