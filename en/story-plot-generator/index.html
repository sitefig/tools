Story Plot Generator: Character, Setting, Conflict and Twist

Combine a random hero, setting, goal, opponent and twist into a short story premise. Press run again for a new one.

Use the tool

Why this tool exists

A premise needs a person who wants something, a place and something in the way. Starting from a random set can break a stale idea.

Each premise joins a hero with a trait, a setting, a goal, an opposing force, a twist and a theme from short lists. Make several, keep the ones that spark something and change the rest. Use a seed to repeat a list.

How to use it

  1. Set how many premises you want.
  2. Optionally enter a seed.
  3. Press run for new combinations.
  4. Keep one and rewrite it in your own words.

Frequently asked questions

Is the output a full plot?

No. It is a premise. Structure and scenes are yours to write.

Can I repeat a result?

Yes, with the same seed.

Does it use AI?

No. It picks items from fixed lists with a random number generator.
