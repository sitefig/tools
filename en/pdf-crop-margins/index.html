Crop PDF Margins

Trim white space from the edges of PDF pages by setting a crop box with top, right, bottom and left margins in millimetres, points or inches.

Use the tool

Why this tool exists

Scans and exported documents often carry wide white borders or scanner shadows around the edge. They waste space on a phone screen, make text look small when printed, and push a one-page figure onto two pages. Cropping the page cleans that up without touching the contents.

This tool sets the page's crop box inward by the amounts you give for each side, measured on the page as it is displayed, so rotated pages behave as you expect. Viewers then show and print only the cropped area. The content outside is hidden rather than deleted, so a determined person could still recover it. Do not use this to redact confidential information. You can crop all pages or a range, and optionally also adjust the media box. It runs in your browser.

How to use it

  1. Choose a PDF file.
  2. Pick a unit and set the top, right, bottom and left margins to remove.
  3. Optionally limit it to a page range, or tick Also set MediaBox.
  4. Run the tool and download the cropped PDF.

Frequently asked questions

Is the cropped content deleted?

No. Cropping only changes the visible area. The original content is still in the file and can be recovered. Never use cropping to hide sensitive information; use proper redaction instead.

What does Also set MediaBox do?

The media box is the full page size, while the crop box is what viewers show. Setting both makes some tools that ignore the crop box respect the new size too.

Which units can I use?

Millimetres, points and inches. A PDF point is 1/72 inch. The default is 10 mm on every side, so start with small values and increase until the result looks right.

Do margins follow page rotation?

Yes, margins refer to the page as displayed, so top really means the top of the page you see, even on a page rotated by the scanner.
