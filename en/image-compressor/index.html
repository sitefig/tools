Image Compressor

Re-encodes images as JPEG or WebP at a chosen quality, with an optional maximum width, and reports the size before and after for each file. Several images can be processed at once.

Use the tool

Why this tool exists

Heavy images are the usual reason a page loads slowly or an email attachment is rejected. A photo of several megabytes can usually be cut by 70 to 90 percent with no visible difference at screen sizes, if you pick the right quality and dimensions.

Choose a format and a quality from 1 to 100, and optionally a maximum width so very large images are scaled down too. The result list shows each file's original and new size, and tells you honestly if the new file came out larger, which can happen with images that were already well optimised. Compression runs in your browser through the canvas, and the pictures are never uploaded to a server.

How to use it

  1. Choose one or more image files.
  2. Pick JPEG or WebP and set the quality, for example 75.
  3. Optionally enter a maximum width in pixels to scale large images down.
  4. Run it, check the size savings and download the compressed files.

Frequently asked questions

What quality should I use?

Around 70 to 80 is a good starting point for photos. Go lower for thumbnails, higher for images with fine detail or text. Compare the result visually, since the best value depends on the picture.

Why did my file get bigger?

Files that are already compressed or optimised, tiny images, and PNGs with flat colours can grow when re-encoded. The result list shows "larger by" when that happens, so keep the original instead.

Does it keep transparency?

WebP keeps transparency, but JPEG does not. Transparent areas in a JPEG output are filled with white. Choose WebP if you need to keep the see-through background.

Is anything uploaded?

No. Compression uses your browser's own image encoder on a canvas, so the files are read and re-encoded locally and never leave your device. You can disconnect from the internet after the page loads and it still works.
