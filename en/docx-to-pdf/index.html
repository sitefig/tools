DOCX to PDF (Text Only)

Turn the text of a Word document into a clean paginated PDF. It is a text converter, not a Word layout engine.

Use the tool

Why this tool exists

A faithful Word to PDF conversion needs Word's layout engine, its fonts and its style rules. This tool does not pretend to have those. It reads the document body of a .docx, keeps the text in order, and sets it in Helvetica on A4 or Letter pages with a margin you choose.

What comes through: paragraphs, line breaks and tabs, Title and Heading styles (larger and bold), list items (with a bullet), and table rows (cells joined with a vertical bar). Long lines are wrapped using real Helvetica widths and the text flows onto as many pages as needed. The result is a normal PDF with searchable text.

What does not: images, charts, text boxes, columns, headers, footers, footnotes, page breaks, numbering formats, fonts, colours, bold and italic inside a paragraph, and the original pagination. Characters outside Western European text become a question mark. For documents where layout matters, use a full word processor. The file is read in your browser and never uploaded.

How to use it

  1. Choose a .docx file.
  2. Pick the paper size, base font size and margin.
  3. Run the tool and download the PDF.
  4. Check the output; if layout matters, use a word processor instead.

Frequently asked questions

Is this a full Word to PDF converter?

No. It converts text only. Images, fonts, columns, headers, footers and exact page layout are not reproduced. The honest goal is a readable, searchable text PDF.

Which file types work?

Only .docx (Office Open XML). Old .doc files, .odt, .rtf, .xlsx and .pptx are not supported.

Why do some characters show as question marks?

The PDF uses the built-in Helvetica font with Western European encoding. Characters outside that set, such as Greek, Cyrillic or CJK, cannot be drawn without embedding a font.

Are tables kept?

Each table row becomes one line with the cell texts separated by a vertical bar. Borders and column widths are not reproduced.

Is my document uploaded?

No. The .docx is unzipped and converted in your browser.
