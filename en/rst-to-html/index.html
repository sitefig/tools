reStructuredText to HTML Converter (Common Subset, Offline)

Converts a practical subset of reStructuredText to HTML without Python or a server.

Use the tool

Why this tool exists

README.rst files and Sphinx sources use reStructuredText. Rendering needs docutils, which is a Python package. This page has a small hand-written converter for the common parts instead.

It handles section titles, paragraphs, bullet and numbered lists, definition and field lists, block quotes, literal blocks, comments, targets and links, basic inline markup, and the note, warning, code-block and image directives. I compared output with docutils on sample documents: structure matched, with differences in wrapper markup and class names. Tables, footnotes, substitutions and most directives are not supported and are reported as warnings.

How to use it

  1. Paste the .rst text.
  2. Read the preview and the warnings comment.
  3. Copy the HTML.
  4. Use docutils for full fidelity.

Frequently asked questions

Is this docutils?

No. It is a hand-written subset converter.

What gets skipped?

Tables, footnotes, substitutions, roles other than a few, and unknown directives.

Are links safe?

Only http, https, mailto, ftp and relative targets are kept.
