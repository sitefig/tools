RSS / Atom Feed Validator

Paste a feed and get a list of errors and warnings before readers and podcast directories find them.

Use the tool

Why this tool exists

The validator parses your XML strictly (mismatched tags are reported with a line number), identifies RSS or Atom, and checks the required elements of each format: channel title, link and description for RSS; id, title, updated and author for Atom. It validates date formats, absolute links, duplicate GUIDs or IDs, and the url, length and type attributes of enclosures.

It does not fetch the feed or its links and is not the W3C validator, but it catches the common mistakes that make feeds fail in readers.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Open your feed URL and copy the XML source.
  2. Paste it and run the validator.
  3. Fix each ERROR, then consider the WARN items.
  4. Re-test in a feed reader or podcast app.

Frequently asked questions

What date format does RSS need?

RFC 822, for example Mon, 05 Oct 2026 09:00:00 GMT. Atom uses RFC 3339, like 2026-10-05T09:00:00Z.

Why do items need GUIDs?

Readers use the guid to tell new items from ones they have already shown.

Does it check podcast tags?

No, only core RSS 2.0 and Atom rules.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
