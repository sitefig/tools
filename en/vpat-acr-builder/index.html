VPAT / ACR Builder: WCAG 2.2 Conformance Report Tables

Builds a Markdown accessibility conformance report from per-criterion levels and remarks.

Use the tool

Why this tool exists

Buyers ask for a VPAT or ACR. The tables are long but mechanical.

Write one line per criterion and the tool fills the Level A, AA and AAA tables for all 86 WCAG 2.2 criteria, marks missing ones as Not Evaluated, flags the new 2.2 criteria and counts the totals. Terms follow the ITI VPAT conventions; check the current official template before publishing.

How to use it

  1. Fill in product, date and contact.
  2. Write criterion, level and remarks per line.
  3. Copy the Markdown tables.
  4. Review against the official template.

Frequently asked questions

Which words are accepted?

supports, partial, no, na and ne.

Is 4.1.1 included?

No. It was removed in WCAG 2.2.

Does it test my site?

No. It only formats your findings.

Is it uploaded?

No.
