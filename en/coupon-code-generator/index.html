Unique Coupon Code Batch Generator

Generates a batch of random, unique coupon codes with the prefix, length and character set you choose.

Use the tool

Why this tool exists

Guessable coupon codes get abused. Codes that are random and long enough to make guessing impractical, with look-alike characters removed, are safer and easier to read out loud.

The tool uses the browser crypto random source with rejection sampling, so every character is equally likely. It refuses a batch if the code space is too small for the count, and it never repeats a code within a batch. It cannot check against codes already in your shop.

How to use it

  1. Set how many codes you need.
  2. Set prefix, length, dash grouping and character set.
  3. Copy the list and import it into your shop.

Frequently asked questions

How long should a code be?

Eight random letters and digits give a very large space, which is enough for most promos.

Why are some letters missing?

O, I and the digits 0 and 1 are left out to avoid confusion.

Will it avoid codes I already used?

No. Compare against your existing list.
