Palette Contrast Matrix (WCAG, All Pairs)

Find out which combinations in your design system are accessible, instead of checking pairs one by one.

Use the tool

Why this tool exists

Enter colours as hex values, optionally with names. The tool computes WCAG 2.x relative luminance contrast for every pair, shows a compact matrix (AAA, AA, large text or UI only, fail), a sorted list with pass levels for normal text (4.5:1 AA, 7:1 AAA), large text (3:1 AA, 4.5:1 AAA) and UI components (3:1), and lists the pairs safe for body text. The ratios match the contrast checker tool.

WCAG 2 contrast has known limits (it ignores font weight, polarity and perceived lightness); APCA is an alternative being studied. Contrast is only one part of accessibility.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Enter 2 to 24 colours, one per line.
  2. Read the matrix and the sorted list.
  3. Pick pairs that pass for text.
  4. Adjust colours that fail with the colour tools.

Frequently asked questions

What ratio do I need?

4.5:1 for normal text and 3:1 for large text and UI components at level AA.

What counts as large text?

18 pt (24 px) or 14 pt (about 18.7 px) bold and above.

Why is a pair listed once?

Contrast is symmetric, so A on B equals B on A.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
