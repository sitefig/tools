GPX Track Analyzer (Distance, Elevation Profile, Time and Speed)

Reads a GPX track or route and reports distance, elevation, time and speed, with a plan view and an elevation profile.

Use the tool

Why this tool exists

Hiking and cycling apps export GPX. Paste the file and see the numbers without uploading your location history. Elevation gain ignores small bumps below a threshold you set, because GPS elevation is noisy; watch brands use their own smoothing, so totals differ.

Distance is the sum of haversine legs between points. For the sample it is 0.1 percent below gpxpy, which uses a larger earth radius, and the elevation gain differs by about 1 m from gpxpy. The plan view has no basemap. Your path is private to the page.

How to use it

  1. Paste the GPX text.
  2. Set the elevation threshold and the stop speed.
  3. Read the numbers, the plan and the profile.
  4. Copy the summary or the SVG.

Frequently asked questions

Why does my watch show other figures?

Different smoothing and elevation sources.

What is moving time?

Time in segments faster than the stop speed.

Are routes supported?

Yes, if there is no track.

Privacy?

The file stays in your browser.
