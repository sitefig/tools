IP Subnet Calculator

Enter an IPv4 address with a CIDR prefix or netmask, or an IPv6 prefix, and get the network range, mask, wildcard, host count and address type. Several lines at once are fine.

Use the tool

Why this tool exists

Subnet maths comes up in cloud networking, firewall rules, VPN setups and exam questions: how many hosts fit in a /26, where does 10.0.0.0/22 end, what is the wildcard mask for an access list? The calculation is simple but easy to botch with a pencil, and one wrong bit means overlapping networks.

This calculator takes IPv4 as CIDR (192.168.10.77/26) or address plus netmask, and shows network and broadcast addresses, netmask in dotted and binary form, wildcard, host range, total and usable hosts, class and type. IPv6 prefixes show the first and last address and the /64 count. It runs locally.

How to use it

  1. Enter one or more addresses with a prefix, such as 192.168.10.77/26, or an address and netmask separated by a space.
  2. Add IPv6 prefixes like 2001:db8:abcd::1/48 if you need them.
  3. Read the network, broadcast, host range and counts for each entry.
  4. Copy the details you need into your firewall or cloud configuration.

Frequently asked questions

Why are usable hosts two fewer than the total?

The first address is the network address and the last is the broadcast address, so neither can be given to a host. The exceptions are /31 networks, which provide two usable addresses, and /32, which is a single host.

What is a wildcard mask?

It is the inverse of the netmask: ones where the netmask has zeros. Cisco-style access lists and OSPF configuration use it. For a /24 the netmask is 255.255.255.0 and the wildcard is 0.0.0.255.

Does it validate that the netmask is contiguous?

Yes. A netmask like 255.0.255.0 is rejected with an error, because only masks made of consecutive ones followed by zeros correspond to a CIDR prefix.

What does the IPv6 output include?

The compressed and expanded address, the prefix, its first and last address, the total number of addresses, how many /64 subnets fit inside and the address type, such as global unicast or unique local.
