Chemical Equation Balancer (Smallest Whole-Number Coefficients)

Balances a chemical equation by finding the smallest whole-number coefficients, and shows the atom count on both sides.

Use the tool

Why this tool exists

Balancing by trial and error gets hard fast. This tool treats the equation as a linear system: one equation per element, one unknown per compound, and finds the exact solution with fractions, then scales it to the smallest integers.

It handles brackets and hydrates and checks the result by counting atoms. If the system has more than one independent solution, it tells you that several reactions are mixed together and shows the smallest all-positive combination. It balances atoms only: it knows nothing about whether a reaction really happens, and ions and charges are not supported. A hard example, the potassium ferrocyanide and permanganate reaction, gives the known coefficients.

How to use it

  1. Type the equation with = or ->, for example C3H8 + O2 -> CO2 + H2O.
  2. Put several equations on separate lines if you like.
  3. Read the balanced equation and the atom check.
  4. If it fails, check the formulas for typos.

Frequently asked questions

Does it support states like (aq)?

Not as part of the formula; leave them out.

Can it balance ionic or redox equations with charges?

No, only neutral formulas.

What if the answer is not unique?

The equation combines several reactions. The tool shows one smallest all-positive solution and warns you.

Is the answer proven?

The atom check confirms every element balances.
