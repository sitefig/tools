Cookie Classifier (Necessary, Analytics, Marketing)

Sorts cookie names into necessary, functional, analytics and marketing, names the likely vendor and says whether consent is usually needed.

Use the tool

Why this tool exists

A cookie policy and a consent banner both start with the same question: which category is each cookie in? Doing it by hand from a browser cookie list is slow, and many names such as _ga or _fbp are well known.

This tool matches names against a built-in list of common cookies and marks everything else as unknown. It matches names only. A site can reuse any name, and regulators disagree on some analytics cookies, so treat the result as a first draft and check each cookie against the script that sets it.

How to use it

  1. Copy cookie names from your browser dev tools, or paste a Cookie or Set-Cookie header.
  2. Run the tool and read the category, vendor and consent note for each name.
  3. Look at the unknown names and trace them to the script that sets them.
  4. Use the result as input for your cookie banner and policy.

Frequently asked questions

Does it read my cookies?

No. It only reads the names you paste. Nothing is uploaded.

Why is a cookie marked Unknown?

The name is not in the built-in list. It may be a custom cookie or from a small vendor. Check the vendor documentation.

Is analytics always consent-exempt?

No. Some regulators, for example the French CNIL, allow narrow first-party audience measurement without consent. Most Google Analytics setups need consent.

Is this legal advice?

No. It is a name-based heuristic.
