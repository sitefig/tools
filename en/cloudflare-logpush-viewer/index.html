Cloudflare Logpush HTTP Request Log Viewer (Cache, Country, Bot Score)

Reads Logpush http_requests NDJSON and shows cache, status, country, bot score bands and edge time to first byte.

Use the tool

Why this tool exists

Logpush files hold one JSON object per request. A summary by cache status and country answers common questions without a log platform.

Bot score bands follow Cloudflare's description: 1 automated, 2 to 29 likely automated, 30 to 99 likely human. Scores exist only on plans with Bot Management.

How to use it

  1. Download Logpush files and paste them or choose them (gzip works).
  2. Add filters such as EdgeResponseStatus>=500.
  3. Read the summary.
  4. Switch to the table for rows.

Frequently asked questions

Which dataset?

The http_requests dataset with fields such as ClientIP and EdgeResponseStatus.

Why is there no bot score?

It needs Bot Management and the field in the Logpush job.

Can it chart over time?

No. Use the spike detector on a CSV-converted log for that.

Is my log uploaded?

No. Parsing happens in your browser and nothing is sent. Logs can hold IP addresses and tokens, so the page does not write them into the address bar.
