Intermittent Fasting Timer (Live 16:8 Countdown)

A live countdown for fasting and eating windows.

Use the tool

Why this tool exists

Pick a plan such as 16:8 and the time your eating window starts each day. The page shows whether you are in the fasting or eating window, the time left, and when the next window begins. It updates every second while the tab is open.

Nothing is stored, so it follows your device clock. The clock is not read out every second to screen readers; the status line changes only when a window changes. Fasting is not right for everyone. Ask a doctor if you have a medical condition, take medication, are pregnant or have had an eating disorder.

How to use it

  1. Choose a plan.
  2. Set the time your eating window starts.
  3. Keep the tab open to watch the countdown.
  4. Change the plan any time.

Frequently asked questions

Does it keep running in the background?

It runs while the page is open. Browsers may slow timers in hidden tabs, but it recalculates from the clock each time, so the display stays correct.

Does it send reminders?

No. It has no notifications.

Is this medical advice?

No. It is an estimate from a published formula. A doctor or dietitian can judge your own case far better.

Is anything uploaded?

No. The work happens in your browser and the page makes no network request with your input.
