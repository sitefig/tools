Schema Deprecation Checker

Flags markup for features that Google has retired or limited, such as FAQ, HowTo, special announcement, course info and the sitelinks search box, with the change date and what to do about it.

Use the tool

Why this tool exists

Google has removed many rich result types in recent years, and old markup is still all over the web. This tool reads your JSON-LD and lists every type that matches a retired feature, with the date from the Google Search Central changelog (read 2026-10-23). FAQ results stopped appearing on 7 May 2026; How-to was removed in 2023; special announcement, course info, estimated salary, learning video and vehicle listing were retired in 2025.

A retired feature does not make the markup invalid. Other search engines and tools may still use it, so the tool says whether keeping it makes sense and marks uncertain cases as review. It only covers Google Search and only what the changelog states.

How to use it

  1. Paste the JSON-LD or HTML.
  2. Read each flagged feature, its status and the source date.
  3. Decide whether to keep the markup for other uses.
  4. Remove what has no purpose to cut page weight.

Frequently asked questions

Will removing retired markup hurt my ranking?

Google does not use it for ranking and no longer shows the result. Removal is usually harmless; keeping it is harmless too.

Why is Course only marked review?

Course info is retired but course list carousels still use Course markup, so it depends on your use.

Does it know about every retired type?

No. It covers the ones named in the changelog text it was built from. Anything else is not flagged.

Are FAQ results restricted or gone?

The May 2026 changelog says the FAQ result no longer appears in Google Search. Older restrictions to certain sites are not covered here.
