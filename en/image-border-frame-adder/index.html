Image Border and Frame Adder (Solid, Rounded, Polaroid)

Add a solid, rounded or polaroid frame to a picture.

Use the tool

Why this tool exists

Pick a style, set the border width and colour, and download the result. Solid adds an even border. Rounded clips the picture to rounded corners with a coloured ring. Polaroid adds a thicker bottom edge like an instant photo.

Transparent corners need PNG. If you save as JPEG the outside area is filled white or with the colour you set.

How to use it

  1. Choose an image.
  2. Pick solid, rounded or polaroid.
  3. Set width, colour and corner radius.
  4. Download the framed image.

Frequently asked questions

Can I make the corners transparent?

Yes, keep the outside colour as transparent and save as PNG.

Is the original changed?

No. A new file is made.

Is the picture resized?

No. The border is added around the full-size picture.

Is anything uploaded?

No. The work happens in your browser and the page makes no network request with your input.
