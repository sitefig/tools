TypeScript Interface to Zod Schema

Converts TypeScript interfaces, type aliases and enums into Zod schemas such as z.object, z.enum, z.union and z.record, with optional and nullable handling and inferred types.

Use the tool

Why this tool exists

TypeScript types vanish at runtime, so a response from an API or a form submission is only trusted until it arrives with the wrong shape. Zod checks the data at runtime, but writing a schema for every existing interface is repetitive work. Paste your declarations and this tool writes the matching schemas, turns JSDoc comments into descriptions and adds the inferred type exports so the two stay in line. It supports the same subset of TypeScript as the TypeScript to JSON Schema tool: common types, unions, tuples, records and enums, but not conditional or mapped types. You can add .strict() to objects. The conversion runs in your browser and your code is not uploaded.

How to use it

  1. Paste your TypeScript interfaces, types and enums into the input box.
  2. Tick "Use .strict() on objects" if unknown keys should be rejected.
  3. Copy the generated Zod module into your project and install zod if you have not already.

Frequently asked questions

What does the output contain?

A Zod schema for each declaration, in dependency order, plus inferred type exports from z.infer so your types follow the schema.

Which TypeScript constructs are supported?

Interfaces, type aliases, enums, optional and nullable properties, unions, literals, tuples, arrays, Record, Date, index signatures and extends. Conditional and mapped types are not supported.

How are optional properties written?

Properties marked with a question mark become .optional(). Types that include null become .nullable(), and a union of several types becomes z.union, so each alternative is still checked at runtime.

Does it validate formats like email or URL?

No. TypeScript has no such information, so strings become plain z.string(). Add .email(), .url() or .min() yourself where needed.

The code is parsed, never executed. .transform() outputs and custom refinements are not inferable.
  • TypeScript Interface to JSON SchemaConvert TypeScript interfaces, type aliases and enums to JSON Schema draft-07 (definitions + $ref). Supports optional props, unions, literals, tuples, arrays, Record, Date, index signatures, extends/intersections and JSDoc descriptions. Not supported: conditional/mapped types, keyof/typeof and most utility generics.
  • JSON Schema to ZodTurn a JSON Schema (draft-07 / 2020-12 subset: types, formats, bounds, enum/const, anyOf/oneOf/allOf, $ref to $defs) into Zod source code.
  • JSON to Zod SchemaGenerate a Zod schema (and inferred type) from a JSON sample.
  • GraphQL Schema to ZodConvert GraphQL SDL types, inputs, enums and unions into Zod schemas (z.object, z.enum, z.union, .nullable() / .optional(), z.array). Custom scalars map to z.string() (edit as needed). Recursive types use z.lazy.
  • JSON Schema GeneratorInfer a draft-07 JSON Schema from a sample document, with optional string format detection.
