Text Box Drawer: ASCII and Unicode Boxes, Code Comment Banners

Put a neat frame around text for READMEs, terminals and source-code headers.

Use the tool

Why this tool exists

Choose a border style, alignment and padding. Box styles use Unicode box-drawing characters or plain ASCII; comment styles wrap each line with //, /* */ or # and add rules above and below. The width is measured in characters so the box lines up in monospace fonts.

Unicode box characters need a monospace font that includes them; use the ASCII style for maximum compatibility.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Paste the text.
  2. Pick a border style and alignment.
  3. Set padding.
  4. Copy the result into your document or code.

Frequently asked questions

Why do borders look broken?

The font may not be monospace or may lack box-drawing characters; use the ASCII style.

Does it handle emoji?

Wide characters can misalign boxes in some fonts.

Can I draw tables?

Use the ASCII table generator for tables.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
