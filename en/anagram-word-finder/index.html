Anagram Word Finder from Your Own Word List

Find which words from a list you paste can be spelled with a set of letters, with blanks allowed. Full anagrams or any shorter word.

Use the tool

Why this tool exists

Word-game helpers usually query a server. This one works offline, but it has no dictionary of its own: you paste the word list you trust, such as a Scrabble list or a class vocabulary.

Enter letters, use ? for a blank, and see every listed word that can be spelled with them, longest first. Choose whether only words using all the letters count, which gives exact anagrams. To test whether two phrases are anagrams, use the Anagram Checker.

How to use it

  1. Enter your letters, with ? for each blank.
  2. Paste a word list, one word per line.
  3. Choose any word that fits, or only full anagrams.
  4. Read the matches by length.

Frequently asked questions

Where do I get a word list?

Use any text file with one word per line, such as a Scrabble or spell-checker list. The tool is offline and ships none.

What does ? do?

It stands for any one letter.

Does it test two phrases?

The Anagram Checker on this site compares two phrases.
