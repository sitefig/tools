Histogram Builder with Adjustable Bin Width

Counts how many of your numbers fall in each bin and draws the bars. You set the bin width and where the first bin starts.

Use the tool

Why this tool exists

The shape of a histogram changes with the bin width, so being able to change it is the whole point. Try several widths and watch whether a second peak appears or disappears.

Bins include their lower edge and exclude the upper edge; the last bin includes both. The table under the chart lists every bin and count, so you can copy the numbers. Automatic width picks a round number from the Sturges rule, which suits roughly bell-shaped data and can hide detail in skewed data.

How to use it

  1. Paste numbers separated by spaces, commas or new lines.
  2. Set a bin width, or 0 for automatic, and optionally the first bin start.
  3. Compare the picture with different widths.
  4. Copy the SVG or the counts table.

Frequently asked questions

Which edge belongs to which bin?

A value equal to a bin edge goes into the bin that starts there. Only the last bin also includes its upper edge.

How many numbers can it take?

Up to 100000.

Can I use percentages instead of counts?

Not yet. The y axis shows counts.

Verified?

Bin counts for the sample were checked against a manual Python count.
