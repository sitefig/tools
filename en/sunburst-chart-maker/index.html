Sunburst Chart Maker (Hierarchy as Concentric Rings)

Draws a hierarchy as rings: the first level in the inner ring, children outside it, arc length by value.

Use the tool

Why this tool exists

A sunburst keeps the parent-child relationship visible while showing proportions. Instead of clicking a segment to zoom, you type the branch path, for example Asia/Japan, which also works with a keyboard and a screen reader.

Labels appear along an arc when they fit and radially in thin ring segments; small arcs keep a tooltip and a table row. Limit the rings if the outer levels become dust.

How to use it

  1. Write rows like Region/Country/City,value.
  2. Optionally type a path in Zoom into to show only that branch.
  3. Limit the number of rings if needed.
  4. Copy or download the SVG.

Frequently asked questions

How do I zoom?

Enter the branch path in the zoom box, using the same names as in your rows.

Why is there a centre label?

It shows the branch you are viewing and its total.

Are values summed up the tree?

Yes. A parent equals its children plus any own value.

Colours?

Each top-level branch has a colour; deeper rings are lighter.
