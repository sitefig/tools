Schema Graph Visualizer

Shows how your JSON-LD entities link together: organization, website, page, person. Missing targets and orphan nodes stand out.

Use the tool

Why this tool exists

A good JSON-LD graph connects its entities by @id, for example a WebPage that is part of a WebSite published by an Organization. A reference to an @id that is never defined is a broken link, and a node nothing connects to is easy to miss in a long block.

The diagram puts nodes on a circle with arrows for references and nesting. Colour is never the only signal: broken references have a dashed outline and the table lists every node and link with its status. The picture has a text description and the tables carry the same facts.

How to use it

  1. Paste the JSON-LD or HTML.
  2. Read the summary line for counts.
  3. Look for red dashed outlines and orange nodes.
  4. Fix the missing @id or add the link, then run again.

Frequently asked questions

What counts as broken?

An object that only has an @id which no full node defines.

What is disconnected?

A node outside the largest connected group.

Is it interactive?

It is a static diagram with tables, so it works with a keyboard and screen reader.

How many nodes can it show?

Large graphs get crowded; the table still lists everything.
