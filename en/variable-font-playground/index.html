Variable Font Playground: Move Axes and Copy font-variation-settings

Reads the axes of a variable font you upload and gives a slider and a number field for each, with a live preview and the CSS to copy.

Use the tool

Why this tool exists

Variable fonts pack many styles into one file along axes such as weight (wght) and width (wdth). The tool reads the fvar table to learn each axis range and default, then applies your values with font-variation-settings.

It works from your own file, so it needs no font catalog or network. Choose a TTF, OTF or WOFF variable font. WOFF2 cannot be read here.

How to use it

  1. Choose a variable font file.
  2. Move the sliders or type axis values.
  3. Edit the preview text and size.
  4. Copy the font-variation-settings line.

Frequently asked questions

Where do I find a variable font?

Many open fonts offer them. Check the license for your use.

What if there are no sliders?

The font is static and has no fvar table.

Can I use named instances?

Not in this version. Set the axis values directly.

Is it uploaded?

No.
