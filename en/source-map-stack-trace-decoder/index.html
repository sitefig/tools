Source Map Stack Trace Decoder (Minified Position Lookup)

Reads a version 3 source map and translates minified positions into original ones. Paste a production stack trace (Chrome, Firefox or Safari style) or plain line:column pairs together with the .map file.

Use the tool

Why this tool exists

A production error that says app.min.js:1:48213 is useless on its own. Source maps hold the answer, but reading them by hand means decoding base64 VLQ segments.

The decoder follows the source map specification and looks up each position in the map you paste. It applies the same map to every frame, so frames from other bundles will be wrong or unmapped. Nothing is uploaded, which matters because maps often contain your source code.

How to use it

  1. Paste the stack trace or line:column lines in the first box.
  2. Paste the contents of the .map file in the second box.
  3. Read the original position under each frame.
  4. Untick source lines if you do not want code shown.

Frequently asked questions

Are lines and columns 1-based?

Yes in the input and the output, like browser stack traces. The map itself is 0-based and the tool converts.

Why does a frame say "no mapping"?

There is no mapped segment at or before that column, or the frame comes from another file.

Are index maps supported?

No. Maps with sections are rejected.

Is my source code uploaded?

No. The map is parsed in your browser.
