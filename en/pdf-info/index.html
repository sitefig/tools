PDF Info

Load a PDF and see its version, page count, page size, fonts, Info fields such as title and author, producer and whether it is encrypted.

Use the tool

Why this tool exists

Before you send, merge or archive a PDF it helps to know what it contains. How many pages are there? Which software made it? Does it carry an author name you would rather not share? Is it encrypted, which would block most editing tools? Opening a heavy viewer to find out is slow, and online inspectors upload the file.

This tool scans the file's structure in your browser and reports the basics: file size, PDF version, linearisation, page count from several methods, object count, encryption, whether object and cross-reference streams are used, first page size in points and millimetres, fonts and the Info dictionary. It is a best-effort reader that works on plain files. Encrypted documents cannot be read, and damaged files are not repaired.

How to use it

  1. Choose a PDF file.
  2. Run the tool.
  3. Read the version, page count, encryption status and font list.
  4. Check the Info dictionary for title, author and producer.

Frequently asked questions

Why do page counts sometimes differ?

The tool counts pages three ways: walking the page tree, counting page objects and reading the root Count. They normally agree. A mismatch can come from incremental updates or deleted pages that remain in the file.

What if the file is encrypted?

It reports Encrypted: YES, and the Info fields cannot be read. This tool does not remove passwords or restrictions.

Is anything uploaded?

No. The file is read and parsed in your browser. Nothing is sent to any server, which makes it fine for contracts and personal documents.

How reliable is it?

It is a pattern-based reader, designed for ordinary files. Broken cross-reference tables, unusual structures and files with leftover deleted objects can produce misleading figures, so treat results as a guide.

Tools often used together

  • PDF Page Count and SizesList the number of pages with each page size, rotation and paper format (A4, Letter...).
  • PDF Metadata EditorEdit Title, Author, Subject, Keywords, Creator and Producer. Leave a field empty to keep it, type - to delete it. The old XMP packet is dropped so it cannot contradict the new values.
  • Remove PDF MetadataStrip the Info dictionary (author, title, creator...) and XMP metadata packets from a PDF.
  • PDF Text Extractor (simple)Best-effort text from PDFs whose content streams are uncompressed or Flate-compressed and use simple fonts. Will NOT work for subset-encoded / Type0 / Identity-H fonts (most Word, Chrome, LaTeX output) or scanned pages.
  • Merge PDFsCombine several PDFs into one, in the order selected. Works on existing PDFs without re-rendering; bookmarks and form fields are dropped.
  • EXIF / Image Metadata ViewerParse JPEG EXIF (camera, dates, GPS) and PNG/WebP chunks with a hand-written parser. File never leaves your browser.
