Ed25519 Sign & Verify

Generate an Ed25519 key pair, sign a message with a 32-byte hex seed, or verify a signature against a public key. The tool uses your browser's WebCrypto support.

Use the tool

Why this tool exists

Ed25519 signatures turn up in SSH keys, JWT variants, software release signing, Nostr, blockchain wallets and many APIs. When an integration fails, you often need to check one thing: does this signature belong to this message and key, and is the key encoding what you thought?

This tool lets you generate a pair, sign with a seed, and verify with the public key and signature in hex, so you can compare against the output of your own library. It relies on WebCrypto, so it needs a browser that supports Ed25519. It is a test and learning tool. Do not paste a seed that protects real funds or production systems into any web page you do not fully trust.

How to use it

  1. Choose a mode: generate, sign or verify.
  2. For signing, enter the message and a 64-character hex seed. For verifying, enter the message, the public key and the 128-character signature.
  3. Choose whether the message is plain text or hex.
  4. Read the key pair, signature or verification result.

Frequently asked questions

Which browsers can run it?

It needs WebCrypto with Ed25519, which recent versions of the major browsers include. If your browser lacks it, the tool shows an error instead of a result, and you can try an updated browser.

What is the seed?

A 32-byte value, written as 64 hex characters, from which the private key and public key are derived. The same seed always gives the same key pair and, for the same message, the same signature.

Can I use it with real keys?

Avoid it. Use throwaway seeds for testing and compare with your library's output. Secrets pasted into any web page can be exposed by extensions, shared screens or compromised devices.
