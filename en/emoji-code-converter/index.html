Emoji and Symbol Code Converter: U+ Code Points, HTML Entities, CSS and JS Escapes

Shows the code points and encodings for each emoji or symbol you paste, and turns U+ codes back into characters.

Use the tool

Why this tool exists

Developers need an emoji as an HTML entity, a CSS content escape or a JavaScript escape, and need to know whether it is one code point or several (flags and ZWJ sequences are several).

The tool splits text into user-perceived characters, then lists code points, HTML hex and decimal entities, CSS escape, JS escape, UTF-8 bytes and UTF-16 units for each. It does not look up emoji names or shortcodes, because that needs a name table which is not bundled.

How to use it

  1. Paste emojis or symbols, or type codes like U+1F680.
  2. Optionally include plain ASCII.
  3. Read the table.
  4. Copy the form you need.

Frequently asked questions

Why do some emojis have several code points?

Flags, skin tones and joined emojis are sequences of code points.

Does it give :shortcodes:?

No. Only encodings are shown.

Is the CSS form safe?

Yes. Use it inside content: "..." with a trailing space handled for you between code points.
