HTML Head Extractor (Meta, Link, Title Table)

Reads the head of pasted HTML and lists its elements with attributes.

Use the tool

Why this tool exists

View-source mixes the head with everything else. A table of title, meta and link elements makes duplicate canonicals, double descriptions and missing viewport tags easy to see.

It reads text up to the closing head tag. It is not a full HTML parser, so very odd markup may be missed. Repeats that are allowed, like several og:image tags, are not flagged.

How to use it

  1. Paste the page source.
  2. Run the tool.
  3. Scan the table.
  4. Fix flagged duplicates and add missing tags.

Frequently asked questions

What is flagged?

More than one title, canonical, description, robots, viewport or similar single-use tag.

Are scripts listed?

Only counted.

Does it need a full page?

No, a head block is enough.

Is the page fetched?

No. Paste the source.
