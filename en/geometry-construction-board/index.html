Geometry Construction Board: Points, Lines, Circles and Dependent Constructions

A construction board where points can be free or computed from other objects. Add objects with commands, a form or the pointer, drag free points, and export SVG with a text description.

Use the tool

Why this tool exists

Classic constructions such as the perpendicular bisector, the circumcircle or a tangent from a point are chains of steps: each new object depends on earlier ones. In this board every object is one line of a small script, so the construction is both the picture and a record of how to rebuild it. Move a red free point and everything that depends on it is recomputed.

Every action has a keyboard route: type a command, use the form with menus for each slot, edit the script, or select a point and move it with the arrow keys or exact coordinates. The page also lists every object in words and reports relations it finds, such as perpendicular lines. Lines, segments and circles only, in floating point, so results are shown to four decimals.

How to use it

  1. Load an example such as "Equilateral triangle", or start by adding two points.
  2. Add objects with the form, or type commands like "circle c1 A B" and press Enter.
  3. Drag a red point, or select it and use the arrow keys or the X and Y boxes. Dependent objects update.
  4. Read the description under the board and download the SVG or the text.

Frequently asked questions

What commands are available?

point, midpoint, segment, line, circle (through a point or with a radius), compass, perp, parallel, bisector, anglebisector, intersect, pointon, dist and angle. The form lists the slots for each.

How are intersections numbered?

For two circles, number 1 is on the left of the line from the first centre to the second. For a line and a circle, number 1 comes first along the line from its first point to its second.

What happens when circles no longer meet?

That line shows an error and everything that depends on it is skipped. Fix the free points and it comes back.

Can I use it without a mouse?

Yes. Commands, the form, the script box, point nudging and the SVG export all work from the keyboard, and the board has a text description.
