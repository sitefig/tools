HAR Performance Analyzer: Waterfall, Heaviest Requests and Third-Party Share

Analyses a HAR file for performance: totals by resource type, largest and slowest requests, third-party share, uncompressed text responses and a text waterfall.

Use the tool

Why this tool exists

A HAR file has everything the Network panel showed, but reading it as JSON is painful. The numbers you need are totals, outliers and who is not you.

This tool adds up transferred bytes by type, lists the biggest and slowest requests, separates third-party hosts using a simple site rule, and flags text sent without compression and slow server waits. The waterfall is drawn in text. HAR files can contain cookies and tokens, so reading it locally matters; nothing leaves this page.

How to use it

  1. In DevTools, open Network, reload the page, then choose Save all as HAR.
  2. Paste the file contents into the box.
  3. Read the type totals and the third-party share first.
  4. Adjust the list length or waterfall rows with the options.

Frequently asked questions

How is third party decided?

By comparing each host with the registrable domain of the first request, using the last two labels (three for names like co.uk). There is no public suffix list.

Why do the sizes differ from DevTools?

The tool uses the transfer size when the HAR has it, otherwise body plus header size, otherwise the uncompressed size.

Is the waterfall exact?

It is a coarse text scale of start and duration. Use DevTools for detail.

Is my HAR uploaded?

No.
