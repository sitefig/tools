MP3 Tag Editor (ID3 Tags and Cover Art)

Shows the ID3 tags of one or more MP3 files and writes new ones, including a cover image. The audio data is copied as it is, so quality does not change.

Use the tool

Why this tool exists

Players sort and display music by its tags. Wrong artists, missing track numbers and absent cover art are common after ripping or downloading. Fixing them should not need an installed program.

The tool reads ID3v2.3, 2.4 and the old ID3v1 block (a v2.2 reader is included but untested), and writes ID3v2.3 with UTF-16 text where needed, which every player understands. Frames you do not edit are kept when the file already has a v2.3 tag; from v2.2 or v2.4 the fields shown on the page are carried over and anything else is listed as dropped.

How to use it

  1. Select one or more MP3 files, plus a PNG or JPEG if you want to set cover art.
  2. Press Run with all fields blank to see the current tags.
  3. Fill in the fields you want to change and press Run again.
  4. Download the tagged files.

Frequently asked questions

Is the audio re-encoded?

No. The audio bytes are copied unchanged, only the tag at the start of the file is rewritten.

What happens to the old ID3v1 tag?

It is removed when you save, to avoid conflicting information.

Can I tag many files at once?

Yes, but the same values are applied to all of them. Use it for artist, album and cover, and tag titles one by one.

Does it support other formats?

Only MP3 with ID3. M4A, FLAC and OGG use other tag systems.
