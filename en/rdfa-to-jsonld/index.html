RDFa to JSON-LD Converter

Reads RDFa attributes from pasted HTML and writes JSON-LD, resolving vocab and prefix declarations.

Use the tool

Why this tool exists

RDFa spreads structured data across many attributes. The converter reads vocab, prefix, typeof, about, property, resource, href, src, content and datetime, builds items and nested items, and shortens schema.org IRIs to plain type names.

It covers the subset used in practice with schema.org. Rel and rev chains, datatypes, language tags and the full RDFa initial context are not handled, and the output says so. Unknown prefixes are reported rather than guessed.

How to use it

  1. Paste the HTML with RDFa attributes.
  2. Read the JSON-LD output and any warnings.
  3. Check nested items and links.
  4. Replace the attributes with a script tag.

Frequently asked questions

Which RDFa features are missing?

rel and rev chaining, datatype, language, inlist and the full initial context.

What does url become?

A link value becomes an object with @id, as RDFa treats it as a resource.

Can it handle prefixes?

Yes, declared in the prefix attribute; schema is known by default.

Is it verified?

By hand against samples; no independent RDFa library was available.
