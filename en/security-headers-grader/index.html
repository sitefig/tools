Security Headers Grader (A to F from Pasted Headers)

Scores a set of response headers out of 100 and explains every point lost.

Use the tool

Why this tool exists

Security headers are cheap to add and easy to forget. A quick check tells you which ones are missing or weak on a page.

Paste the response headers from dev tools or curl -I and the tool gives each header points: HSTS, Content-Security-Policy, nosniff, framing protection, Referrer-Policy, Permissions-Policy and the two cross-origin headers. Version leaks cost points. The scoring is a simple heuristic made for this site, not the scale of any other grader, and the CSP check is only a quick look.

How to use it

  1. Run curl -I https://yoursite or copy headers from the Network tab.
  2. Paste them into the box.
  3. Read the grade and the points per header.
  4. Add or fix headers and test again.

Frequently asked questions

Is this the same as other header graders?

No. The weights are different. Compare results only within this tool.

Does it fetch my site?

No. It reads the text you paste.

Why is CSP half marked?

A policy with unsafe-inline, unsafe-eval or wildcard script sources gets half the points. Use the CSP Analyzer for details.
