App Name Ideas

Enter a few keywords and get a shuffled list of name ideas built from prefixes, suffixes, blends and simple endings. A seed number makes the shuffle repeatable.

Use the tool

Why this tool exists

Naming is hard because you start from nothing. A list of mechanical combinations will not give you a perfect name, but it can break the block: a word you would not have thought of, a blend that sounds good out loud, a suffix that gives a plain word some character.

This generator takes your keywords and mixes them with common prefixes like Go and Smart, suffixes like -ly, -ify, -hub and -kit, endings such as -r and -o, and blends of two of your keywords. It then shuffles them with a seed you control. The output is names only. Before falling for one, check trademarks, domain names and app store listings yourself.

How to use it

  1. Enter your keywords, one per line.
  2. Set how many names you want and a shuffle seed number.
  3. Run the tool to see the list of capitalised names.
  4. Change the seed to get a different selection, and shortlist the names that sound right out loud.

Frequently asked questions

Are these names available?

Unknown. The tool does not check anything. Search trademark registers, domain registrars and app stores before you commit to a name.

What does the seed do?

It controls the random shuffle. The same keywords, count and seed always give the same list, so you can return to a good one. A different seed gives a different set of names.

How many names can I get?

As many as you ask for, up to the number of combinations the keywords produce. More keywords give many more combinations, especially because pairs of keywords are blended.

Does it use AI?

No. It is plain string combination with a fixed list of prefixes and suffixes, so the names are mechanical and need your judgement.
