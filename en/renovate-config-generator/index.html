Renovate Config Generator

Create a renovate.json with the recommended preset, a schedule and timezone, automerge for minor and patch updates, grouped updates, pinned GitHub Action digests and weekly lock file maintenance.

Use the tool

Why this tool exists

Renovate keeps dependencies current, but out of the box it can open a large number of pull requests at awkward times. Most teams end up wanting the same few settings: a quiet schedule, minor and patch updates grouped into one pull request, safe updates merged automatically and a cap on open pull requests.

Tick the options you want and the tool writes valid JSON with the schema URL, the extends list and the packageRules that implement grouping and automerge. Automerge is limited to updates from versions that are not 0.x, because those can break in minor releases. Add labels, reviewers and a concurrency limit. Automerge only helps if your tests are good, since a merged update is only as safe as your CI. Nothing is uploaded.

How to use it

  1. Choose whether to extend config:recommended and pin GitHub Action digests.
  2. Pick a schedule and enter your timezone.
  3. Tick automerge, grouping and lock file maintenance as you wish, then set labels, reviewers and the pull request limit.
  4. Copy the JSON into renovate.json in your repository.

Frequently asked questions

Is automerge safe?

It is as safe as your tests. The tool restricts automerge to minor and patch updates of packages already at version 1.0 or higher, but you still need passing CI and branch protection.

What does grouping do?

It puts all minor and patch updates into a single pull request, which cuts noise. Major updates still arrive separately so you can review breaking changes.

What is pinning action digests?

It replaces version tags in GitHub Actions workflows with commit hashes, which protects against a tag being moved to malicious code. Renovate then updates the hashes for you.

How is this different from Dependabot?

Both open update pull requests. Renovate offers more grouping and configuration options. Use the Dependabot generator if you prefer GitHub's built-in tool.
