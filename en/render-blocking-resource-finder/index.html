Render-Blocking Resource Finder for Scripts and Stylesheets

Lists render-blocking scripts and stylesheets in pasted HTML and suggests a fix for each.

Use the tool

Why this tool exists

Render-blocking resources delay the first paint. They are easy to spot in the source.

The tool flags scripts without async, defer or module, stylesheets that apply to every screen, @import inside style tags and large inline scripts in the head. It lists what is not blocking so you can see the pattern you already use. File sizes and caching are not known here; Lighthouse measures the real cost.

How to use it

  1. Paste the full page HTML.
  2. Read each finding and its line.
  3. Apply the suggested attribute or loading pattern.
  4. Re-run to confirm.

Frequently asked questions

Is defer or async better?

defer keeps order and runs after parsing; async runs as soon as it arrives. Use defer for dependent scripts.

Are all stylesheets blocking?

Yes unless a media query does not match, as with print.

What about module scripts?

They are deferred by default.

Is the HTML sent anywhere?

No.
