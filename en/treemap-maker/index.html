Treemap Maker (Nested Rectangles from Category Paths)

Draws a treemap from path and value rows. Each rectangle has an area proportional to its value, and groups nest inside their parents.

Use the tool

Why this tool exists

Treemaps are good for seeing which few items make up most of a total, such as disk usage, revenue by product line or traffic by section. Write the hierarchy as a path separated by slashes and give each leaf a value.

The layout uses the squarified method so rectangles stay close to square and are easy to compare. Very small rectangles lose their labels but keep a hover title and a row in the table. Areas encode values, so negative numbers are not allowed.

How to use it

  1. Write one row per leaf: Group/Sub/Item,value.
  2. Choose whether labels include values.
  3. Look at the table to check totals.
  4. Copy or download the SVG.

Frequently asked questions

Can a node have its own value and children?

Yes, its own value is shown as an extra "(own)" rectangle.

How deep can it go?

As deep as the labels stay readable; there is no hard depth limit.

Why is a label missing?

The rectangle was too small. Hover for the title.

Does it handle zero values?

Zero rows are ignored.
