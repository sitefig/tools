SEPA Payment QR Code Generator (EPC QR for Banking Apps)

QR code image for a SEPA credit transfer, built to the EPC format.

Use the tool

Why this tool exists

Many banking apps in the euro area can scan a QR code that fills in beneficiary, IBAN, amount and reference. Put one on an invoice and payers make fewer mistakes.

The tool validates the IBAN checksum and field lengths, then builds the payload and the code in your browser. Test the code with a banking app before printing.

How to use it

  1. Enter name, IBAN, amount and reference.
  2. Choose a text or structured reference.
  3. Download the PNG or copy the SVG.

Frequently asked questions

Is the IBAN sent anywhere?

Nothing you type leaves your browser.

What limits apply?

Name up to 70 characters, text up to 140, structured reference up to 35, payload up to 331 bytes.

Does every app support it?

Support varies by bank. Test first.
