Pie and Donut Chart Maker with Percentages

Builds a pie or donut chart from category and value lines. Each slice shows its share of the total, and a legend lists the exact percentages.

Use the tool

Why this tool exists

Pie charts work for a few parts of a whole and fail beyond that. This tool warns by design: it draws what you give it, labels each slice with its percentage, and supplies a table so the numbers are never only in the colours.

The donut option leaves room for a total or note when you place the SVG in a slide. Slices smaller than about 4 percent keep their value in the legend rather than crowding the chart. Negative values are rejected because they have no meaning in a pie.

How to use it

  1. Type one category and value per line, separated by a comma.
  2. Set the hole size: 0 for a pie, about 55 for a donut.
  3. Choose decimals and whether to sort the largest first.
  4. Copy or download the SVG.

Frequently asked questions

Why are tiny slices not labelled?

Labels under 4 percent would overlap. The legend still shows every percentage.

Can values be zero?

Zero rows are dropped. Negative values give an error.

How many slices?

Up to 40, but readability drops fast after about 6.

Is the order kept?

Yes unless you tick sort largest first.
