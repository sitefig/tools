Raffle Picker

Paste names, one per line, and set the number of winners. The tool shuffles the list and returns that many winners in order.

Use the tool

Why this tool exists

Giveaways, classroom helpers, office prizes and meeting turns all come down to the same fair draw. Drawing names from a hat is charming but slow, and spreadsheets need formulas that recalculate every time you touch them. This picker takes a pasted list, shuffles it using the browser's secure random generator in an unbiased way and returns the requested number of winners as a numbered list, so first, second and third place are clear. Each entry can win only once. Entries are counted at the top, so you can check nothing was lost in the paste. The names are processed in your browser and never uploaded, but for regulated prize draws check your local rules, as this is not a certified system.

How to use it

  1. Paste the names into the box, one per line.
  2. Set the number of winners.
  3. Run the tool and read the numbered list of winners.

Frequently asked questions

Can the same name win twice?

No. The list is shuffled and the first winners are taken from the top, so each line can appear once. If a person has several entries, list their name several times.

Is the draw fair?

Yes. It uses a Fisher-Yates shuffle with random numbers from the browser's secure generator, so every entry has an equal chance in each position.

What are the limits?

You need at least one name, and the winners must be between 1 and the number of lines. Blank lines are ignored and surrounding spaces trimmed.

Is it suitable for official prize draws?

It is fine for informal giveaways, but formal competitions may have legal requirements for how winners are chosen and recorded. This page keeps no record of draws.
