Wide to Long Reshaper (Unpivot and Pivot Back)

Melts a wide table into long format or casts a long table back to wide.

Use the tool

Why this tool exists

Charts, databases and statistics tools like long data: one row per observation. Spreadsheets often hold wide data with a column per year or month. Choose the identifier columns to keep and the rest are stacked into a name column and a value column.

The reverse mode needs a name column and a value column and creates one column per distinct name; two rows with the same identifiers and name are an error rather than a silent overwrite.

How to use it

  1. Paste the CSV and list the identifier columns.
  2. Choose wide to long or long to wide.
  3. Name the new columns, or set the name and value columns for the reverse.
  4. Copy or download the result.

Frequently asked questions

Which columns get stacked?

All except the identifiers, unless you list columns to stack.

Are values converted?

No, text is carried over unchanged.

What if long to wide has duplicates?

You get an error naming the name.

Large output?

Limited to 500000 rows.
