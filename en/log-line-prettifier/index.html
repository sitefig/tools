Log Line Prettifier: Expand JSON Inside Log Lines

Expands embedded JSON in application log lines into readable indented blocks.

Use the tool

Why this tool exists

Structured logs often put a JSON object in the middle of a text line. On one line it is hard to read.

The tool scans each line for balanced braces and brackets, tries to parse each as JSON, and prints the valid ones pretty. Text before and after stays on its own lines. Arrays that hold only plain values such as [INFO] or [2025] are left alone unless you tick the option.

How to use it

  1. Paste log lines.
  2. Pick the indent.
  3. Tick the option to expand arrays of plain values if needed.
  4. Copy the result.

Frequently asked questions

What if the JSON is invalid?

It is left in the line as it was.

Does it handle JSON inside quoted strings?

No. Only JSON written directly in the line.

Do I need to remove secrets first?

The tool is local, but logs often hold tokens. Use the log privacy workbench before sharing.

Is my input sent anywhere?

No. Everything runs in your browser and nothing is uploaded.
