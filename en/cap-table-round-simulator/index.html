Cap Table Simulator With Option Pool and New Round

Builds a simple cap table before and after one priced round, with an option pool top-up if you want it.

Use the tool

Why this tool exists

A cap table lists who owns how many shares. A priced round gives the investor shares at a price set by the pre-money valuation and all shares that exist before it, including a pool top-up demanded before the round.

The pool size needed to reach your target after the round is solved in closed form, so the target is met exactly. The model is one round of common-equivalent shares with no preferences, SAFEs or notes, so use it to see magnitudes and not to sign anything.

How to use it

  1. Enter holders as name, shares. Name the option pool row with the word pool.
  2. Enter investment, pre-money and a pool target.
  3. Read the table and the price per share.

Frequently asked questions

What does the pool target mean?

The share of the post-round company that the pool should hold.

Is the top-up before or after the round?

Before. It is part of pre-money, so only existing holders are diluted.

Is this legal advice?

No. Check any real cap table with a lawyer.
