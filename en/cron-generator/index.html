Cron Expression Generator

Pick how often a job should run, set the time with dropdowns and get the matching cron expression, a plain-English meaning and the next three run times.

Use the tool

Why this tool exists

Almost nobody remembers the field order of a cron expression, and the mistakes are costly: swapping the hour and minute, or forgetting that Sunday is 0. Looking up examples on every deployment is a waste of time.

This generator lets you choose a frequency such as every 15 minutes, daily at 09:00, on the 1st of each month or yearly in March, with an optional weekday filter. It produces the five-field expression, explains it in English and shows when it will next run in UTC so you can confirm it before pasting it into a crontab, CI pipeline or cloud scheduler.

How to use it

  1. Choose how often to run: every minute, every N minutes, every N hours, daily, monthly or yearly.
  2. Set N, the minute, the hour, the weekdays, the day of month and the month as needed.
  3. Read the generated expression and its plain-English meaning.
  4. Check the next three run times, then copy the expression.

Frequently asked questions

Which options matter for each frequency?

"Every N minutes" uses N and the weekday filter. "Every N hours" uses N, the minute and weekdays. Daily uses minute, hour and weekdays. Monthly uses minute, hour and day of month. Yearly adds the month. Unused fields are ignored.

Can it build complex schedules?

It covers the common cases only. For lists, ranges or combinations, such as 9-17 on weekdays, write the expression yourself and test it with the Cron Expression Explainer.

Does it match every scheduler?

It produces standard five-field cron, which works in crontab, most CI systems and many cloud schedulers. Some tools, such as Quartz or AWS EventBridge, use a different syntax with extra fields.

Which time zone are the run times in?

The preview shows UTC. Your scheduler may run in another zone, so check its documentation. The Cron Timezone Converter helps translate a schedule between zones.
