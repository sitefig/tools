File Hash

Choose a file and get its MD5, SHA-1, SHA-256, SHA-384 and SHA-512 checksums, together with its name and size in bytes. The file is read locally.

Use the tool

Why this tool exists

Download pages for installers, disk images and firmware publish a checksum so you can confirm that the file you received is the file they built. Comparing it takes a command-line tool most people do not remember, and online checkers ask you to upload the file.

This tool reads the file in your browser and computes five hashes at once, so you can match whichever one the publisher lists. Compare the result with the published value, using the Hash Compare tool if you want a careful check. Nothing is uploaded. A matching hash proves the file is unchanged, not that its source is trustworthy.

How to use it

  1. Click the file chooser and select the file you want to check.
  2. Run the tool to compute the hashes.
  3. Read the file name, its size and the five hashes.
  4. Compare the one that matches the publisher's checksum, or paste both into Hash Compare.

Frequently asked questions

How do I verify a download?

Compute the hash here, then compare it with the checksum shown on the official download page. If every character matches, the file is identical. If not, download it again before using it.

Does it upload my file?

No. The file is read by your browser and hashed in the page. This makes it suitable for private documents and large installers alike.

Is there a file size limit?

The whole file is loaded into memory before hashing, so the practical limit is your device's memory. Files of a few hundred megabytes usually work, while multi-gigabyte images may fail.

Is a matching hash a guarantee of safety?

It guarantees the file matches the checksum you compared with. If an attacker controls both the download and the checksum on the same page, that proves little. Prefer checksums or signatures from a separate, trusted source.
