CSV Delimiter Converter (Comma, Semicolon, Tab, Pipe)

Changes the delimiter of a CSV file and re-quotes fields so values that contain the new delimiter, quotes or line breaks stay intact.

Use the tool

Why this tool exists

Spreadsheet programs in many countries export semicolon-separated files because the comma is the decimal mark. Tools elsewhere expect commas or tabs. A find and replace breaks as soon as a quoted field contains the old delimiter.

This page reads the data as real CSV first, then writes it again with the delimiter you pick. It can guess the input delimiter from the first line. Rows with a different number of columns are kept as they are, not padded.

How to use it

  1. Paste the CSV or load it into the box.
  2. Leave the input delimiter on auto, or pick it if the guess is wrong.
  3. Choose the output delimiter, quoting and line ending.
  4. Copy the result.

Frequently asked questions

How does auto detection work?

It counts each candidate delimiter in the first non-empty line, ignoring quoted text, and picks the most frequent one. Pick it by hand for files with one column or unusual headers.

Are quotes kept?

Fields are quoted only when needed (they contain the delimiter, a quote or a line break), unless you tick Quote every field.

Is my data uploaded?

No. Parsing runs in your browser.

What about an unclosed quote?

You get an error instead of a silent wrong result.
