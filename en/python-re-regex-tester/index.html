Python re Regex Tester (Python 3.12 Syntax, finditer and sub)

Applies a Python re pattern to your text and shows every match span, group and named group the way re.finditer would, with an optional re.sub replacement template.

Use the tool

Why this tool exists

Python's re module differs from JavaScript and from PCRE in details that matter: named groups are written (?P<name>...), lookbehind must have a fixed width, \Z means the very end, \w and \d are Unicode aware unless the ASCII flag is set, and empty matches next to a previous match are reported. Testing in the wrong flavour gives surprises later.

This tool uses its own matcher written to follow Python 3.12 re. It was compared with the real re module on tens of thousands of generated cases and agreed on every one that both accepted, including error cases. Limits: no Unicode case folding beyond simple lower and upper case, \N{name} escapes are not supported, \w uses letters and digits from the browser's Unicode data, and group state inside very deep repetition may hit a recursion limit on subjects of several thousand characters.

How to use it

  1. Enter the pattern as you would pass it to re.compile, without quotes.
  2. Paste the subject text and tick the flags (i, m, s, x, a).
  3. Check the list of matches and the groups with their spans.
  4. Add a replacement template such as \g<year>/\2 to preview re.sub.

Frequently asked questions

Does it match what re.findall returns?

The match list is what re.finditer yields, including empty matches. Spans are code point offsets like Python string indexes.

Why does a lookbehind give an error?

Python requires a fixed width inside (?<=...) and (?<!...). Alternatives of different length are rejected, as in Python itself.

Which Python version is mirrored?

Behaviour was compared with Python 3.12, which supports atomic groups (?>...) and possessive quantifiers. Older versions reject those.

What is not supported?

\N{name} escapes, the locale flag, (?L), and flags set in the middle of the pattern, which Python 3.11 and later also reject.
