Flowchart Maker from Text Arrows (SVG)

Generates a flowchart from lines such as "Start -> Check input -> End". Brackets pick shapes and -label-> names an arrow.

Use the tool

Why this tool exists

Writing a flow as text is faster than dragging boxes, and the text is easy to review and keep in version control. The tool lays out the steps in layers, top to bottom or left to right, and draws arrows with labels.

A step ending in a question mark becomes a decision diamond; (Start) is a terminal and [text] a box. A step with the same text is the same node, so loops are written by repeating the name. The automatic layout is plain: very large or heavily crossing graphs need hand layout.

How to use it

  1. Write chains, one per line: A -> B -> C.
  2. Label an arrow with -yes-> between steps.
  3. Choose top to bottom or left to right.
  4. Copy or download the SVG.

Frequently asked questions

How do I make a decision?

End the step with ? or wrap it in braces, then use -yes-> and -no-> arrows.

Can I draw a loop?

Yes, point an arrow back at an earlier step.

Is it the same as Mermaid?

No. It has its own small syntax; the Mermaid tools on this site handle Mermaid text.

How many steps?

Up to 80.

Not supported: HTML labels, record ports, ports/compass points, splines/ratio/size/nodesep and other layout attributes (ignored).
