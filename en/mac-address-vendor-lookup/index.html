MAC Address Vendor Lookup (IEEE OUI)

Paste one or more MAC addresses or OUI prefixes in any format and see the registered vendor, the registry block that matched, and whether the address is locally administered.

Use the tool

Why this tool exists

A MAC address starts with a prefix the IEEE assigns to a manufacturer. Knowing the vendor helps when you sort out an unknown device on your network, read a DHCP or ARP table, or check a log.

Most lookup sites send your addresses to a server. This one carries a copy of the public IEEE listings (54,000 blocks, company names only) and does the match in your browser. Modern phones and laptops often use random MAC addresses. Those have the locally administered bit set and no real vendor, so the tool flags them instead of guessing. The bundle is a snapshot from 2026-10-23, so devices from newer assignments will not match.

How to use it

  1. Paste one address or prefix per line. Colons, dashes, dots and plain hex all work.
  2. Read the vendor, the block (MA-L, MA-M or MA-S) and the address bits for each line.
  3. If the vendor is the IEEE Registration Authority, paste the full address: the block is split into smaller ones.
  4. Copy the result.

Frequently asked questions

Why does my device show no vendor?

If the second hex digit is 2, 6, A or E, the address is locally administered. Phones, VMs and containers use those, and the prefix does not name a company.

What are MA-L, MA-M and MA-S?

They are IEEE block sizes: MA-L covers 24 bits (the classic OUI), MA-M 28 bits and MA-S 36 bits. Smaller blocks let one prefix be shared by several companies.

Is the data complete and current?

It is a snapshot of the public IEEE listings taken on 2026-10-23. Private registrations show as private and newer ones are missing until the file is refreshed.

Are my addresses sent anywhere?

No. The page downloads one static data file once and the match runs locally.
