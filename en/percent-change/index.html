Percent Change Calculator

Enter an old value and a new value. The tool returns the absolute difference and the percentage increase or decrease, with the formula used.

Use the tool

Why this tool exists

Reports, price lists and dashboards love to say 'up 12%' without showing the sum behind it. When you have the before and after figures, you often need the exact percentage yourself: how much did monthly traffic grow, how far has a supplier raised its prices, how much has a bill dropped since last year. Getting the base wrong is the classic mistake, since dividing by the new value instead of the old one gives a different answer. This page fixes the base as the old value and tells you whether the result is an increase or a decrease. It works offline once loaded, so internal figures stay on your device.

How to use it

  1. Enter the old (starting) value.
  2. Enter the new (ending) value.
  3. Read the change, the percent change and the increase or decrease label, then copy them if needed.

Frequently asked questions

Which number is the base for the percentage?

The old value. The formula is (new minus old) divided by the absolute old value, times 100. Using the new value as the base would give a different, usually smaller, percentage.

Why is a drop of 50% followed by a rise of 50% not back to the start?

Because each percentage applies to a different base. A fall from 100 to 50 is minus 50%, but 50 rising by 50% gives only 75. To recover the original you need a 100% rise.

Can I use negative numbers?

Yes. The tool divides by the absolute value of the old value, so the direction of the label still makes sense. A starting value of zero is rejected because the change would be undefined.

Does it round the result?

The percentage is shown with up to four decimal places and the absolute change with up to six. Round it yourself when you quote it in a report.
