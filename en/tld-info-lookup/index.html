TLD Info Lookup (IANA Root Zone: Type, Manager, Punycode)

Enter TLDs, domains, URLs or email addresses and get the TLD type, the organisation that manages it and the punycode and Unicode spellings, from a bundled copy of the IANA root zone data.

Use the tool

Why this tool exists

Domain tools often need to know whether a suffix is a country code, a generic TLD or something special, who runs it, and how an internationalised TLD looks in punycode. The answers live in the IANA root zone database.

This page bundles that list (1,437 TLDs, version 2026102300) so you can check many names at once without sending them anywhere. It takes the last label of what you paste, so a URL or email works too. It does not know second-level suffixes such as co.uk: those come from the Public Suffix List, which is a separate dataset.

How to use it

  1. Paste one TLD, domain, URL or email per line.
  2. Read the type, manager and punycode form for each.
  3. A TLD that is missing may be new, retired or mistyped.
  4. Copy the result.

Frequently asked questions

Where does the data come from?

The IANA Root Zone Database page and tlds-alpha-by-domain.txt, retrieved on 2026-10-23. The file version is shown under the results.

Does it support internationalised TLDs?

Yes. Paste the Unicode form or the xn-- form and you get both spellings.

Why is co.uk not found as a TLD?

Only uk is in the root zone. co.uk is a registry-level suffix listed in the Public Suffix List.

Can it tell me if a domain is registered?

No. That needs a live DNS or WHOIS query. This tool only describes the TLD.
