Accessible Name and Role Calculator for HTML Elements

Computes roles and accessible names for elements in pasted HTML and shows the source of each name.

Use the tool

Why this tool exists

The accessible name is what a screen reader says. It comes from many sources in a fixed order.

The tool follows the accessible name algorithm in simplified form: aria-labelledby, aria-label, native sources such as label, alt, value, legend and caption, then content, then title or placeholder. It shows the role too, from the role attribute or the element default. Check hard cases in the browser accessibility tree.

How to use it

  1. Paste the HTML.
  2. Optionally enter a CSS selector for one element.
  3. Read role, name and source.
  4. Fix elements with no name.

Frequently asked questions

What does "weak" mean?

Names from title or placeholder are used only as a last resort and are unreliable.

Does it handle hidden elements?

Yes for hidden, aria-hidden and display none inline.

Is it exact?

It is a simplified version. Browsers differ in edge cases.

Is the HTML uploaded?

No.
