LEI Code Validator and Parser (ISO 17442 Check Digits)

Validates 20-character Legal Entity Identifiers and splits them into their parts.

Use the tool

Why this tool exists

An LEI has 20 characters: a four character issuer prefix, two reserved characters, a twelve character entity part and two check digits. The check digits use the ISO 7064 MOD 97-10 method, the same as IBANs, so typing errors are caught.

A valid check does not mean the code is registered or active. The public GLEIF register has the entity data, and this tool makes no network calls and does not look anything up.

How to use it

  1. Paste LEI codes, one per line.
  2. Read the format and check digit result.
  3. Look up valid codes in the GLEIF register yourself.

Frequently asked questions

Does it say who the company is?

No. It makes no lookup. Use the GLEIF register.

What is the check?

Letters become numbers and the whole number must leave remainder 1 when divided by 97.

Is a valid LEI active?

Not necessarily. Status is in the register.
