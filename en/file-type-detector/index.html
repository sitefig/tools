File Type Detector (Magic Bytes)

Drop in any file and see its true type, MIME type and the first bytes in hex.

Use the tool

Why this tool exists

The tool reads the first 32 KB of each file and compares them with a table of about 70 well-known signatures (PNG, JPEG, PDF, ZIP, gzip, 7z, RAR, ELF, Mach-O, PE, WebAssembly, MP3, MP4, WebM, SQLite, fonts and more), falling back to text or JSON detection. It tells you when the extension does not match the content.

Container formats share headers: a .docx, .jar and .apk are all ZIP files, so a ZIP result can be correct for those. A file renamed to hide its type is revealed, but a signature is not proof the file is safe.

The file is read in your browser and is not uploaded anywhere.

How to use it

  1. Choose one or more files.
  2. Read the detected type and hex header.
  3. Check the mismatch note.
  4. Treat unexpected executables with caution.

Frequently asked questions

Is my file uploaded?

No. Only the first 32 KB are read in your browser.

Why is my .docx shown as ZIP?

Office documents are ZIP archives; the extension distinguishes them.

Can it detect malware?

No. It identifies formats only.

Is my data sent anywhere?

The file is read in your browser and is not uploaded anywhere.
