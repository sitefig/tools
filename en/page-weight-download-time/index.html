Page Weight Download Time on 3G, 4G and Broadband

Estimates download time for a page weight across common connection profiles, adding connection setup and extra sequential round trips.

Use the tool

Why this tool exists

A 2 MB page feels fine on office Wi-Fi and painful on a phone. Seeing the same weight on several connections makes the cost concrete.

The model is size divided by speed plus about three round trips for DNS, TCP and TLS, plus any extra trips you enter. The profiles use the nominal values in Chrome DevTools throttling and Lighthouse. It ignores slow start, parallel connections and caching, so use it for order of magnitude, then measure with real throttling.

How to use it

  1. Enter the total transfer size and choose KB or MB.
  2. Set the number of extra sequential round trips, such as redirects or blocking chains.
  3. Optionally add your own speed and round-trip time.
  4. Compare the totals per connection.

Frequently asked questions

Where do the speeds come from?

From the DevTools network presets and Lighthouse desktop settings as found in their source code in October 2026.

Is this the load time of my page?

No. It is the transfer time only. Rendering, scripts and server time come on top.

Which size should I enter?

The transferred (compressed) size from the Network panel or a HAR file, not the uncompressed size.

Why add round trips?

Each blocking step, such as a redirect or a chain of CSS imports, costs at least one round trip.
