pre-commit Config Generator

Generate a .pre-commit-config.yaml from named presets such as basic, prettier, eslint, ruff, black, shellcheck, gitleaks, hadolint, terraform, yamllint, commitlint and codespell.

Use the tool

Why this tool exists

The pre-commit framework runs checks before each commit, catching trailing whitespace, broken YAML, leaked secrets and style problems before they reach review. Setting it up means finding each hook repository, its current revision and the right hook ids.

List the presets you want, one per line, and the tool writes the repos section with the repository URL, a revision and the hook ids for each. Optional fail_fast stops at the first failure and default_install_hook_types lets you install hooks for stages other than pre-commit. The revisions in the file are examples that were current when the tool was written, so run pre-commit autoupdate after saving to move to the latest. Nothing is uploaded.

How to use it

  1. List the presets you want, one per line, for example basic, ruff and gitleaks.
  2. Set the install hook types and tick fail_fast if you want to stop at the first failing hook.
  3. Copy the YAML into .pre-commit-config.yaml.
  4. Run pre-commit autoupdate, then pre-commit install.

Frequently asked questions

Are the revisions up to date?

Not necessarily. They are example revisions. Run pre-commit autoupdate after saving the file to bump every hook to its latest tag.

What does the basic preset include?

Six hooks from the pre-commit-hooks repository: trailing-whitespace, end-of-file-fixer, check-yaml, check-json, check-merge-conflict and check-added-large-files. They are a common baseline for most projects.

What happens with a preset name the tool does not know?

It reports an error and lists the known presets. For other hooks, add them to the generated file by hand from the hook repository's documentation.

How do I enable the hooks?

Install pre-commit, then run pre-commit install in your repository. Hooks then run on every commit, and pre-commit run --all-files checks existing files.
