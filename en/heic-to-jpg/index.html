HEIC to JPG / PNG / WebP

Convert HEIC or HEIF photos to JPG, PNG or WebP. It uses your browser's built-in image decoder, so it only works where the browser can already open HEIC files.

Use the tool

Why this tool exists

iPhones save photos as HEIC, and plenty of websites, forms and older apps still refuse anything but JPG. The usual fix is an online converter that takes your photos onto someone else's server, which is a poor deal for family pictures or scanned documents.

This converter hands the file to the decoder your browser already has and redraws it into the format you choose. Safari on macOS and iOS can do this, as can some Chrome and Edge builds with system HEVC codecs. If your browser cannot decode HEIC, the tool says so rather than failing silently. Nothing is uploaded.

How to use it

  1. Choose one or more HEIC or HEIF files with the file picker.
  2. Pick the output format: jpeg, png or webp.
  3. Set the quality between 0.1 and 1. The default is 0.92.
  4. Run the conversion and download the converted files.

Frequently asked questions

Why does it say my browser cannot decode HEIC?

The tool relies on the decoder already inside your browser and does not bundle its own. Safari supports HEIC, and some Chrome or Edge builds do when the system has HEVC codecs. Firefox and many Linux setups do not.

Does it upload my photos?

No. The file is decoded, drawn onto a canvas and re-encoded entirely in your browser, and the result is offered as a download. Nothing is sent to a server.

Will I lose quality?

JPG and WebP are lossy, so a little detail is lost at any setting below 1. The default 0.92 is visually close to the original. PNG is lossless but produces much larger files for photos.

What happens to transparency and metadata?

JPG has no transparency, so any transparent area is filled with white. The image is redrawn on a canvas, so metadata such as location and camera model is not carried over to the new file.
