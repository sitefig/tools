Number Extractor with Sum, Average, Min and Max

Find every number in a block of text, list them, and get the total, average, smallest and largest. Handles thousands separators and decimal commas.

Use the tool

Why this tool exists

Numbers buried in notes, receipts or chat logs are tedious to add up. Copying each one into a calculator invites mistakes.

Paste the text and the tool lists every number it finds and sums them exactly, using integer arithmetic so decimals do not drift. Pick the number style: comma thousands with a decimal point, or decimal comma. Negative numbers are supported. Dates and codes are read as numbers too, so scan the list before trusting the sum.

How to use it

  1. Paste the text.
  2. Choose the number style.
  3. Read the list and the totals.
  4. Remove lines you do not want and run again.

Frequently asked questions

Is the sum exact?

Yes for decimals. The numbers are added as scaled integers, and the average is shown to four places.

Why are dates split into numbers?

The tool finds digits, not meaning. 2026-03-01 gives 2026, -3 and -1. Remove such parts first.

Can it handle currency symbols?

Symbols are ignored, but mixed currencies are added as plain numbers.
