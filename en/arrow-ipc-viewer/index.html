Apache Arrow / Feather File Viewer (IPC Decoder)

Look inside an Arrow or Feather file without Python: see the schema, the metadata and the first rows.

Use the tool

Why this tool exists

The decoder reads the Arrow IPC stream and file formats, including Feather v2, with a hand-written FlatBuffers reader. It decodes the schema, record batches and dictionary batches, applies validity bitmaps for nulls, and understands booleans, signed and unsigned integers of all widths, half, single and double floats, UTF-8 and large UTF-8 strings, binary and fixed-size binary, dates, times, timestamps with time zones, durations, decimal128, lists, large lists, fixed-size lists, structs, maps and dictionary-encoded columns. Buffers compressed with LZ4 (what pandas and pyarrow write by default for Feather) are decompressed with a hand-written LZ4 frame decoder.

Results were compared with pyarrow on files it wrote, both stream and file formats, uncompressed and LZ4, plus a 300,000-row Feather file: every value matched.

Limits: ZSTD-compressed buffers (a ZSTD decoder is a separate large piece of code), union, run-end and view types, decimal256, intervals, big-endian files and extension types beyond their storage type. The whole file is read into memory, so very large files will be slow. 64-bit integers beyond 2^53 are shown as strings so no digits are lost.

How to use it

  1. Choose an .arrow, .arrows or .feather file.
  2. Read the schema and metadata at the top.
  3. Pick JSON or CSV and the number of rows to show.
  4. Copy the rows or download them.

Frequently asked questions

Does it open Parquet files?

No, Parquet is a different format. Use the Parquet viewer.

Why does my file say it uses ZSTD?

The writer chose ZSTD compression for the buffers. Re-save it with compression off or LZ4 (for example compression='lz4' in pyarrow).

Why are some large integers strings?

JSON numbers lose precision above 2^53, so larger values are written as text to keep every digit.

Can it edit or convert files?

It only reads them, and exports the shown rows as JSON or CSV.

Is my data uploaded?

No. The file is decoded in your browser.
