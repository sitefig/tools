IPv6 Prefix Expander, Compressor and Subnet Splitter

Expands and compresses IPv6 prefixes (RFC 5952 style), shows the first and last address and the address count, and lists the subnets you get when you split a prefix into a longer one.

Use the tool

Why this tool exists

IPv6 plans are usually made by cutting a large prefix into equal pieces: a /48 per site, a /64 per VLAN. Doing that by hand means hex arithmetic on 128-bit numbers, and one slipped digit gives you overlapping ranges.

Paste a prefix, choose the new length and read the list. The tool uses exact integer maths, clears host bits and tells you when it did so. It does not know which prefixes are allocated to you. It only does the arithmetic.

How to use it

  1. Paste one IPv6 address or prefix per line.
  2. Set the split length, for example 64 for a /48 prefix, or 0 to only expand and compress.
  3. Read the expanded and compressed forms and the list of subnets.
  4. Raise the list limit if you need more than the first subnets.

Frequently asked questions

Why is the list cut off?

A /32 split into /64 gives four billion subnets. The tool lists only the first ones (you choose how many) and tells you how many remain.

What happens to bits after the prefix length?

They are cleared to zero, and the result says so. 2001:db8::1/64 becomes 2001:db8::/64.

Which compressed form is used?

The longest run of zero groups, at least two groups long, becomes ::, with lowercase hex and no leading zeros, as in RFC 5952.

Does it check if the prefix is in use?

No. It is pure arithmetic and makes no lookups.
