Language Detector

Looks at the writing script and counts common words to suggest which language your text is in, with a rough percentage. It covers about twenty languages and is a hint, not a verdict.

Use the tool

Why this tool exists

Sometimes you receive text and have no idea what language it is: a support message, a scraped review, a line in a spreadsheet of user input. Before you translate it, route it or set a lang attribute, a quick guess saves time.

This tool uses two simple signals. First the Unicode script, which separates Cyrillic, Greek, Hebrew, Thai, Korean, Japanese and others at once. Then, for Latin-script text, a list of very common words in languages such as English, Spanish, French, German, Italian, Portuguese and Dutch. It is a heuristic, so short snippets are unreliable. Detection runs in your browser and the text is not uploaded.

How to use it

  1. Paste the text whose language you want to identify.
  2. Read the ranked guesses with their percentages.
  3. Check the note under the result for warnings about short or unknown text.
  4. Use a longer sample if the answer looks uncertain.

Frequently asked questions

How accurate is it?

Good for several sentences of ordinary prose, poor for a few words. It counts common words and Unicode scripts, not full language models. Treat the top answer as a hint and confirm important cases another way.

Which languages does it recognise?

Script-based detection covers Japanese, Chinese, Korean, Cyrillic, Arabic script, Hebrew, Greek, Devanagari and Thai. Common-word detection covers English, Spanish, French, German, Italian, Portuguese, Dutch, Swedish, Polish, Turkish and Indonesian.

Why does it say Russian or other Cyrillic?

Many languages share the Cyrillic alphabet. The tool looks for a few telltale letters to pick Ukrainian, Belarusian or Bulgarian, and otherwise falls back to a general answer. It cannot reliably separate every Cyrillic language.

What if my language is not listed?

A Latin-script text in an unsupported language may match no common words, and the tool then says so. It will not invent an answer, but it may also misattribute closely related languages.
