Social Media Image Size Reference (Instagram, Facebook, LinkedIn, X, YouTube)

Look up recommended image sizes and aspect ratios per platform and format, or type your image size (like 1200x630) to see which formats it suits.

Use the tool

Why this tool exists

Each network crops images to its own shapes. A 16:9 picture on a 4:5 feed loses its sides.

Filter by platform or type your image size, such as 1200x630, to see which formats share its aspect ratio. Only the YouTube values were checked at the source on the date shown. The others are widely quoted values that were not verified, and platforms change them often, so confirm in the platform before you design.

How to use it

  1. Type a platform name, or your image size like 1200x630.
  2. Read the sizes and ratios.
  3. Check the source status of each row.
  4. Confirm in the platform before final export.

Frequently asked questions

Are these sizes official?

Only the YouTube rows were checked at the source. The rest are commonly quoted and marked as not checked.

Why do ratios matter more than pixels?

A platform scales images but crops by ratio.

How do I check an image file?

Use the Social Image Size Checker for Open Graph images.
