Course Schema Generator

Builds Course markup with provider and one CourseInstance per run, each with mode, schedule, workload and instructor.

Use the tool

Why this tool exists

Each run of a course is a CourseInstance with its own dates and delivery mode. Write one instance: line per run and the tool builds the schedule, and turns a workload such as 3h/week into a repeat frequency and an ISO 8601 duration.

Google retired the course info result in 2025; course list carousels still use name, description and provider. The tool says so and checks those three.

How to use it

  1. Enter the name, description and URL.
  2. Enter the provider as Name | URL.
  3. Add instance: lines with mode, dates, workload and instructor.
  4. Copy the script tag onto the course page.

Frequently asked questions

What modes are allowed?

online, onsite and blended.

How is workload read?

3h/week becomes a weekly schedule and PT3H; a plain duration like 20 hours also works.

Does Google still show course results?

Course info was retired. The list carousel remains; see the notes in the output.

Can a course have several instances?

Yes, repeat the instance: line.
