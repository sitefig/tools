Lorem Ipsum Generator

Produces Lorem Ipsum placeholder text in words, sentences or paragraphs. You can start with the classic opening line and set a seed so the same settings give the same text.

Use the tool

Why this tool exists

Designers and developers need filler text long before the real copy exists. A card layout, a blog template or a form with a long description field all need something that looks like language without distracting the reviewer.

Pick words, sentences or paragraphs and a count, and the generator assembles pseudo-Latin text from a fixed vocabulary. The classic "Lorem ipsum dolor sit amet" opening can be switched on or off. A seed, which can be any word, makes the output repeatable, so screenshots, snapshot tests and design hand-offs stay stable between runs. The text is built locally in your browser and nothing is requested from a server.

How to use it

  1. Choose a unit: paragraphs, sentences or words.
  2. Enter a count between 1 and 2000.
  3. Tick Start with Lorem ipsum if you want the classic opening, and add a seed for repeatable text.
  4. Copy the generated text into your layout.

Frequently asked questions

Is this the original Cicero text?

No. It draws random words from a Latin-style vocabulary, so the sentences are nonsense that merely look like Latin. That is the point: readers focus on layout rather than meaning.

What is the seed for?

With a seed, the same settings always return the same text, which is useful for tests and design files. Leave it empty for a fresh random result each time.

What counts can I use?

From 1 to 2000 of the chosen unit. Paragraphs contain three to six sentences, and sentences are six to fourteen words long, with an occasional comma. Words mode returns exactly the number you ask for.

Does it need a network connection?

No. The vocabulary is built into the page and the text is generated in your browser, so it works offline once the page has loaded.
