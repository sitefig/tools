Redirect Type Advisor: 301, 302, 307, 308 or Meta Refresh

Choose what is happening to the URL and get the redirect status code to use, the reason, and the usual mistakes. Covers 301, 302, 303, 307, 308 and meta refresh.

Use the tool

Why this tool exists

Choosing between 301, 302, 307 and 308 is a small decision with large effects. The wrong code can leave an old URL in the index or lose the request method on a form post.

The advice follows Google Search Central: 301 and 308 are strong signals that the target is the canonical URL, 302 and 307 are weak signals, and Google follows up to 10 hops. Other search engines may behave differently. It is guidance for common cases, not a guarantee.

How to use it

  1. Pick the closest situation from the list.
  2. Read the recommended code and the reason.
  3. Check the "watch for" line before you write the rule.
  4. Build the rules with the bulk redirect generator.

Frequently asked questions

What is the difference between 301 and 308?

Both are permanent. 308 forces the client to repeat the same method and body, 301 lets old clients change POST to GET. For normal page moves they are equivalent for Google.

When should I use 410 instead of a redirect?

When a page is gone and no close replacement exists. Redirecting it to the home page can be treated as a soft 404.

Is a meta refresh as good as a 301?

No. Google can follow it, but a server-side redirect is clearer and faster. Use meta refresh only when you cannot change server config.

How long should I keep a redirect?

Google advises at least a year for site moves.
