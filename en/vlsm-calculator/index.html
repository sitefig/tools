VLSM Subnet Calculator (Variable-Length Subnet Masks)

Plan an IPv4 address layout that wastes as few addresses as possible.

Use the tool

Why this tool exists

Enter the parent network in CIDR and the subnets you need as "name hosts". The calculator sorts requests from largest to smallest, assigns each the smallest block that fits (hosts plus network and broadcast addresses), keeps blocks aligned, and prints network, mask, host range, broadcast and usable count. Results were compared with Python's ipaddress module.

Leave room for growth by requesting more hosts than today, and note that /31 point-to-point links (RFC 3021) are not used here.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Enter the parent network.
  2. List required subnets, one per line.
  3. Read the allocation table.
  4. Check how much space is left.

Frequently asked questions

Why largest first?

It keeps blocks aligned to their size boundaries and avoids fragmentation.

What if the plan does not fit?

The tool reports which subnet could not be placed.

Does it support IPv6?

No, IPv4 only. IPv6 subnets are usually /64s.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
