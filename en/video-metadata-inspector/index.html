Video Metadata Inspector: Codec, Frame Rate, Bitrate and Duration

Reads the container of an MP4, MOV, M4V or WebM file and lists tracks, codecs, size, frame rate, average bitrate and duration.

Use the tool

Why this tool exists

Knowing the codec and frame rate is the first step in fixing a file that will not play or upload. The tool parses the container itself: sample tables in MP4 and track entries in WebM. Average bitrate is computed from sample sizes (MP4) or file size (WebM).

Values were checked against ffprobe on test files. Files with unusual structure may show less detail. Nothing is uploaded.

How to use it

  1. Choose the video file.
  2. Press Run.
  3. Read the container, tracks and values.
  4. Copy the text if you need it.

Frequently asked questions

Which formats are read?

MP4, MOV, M4V and WebM. MKV is not parsed fully.

Is the frame rate exact?

For MP4 it is the sample count divided by the track duration. For WebM it is the declared value.

Why is the WebM duration missing?

Browser recordings often omit it. Our recorders add it, but other files may not have it.

How does it differ from the MP4 Box Inspector?

That tool shows the box layout and fast-start flag. This one adds frame rate, bitrate and WebM support.
