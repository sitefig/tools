PDF Page Count and Sizes

Load one or more PDFs and see how many pages each has, with every page's dimensions, rotation and paper format.

Use the tool

Why this tool exists

Print shops, mailing services and upload forms often ask for the page count and a specific paper size, and a single odd page can wreck a print job: a landscape insert, a Letter page in an A4 document or a page rotated by the scanner. Finding such a page by flipping through a viewer is easy to get wrong.

This checker reads the pages' dimensions straight from the file and lists them. For each PDF you get the page count and, per page, width and height in points and millimetres, the rotation and the closest standard format such as A4 or Letter. You can select several files at once and see a report for each. It reads file structure only and does not render pages. Encrypted files are not supported. Nothing is uploaded.

How to use it

  1. Choose one or more PDF files.
  2. Run the tool.
  3. Read the page count and the list of page sizes for each file.
  4. Look for pages whose size or rotation differs from the rest.

Frequently asked questions

What units are used?

Sizes are shown in PDF points, where 72 points make an inch, together with millimetres, so you can compare with paper sizes. A4 is about 595 by 842 points.

Does it show the size as displayed?

The report includes the rotation of each page, so you can tell whether a portrait page is shown sideways. Check the rotation column when a page seems the wrong way round.

How are paper formats named?

Page dimensions are compared with common sizes such as A4, A3 and Letter, within a small tolerance. Non-standard sizes are shown by their measurements only.

Can it read several files at once?

Yes. Select more than one file and each gets its own report. A file that cannot be read gets an error line with its name, and the others still run.
