YouTube Link, ID & Thumbnail URL Extractor

Turn any YouTube URL into its video ID and the standard watch, youtu.be, embed (privacy-enhanced) and thumbnail links.

Use the tool

Why this tool exists

Paste links in any common form: watch?v=, youtu.be, embed, shorts, live or a bare 11-character ID. For each one the tool prints the canonical URLs, an embed iframe using youtube-nocookie.com, a timestamped link if you set a start time and the five thumbnail image URLs (maxresdefault down to default).

The tool builds URLs from YouTube's public patterns and never loads them, so it cannot tell whether a thumbnail size exists; maxresdefault is only present for HD uploads.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Paste one or more YouTube links.
  2. Optionally set a start time in seconds.
  3. Copy the URL or iframe you need.
  4. Add loading="lazy" and a title to embeds for performance and accessibility.

Frequently asked questions

Why use youtube-nocookie.com?

It avoids setting tracking cookies until the visitor plays the video.

Which thumbnail size should I use?

maxresdefault (1280x720) when available, otherwise hqdefault.

Does it work with playlist links?

It extracts the video ID only; playlist parameters are ignored.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
