ISBN Validator and ISBN-10 / ISBN-13 Converter

Check the check digit of ISBN-10 and ISBN-13 numbers and convert between the two forms. Works offline; it does not look up the book.

Use the tool

Why this tool exists

A wrong digit in an ISBN sends an order to the wrong book. The last digit is a check digit, so most typing errors can be caught offline.

Paste ISBNs, one per line, with or without hyphens. The tool checks ISBN-10 (weights 10 to 1, modulus 11, X for ten) and ISBN-13 (weights 1 and 3, modulus 10) and converts between the two. ISBNs starting 979 have no ISBN-10. It does not add hyphens, which needs the agency's range tables, or look up the book.

How to use it

  1. Paste ISBNs, one per line.
  2. Read the type and result for each.
  3. Copy the converted forms.
  4. Look up valid numbers in a library or shop for the book itself.

Frequently asked questions

Does a valid ISBN mean the book exists?

No. It only means the check digit is right.

Why is there no ISBN-10 for some?

ISBN-10 maps only to 978 numbers. 979 numbers were created later.

Why no hyphens?

Hyphen positions depend on published range tables that change, so this tool leaves them out.
