ZIP Creator

Select several files and pack them into a single .zip archive. Compression is optional, and you can name the archive before downloading it.

Use the tool

Why this tool exists

Sending ten files as ten attachments is clumsy, and many forms accept only one upload. Zipping is the usual fix, but on a locked-down work laptop, a Chromebook or a phone you may have no archive tool, and online zippers want you to upload files you would rather keep private.

This creator builds the archive locally. Each file is read in your browser, compressed with deflate if you leave Compress ticked, and written into a standard ZIP structure that Windows, macOS, Linux and phone file managers open. If two files share a name, the later ones get a number in brackets so none is overwritten. The tool reports the total size before and after compression. It does not add passwords or encryption, and archives are limited to 4 GB.

How to use it

  1. Choose the files to include; you can select many at once.
  2. Keep Compress (deflate) ticked, or untick it to store files without compression.
  3. Enter an archive name ending in .zip.
  4. Run the tool and download the archive.

Frequently asked questions

Can I password-protect the zip?

No. This tool creates standard unencrypted archives only. If the contents are sensitive, encrypt the files separately before zipping, or use a dedicated tool that supports modern encryption.

What size limits apply?

The ZIP64 extension is not used, so the archive and each file must stay under 4 GB, and everything is held in your browser's memory. For very large sets, a desktop archiver is more reliable.

Why would I untick Compress?

Files such as JPEG, MP4 and existing zips are already compressed, so deflate gains little. Storing them uncompressed is slightly faster. For text and documents, compression usually helps.

What happens to duplicate file names?

A second file called report.pdf becomes report (2).pdf inside the archive, so nothing is lost. Folder paths are kept only if your browser provides them for the selected files.
