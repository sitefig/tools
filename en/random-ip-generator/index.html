Random IP Address Generator

Creates random IPv4 or IPv6 addresses from a range you choose, for test data, fixtures and documentation.

Use the tool

Why this tool exists

Test data often needs addresses that look real but are safe. Documentation ranges (192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24, and 2001:db8::/32) are set aside for examples and will not point at real hosts. Private ranges suit internal network tests.

You can also generate from any CIDR block you give, or from public space. Public random addresses may belong to real servers, so do not scan or connect to them. The excluded ranges come from the IANA special-purpose registry, checked when this page was written.

How to use it

  1. Choose IPv4 or IPv6.
  2. Pick a range: public, private, documentation, any or your own CIDR.
  3. Set the count and whether to avoid duplicates.
  4. Copy the list.

Frequently asked questions

Which range is safest for examples?

Documentation ranges. They are reserved for this purpose.

Is the randomness cryptographic?

Yes, it uses the browser crypto source with unbiased sampling.

Can I get more addresses than the range holds?

Not without duplicates. The tool refuses when no duplicates is on and the range is too small.

What does public mean here?

Outside the IANA special-purpose blocks and multicast. It does not mean the address is in use or routed.
