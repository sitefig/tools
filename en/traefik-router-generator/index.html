Traefik Dynamic Config Generator (Routers, Services, TLS)

Publish a service behind Traefik with HTTPS and common middlewares from a few inputs.

Use the tool

Why this tool exists

Enter the host, the backend URL, the certificate resolver name, an optional rate limit and whether to add a security headers middleware. The YAML defines an HTTPS router with a certificate resolver, an HTTP router that redirects to HTTPS, a load-balancer service and the middlewares. The Docker label output carries the same settings for use in docker-compose.

Entry points web and websecure and the certificate resolver must exist in your static configuration. The generated YAML parses correctly; run Traefik with the file provider enabled to validate it.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Enter host and backend.
  2. Choose file provider or Docker labels.
  3. Copy the output into your dynamic config or compose file.
  4. Check the Traefik dashboard for router errors.

Frequently asked questions

What is a certificate resolver?

A static-config entry that tells Traefik how to obtain certificates, for example via ACME/Let's Encrypt.

Where do labels go?

Under the service in docker-compose.yml.

Is the rate limit per client?

The default source criterion is the client IP, and burst is set to twice the average.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
