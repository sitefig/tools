Marketing Funnel Calculator (Visitors Needed for a Revenue Goal)

Enter a revenue goal, deal size and four stage rates to see the volume needed at each stage.

Use the tool

Why this tool exists

Goals are set in revenue but campaigns run on traffic. Working backward through the funnel shows the size of the gap between the two.

Each stage is rounded up. The rates are inputs, so use real rates from your own history. The output shows the volume implied, not whether it is reachable.

How to use it

  1. Enter revenue goal and average deal size.
  2. Enter the four stage conversion rates.
  3. Read the counts at each stage.
  4. Compare with current traffic.

Frequently asked questions

Why start from revenue?

It shows the traffic needed to hit the target.

Can I change the stage names?

Not here; the stages are fixed.

Does it include time?

No, only volume.

Is data stored?

No.
