Helm Values Diff: Compare Two values.yaml Files by Key Path

Flattens two YAML files to dotted key paths and lists what was added, removed or changed, with old and new values.

Use the tool

Why this tool exists

Values files grow over time and a plain text diff shows moved lines and comments as changes. Comparing by key path shows only what changes the rendered chart.

For each path the tool shows the old and new value. Lists are compared by index, so inserting an item near the top marks every later item as changed. Comments and key order are ignored. Anchors and merge keys are expanded.

How to use it

  1. Paste the old values in the first box and the new values in the second.
  2. Tick the option to list unchanged keys if you want the full picture.
  3. Pick table, CSV or JSON output.
  4. Copy the result into your review.

Frequently asked questions

Does key order matter?

No. Keys are compared by path, so reordering is not a change.

How are lists compared?

By position, as path[0], path[1] and so on. Inserting an item shifts the later ones.

Can I use it for non-Helm YAML?

Yes. Any YAML mapping works.

Is anything uploaded?

No.
