Apache and Nginx Access Log Parser (Common and Combined Format Table)

Parses Common and Combined Log Format into columns and lets you filter by text, regex, status or method, sort, and export.

Use the tool

Why this tool exists

Web server logs are one long line per request and are hard to scan. A table with IP, time, method, path, status and bytes makes patterns visible, such as one IP hitting one URL.

The parser handles the standard Common and Combined formats used by Apache and nginx. Custom formats need the log format converter first. Time is shown as written in the log.

How to use it

  1. Paste log lines or choose a file (gzip works).
  2. Set filters such as a status class like 5xx or a text match.
  3. Choose columns, sort order and table, CSV or JSON.
  4. Copy or download the result.

Frequently asked questions

What if some lines do not match?

They are skipped and the result says how many. Custom log formats need the Log Format to Regex tool.

Can I open a .gz file?

Yes. Gzip files are unpacked in the browser.

How big a file works?

A few hundred MB can work, depending on memory. For multi-GB files use the large log viewer.

Is my log uploaded?

No. Parsing happens in your browser and nothing is sent. Logs can hold IP addresses and tokens, so the page does not write them into the address bar.
