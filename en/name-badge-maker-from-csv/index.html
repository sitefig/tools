Name Badge Maker from a CSV of Attendees

Fills one badge layout with each row of a CSV and lays the badges out on printable pages.

Use the tool

Why this tool exists

Events need badges fast. Paste the attendee list with a header row such as name,title,company, then write the three lines of the badge with placeholders like {{name}}. Every row becomes a badge, with an optional event name on top and an accent color bar.

The CSV reader handles quoted fields with commas inside, such as "Turing, Alan". A placeholder that has no matching column gives a clear error instead of a blank badge. Names stay in your browser, which matters for attendee lists. Set the badge size to match your holders and print from the browser.

How to use it

  1. Paste the CSV with a header row.
  2. Set the three lines using {{column}} placeholders.
  3. Set badge size, color and paper.
  4. Print the pages.

Frequently asked questions

Is the attendee list uploaded?

No.

Can I add a logo?

Not in this version.

How many badges?

Up to 500.

What if a name has a comma?

Put it in quotes in the CSV.
