Design Tokens Converter (W3C JSON to CSS, SCSS, Tailwind, JS)

Turn a tokens file from a design tool into code for your stylesheets and components.

Use the tool

Why this tool exists

The converter flattens groups, inherits $type down the tree, resolves {alias.references} (reporting circular or missing ones) and formats each type for output: colours, dimensions and durations with units, font families, cubic-bezier easings and shadows. CSS output keeps aliases as var(--other-token); SCSS keeps them as variables; the Tailwind output maps tokens to --color-, --spacing-, --font- and other theme namespaces.

The Design Tokens format is still a community specification and tools differ, so check that your file follows the $value/$type convention. Composite types such as typography are written as JSON text.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Paste your tokens JSON.
  2. Choose CSS, SCSS, Tailwind or JavaScript.
  3. Optionally add a prefix.
  4. Copy the output into your project.

Frequently asked questions

What is the W3C format?

A JSON structure where each token has $value and optional $type and $description, and groups nest tokens.

How are aliases handled?

A value like {color.brand} becomes a reference to that token.

Does it support dark mode themes?

Convert each theme file separately and scope the CSS yourself.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
