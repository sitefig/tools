Endianness Swapper (Big and Little Endian Byte Order)

Swaps the byte order of a hex value or a stream of fixed-size words and shows both decimal readings.

Use the tool

Why this tool exists

Network protocols use big-endian order and most CPUs store numbers little-endian, so the same bytes read as two different numbers. Debugging a memory dump or packet often needs a quick swap.

Paste hex with or without 0x, spaces or colons. Pick the whole value or a word size, and the page reverses the bytes in each word and shows the decimal value of each reading. An odd number of digits is rejected, because the byte boundary would be a guess.

How to use it

  1. Paste the hex bytes.
  2. Choose whole value or a word size.
  3. Read the swapped bytes and both numeric readings.
  4. Copy what you need.

Frequently asked questions

Why does it reject an odd digit count?

A byte is two hex digits. Add a leading 0 where you mean one.

What is a word size?

The group of bytes that is reversed as one unit, for example 4 for 32-bit values.

Are signed values shown?

No, readings are unsigned. Use the number base converter for two's complement.

Is the data uploaded?

No.
