Multilingual Title Width Checker (CJK, Thai, Arabic, Cyrillic)

Estimates how wide each title is in pixels using per-script glyph widths and shows the likely truncation point.

Use the tool

Why this tool exists

Search results truncate titles by pixel width, not characters. A Japanese title fills the same space with half as many characters as an English one, while Thai and Arabic fall in between. The tool assigns each character a width for its script, sums them at your font size and shows where a limit would cut the title.

The numbers are estimates: Google does not publish its font metrics or an exact limit, and 600px at 20px is only a common rule of thumb. Use it to compare titles and to avoid obviously long ones.

How to use it

  1. Paste titles, one per line.
  2. Set the width limit and font size if you use different assumptions.
  3. Read the estimate and cut-off preview.
  4. Shorten titles marked REVIEW.

Frequently asked questions

How accurate is it?

It is a rough guide, not a measurement.

Why 600px?

It is a widely quoted community figure; Google does not state a limit.

Are combining marks counted?

They have zero width in the estimate.

Does it replace the Title Length Checker?

It complements it for non-Latin scripts.
