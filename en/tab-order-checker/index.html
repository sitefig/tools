Tab Order Checker: Keyboard Focus Sequence and tabindex Problems

Lists the keyboard focus order of pasted HTML and flags tabindex problems.

Use the tool

Why this tool exists

Keyboard users depend on a logical focus order and reachable controls.

The tool builds the tab sequence from the source order and tabindex values, shows elements removed from it, and flags positive tabindex, clickable elements that cannot be focused, and aria-hidden elements that can. It cannot see CSS that reorders content visually, so test the real page too.

How to use it

  1. Paste the HTML.
  2. Read the tab order table.
  3. Fix the flagged elements.
  4. Tab through the real page to confirm.

Frequently asked questions

What is wrong with positive tabindex?

It jumps ahead of the natural order and is hard to maintain. Fix the DOM order instead.

What about tabindex -1?

It removes an element from Tab but allows script focus; it is listed separately.

Does it know CSS order?

No. Visual order must be checked in the browser.

Is the HTML uploaded?

No.
