ISO 8601 Date, Time and Interval Parser

Breaks ISO 8601 strings into year, month, day, weekday, ISO week, time, offset and Unix time, and explains why an invalid one fails.

Use the tool

Why this tool exists

ISO 8601 allows many forms: 2026-03-01, 20260301, 2026-060, 2026-W09-7, PT1H30M, 2026-03-01/P1W. Reading them by eye is error prone, and an impossible date such as 2026-02-30 is easy to miss.

Enter one value per line. The page identifies the form, checks ranges including leap years and ISO week counts, and shows the weekday and ISO week. A value without an offset has no fixed instant, so the UTC line says it is an assumption. It was compared with Python date functions, not with the paywalled standard text.

How to use it

  1. Paste one ISO 8601 value per line.
  2. Read the parts and any Review message.
  3. For intervals, check the computed end.
  4. Copy the result.

Frequently asked questions

Which forms are supported?

Calendar, ordinal and week dates, times with offsets, durations, intervals and repeating intervals.

What does "If read as UTC" mean?

The value has no offset, so any instant is an assumption. The page shows UTC as one possible reading.

How long is a month in a duration?

It varies. Totals with years or months are approximate and say so.

Is anything sent out?

No.
