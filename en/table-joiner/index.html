Table Joiner (VLOOKUP-Style Join of Two CSVs on a Key)

Matches rows of two tables on a key and returns one table with the columns of both, like VLOOKUP but for every column.

Use the tool

Why this tool exists

Spreadsheets split information across files: customers in one, orders in another. A join puts it back together. Choose the key in each table, ignore case and spaces if needed, and pick how to treat rows without a partner.

If the right table has several rows for a key, the left row repeats once per match, as in a database. Columns with the same name get a _right suffix. The summary counts unmatched rows on both sides, which is the quickest check of a key problem.

How to use it

  1. Paste the left table and the right table.
  2. Type the key column of each side.
  3. Choose left, inner, right or full join.
  4. Copy or download the joined CSV.

Frequently asked questions

Left or inner?

Left keeps every row of the first table, filling blanks where there is no match. Inner keeps only matches.

What if a key repeats?

Rows multiply, as in SQL.

Does it match numbers like 1 and 01?

No, matching is on text.

Can I join on two columns?

Merge the columns into one key first.
