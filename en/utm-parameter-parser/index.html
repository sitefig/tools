UTM Parameter Parser (Source, Medium, Campaign Table)

Paste campaign links and see each UTM parameter, the clean URL and other tracking IDs found.

Use the tool

Why this tool exists

Long campaign links are hard to read. A table of the parts shows what a link is tagged with, and the clean URL shows the page without any tracking.

It also lists click IDs such as gclid and fbclid. Capitals in values are flagged because analytics tools treat them as separate values.

How to use it

  1. Paste one or more URLs.
  2. Read the parameter table.
  3. Copy the clean URL if you need it.
  4. Fix flagged values in your link builder.

Frequently asked questions

Which parameters are read?

utm_source, medium, campaign, term, content and id, plus common click IDs.

Does it follow redirects?

No, it only parses the text.

Does it change my link?

No.

Is the link sent anywhere?

No.
