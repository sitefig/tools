Entropy Calculator (Shannon, Bits per Character)

Measures how evenly a string uses its symbols, as bits per symbol and in total, and shows a random-pool estimate.

Use the tool

Why this tool exists

Shannon entropy tells you how unpredictable a string is, judged only from its own symbol counts. "aaaa" has 0 bits, "abcd" has 2 bits per character. It is useful for spotting random-looking data such as keys, tokens or packed files.

It is not a password strength score. A common password can have high Shannon entropy and still be guessed instantly. The second figure, pool entropy, assumes every character was chosen at random from the classes present, and is only valid for truly random strings such as generator output.

How to use it

  1. Paste the text or key.
  2. Choose whether symbols are characters, bytes or words.
  3. Read bits per symbol, total bits and the pool estimate.
  4. Use the results to compare strings, not to rate passwords.

Frequently asked questions

What is a good entropy value?

There is no universal value. For random keys, the pool entropy of the generator matters, for example 128 bits or more for symmetric keys.

Why is a short string low in entropy?

Few symbols cannot show a spread. A 5-letter string has at most log2(5) bits per symbol.

Is Shannon entropy the same as password strength?

No. Strength depends on how an attacker would guess, not on letter counts.

What does the evenness figure mean?

Entropy divided by the maximum possible for the distinct symbols used. 100% means every symbol appears equally often.
