PDF Bookmark Editor (Outline)

Shows the bookmarks (outline) of a PDF as editable text, and writes a new outline from lines of the form "Title | page" with two spaces of indent per level.

Use the tool

Why this tool exists

Bookmarks make a long PDF navigable in any viewer. Editing them in a graphical tree is fiddly, while a text list is quick to type, paste from a table of contents and reorder.

Leave the box empty and press Run to see the current bookmarks in the same format. Edit and run again to save. Titles can use any Unicode characters. As with the other page tools here, the file is rewritten: form fields, named destinations, tagged structure and JavaScript are dropped, and the bookmarks open each page at the current zoom. We checked the result with Ghostscript, which read all the titles.

How to use it

  1. Choose a PDF and press Run with the box empty to see any existing bookmarks.
  2. Write or edit lines such as "Introduction | 1", indenting sub-entries by two spaces.
  3. Press Run again.
  4. Download the bookmarked PDF.

Frequently asked questions

How do I make a sub-bookmark?

Indent the line by two spaces under its parent. Indent one level at a time.

Can a bookmark jump to a position on the page?

No. Each one opens its page; that covers most documents.

Are old bookmarks kept?

Existing ones are replaced by what you type. Copy them from the preview first if you want to keep them.

Why did my fillable form stop working?

The file is rebuilt and form definitions are dropped. Fill the form first, or add bookmarks to a flattened copy.
