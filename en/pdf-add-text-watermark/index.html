Add Text Watermark to PDF

Stamp a faint diagonal text such as CONFIDENTIAL or DRAFT across every page of a PDF, with control over opacity, lightness, size and angle.

Use the tool

Why this tool exists

Drafts, review copies and sensitive documents are often marked so that nobody mistakes them for the final version or forwards them as if they were. A watermark makes that status visible on every page without editing the original in a word processor.

This tool overlays your text on each page of an existing PDF. By default it is a light grey, 30 percent opaque and set at an angle that follows the page diagonal, with the size chosen automatically to fit. You can change the opacity, how light or dark the grey is, the size and the angle. It is a visual marker, not protection: anyone can remove an overlay with the right software, so do not rely on it to keep a document secret. Text is set in Helvetica with Western characters only. Processing is local.

How to use it

  1. Choose a PDF file.
  2. Type the watermark text, such as DRAFT or CONFIDENTIAL.
  3. Adjust opacity, lightness, font size and angle, or keep the automatic values.
  4. Run the tool and download the watermarked PDF.

Frequently asked questions

Can the watermark be removed?

Yes, by someone with PDF editing software. It is a visible reminder, not security. For protection, control who receives the file and use access controls rather than relying on a watermark.

What do the automatic size and angle do?

With size 0 the text is scaled to fit the page, and with the angle set to auto it follows the page diagonal. Enter numbers for either to set them yourself.

Will it hide the text underneath?

The overlay is semi-transparent and light by default, so the page stays readable. If it is distracting, lower the opacity or raise the lightness value towards 100.

Which characters can I use?

Letters, digits and punctuation from the standard Western set. Other scripts and emoji appear as question marks because only a built-in PDF font is used.
