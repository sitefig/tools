Character Name Generator by Culture and Era

Generate names for fictional characters from several cultures and eras (Victorian English, Norse, Japanese, Slavic and more) or invented fantasy names.

Use the tool

Why this tool exists

Names carry a place and a time. A Victorian clerk and a Norse raider should not share a naming style.

Choose a style, a gender and how many names. Each name joins a given name and a surname or byname from a list of about ten per group. Fantasy names are built from invented syllables. The lists are small and for fiction: real naming customs are more varied, for example with patronymics.

How to use it

  1. Pick a style.
  2. Choose male, female or any.
  3. Set how many names to make.
  4. Use a seed to repeat the list.

Frequently asked questions

Are these real names?

The parts are real common names, but combinations are random and not records of real people.

Why so few options?

Each list has about ten items. Combining them gives about a hundred names per group.

Can I get patronymics?

Not yet. The Norse list includes some bynames.
