Image Extractor from HTML (img, srcset, og:image, CSS, Alt Check)

List all images a page references and spot missing alt text, missing dimensions and lazy-loading gaps.

Use the tool

Why this tool exists

Images drive both SEO and layout shift. This tool lists every image reference in pasted HTML: img tags with alt text, srcset and picture candidates, og:image and twitter:image, icons, video posters, CSS background URLs and JSON-LD images. For img tags it flags missing alt attributes, empty alt (fine only for decorative images), missing width and height (a cause of layout shift) and absent loading="lazy".

It cannot download or measure files, because a web page cannot fetch other sites. Open or save the URLs yourself, or use the Image SEO audit for on-page rules.

How to use it

  1. Paste the page HTML and the page URL.
  2. Run the extractor.
  3. Fix the flagged images and copy the URL list.

Frequently asked questions

Can it download the images?

No, downloads from other sites are blocked in a web page. It lists the URLs.

Why flag missing width and height?

Without them the browser cannot reserve space and the page shifts when images load.

Does the first image need lazy loading?

No. Lazy loading the main hero image slows the largest contentful paint.
