CLS Risk Finder: Layout Shift Causes in Your HTML

Reviews markup for the usual causes of Cumulative Layout Shift and lists what to fix.

Use the tool

Why this tool exists

Layout shift mostly comes from a short list of mistakes. Many can be seen in the source before any test.

This is a static read: images and iframes without dimensions, ad and banner slots with no reserved height, Google Fonts without display, @font-face without font-display, scripts that insert content at the top, and keyframes that move layout properties. It cannot see external CSS or real timing, so confirm with the Layout Instability API or Lighthouse.

How to use it

  1. Paste the page HTML including inline style and script.
  2. Read each review item with its line.
  3. Add sizes, reserved space or font-display.
  4. Measure again with the Web Vitals bookmarklet.

Frequently asked questions

Is this a CLS score?

No. It lists risks. Only a browser measurement gives a score.

Why flag banners and cookie notices?

Late-inserted blocks without reserved height push content down.

Does it read my CSS files?

Only inline style tags you paste.

Is the HTML sent anywhere?

No.
