Network Connection Info (Online, Speed Class, Data Saver)

Read the connection details your browser exposes to web pages and watch them change live.

Use the tool

Why this tool exists

The Network Information API lets pages adapt to slow or metered connections. This viewer shows what it reports: effective connection type (4g, 3g...), the browser's estimate of downlink and round-trip time, whether data saver is on, and online/offline events, together with logical CPU cores, device memory and languages.

Values are coarse by design (rounded and capped for privacy) and the API exists only in Chromium browsers; Firefox and Safari show a notice. It is not a speed test and cannot reveal your public IP, because that would need a request to a server. Nothing is sent anywhere.

How to use it

  1. Open the page; values load immediately.
  2. Switch networks or toggle airplane mode to see the change log update.
  3. Press Refresh to re-read the values.

Frequently asked questions

Why are there no values in my browser?

Firefox and Safari do not implement the Network Information API.

Is the downlink a speed test?

No. It is a rounded estimate from recent browser traffic.

Does this reveal my IP?

No. Looking up a public IP needs a server request, which this tool never makes.
