Video Reverser: Play a Short Clip Backwards

Plays a short clip backwards. Frames are read at fixed steps, stored, and recorded in reverse order.

Use the tool

Why this tool exists

Reverse playback is not possible in a browser, so the tool seeks to each frame, keeps it in memory and then plays the list backwards. That limits the clip to 15 seconds and a modest width.

Audio is left out. It records in real time, so a 60 second clip takes about a minute and the tab must stay visible.

How to use it

  1. Choose the video and set start and end.
  2. Set the frame rate and width.
  3. Process: first it reads the frames, then it records them.
  4. Download the reversed clip.

Frequently asked questions

Why 15 seconds at most?

Every frame is stored in memory.

Why no audio?

Reversed speech is rarely wanted, and reversing audio in real time is not available in the browser.

Can the frames be smoother?

Raise the frame rate, within the memory limit.

Is it exact?

Frames are taken at even steps, so very fast motion may skip.
