Form Label Checker: Inputs Without an Accessible Name

Finds form controls that have no accessible name or a weak one.

Use the tool

Why this tool exists

A field without a name is unusable with a screen reader and hard for voice control.

The tool computes each control name from label, aria-label and aria-labelledby, flags placeholder-only and title-only names as weak, finds label for values pointing nowhere, duplicate ids, and radio or checkbox groups outside a fieldset.

How to use it

  1. Paste the form HTML.
  2. Read errors first, then review items.
  3. Add a visible label for each control.
  4. Group related radios with fieldset and legend.

Frequently asked questions

Is a placeholder a label?

No. It disappears when typing and is not a reliable name.

Are buttons checked?

Yes, buttons and submit inputs need text, a value or an aria-label.

Which WCAG criteria does this cover?

1.3.1, 3.3.2 and 4.1.2 patterns.

Is my form uploaded?

No.
