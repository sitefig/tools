Weighted Decision Matrix

List your criteria with weights in the first box and your options with a score per criterion in the second, and get a ranked table of weighted totals.

Use the tool

Why this tool exists

Choosing between vendors, tools, job offers or locations rarely comes down to one factor, and gut feeling tends to follow the most recent conversation. A weighted matrix makes the trade-offs explicit: what matters, how much, and how each option does.

Write criteria with a weight, then score each option on every criterion in the same order. The tool multiplies each score by its weight, divides by the total weight, and ranks the options. Because it shows the per-criterion scores next to the total, you can see why something won. The matrix supports a decision but does not make it, and changing a weight shows how sensitive the result is. Nothing is uploaded.

How to use it

  1. In the first box, write one criterion per line as "name, weight", for example Price, 5.
  2. In the second box, write one option per line as "name, score, score, ..." in the same order as the criteria.
  3. Run the tool to see the options ranked by weighted score.
  4. Change weights or scores and run again to test how stable the ranking is.

Frequently asked questions

What scale should I use for scores?

Any consistent scale, commonly 1 to 10, with higher meaning better. For a cost criterion where lower is better, invert it first so a cheap option gets a high score.

How is the weighted score calculated?

Each score is multiplied by its criterion's weight, the products are added and the sum is divided by the total weight. The result stays on your score scale, so a 10-point scale gives totals up to 10.

Why do I get an error about the number of scores?

Every option needs exactly one score per criterion. If you have three criteria, each option line must have its name plus three numbers.

Can I put commas in names?

In the criteria box, yes, because the weight is read from the end of the line. In the options box, the first value is the name and the remaining values are scores, so avoid commas in option names.
