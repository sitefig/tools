AndroidManifest.xml Builder

Generates an AndroidManifest.xml with application attributes, a launcher activity with explicit android:exported, an optional deep link or App Link filter, permissions and hardware features.

Use the tool

Why this tool exists

Android manifests are verbose, and a few details trip people up: android:exported must be explicit for activities with intent filters on recent Android versions, permission names need the android.permission prefix, and some permissions need a runtime prompt on top of the manifest entry. This builder helps with the basics. Enter the app label, main activity, theme and orientation, and list permissions by short name, such as CAMERA or INTERNET, and they are expanded and checked against those needing a runtime request. You can add a deep link with scheme, host and path prefix with autoVerify for App Links, hardware features and a Firebase Messaging service. It is a template to adapt, not a full project setup. It runs in your browser.

How to use it

  1. List permissions and features one per line, using short names such as CAMERA or feature:android.hardware.camera.
  2. Fill in the app label, main activity, theme, orientation and the backup and cleartext options.
  3. Add a deep link if you need one, then copy the manifest into your project.

Frequently asked questions

Why is android:exported set?

Recent Android versions require an explicit android:exported value for components with intent filters. The launcher activity is generated with it set to true.

How are permissions written?

Short names like CAMERA become android.permission.CAMERA. The tool also lists those that need a runtime prompt, such as camera, location and notifications, so you remember to request them in code.

How do I mark a feature as optional?

Add a question mark after a feature name, as in feature:android.hardware.camera?, and it is declared with required set to false.

What does the application ID field do?

It is for reference. In modern Gradle projects the application ID is set in the build file, not in the manifest.
