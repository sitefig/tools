Number Line Tool: Show Addition and Subtraction as Jumps

Draws a sum or difference of integers or decimals as jumps along a number line, with the start, each step and the answer marked.

Use the tool

Why this tool exists

Negative numbers are easier when you can see them: start at -3, jump 5 to the right, land on 2. The tool draws each step as an arc, blue for adding and red for subtracting, with the start in green and the answer in black.

Several steps are allowed, such as 2 - 7 + 4. The text under the picture lists each jump in words, so the page also works for people who cannot see the drawing. For long ranges the labels thin out automatically.

How to use it

  1. Type a problem with plus and minus signs.
  2. Press the run button or change the text.
  3. Follow the arcs from the green dot to the black dot.
  4. Read the steps in words below.

Frequently asked questions

Does it do multiplication?

No, only addition and subtraction.

Can I use decimals?

Yes.

How many steps?

Up to 12 numbers.

Is there a screen reader description?

Yes, the picture has a text description and the steps are listed in words.
