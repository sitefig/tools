Character Frequency

Counts every character in your text and lists them from most to least common, with the count, percentage, Unicode code point and a small bar. Case and whitespace handling are optional.

Use the tool

Why this tool exists

Counting letters comes up in more places than you would expect. Cryptography puzzles and simple substitution ciphers are cracked by frequency analysis, linguists compare letter distributions, and developers want to know which odd characters crept into a data file.

This tool gives you the full table in one go. Each character shows its code point, so a lookalike such as a Cyrillic letter inside Latin text becomes obvious. You can fold case, count or ignore whitespace, and limit the count to letters and digits. Whitespace is displayed with a visible symbol so it can be read. Your text stays in the browser, which matters when you are analysing private data.

How to use it

  1. Paste the text you want to analyse.
  2. Tick Case sensitive if capital and lower-case letters should be counted separately.
  3. Choose whether to include whitespace, or limit the count to letters and digits.
  4. Read the sorted table and copy it if needed.

Frequently asked questions

What does each column mean?

The columns show the character, its Unicode code point, how many times it appears, its share of the total and a bar scaled to the most common character. The header line gives the total and the number of distinct characters.

How are spaces and line breaks shown?

When whitespace is included, a space appears as a visible symbol and tabs and line breaks as escape sequences, so they can be told apart. By default whitespace is excluded from the counts.

Can it help break a simple cipher?

It is a useful first step. In a monoalphabetic substitution cipher the most common ciphertext letters often map to common plain letters such as E and T. It will not solve the cipher for you.

Are emoji counted correctly?

Characters are counted as Unicode code points, so most emoji count as one. Emoji built from several code points, such as skin tone variants or flags, appear as separate entries.
