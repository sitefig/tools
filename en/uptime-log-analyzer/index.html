Uptime Log Analyzer (Availability %, Outages, MTTR, SLA Budget)

Turn raw monitoring checks into availability, outages and an SLA comparison.

Use the tool

Why this tool exists

Uptime monitors log a timestamp and a status for every check. This analyzer treats HTTP 2xx and 3xx or words such as up and ok as up, everything else as down, computes availability, lists each outage with start and length, and reports longest outage, mean time to recover and mean time between failures. A table shows the downtime budget of common SLAs (99%, 99.9%, 99.99%...) and whether the log meets them.

Results depend on what your monitor measures: its location, interval and definition of up. A one-minute interval cannot see a 20-second outage.

How to use it

  1. Paste lines like "2026-10-01T10:05:00Z 200" or "... down".
  2. Set the check interval, or use 0 to measure the gap between lines.
  3. Read availability, outages and the SLA table.

Frequently asked questions

Which timestamp formats work?

ISO 8601 and "YYYY-MM-DD HH:MM:SS".

How is availability counted?

Each check represents one interval; time in failing intervals counts as down.

Does it contact my site?

No, it analyses the log you paste.
