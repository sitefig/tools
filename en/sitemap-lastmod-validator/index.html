Sitemap Lastmod Date Validator

Validates every lastmod in a sitemap and flags suspicious patterns.

Use the tool

Why this tool exists

Google uses lastmod only when it is consistently accurate. A build script that stamps every URL with the same date teaches crawlers to ignore it.

This tool checks the format (including a time without a zone), real calendar dates and future dates, and it counts distinct days. It cannot tell if a date is true, only if it looks plausible.

How to use it

  1. Paste the sitemap XML, or lines of URL and date.
  2. Run the tool.
  3. Fix the errors first.
  4. Review warnings about identical dates.

Frequently asked questions

Which formats are valid?

W3C datetime: YYYY-MM-DD or a full date and time with Z or +hh:mm.

Why is a shared date a problem?

It often means the date is generated at build time and not the real change date.

Is a future date an error?

It is a warning. Dates more than a day ahead are flagged.

Does this replace the sitemap validator?

No. It focuses on dates; use both.
