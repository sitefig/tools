Web Vitals Bookmarklet Builder (LCP, CLS, INP on Any Page)

Builds a bookmarklet that reads Core Web Vitals from the performance APIs and shows them on the page you visit.

Use the tool

Why this tool exists

A quick way to see Web Vitals on any page without installing an extension.

The bookmarklet uses PerformanceObserver for LCP, layout shifts (grouped in session windows like CLS), event timing for INP, paint and navigation timing. Click it again to remove it. It is lab data from your own browser and needs a Chromium browser for most metrics.

How to use it

  1. Choose overlay and console options.
  2. Create a new bookmark and paste the generated URL as its address.
  3. Open a page and click the bookmark.
  4. Interact with the page to see INP.

Frequently asked questions

Why does INP say waiting?

It needs at least one click, tap or key press after the bookmarklet loads.

Does it work on every site?

Not where a strict Content-Security-Policy blocks javascript: URLs. Use the source in the DevTools console instead.

Are these the field numbers Google uses?

No. They are measured in your browser for this visit.

Does anything leave the page?

No. It only writes to the console and the overlay.
