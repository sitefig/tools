Java .properties to YAML Converter (Spring application.properties)

Converts Java .properties text to nested YAML and back, with dotted keys turned into maps and a[0] keys into lists.

Use the tool

Why this tool exists

Spring Boot and other Java tools accept both application.properties and application.yml. Moving from one to the other by hand means retyping every nesting level.

The parser follows the Java properties format: comments with # or !, separators =, : or whitespace, line continuation with a trailing backslash, and \uXXXX escapes. A conflict such as a=1 and a.b=2 is reported with the line instead of guessed. Values can optionally become numbers and booleans.

How to use it

  1. Choose the direction.
  2. Paste the text.
  3. Decide whether numbers and true or false become YAML types.
  4. Copy the result.

Frequently asked questions

What about key conflicts?

If a key is both a value and a parent, you get an error naming the line.

Are comments kept?

No, they are dropped.

How are lists written?

As key[0], key[1] in properties and as YAML lists in YAML.

Is it uploaded?

No.
