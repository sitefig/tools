IP Address Extractor (IPv4 and IPv6 from Logs)

Finds every valid IPv4 and IPv6 address in a block of text and lists them with how often each appears.

Use the tool

Why this tool exists

A log line or incident report can hide dozens of addresses. Regex alone matches things that are not addresses, such as 999.1.1.1 or the version number 1.2.3. This tool validates each candidate: IPv4 needs four numbers from 0 to 255 without leading zeros, and IPv6 is parsed in all its forms, including :: and embedded IPv4.

You can list each address once with a count, sort by first appearance, frequency or numeric value, and drop private, loopback and link-local addresses. Defanged text such as 192[.]0[.]2[.]44 is restored before matching.

How to use it

  1. Paste the log or report text.
  2. Choose IPv4, IPv6 or both and a sort order.
  3. Untick private addresses if you only want public ones.
  4. Copy the list.

Frequently asked questions

Are IPv6 zone IDs kept?

No. A zone such as %eth0 is ignored and the address itself is listed.

Why is 01.2.3.4 skipped?

Leading zeros are ambiguous (some systems read them as octal), so such forms are not accepted.

Does it look up the owners?

No. It only extracts. The offline lookup tool classifies ranges without a network call.

Can it list ports too?

No. Ports are ignored.
