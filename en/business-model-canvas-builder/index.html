Business Model Canvas Builder (Nine Blocks)

Lays the nine business model canvas blocks out on one page you can save or print.

Use the tool

Why this tool exists

The business model canvas describes how a business creates and captures value in nine blocks, from key partners to revenue streams. Putting it on a single page makes the links between blocks visible.

Write a point per line in each block. The result is an HTML page to save or print to PDF. Nothing is uploaded.

How to use it

  1. Write notes for each block, one per line.
  2. Review the layout.
  3. Save or print the page.

Frequently asked questions

What is the difference from a lean canvas?

The lean canvas focuses on problem and solution for startups; this one covers partners and resources.

Can I add more than one note?

Yes, one per line.

Is anything uploaded?

No.
