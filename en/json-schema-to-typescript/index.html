JSON Schema to TypeScript

Turn a JSON Schema into TypeScript declarations you can paste into your project.

Use the tool

Why this tool exists

Properties become interface members, optional unless listed in required; enum and const become literal unions; type arrays such as ["string","null"] become unions; oneOf and anyOf become unions and allOf becomes an intersection; $ref to #/$defs or #/definitions becomes a named type; additionalProperties maps to index signatures; descriptions become JSDoc comments. The output was compiled with tsc against valid and invalid sample values.

Schema features that TypeScript cannot express (patterns, min/max, formats) are not enforced by the types. Remote $ref files are not fetched.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Paste the JSON Schema.
  2. Set the root type name and style.
  3. Copy the generated declarations.
  4. Validate data at runtime with the JSON Schema validator.

Frequently asked questions

Does it support $ref to other files?

Only references inside the same document (#/$defs/... or #/definitions/...).

How are integers typed?

As number, because TypeScript has no integer type.

What about additionalProperties: false?

It produces an object type without an index signature.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.

Tools often used together

  • JSON Schema ValidatorValidate JSON data against a schema (type, properties, required, items, enum, min/max, pattern, anyOf/oneOf/allOf, local $ref).
  • TypeScript Interface to JSON SchemaConvert TypeScript interfaces, type aliases and enums to JSON Schema draft-07 (definitions + $ref). Supports optional props, unions, literals, tuples, arrays, Record, Date, index signatures, extends/intersections and JSDoc descriptions. Not supported: conditional/mapped types, keyof/typeof and most utility generics.
  • JSON to TypeScriptGenerate TypeScript interfaces or types from a JSON sample, merging array elements.
  • JSON Schema to ZodTurn a JSON Schema (draft-07 / 2020-12 subset: types, formats, bounds, enum/const, anyOf/oneOf/allOf, $ref to $defs) into Zod source code.
  • Zod to JSON SchemaParse Zod source (z.object, string/number checks, enum, union, array, optional/nullable/default, const references) and emit JSON Schema. Static parser, no code is executed.
  • JSON Schema GeneratorInfer a draft-07 JSON Schema from a sample document, with optional string format detection.
