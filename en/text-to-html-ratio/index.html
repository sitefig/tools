Text-to-HTML Ratio

Paste HTML to see the share of visible text against total page size, plus the weight of inline JavaScript and CSS and the word count.

Use the tool

Why this tool exists

Text-to-HTML ratio is a rough measure of how much of a page is content and how much is code. A very low figure usually means heavy markup, large inline scripts or a page with little to say, which is worth a look for both speed and content depth.

This tool strips scripts, styles and tags from the HTML you paste, counts the bytes of visible text against the full source and shows the percentage with a short verdict. It also reports the size of inline JavaScript and CSS and the number of words. It is not a Google ranking factor and app-like pages naturally score low, so use it as a prompt to investigate, not as a target. The calculation is done in your browser.

How to use it

  1. Copy the page source and paste it into the input box.
  2. Run the tool to compute the ratio.
  3. Read the percentage, the verdict, the byte sizes and the word count.
  4. If the ratio is very low, check for heavy inline scripts, repeated markup or thin content.

Frequently asked questions

Is text-to-HTML ratio a ranking factor?

Not directly. Search engines do not publish it as a signal. It is a quick indicator of bloat or thin content, which can matter indirectly through speed and usefulness.

What ratio is good?

The tool treats under 10 per cent as very low, 10 to 25 as low to average and above 25 as healthy. Content pages usually score higher than application pages.

Does it measure rendered content?

No. It measures the HTML you paste. Content added by JavaScript after loading is not counted unless you paste the rendered DOM.

Is the HTML uploaded?

No. Everything is calculated in your browser, and the source you paste is not sent anywhere. No account, upload or request to a remote service is involved at any point.
