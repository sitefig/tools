Dataset Schema Generator

Generates Dataset markup with name, description, license, creator, keywords, time range, place and a DataDownload for each file.

Use the tool

Why this tool exists

Dataset Search needs a clear name and description, and works better with a license, creator and file links. Each download line becomes a DataDownload with contentUrl and encodingFormat. The time range must be an ISO 8601 date or interval, which the tool checks.

Google clarified in November 2025 that Dataset markup is used by Dataset Search only and not by Google Search results, and the output repeats this.

How to use it

  1. Enter name, description, URL and license.
  2. Add creator, keywords, temporal and spatial coverage.
  3. Add one download: line per file: URL | format.
  4. Copy the script tag.

Frequently asked questions

What is a valid temporal value?

A date like 2020-01-01 or an interval like 2020-01-01/2024-12-31.

How long should the description be?

The tool warns outside 50 to 5000 characters, the range Google documents.

Where does the data show up?

In Google Dataset Search, not in normal results.

Can I list several files?

Yes, repeat download:.
