Decision Wheel

Enter your options, one per line, and press Spin. The wheel turns for a few seconds and lands on a winner, shown below the wheel.

Use the tool

Why this tool exists

Where to eat, who goes first, which task to start with, which movie to watch: small decisions can eat more time than they deserve, especially in a group. Spinning a wheel makes the choice feel fair and takes the argument out of it. Type the options, press Spin, and the result is picked using the browser's secure random number generator before the animation starts, so it is not influenced by when you stop watching. The wheel redraws as you edit the list, coloured by segment, and takes up to 40 options. Longer labels are shortened on the wheel itself but the winner is shown in full text. Nothing is uploaded, so you can use private options.

How to use it

  1. Type one option per line in the box.
  2. Press Spin and wait for the wheel to stop.
  3. Read the winner below the wheel, edit the list and spin again if you like.

Frequently asked questions

Is the result really random?

The final angle is chosen with the browser's cryptographically secure random generator, then the wheel animates to it. Every option occupies an equal slice, so each is equally likely.

How many options can I add?

Up to 40 lines are used. At least two are needed, otherwise the tool asks you to add more. Blank lines are ignored.

Why are some labels cut off?

Long names are shortened to about 18 characters so they fit on the wheel. The winner line below shows the complete option text.

Can I weight an option?

Not directly. Each line gets an equal slice. To make an option more likely, list it more than once.
