YAML to TypeScript Interfaces

Infers TypeScript interfaces from YAML or JSON. Nested objects get their own named interface, arrays of objects are merged so missing keys become optional, and mixed values become unions.

Use the tool

Why this tool exists

Configuration lives in YAML: app settings, CI files, Kubernetes manifests, feature flags, content front matter. Reading that config in TypeScript without types means property typos only show up at runtime. Writing the interfaces by hand for a large file is slow. Paste the YAML and this tool infers the shapes: each nested object becomes a named interface, list items are merged so a key present in only some entries is optional, and fields that change type become unions. A null value is typed accordingly. It looks only at the sample you give it, so a single example gives a narrow picture, and you should widen types where real data varies. If the file has several YAML documents, the first is used. It runs in your browser.

How to use it

  1. Paste YAML, or JSON, into the input box.
  2. Set the name of the root interface, for example Config.
  3. Copy the generated interfaces and adjust any type that the sample made too narrow.

Frequently asked questions

How are arrays of objects handled?

All items are merged into one interface. A key missing from some items becomes optional, and a key that has different types in different items becomes a union.

What about multi-document YAML?

Only the first document is used. Split the file and run each document separately if you need all of them.

Can I paste JSON?

Yes. JSON is valid YAML, so you can paste a JSON document and get the same kind of interfaces, with nested objects, optional keys and unions worked out in the same way.

Why are my types too narrow?

The tool can only see your sample. A field with one example string becomes string, and an empty list has no known element type. Provide a fuller sample or edit the output.

Tools often used together

  • YAML to JSONConvert YAML to JSON. Supports maps, lists, flow style, | and > blocks, anchors/aliases/merge keys, multiple documents.
  • JSON to TypeScriptGenerate TypeScript interfaces or types from a JSON sample, merging array elements.
  • YAML FormatterRe-indent and normalise YAML (comments are not preserved; anchors are expanded).
  • SQL CREATE TABLE to TypeScriptTurn CREATE TABLE statements (MySQL, PostgreSQL, SQLite flavours) into TypeScript interfaces: NOT NULL columns become required, nullable ones get "| null". Handles quoted identifiers, constraints and IF NOT EXISTS.
  • TypeScript Interface to JSON SchemaConvert TypeScript interfaces, type aliases and enums to JSON Schema draft-07 (definitions + $ref). Supports optional props, unions, literals, tuples, arrays, Record, Date, index signatures, extends/intersections and JSDoc descriptions. Not supported: conditional/mapped types, keyof/typeof and most utility generics.
  • JSON to Go StructGenerate Go structs with json tags from a JSON sample.
