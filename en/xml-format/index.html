XML Formatter

Pretty-print XML with consistent indentation. Elements, attributes, CDATA and the XML declaration are kept, mixed text content is preserved, and comments can be kept or removed.

Use the tool

Why this tool exists

XML from a SOAP response, an RSS feed or an export is often delivered on a single line. That makes it nearly impossible to see which element contains which, or where a closing tag is missing. A formatter lays the tree out so you can read it.

The tool re-indents elements, keeps attributes and CDATA sections, and treats text mixed with tags, like a paragraph with a bold word, carefully so that spacing in the text is not changed. You choose 2, 4 or 8 spaces or a tab, and whether comments stay. Malformed XML is reported rather than guessed at. Formatting happens in your browser and nothing is uploaded, which matters when the XML contains customer records.

How to use it

  1. Paste your XML into the input box.
  2. Choose the indent: 2, 4 or 8 spaces, or a tab.
  3. Tick Keep comments if you want comments retained.
  4. Copy the formatted XML.

Frequently asked questions

Does formatting change my data?

Whitespace between elements is rearranged, but text content is not altered. Where text and tags are mixed, as in an element containing text and a child, the original spacing is preserved.

What if the XML is not well-formed?

The tool reports an error instead of producing output. Use the XML Validator for a clear check of well-formedness using the browser parser.

Are CDATA sections and comments kept?

CDATA sections are kept as they are. Comments are kept when the option is ticked and removed when it is not.

Can it format XML with namespaces?

Namespace prefixes and declarations are kept as written. The tool re-indents; it does not resolve or validate namespaces or check against a DTD or schema.
