Shell Command Builder (tar, find, rsync, ssh, openssl, dump)

Pick a task, fill in a few values and get a command you can paste into a terminal, plus an explanation of its options.

Use the tool

Why this tool exists

Each recipe takes up to five values (shown in the output with their meaning); empty fields use the example, and a dash means none. Arguments are single-quoted when they contain special characters. The tar, find, du, rsync, grep and openssl recipes were executed against a test directory to check that the generated commands work as described, and the rest were syntax-checked.

The tool does not run anything. Test destructive commands (find -delete, rsync --delete) with a dry run or on a copy first.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Choose the task.
  2. Fill Value 1 to 5 in the order shown in the output.
  3. Copy the command.
  4. Run it with care, starting with a safe variant.

Frequently asked questions

What do Value 1-5 mean?

They map to the parameters listed under "Values used" in the output for the chosen task.

Is it safe to paste a command?

Read it first. The tool quotes arguments, but you are responsible for what you run.

Which shell is assumed?

POSIX-compatible shells such as bash and zsh; the grep recipe uses bash brace expansion.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
