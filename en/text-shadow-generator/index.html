Text Shadow Generator

Builds a CSS text-shadow declaration from offset, blur, colour and opacity, with optional extra glow layers. A live preview shows the effect on sample text.

Use the tool

Why this tool exists

Text shadows can lift a heading off a photo, add a neon glow or give a button label a little depth. They are also easy to overdo, and legibility suffers when the blur is too heavy or the colour too strong.

Set the horizontal and vertical offset, the blur, the colour and the opacity, and watch the sample heading change. The glow option stacks up to five additional zero-offset shadows with growing blur, which produces a soft neon halo without writing each layer yourself. The output is a single text-shadow line using rgba colours, ready to paste into your stylesheet. It runs in your browser.

How to use it

  1. Set the X and Y offsets and the blur radius.
  2. Choose a colour and an opacity percentage.
  3. Raise Extra glow layers for a neon effect.
  4. Copy the text-shadow line from the output.

Frequently asked questions

How do I make a glow rather than a drop shadow?

Set both offsets to 0 and increase the extra glow layers. Each layer adds a shadow centred on the text with a larger blur, so the light appears to spread outward.

Will a shadow help readability on images?

A subtle dark shadow can separate light text from a busy photo, but it is not a substitute for enough contrast. Check the text and its real background with a contrast checker.

Does text-shadow affect layout or performance?

It does not change layout. Large blurs on lots of text can slow painting on weak devices, so use heavy glows sparingly and avoid animating them.

Can I add more than one colour?

This tool uses one colour for all layers. For multi-coloured effects, copy the output and add further comma-separated shadows by hand.
