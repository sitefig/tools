Top IPs and User Agents Report from an Access Log

Two rankings from a Common or Combined log: client IPs and user agents.

Use the tool

Why this tool exists

Which client causes most of the load? The answer is often one IP or one library user agent. Each row shows requests, share, bytes, 4xx and 5xx counts and the time range.

A user agent is a claim by the client and can be faked. Many requests from one IP may be a proxy with many users.

How to use it

  1. Paste the access log or choose a file.
  2. Set how many rows to show.
  3. Read the IP ranking.
  4. Read the user agent ranking.

Frequently asked questions

Does it look up countries?

No. That needs a database or an online service. See the offline IP lookup tool for private ranges and registry data.

What are first and last?

The time of day (UTC) of the first and last request from that entry.

Can it detect bots?

Use the bot identifier tool on the user agents.

Is my log uploaded?

No. Everything is processed in your browser and nothing is sent. Logs can hold IP addresses and tokens, so the page does not write them into the address bar.
