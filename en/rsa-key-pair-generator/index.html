RSA Key Pair Generator

Generate an RSA key pair at 2048, 3072 or 4096 bits and get the private key as PKCS#8 or PKCS1 PEM, plus the public key as SPKI PEM.

Use the tool

Why this tool exists

RSA keys are still needed for TLS test certificates, JWT signing with RS256, legacy SSH servers and sample integrations. Reaching for OpenSSL just to make a test key is slow when you are on a borrowed machine or in a hurry.

This tool uses your browser WebCrypto engine to create the pair locally. It then rewrites the key identifiers so that tools treat it as a plain RSA key, rather than a key restricted to the PSS scheme, and outputs PEM in the layout you choose. A 4096-bit key can take a few seconds. For long-lived production secrets, generate keys on the machine or HSM that will keep them.

How to use it

  1. Choose the key size: 2048, 3072 or 4096 bits.
  2. Choose PKCS#8 or PKCS1 for the private key format.
  3. Run it and copy the private and public PEM blocks.

Frequently asked questions

Which key size should I pick?

2048 bits is the usual minimum today, and 3072 gives a larger margin. 4096 is slower to generate and use. Match the size to what your platform policy requires.

Why does the key use the RSA-PSS algorithm in WebCrypto?

WebCrypto requires a signing scheme when generating a key. The tool then rewrites the identifier to plain rsaEncryption, so the key works as a general RSA key with other software.

Is the key stored anywhere?

No. It is created in the page and shown to you. Nothing is saved or sent, and it disappears when you close or reload the tab.

Is the private key protected by a passphrase?

No. It is unencrypted PEM. Protect any file you save it to, and avoid using browser-made keys for high-value systems.
