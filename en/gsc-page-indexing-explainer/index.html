Search Console Page Indexing Report Explainer (Why Pages Are Not Indexed)

Understand each reason in the Search Console Pages report and know which ones actually need action.

Use the tool

Why this tool exists

The Pages report lists reasons such as "Crawled - currently not indexed", "Duplicate without user-selected canonical" or "Alternate page with proper canonical tag", and many are expected behaviour. This explainer takes your table (CSV or plain "reason, count" lines), explains each reason, marks it normal, review or fix, gives the usual remedy and totals how many URLs fall in each class.

Wording follows the English interface; other languages will not match. The tool cannot see your pages or the example URLs, so inspect those in Search Console before changing anything.

How to use it

  1. Open Search Console > Pages, scroll to "Why pages aren't indexed" and copy or export the table.
  2. Paste it here.
  3. Start with the FIX class, then review the largest groups.

Frequently asked questions

Is "not indexed" always bad?

No. Redirects, canonical alternates, noindex pages and 404s are meant to be excluded.

What should I do about "Discovered - currently not indexed"?

Improve internal links to those URLs, remove low-value pages and make sure the server is fast.

Are my URLs uploaded?

No; only the table you paste is processed, in your browser.
