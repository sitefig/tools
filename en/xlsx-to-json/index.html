Excel (XLSX) to JSON Converter

Pick an Excel workbook, choose a sheet, and get JSON you can paste into code, a mock API or a test fixture. The file is read in the browser and never uploaded.

Use the tool

Why this tool exists

Spreadsheets are where a lot of reference data starts, but code wants JSON. Opening Excel, exporting CSV and then converting that again is three steps for one result. This tool reads the .xlsx file directly and produces an array of objects whose keys come from the first row, or a plain array of rows if your sheet has no header.

It reads the cached values stored in the file, so formulas appear as their last calculated result. Dates are stored by Excel as serial numbers and are kept that way here rather than guessed at; convert them with the date tools if you need ISO strings. Numbers and TRUE/FALSE cells become JSON numbers and booleans, and numbers longer than 15 digits stay as text so they do not lose precision. Only .xlsx files are supported, not the old .xls format.

How to use it

  1. Choose an .xlsx file.
  2. Set the sheet number if the data is not on the first sheet.
  3. Pick array of objects (first row is the header) or array of arrays.
  4. Copy or download the JSON.

Frequently asked questions

Does it support the old .xls format?

No. Only .xlsx (Office Open XML) workbooks are read. Save an .xls as .xlsx first.

How are dates handled?

Excel stores dates as numbers (days since 1900). They are left as those numbers, because a number alone cannot tell a date from a quantity. Convert them separately if you need ISO dates.

What happens to formulas?

You get the value Excel last calculated and saved in the file. If the file was produced by a program that never calculated the formulas, those cells may be empty.

Is the spreadsheet uploaded?

No. The file is opened in your browser and nothing is sent to a server.
