GPT Token Counter (cl100k + o200k, chat overhead)

Counts tokens for your text under both OpenAI encodings at once. A second box accepts chat messages as JSON and adds the usual per-message overhead to estimate a request size.

Use the tool

Why this tool exists

Prompts have a budget. Context windows, rate limits and per-token pricing all depend on counts, and guessing from word counts is off by a wide margin for code, numbers and non-English text.

Paste your text and see the exact figure for cl100k_base, used by GPT-4 and GPT-3.5, and for o200k_base, used by GPT-4o and later models. If you are building a chat request, paste the messages as a JSON array and the tool adds the per-message overhead from OpenAI's cookbook rule: three tokens per message, one more for a name and three to prime the reply. That total is an estimate, since real usage can vary slightly by model. All counting is local in your browser.

How to use it

  1. Paste the text you want to count into the Text box.
  2. Optionally paste chat messages as a JSON array of role, optional name and content.
  3. Read the token counts for cl100k_base and o200k_base.
  4. Use the chat total, with its content-only and overhead split, to plan your request size.

Frequently asked questions

How are chat messages counted?

Each message adds 3 tokens, plus 1 if it has a name, plus the tokens of every field value, and 3 more tokens are added once for the reply. It is the cookbook approximation, not a guarantee for every model version.

What is the difference between the two encodings?

cl100k_base belongs to GPT-4 and GPT-3.5-turbo, o200k_base to GPT-4o and later families. The newer one has a larger vocabulary and usually produces fewer tokens for non-English text and code.

Will it count tool calls or images?

No. Function and tool definitions, images, audio and newer message fields add their own overhead in real requests, and this tool does not model that. Treat the total as a lower-bound estimate.

Is my text uploaded?

No. A vocabulary file is loaded from this site on first use. The counting itself runs in your browser, so prompts and messages stay on your device.
