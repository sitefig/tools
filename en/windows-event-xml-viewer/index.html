Windows Event Log XML Viewer (Filter by Event ID)

Parses Event Viewer XML exports, lists events and summarises failed logons.

Use the tool

Why this tool exists

Event Viewer can save events as XML. This tool reads them, so you can filter 4625 failed logons or 4688 new processes without opening Event Viewer.

Titles for the listed Security event IDs come from the Microsoft Learn pages. Other IDs show no title. Binary .evtx files are not read; export to XML first.

How to use it

  1. In Event Viewer choose Save All Events As and pick XML, or run wevtutil qe Security /f:xml.
  2. Paste or open the XML.
  3. Enter event IDs to show, if you want a subset.
  4. Read the summary and the table.

Frequently asked questions

Can it open .evtx?

No. Export to XML first.

What does Level LogAlways mean?

Level 0. Security audit events use it.

Which logon types are named?

2 Interactive, 3 Network, 4 Batch, 5 Service, 7 Unlock, 8 NetworkCleartext, 9 NewCredentials, 10 RemoteInteractive, 11 CachedInteractive.

Is my log uploaded?

No. Everything is processed in your browser and nothing is sent. Logs can hold IP addresses and tokens, so the page does not write them into the address bar.
