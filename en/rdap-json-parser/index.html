RDAP JSON Response Reader (Domain, IP and ASN)

Turns a raw RDAP JSON response (RFC 9083) into a plain summary: dates with days to expiry, status values, name servers, DNSSEC state, network ranges and the entities with their roles.

Use the tool

Why this tool exists

RDAP is the JSON successor to WHOIS, but the raw answer is long and nested, with contacts hidden inside vCard arrays. You usually want five things: who, when it expires, what the status is, which name servers and who to contact.

Paste the JSON you got from your registry or a command-line client. The tool never queries a registry itself, so it cannot tell you whether the data is current. For plain-text WHOIS output use the WHOIS record parser.

How to use it

  1. Copy the RDAP JSON response from your client or browser.
  2. Paste it into the box.
  3. Optionally set a fixed "today" date to count days to expiry.
  4. Read the summary.

Frequently asked questions

Where do I get the JSON?

From a command such as curl against the registry RDAP URL, or from a registrar or registry web page that exposes it. This page does not fetch anything.

Which object types work?

Domain, IP network and autnum responses. Others show the common fields only.

Why are some contacts missing?

Registries often redact personal data. The tool shows only what the response contains.

Is this the same as WHOIS?

It carries similar data in a structured form. Use the WHOIS parser for plain text records.
