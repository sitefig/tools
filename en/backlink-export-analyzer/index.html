Backlink Export Analyzer (Referring Domains, Anchors, Nofollow, Risky Links)

Summarise a backlink export: who links to you, with what anchors, how natural the profile looks and what to review.

Use the tool

Why this tool exists

Backlink tools export thousands of rows. This analyzer finds the source column automatically, counts links and referring domains, shows the dofollow and nofollow share, ranks the top linking domains, classifies anchor text (branded, naked URL, generic, empty, keyword-style), shows TLD spread and link growth by month and lists links from cheap TLDs or spam words for manual review.

It cannot compute authority or spam scores, which need crawled link graphs, and tools sample the web differently, so a single export is incomplete. Google ignores most spam links; reserve the disavow tool for unnatural link patterns you cannot remove.

How to use it

  1. Export links from your backlink tool or Search Console and paste the CSV.
  2. Enter your brand terms and domain for anchor classification.
  3. Review the risky list manually before any disavow.

Frequently asked questions

Which columns are needed?

A source URL column. Anchor, nofollow/rel and first-seen columns improve the output.

Should I disavow the risky links?

Only for a clear unnatural pattern. Google usually ignores low-quality links by itself.

Does it call any API?

No, it only reads the CSV you paste.
