Bubble Chart Maker (X, Y and Size as Circle Area)

Draws bubbles at x and y with area proportional to a third value, with optional labels.

Use the tool

Why this tool exists

A bubble chart adds a third number to a scatter plot. Area, not diameter, follows the value, which is the honest way to scale circles.

Labels print inside or next to bubbles. Overlaps are drawn with translucent fill, biggest first, so small bubbles stay visible. The table under the chart lists all values for exact reading.

How to use it

  1. Paste rows x, y, size, label (label optional).
  2. Choose whether to print labels.
  3. Set the chart size and title.
  4. Copy or download the SVG.

Frequently asked questions

Is size area or diameter?

Area.

Negative sizes?

Not allowed.

Can I add colours by group?

No, colours cycle per row.

Limit?

500 bubbles.
