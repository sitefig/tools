Waterfall Chart Maker (Running Total of Gains and Losses)

Draws floating bars for each change on top of a running total, with subtotal bars where you leave the value blank.

Use the tool

Why this tool exists

Waterfalls explain how you got from one number to another: profit bridges, headcount changes, budget variance. Start with the opening value and list each change.

Increases and decreases are coloured differently and also carry a plus or minus sign, so the picture does not depend on colour. A row with a blank value shows the running total as a subtotal bar. The table lists every step and the running total.

How to use it

  1. Write rows label, value; leave the value blank for a subtotal.
  2. Tick the final total option if you do not end with a subtotal row.
  3. Set title and size.
  4. Copy or download the SVG.

Frequently asked questions

Does the first row need to be a total?

Its value is shown as the starting bar.

How are decreases drawn?

In orange-red below the previous total with a minus sign.

Can the total go below zero?

Yes, bars cross the zero line.

How many steps?

Up to 60.
