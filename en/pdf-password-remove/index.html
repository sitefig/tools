Remove PDF Password (Unlock)

Remove the encryption from a PDF when you know its password, so it opens without a prompt and without restrictions. Your file stays on your device.

Use the tool

Why this tool exists

A PDF that asks for a password every time, or refuses to print or copy, is a chore when you own the document. Give this tool the user password, or the owner password for a file that opens freely but is restricted, and it writes a copy with the encryption removed.

It reads the standard security handler in all its forms: RC4 40-bit and 128-bit, AES-128 and AES-256 (both revision 5 and 6). Every string and stream is decrypted and the file is rewritten without an Encrypt dictionary. Pages, fonts, images, form fields and bookmarks are kept; digital signatures become invalid because the bytes change.

This is not a password cracker. It needs the right password, and says so when it is wrong. Files that rely on a public-key security handler are refused. Everything runs in your browser; neither the file nor the password is uploaded.

How to use it

  1. Choose the protected PDF.
  2. Type the user or owner password; leave it empty for files that open without one but are restricted.
  3. Run the tool and download the unlocked copy.

Frequently asked questions

Can it recover a lost password?

No. It only removes protection when you supply the correct password. A forgotten open password cannot be bypassed here.

What is the difference between the user and the owner password?

The user password opens the file. The owner password additionally allows changing restrictions. A file with only an owner password opens without a prompt but may block printing or copying; give the owner password (or leave the field empty if the restrictions use an empty user password) to lift them.

Which encryption types work?

RC4 40/128 bit, AES-128 and AES-256 of the standard handler. Public-key (certificate) encryption and custom handlers are not supported.

Is it legal to remove a PDF password?

Only do it on documents you own or have permission to change. The tool needs the password, so it cannot be used to break into files you cannot already open.

Does it keep the document intact?

Content, fonts and forms are kept. Unreferenced objects are dropped, and object streams become plain objects. Digital signatures are invalidated by any rewrite.
