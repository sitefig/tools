Anagram Checker

Compares two phrases letter by letter, ignoring case, spaces and punctuation, and says whether they are anagrams. If not, it lists the letters that do not match.

Use the tool

Why this tool exists

Anagrams are a staple of word games, crossword setting, puzzle hunts and classroom exercises, and checking one by hand means crossing off letters one at a time. It is easy to miss a single stray letter in a longer phrase such as a name or a motto.

This checker counts every letter and digit in both phrases and compares the totals. When they differ, it shows exactly which characters are over or under, so you can tweak your attempt. Accents can be ignored, which helps with names that mix spelled variants. Spaces and punctuation never count. The comparison happens in your browser, so you can try out puzzle answers without sharing them.

How to use it

  1. Type the first word or phrase into Phrase A.
  2. Type the second one into Phrase B.
  3. Leave Ignore accents ticked if accented letters should match plain ones.
  4. Read the verdict and the sorted letters, plus any differences.

Frequently asked questions

What is ignored in the comparison?

Case, spaces and punctuation. Only letters and digits are compared. So "Dormitory" and "Dirty room" match, because both contain the same letters once spaces are removed.

What does Ignore accents do?

When ticked, accents are removed before comparing, so an e with an acute accent matches a plain e. Untick it if you want accented letters to be treated as different characters.

Why does it say identical words are not true anagrams?

If both phrases reduce to the same sequence of letters, they are the same word with different spacing or punctuation. The tool still reports a match but adds a note, because a true anagram rearranges the letters.

How do I see why two phrases do not match?

The result lists the differences as letter counts, for example "e: 2 vs 1". That tells you which letters you have too many or too few of in each phrase.
