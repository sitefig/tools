PDF Blank Page Inserter

Adds one or more empty pages after the page numbers you list. Each new page takes the size of the page before it, and can carry a short line of text.

Use the tool

Why this tool exists

Chapters that must start on a right-hand page, double-sided printing, and separator sheets between sections all need blank pages in the right places. Doing this in a desktop editor is heavy for a one-off job.

List the page numbers after which blanks go, for example "0, 2, 5", where 0 means at the start. A number repeated adds more blanks. A blank page copies the displayed size of the page it follows, including rotation. The file is rewritten, so bookmarks, form fields and links are not carried over.

How to use it

  1. Choose a PDF.
  2. Enter the page numbers after which to insert blanks.
  3. Set how many blanks and an optional line of text.
  4. Press Run and download.

Frequently asked questions

How do I add a blank page at the start?

Enter 0 in the list.

Can I add text to the blank pages?

Yes, enter a short line such as "This page is intentionally blank".

Which size is used?

The size of the page before the blank. At the start, the size of the first page.

Are my bookmarks kept?

No. Page tools in this set rewrite the file and drop bookmarks. Add them back with the bookmark editor.
