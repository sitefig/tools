Passphrase Generator

Generate pronounceable passphrases from random syllables using the browser secure random generator. The page tells you how many bits of entropy each phrase has.

Use the tool

Why this tool exists

Some passwords you must remember or read aloud: a laptop disk password, a Wi-Fi key shared in a meeting, a master password you type daily. Random strings like k9$Zq are hard to type and recall, while a few real words can be guessed if you choose them yourself.

This tool builds each word from random syllables, so the words are easy to say but are not dictionary entries. Because the syllable space is fixed and known, the entropy can be computed exactly: it is shown per word and in total. Choose how many words, the separator, capitalisation and whether to append a digit. Generation is local and uses secure randomness.

How to use it

  1. Set the number of words per passphrase and how many passphrases you want.
  2. Choose a separator, capitalisation and an optional trailing digit.
  3. Run the tool and read the bits of entropy shown below the list.
  4. Pick one, memorise it or store it in a password manager, and do not reuse it.

Frequently asked questions

How strong is a passphrase from this tool?

The page prints exact bits per word and in total. More words means more entropy. Five words of this kind give a good level for most uses, but check the figure shown for your settings.

Why are the words not real dictionary words?

Each word is three random syllables, which makes it pronounceable but unpredictable. That lets the entropy be calculated exactly, unlike lists where people pick favourite words.

Is randomness secure?

Yes, it uses crypto.getRandomValues with an unbiased selection. Nothing is uploaded or stored, so the phrases only exist in your browser while you view them.

How many words can I generate?

Between 2 and 20 words per passphrase, and up to 100 passphrases at once. Longer phrases are safer but harder to type.
