Line Chart Maker (Multi-Series Time Series to SVG)

Draws a multi-series line chart from a table. The first column may hold dates (YYYY-MM-DD), numbers or labels, and empty cells break the line instead of inventing values.

Use the tool

Why this tool exists

Time series arrive as spreadsheets, and a line chart is usually the first thing you want. Paste the columns and get an SVG with axes, ticks, a legend and point markers, without installing a plotting library.

Dates are placed to scale on the axis, so uneven gaps look uneven, which is how they should look. A table of the values sits under the chart as the text alternative. The y axis can start at zero or at the data minimum; truncated axes exaggerate small changes, so choose on purpose.

How to use it

  1. Paste a header row, then one row per time point: x value first, one column per series.
  2. Choose whether the y axis starts at zero and whether to show point markers.
  3. Add a title and optional y axis label, and set the size.
  4. Copy or download the SVG.

Frequently asked questions

Which date formats work?

YYYY-MM-DD, YYYY/MM/DD and YYYY-MM. Anything else is treated as a number or a plain label.

What happens with empty cells?

The line stops and restarts after the gap. Missing values are never filled in.

Can I plot two scales?

No. All series share one y axis. Index the series or make two charts if the units differ.

Is there a point limit?

Up to 2000 rows.
