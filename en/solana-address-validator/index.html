Solana Address Validator

Paste Solana addresses to check the Base58 alphabet and the 32-byte length, and see whether each key lies on the ed25519 curve or off it like a program-derived address.

Use the tool

Why this tool exists

A Solana address is a Base58 encoding of a 32-byte public key. A typo, a truncated copy or an address from another chain fails in different ways, and wallets sometimes accept the text before they complain about it.

This validator decodes each line, reports the byte length and tells you whether the point is on the ed25519 curve. Wallet keypairs are on the curve, while program-derived addresses are deliberately generated off the curve so nobody holds a private key for them. That distinction matters when you are checking an account in a transaction. A valid address does not mean the account exists on chain or holds funds.

How to use it

  1. Paste Solana addresses, one per line.
  2. Read the result: VALID or INVALID, with the reason if invalid.
  3. For valid keys, see whether the address is on the curve or a PDA.

Frequently asked questions

What does a valid address prove?

Only that the text decodes to exactly 32 bytes using the Base58 alphabet. It says nothing about whether an account exists, is funded or is owned by a particular program.

What is the meaning of off the curve?

Program-derived addresses are produced so that they are not valid ed25519 public keys, which means no private key exists and only the owning program can sign for them.

Why do some addresses fail with a length error?

Base58 strings of other chains, such as Bitcoin, decode to a different number of bytes. A truncated paste also gives the wrong size, and the tool reports the byte count it found.

Does it contact the network?

No. The checks use local arithmetic only, so it works offline and no address is sent to any server.
