HTML Tag Stripper

Paste HTML and get plain text back. Tags, comments, script and style blocks are removed, and entities such as &amp; are decoded.

Use the tool

Why this tool exists

Copying text out of a web page, an email template or a CMS export usually drags the markup along. You end up with stray div tags, inline styles and entities like &nbsp; in the middle of a sentence. Retyping is slow and a quick regex in an editor tends to leave the script contents behind.

This tool removes comments first, drops whole script and style blocks, then strips the remaining tags. Block-level closers such as paragraphs, list items and headings can become line breaks, so the result still reads as paragraphs. It suits cleaning descriptions for a spreadsheet, preparing text for a word count, or checking what a crawler would see without markup. Everything runs locally.

How to use it

  1. Paste the HTML into the input box.
  2. Tick Keep line breaks for block tags if you want paragraphs to stay on separate lines.
  3. Tick Decode entities to turn &amp;, &nbsp; and numeric codes into characters.
  4. Copy the cleaned text from the output.

Frequently asked questions

Does it remove the contents of script and style tags?

Yes. Script and style elements are removed together with everything inside them, and HTML comments are removed first. Only the visible text between other tags is kept.

Which entities are decoded?

Numeric entities in decimal and hex, plus a short list of named ones: amp, lt, gt, quot, apos, nbsp, copy, reg, hellip, mdash and ndash. Other named entities are left exactly as typed.

Is this safe for sanitising user input?

No. It is a text clean-up helper based on pattern matching, not an HTML sanitiser. Do not rely on it to make untrusted markup safe for rendering; use a proper sanitiser in your application.

Why are blank lines collapsed?

Whitespace on each line is squeezed to single spaces and runs of empty lines are reduced to one, so the output does not inherit the indentation of the source markup.
