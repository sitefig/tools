Duplicate Row Remover (By Selected Columns, CSV)

Finds rows that match on the columns you choose and keeps one of each, reporting which rows were removed.

Use the tool

Why this tool exists

Duplicates usually mean the same person or item entered twice, but only some columns define sameness: an email, an ID, a name and date together. Choose those columns and ignore the rest.

Comparison can ignore letter case and surrounding spaces, so Ann@x.com and ann@x.com match. You choose whether the first or the last occurrence survives. The summary lists the removed row numbers so you can check before using the result.

How to use it

  1. Paste the CSV with a header.
  2. Type the columns that define a duplicate, or leave blank for whole rows.
  3. Pick keep first or keep last.
  4. Copy or download the cleaned CSV.

Frequently asked questions

Does it find near-duplicates?

No, only exact matches after trimming and lowercasing. Use the fuzzy match tool for typos.

Which row numbers are shown?

Data rows counted from 1 below the header.

Are other columns merged?

No. The kept row is left as is.

Does order change?

No, kept rows stay in their original order.
