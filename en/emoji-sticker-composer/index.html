Emoji Sticker Composer: Combine Two Emoji into a Transparent PNG

Draws two emoji side by side, overlapping or as a big and small pair on a transparent canvas and saves a PNG.

Use the tool

Why this tool exists

Emoji Kitchen blends emoji into new artwork made by Google, which is not available offline. This tool does a simpler job: it places two emoji from your device font in one image, with an optional white sticker edge, at any size up to 2048 pixels.

The emoji look depends on your system font. Check the license of your system emoji set before using the image commercially.

How to use it

  1. Type or paste two emoji.
  2. Pick a layout, size and border.
  3. Run the tool.
  4. Download the transparent PNG.

Frequently asked questions

Does it blend the two emoji?

No. It places them together. True blending uses artwork this site does not have.

Why does it look different on another computer?

Each system has its own emoji font.

Can I use more than two emoji?

Only the first emoji of each box is used.

Is the PNG transparent?

Yes, outside the emoji and border.
