GPS Location Stripper for JPEG (Keep Other Metadata)

Remove only the GPS tags from JPEG photos.

Use the tool

Why this tool exists

Choose JPEG files. The tool finds the GPS block in the EXIF data, zeroes it in place and blanks GPS fields in XMP. The picture data is not re-encoded, so there is no quality loss and the other EXIF fields (camera, exposure, date) stay.

It looks at the EXIF and XMP blocks. Some cameras keep location in maker notes or in a thumbnail, and sidecar files are not touched. Check the result in the EXIF viewer, or use the full metadata remover if in doubt.

How to use it

  1. Choose one or more JPEGs.
  2. Read the report of what was removed.
  3. Download the cleaned files.
  4. Check with the EXIF viewer.

Frequently asked questions

Does it change the pixels?

No. Only the metadata bytes change.

Does it work for PNG or HEIC?

No. Only JPEG. Use the full metadata remover for other types.

Is the location really gone?

The EXIF GPS values are overwritten with zeros. Other places that might hold a location are listed in the notes.

Is anything uploaded?

No. The work happens in your browser and the page makes no network request with your input.
