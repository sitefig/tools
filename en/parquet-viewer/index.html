Parquet File Viewer and CSV Converter (Flat Tables)

Inspect a Parquet file from a data lake or export without Python or Spark.

Use the tool

Why this tool exists

The reader parses the file footer (Thrift compact protocol), the schema, row groups and column chunks, decompresses pages (Snappy decoder included, gzip via the browser) and decodes PLAIN, dictionary, RLE/bit-packed, delta-binary-packed and byte-stream-split encodings with null handling for data pages version 1 and 2. Dates, timestamps (millis, micros, INT96), decimals and strings are formatted. Output was compared value by value with pyarrow on files written with several compression, encoding and page-version settings.

It reads flat tables only: nested structures, repeated fields and ZSTD, LZ4 or Brotli compression are reported as unsupported, since browsers provide no decoders for them. Large files are read in memory, and only the requested number of rows is decoded.

The file is read in your browser and is not uploaded anywhere.

How to use it

  1. Choose a .parquet file.
  2. Set how many rows to read.
  3. View the table, or choose CSV output to copy the rows.
  4. Use a data tool for nested or ZSTD-compressed files.

Frequently asked questions

Why does it say ZSTD is not supported?

Browsers expose no Zstandard decompressor to pages, and third-party code is not used here.

Can it read nested columns?

No, only flat tables.

Is my file uploaded?

No, it is read locally.

Is my data sent anywhere?

The file is read in your browser and is not uploaded anywhere.
