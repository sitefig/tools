JSON to Protobuf (.proto) Generator

Start a Protocol Buffers schema from a sample payload instead of writing it by hand.

Use the tool

Why this tool exists

Objects become messages (named from their keys), arrays become repeated fields, integers become int32 or int64 depending on size, other numbers double, booleans bool and strings string. Field names are converted to snake_case and numbered in order. Nulls and empty arrays have no type information, so they are typed as string and noted at the end.

The result compiles with protoc. A sample cannot tell optional from required, enums from strings or timestamps from text, so review the schema before using it on the wire; field numbers must never change once published.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Paste a representative JSON object.
  2. Set the root message and package.
  3. Copy the .proto output and fix the notes.
  4. Compile with protoc.

Frequently asked questions

Why are nulls typed as string?

A null reveals no type. Change it to the real type.

How are arrays of objects merged?

Keys from all elements are combined into one message.

Is proto3 the right version?

It is the current default; proto2 features such as required fields are not generated.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.

Tools often used together

  • Protobuf Message to Sample JSONParse a .proto (proto2/proto3) file and generate a sample JSON document for a message following the canonical proto3 JSON mapping: lowerCamelCase names, int64 as strings, bytes as base64, enums by name, maps as objects, Timestamp as RFC 3339, oneof (first member only).
  • Protobuf FormatterFormat .proto files: one statement per line, consistent indentation and spacing; comments are kept.
  • Protobuf to JSON SchemaConvert .proto messages and enums to a JSON Schema draft-07 document with definitions, following the proto3 JSON mapping (int64 as numeric strings, bytes as base64, Timestamp as date-time).
  • JSON Schema to ProtobufConvert a JSON Schema (draft-07 / 2020-12 subset with properties, $ref/definitions, enums, arrays, additionalProperties) into proto3 messages: nested objects become messages, arrays become repeated, string enums get an UNSPECIFIED zero value, date-time maps to google.protobuf.Timestamp, non-required fields are optional. oneOf/anyOf with several non-null branches fall back to google.protobuf.Value.
  • JSON to TypeScriptGenerate TypeScript interfaces or types from a JSON sample, merging array elements.
  • JSON to Go StructGenerate Go structs with json tags from a JSON sample.
