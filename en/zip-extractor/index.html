ZIP Extractor

Open a .zip archive and download the files inside one at a time. Unsupported entries are listed with a reason rather than failing silently.

Use the tool

Why this tool exists

A zip arrives and the device cannot open it: a locked-down computer, a phone without an unzip app or a browser-only workstation. Online extractors solve this by uploading the archive to a server, which is a bad idea for contracts, photos or anything with personal data.

This extractor reads the archive on your device. It lists every entry, then inflates each stored or deflate-compressed file and offers it as a separate download. Folder structure is flattened in the file names, because downloads cannot create folders. Entries that use encryption or ZIP64, or an unusual compression method, are marked as skipped. As a safety measure it refuses archives that would expand beyond 1.5 GB, and downloads are capped at 300 files per run.

How to use it

  1. Choose a .zip file from your device.
  2. Run the tool.
  3. Read the list of entries and any that were skipped.
  4. Download the extracted files from the results.

Frequently asked questions

Which zip features are not supported?

Encrypted entries, ZIP64 archives and compression methods other than stored and deflate (such as bzip2 or LZMA). These entries appear in the list marked as skipped, with the reason.

Why is there a 1.5 GB limit?

Extraction happens in browser memory, so a very large or deliberately booby-trapped archive could crash the tab. The tool checks the declared uncompressed size and refuses anything above 1.5 GB.

What happens to folders?

Directories are listed, but each file is downloaded on its own, so path separators in names are replaced with underscores. For a full folder tree use a desktop unzip tool.

Are my files uploaded?

No. The archive is read and decompressed in your browser, and the downloads are generated on your device. Nothing is sent to any server.
