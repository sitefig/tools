Competitor Comparison Matrix

Edit a table of features against your product and your competitors, add or remove rows and columns, and copy the result as a Markdown table or CSV.

Use the tool

Why this tool exists

Comparing yourself with competitors forces useful questions: which features really differ, what do they charge, who has a free plan? A table makes the gaps visible, but formatting Markdown tables by hand is fiddly, and pasting from a spreadsheet loses pipes and alignment.

This tool gives you a small grid to fill in. Start with your product and two rivals, add rows for each feature and columns for more competitors, and the Markdown and CSV versions update as you type. The table is stored in your browser so it is still there next time. It never leaves your device, so competitive notes stay private. Check every claim against the competitor's own pages.

How to use it

  1. Edit the column headings to name your product and each competitor.
  2. Fill in the cells for each feature row. Rename the feature labels as needed.
  3. Use + Row, + Competitor, - Row and - Column to resize the table.
  4. Copy the Markdown or CSV output from the boxes below the table.

Frequently asked questions

Is the table saved?

Yes, in your browser's local storage as you type. It stays on this device and browser only. Clearing site data removes it, so copy important tables elsewhere.

Can I use the Markdown in GitHub or a wiki?

Yes. It is standard pipe-table Markdown, and vertical bars in your text are escaped. Most Markdown renderers, including GitHub, display it as a table.

How do I open the CSV in a spreadsheet?

Copy the CSV box, save it as a .csv file or paste it into a new sheet. Cells with commas, quotes or line breaks are quoted properly.

Does it fetch competitor data?

No. You type everything yourself, and the page makes no network requests for it. Verify competitor facts from their public pages before you publish a comparison.
