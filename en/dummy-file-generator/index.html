Dummy File Generator (Exact Size)

Builds a file of the exact number of bytes you ask for and offers it as a download.

Use the tool

Why this tool exists

When you test upload limits, quotas or slow connections, you need files of a precise size. Enter the size in bytes, KB, KiB, MB, MiB, GB or GiB and download it. Decimal units use 1000, binary units use 1024.

Zero bytes and repeating text compress to almost nothing, so choose random bytes if a server or proxy compresses uploads. The file is built in memory in your browser and is limited to 256 MiB so the tab stays responsive.

How to use it

  1. Enter the size and unit.
  2. Choose the content type.
  3. Set the file name.
  4. Download the file.

Frequently asked questions

Is the size exact?

Yes. The file has exactly the number of bytes shown in the result.

Why is there a 256 MiB limit?

The file is built in browser memory. Larger files could crash the tab.

What is the difference between MB and MiB?

MB is 1,000,000 bytes and MiB is 1,048,576 bytes.

Is any data uploaded?

No. The file is made locally.
