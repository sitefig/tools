React Hook Form Generator

Describe your form fields in a short list and get a React Hook Form component with validation rules. Choose TypeScript and an optional Zod schema with the Zod resolver.

Use the tool

Why this tool exists

Every form needs the same boilerplate: useForm, a register call for each input, error messages and a submit handler. Writing that for a ten-field form is repetitive, and keeping types, rules and markup in step is where bugs creep in.

List each field as a name, a type and optional rules such as required, min, maxLength, pattern or options for a select. The tool generates a component with the right input elements, register calls with rules and error output, plus a FormValues type. Switch on the Zod option and the rules move into a schema used by zodResolver. The markup is deliberately plain, so you can style it to your design system. Treat the result as a starting point. Nothing leaves your browser.

How to use it

  1. Write one field per line: name, type, then rules like required or minLength=2.
  2. For a select, add options=a|b|c.
  3. Set the component name and tick TypeScript and Zod resolver as needed.
  4. Copy the component into your project and style the markup.

Frequently asked questions

Which field types are supported?

text, email, password, number, tel, url, date, textarea, checkbox and select. A select must have options, written as options=free|pro|team.

Which rules can I add?

required, min, max, minLength, maxLength and pattern. With the Zod option on, they become schema checks; otherwise they are passed to register with messages.

What packages do I need?

react-hook-form always. With the Zod option you also need zod and @hookform/resolvers. The generated code imports them for you.

Does it style the form?

No. The markup is plain HTML with labels and error paragraphs, so you can apply your own classes or replace the inputs with components from your UI library.
