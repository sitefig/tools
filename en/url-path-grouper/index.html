URL Sorter and Folder Counter: Sort URLs by Path and Depth

Groups URLs under their folders at the level you choose, counts them, shows the depth distribution and lists the URLs sorted by path.

Use the tool

Why this tool exists

A flat list of thousands of URLs hides the structure of a site. Counting by folder shows where the pages are, which sections are large and how deep the site goes.

Pick the folder level (1 = first folder, 2 = first two folders). A URL that is a file or page directly in a folder counts toward that folder; the last path segment is never treated as a folder. Nothing is requested: it only reads the list.

How to use it

  1. Paste your URLs.
  2. Choose the folder level and order.
  3. Read the folder table and depth table.
  4. Switch off the URL list if you only need the counts.

Frequently asked questions

What does depth mean here?

The number of path segments. The home page is 0, /blog/post is 2.

Is the last segment a folder?

No. /shop/widgets groups under /shop/ with widgets as the page.

Does it handle hosts?

Only the path is used for grouping, so different hosts with the same path end up together.

How big a list can it take?

Tens of thousands of lines are fine in a modern browser.
