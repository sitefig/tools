Sleep Noise Player with Timer

Plays continuous noise and stops it by itself after the number of minutes you choose, with a 20 second fade at the end.

Use the tool

Why this tool exists

Steady noise helps some people fall asleep, block out a neighbour or focus. A timer means it does not run all night. White noise is bright and hissy, pink noise is balanced like steady rain, and brown noise is deep like a distant rumble.

The noise is generated in your browser as a looped buffer, so it works offline once the page is loaded. Keep the volume low enough to hear what is going on around you if that matters. The countdown is shown on screen but is not read out every second by screen readers; start and stop messages are.

How to use it

  1. Pick a noise colour.
  2. Set the volume and the timer in minutes.
  3. Press Start.
  4. The sound fades out and stops when the time is up, or press Stop.

Frequently asked questions

Which colour is best for sleep?

It is personal. Many people prefer pink or brown because they are less harsh than white.

Does it keep playing if the screen locks?

It depends on your device and browser. Some phones suspend audio from web pages; test it before bedtime.

Is the sound a recording?

No. It is generated live, so there is no audible repeat beyond a loop of a few seconds.

Can I leave the timer off?

Set a long timer, up to 720 minutes.
