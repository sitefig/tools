Elementary Cellular Automaton Generator (Rule 30, 90, 110, Any Rule 0-255)

Watch simple rules produce complex patterns, and download the picture as SVG.

Use the tool

Why this tool exists

Each cell looks at itself and its two neighbours; the 8-bit rule number lists the new state for each of the eight neighbourhoods. The tool builds the generations row by row (with periodic or fixed boundaries) and draws them as text and as an SVG. Output for rules 0, 30, 90, 110, 184 and 255 was compared with an independent implementation.

Rule 30 is chaotic, rule 90 draws the Sierpinski triangle and rule 110 is Turing complete. Wide, long runs make large images, so size is limited to 400 cells.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Enter a rule number from 0 to 255.
  2. Set width and generations.
  3. Choose a single-cell or random start.
  4. Download the SVG or copy the text.

Frequently asked questions

What does the rule number mean?

Write it in binary; each bit gives the next state of the neighbourhood 111, 110, 101, 100, 011, 010, 001, 000.

Which rules are interesting?

Try 30, 54, 60, 90, 110, 150 and 184.

Is it the same as Conway's Game of Life?

No. Life is two-dimensional; these automata are one-dimensional rows evolving over time.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
