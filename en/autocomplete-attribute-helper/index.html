Autocomplete Attribute Helper for WCAG 1.3.5 Input Purposes

Suggests and validates autocomplete tokens for form fields.

Use the tool

Why this tool exists

The autocomplete attribute lets browsers fill fields and lets assistive tools show the purpose (WCAG 1.3.5).

The tool guesses a token from the field type, name, id, label and placeholder, and checks existing values against the HTML autofill field names, section and shipping or billing prefixes, and contact types. Guesses are keyword based, so check each.

How to use it

  1. Paste the form HTML.
  2. Read the table of current and suggested values.
  3. Add or fix the attribute.
  4. Skip fields not about the user.

Frequently asked questions

Does it apply to search boxes?

No. Only fields collecting information about the user.

Is autocomplete="off" allowed?

It blocks autofill, so on user data fields it conflicts with 1.3.5.

Where do the tokens come from?

The HTML Standard autofill field names, read in October 2026.

Is the form uploaded?

No.
