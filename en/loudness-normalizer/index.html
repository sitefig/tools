Loudness Normalizer (LUFS Target)

Measures the integrated loudness of an audio file in LUFS and applies the gain needed to reach a target, with a peak ceiling so the result does not clip.

Use the tool

Why this tool exists

Peak normalising makes a file reach 0 dB at its loudest instant, which says little about how loud it sounds. Loudness in LUFS is a better match for what people hear, and broadcasters and streaming services use it to level programmes.

The measurement follows ITU-R BS.1770-4: a K-weighting filter, 400 ms blocks with 75 percent overlap, an absolute gate at -70 LUFS and a relative gate 10 LU below the average. We checked it against ffmpeg's ebur128 filter and it agrees to the tenth of a LU. The true peak value is an estimate from 4x cubic oversampling, not a certified meter.

How to use it

  1. Choose an audio file.
  2. Enter the target LUFS and the peak ceiling.
  3. Pick what to do when peaks would exceed the ceiling: reduce the gain, limit the peaks or allow clipping.
  4. Press Run and download the WAV, or tick "only measure" to read the loudness.

Frequently asked questions

Which target should I use?

EBU R128 broadcast uses -23 LUFS. Streaming services and podcast platforms publish their own values, often between -14 and -16. Check the current guidance of the service you upload to.

What does "limit peaks" do?

It applies a simple look-ahead limiter so no sample goes above the ceiling while keeping the loudness target. It is not a mastering limiter; heavy limiting can change the sound.

Why did I not reach the target?

With "reduce gain", the tool lowers the gain to keep peaks under the ceiling. Use "limit peaks" to get closer to the target.

Does it handle surround files?

Up to six channels are read as L R C LFE Ls Rs with the BS.1770 weights. Most files are mono or stereo.
