X.509 Certificate Viewer

Paste a PEM certificate and see who it was issued to and by whom, when it expires, which names it covers, its key type and its SHA-1 and SHA-256 fingerprints.

Use the tool

Why this tool exists

Certificate problems show up as vague browser warnings or failed TLS handshakes: wrong name, expired, wrong chain. Reading the certificate itself usually answers the question, but openssl commands are hard to remember and a PEM block is unreadable by eye.

This viewer parses the certificate in your browser and lists the subject, issuer, serial number, validity period, public key, key usage and Subject Alternative Names. It tells you whether the certificate is valid now or how long ago it expired, and calculates the fingerprints used in pinning and trust-store checks. A certificate is public data, but nothing is uploaded in any case.

How to use it

  1. Paste one or more PEM certificates, from -----BEGIN CERTIFICATE----- to -----END CERTIFICATE-----.
  2. Run the viewer.
  3. Check the subject, issuer, validity status and Subject Alternative Names.
  4. Copy the fingerprints or other fields you need.

Frequently asked questions

Does it validate the certificate chain?

No. It parses and displays one certificate at a time and does not check signatures, revocation or trust. A "valid" status here only means the current date is inside the validity period.

What certificate formats does it accept?

PEM text, or just the Base64 body. DER binary files, PKCS#12 bundles and keys are not supported. Convert with openssl or export as Base64 PEM first.

Which fields does it show?

Subject, issuer, version, serial, signature algorithm, validity dates, public key type and size, and common extensions: Subject Alt Names, Basic Constraints, Key Usage, Extended Key Usage and key identifiers. Other extensions are listed by name or OID with their size.

Can I paste a private key?

Do not. This tool needs only the public certificate. A private key must never be pasted into a web page you cannot fully trust, and anything labelled PRIVATE KEY is not parsed here.
