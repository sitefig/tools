Redirect Chain Analyzer (from curl -IL output)

Turn the raw output of a redirect check into a readable chain with the status of each hop and a list of SEO problems.

Use the tool

Why this tool exists

Run curl -sIL URL (or copy response headers from your browser), paste the output and the tool lists each hop with its status, Location and cache-control, resolves relative Locations against the start URL, and flags loops, temporary redirects where a permanent one is expected, downgrades from https to http, chains of several redirects and chains that end in an error.

The page cannot fetch URLs itself (browsers block cross-site requests), so you supply the headers. Aim for at most one redirect between a link and its final URL.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Run curl -sIL https://example.com/old in a terminal.
  2. Paste the full output, including all hops.
  3. Optionally enter the start URL so relative redirects resolve.
  4. Fix chains longer than one hop and replace 302s with 301/308 where the move is permanent.

Frequently asked questions

How many redirects are too many?

One is fine. Googlebot follows up to about 10 hops, but every extra hop wastes crawl budget and slows users.

301 or 302?

Use 301 or 308 for permanent moves and 302 or 307 for temporary ones. Search engines treat them differently.

Can this tool check a URL for me?

No, it only analyses headers you paste. A browser extension could fetch them.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
