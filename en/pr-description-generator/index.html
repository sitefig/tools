Pull Request Description Generator (from a git diff)

Generate a structured pull request description from a git diff.

Use the tool

Why this tool exists

Good PR descriptions save reviewers time. This generator reads a unified diff and produces a draft: a suggested title, a summary of files grouped by area (source, tests, database, dependencies, config, docs), line counts, review notes (no tests, new dependencies, migrations, large files, TODOs added, secret-looking lines) and a checklist.

It is rule-based, not an AI: it describes what changed, not why, so always add the reason and your testing. The diff never leaves your browser, which matters for private code.

How to use it

  1. Run git diff main...HEAD (or git show) and copy the output.
  2. Paste it here.
  3. Copy the draft into the PR and add the why.

Frequently asked questions

Does it use AI?

No, simple rules over the diff.

Is my code uploaded?

No, parsing happens in your tab.

Which diff format?

Unified diffs with "diff --git" headers, as printed by git.
