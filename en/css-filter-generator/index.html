CSS Filter Generator

Assembles a CSS filter property from sliders-style inputs: blur, brightness, contrast, grayscale, hue-rotate, invert, opacity, saturate and sepia. Only changed values are included.

Use the tool

Why this tool exists

CSS filters can recolour an icon, dim an image on hover, or soften a background, all without editing the picture. The syntax is simple, but the effect of combining several is hard to predict, and the order matters.

Enter values for the filters you want, leave the rest at their defaults, and the tool writes a clean declaration that leaves out anything unchanged. A sample image shows the result, so you can see how a hue rotation interacts with a saturation boost. The preview is a colourful gradient rather than your own image, so use it to find a recipe, then test on the real thing. It all runs in your browser.

How to use it

  1. Set the filter values you want to change.
  2. Leave the others at their defaults so they are left out.
  3. Look at the preview, which updates as you type.
  4. Copy the filter line.

Frequently asked questions

In what order are the filters applied?

In the order they are written, and this tool writes them in a fixed order: blur, brightness, contrast, grayscale, hue-rotate, invert, opacity, saturate, sepia. If you need a different order, edit the copied line.

What are the default values?

Blur, grayscale, hue-rotate, invert and sepia default to 0. Brightness, contrast, opacity and saturate default to 100%. A value at its default is omitted, and no change at all gives filter: none.

Does filter affect performance?

Heavy blur on big areas or animated filters can be expensive to render. Use modest values, and avoid animating them across large elements.

How is this different from the Image Filters tool?

This tool only writes CSS for use in a web page. The Image Filters tool bakes the effect into a new image file that you can download.
