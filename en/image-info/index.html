Image Info

Reads one or more images and reports their type, file size, pixel dimensions, megapixels, aspect ratio, whether they contain transparency, average brightness and five dominant colours.

Use the tool

Why this tool exists

Before you upload an image to a CMS, send it to a printer or write a CSS rule for it, you often need to know a few basics: how big is it in pixels, is it really a PNG, does it have an alpha channel, what ratio is it? Right-clicking through properties dialogs differs on every system and rarely shows all of that.

Drop in your files and each gets a short report. Transparency is detected by scanning a reduced copy of the image, and dominant colours come from a median-cut palette with the share of each. Several images can be checked at once, which is helpful when auditing a folder. Reading happens in your browser, so private pictures do not leave your device. EXIF metadata is not shown here.

How to use it

  1. Choose one or more image files.
  2. Run the tool.
  3. Read the report for each image: type, size, dimensions, ratio, transparency and colours.
  4. Copy any values you need.

Frequently asked questions

What does the transparency check look at?

It scans a reduced copy of the image and reports yes if any pixel has an alpha value below fully opaque. A PNG with a fully opaque image will say no, even though the format could hold transparency.

How are dominant colours chosen?

The image is shrunk, then the median-cut method groups similar colours and averages each group. The five largest groups are listed as hex values with their approximate share of the picture.

Does it show camera details or location?

No. It reports basic properties only. To read EXIF metadata such as the camera model or GPS position, use the EXIF viewer.

What is average brightness?

The mean perceived lightness of all pixels as a percentage, using standard luminance weights. 0 is black and 100 is white. It gives a rough idea of how dark or light the picture is.
