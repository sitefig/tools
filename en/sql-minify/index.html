SQL Minifier

Remove comments and extra whitespace from SQL and get a compact query. Quoted strings are kept exactly, so values containing double spaces or dashes are not damaged.

Use the tool

Why this tool exists

A formatted query is great in an editor, but you sometimes need it on one line: in a log message, a configuration value, a code string, or a command line. Collapsing it by hand risks cutting into a string literal or leaving a comment that swallows the rest of the line.

The minifier deletes line and block comments, collapses runs of whitespace into a single space and trims spaces around punctuation. String literals are recognised and copied unchanged, so a value like 'a -- b' stays exactly as written. Because comments are removed, the single-line result cannot be broken by a trailing -- comment. The tool does not check whether the SQL is valid. Nothing is uploaded; everything happens in your browser.

How to use it

  1. Paste your SQL into the input box.
  2. Read the single-line result in the output.
  3. Copy it into your code, log or configuration.

Frequently asked questions

Are string values safe?

Yes. Text inside single-quoted strings is copied as it is, including double spaces and characters that look like comments, such as -- or /*.

Why remove comments?

On one line, a -- comment would hide everything after it. Removing comments avoids that, and also makes the result shorter.

Does it check SQL syntax?

No. It only removes whitespace and comments and does not parse the query as a whole. A query with a mistake stays wrong after minifying, so test it in your database.

How do I make it readable again?

Paste the minified query into the SQL Formatter. It restores line breaks and indentation, but any comments that were removed earlier cannot be brought back.
