Thin Content Detector (Unique Words per Page)

Counts total, shared and unique words for each pasted page.

Use the tool

Why this tool exists

Word count alone overstates thin pages, because every page includes the menu and footer. Removing lines that repeat across most pages leaves the part that is actually unique.

Paste pages separated by --- and an optional URL line. Boilerplate removal needs at least 3 pages. A short page can still be good, so treat the ranking as a list to read, not a verdict.

How to use it

  1. Paste each page, separated by a line with ---.
  2. Start a page with URL: to label it.
  3. Set the thin threshold and boilerplate share.
  4. Review the pages marked THIN.

Frequently asked questions

How is boilerplate found?

Lines that appear on a set share of the pages, default 60%.

Can I paste HTML?

Yes. Scripts and styles are removed.

Is there a standard threshold?

No. Pick one that fits your content.

Does it detect duplicates?

Not between pages. Use the similarity checker for that.
