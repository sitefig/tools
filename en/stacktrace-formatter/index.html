Stack Trace Formatter (Java, Python, JavaScript, .NET, Go)

Make a long exception readable: the failing exception and message at the top, your own frames highlighted, framework frames folded away.

Use the tool

Why this tool exists

The formatter detects Java/Kotlin, Python, JavaScript/Node, .NET and Go traces, extracts the exception types and messages (including Caused by chains), lists frames with file and line, and collapses frames from common libraries when you name your own package or path (for example com.acme). It reports the first frame in your code.

Parsing is by pattern, so unusual log prefixes or truncated traces may need trimming. Remember that Java, JavaScript and .NET list the throw site first, while Python and Go list the most recent call last.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Paste the trace.
  2. Enter a package or path that identifies your code.
  3. Keep "collapse library frames" on for a short view.
  4. Start debugging at the first highlighted frame.

Frequently asked questions

Which languages are supported?

Java/Kotlin, Python, JavaScript/Node, .NET and Go panics.

Does it remove sensitive paths?

No, it shows frames as pasted. Remove secrets before sharing.

Why are frames hidden?

Frames that match common library prefixes are collapsed to keep the focus on your code; switch the option off to see all.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
