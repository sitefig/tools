Mesh Gradient Image Maker: PNG and SVG Backgrounds

Turns a list of coloured points into a soft blended background and exports it as a PNG image or an SVG file.

Use the tool

Why this tool exists

The existing mesh gradient tool outputs CSS. This one produces files for slides, design tools and hero images. Each line gives a position, a colour and an optional radius. Points fade into the background colour with radial gradients.

SVG output is small and scales to any size. PNG output is fixed in pixels. Point positions are typed, which keeps the tool usable with a keyboard.

How to use it

  1. Enter one point per line: x percent, y percent, colour and optional radius percent.
  2. Set the size and background colour.
  3. Choose PNG or SVG.
  4. Download the image.

Frequently asked questions

Can I drag the points?

No. Edit the numbers; the preview updates when you run it again.

What does the radius mean?

The spread of a point as a percent of the longer side.

Is the SVG the same as the PNG?

Very close. Both use radial gradients that fade to transparent.

Can I use CSS instead?

The Mesh Gradient Generator gives CSS.
