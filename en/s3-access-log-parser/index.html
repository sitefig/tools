S3 Server Access Log Parser: Requesters, Operations and Bytes

Parses S3 server access logs and shows who requested what, with errors and bytes sent.

Use the tool

Why this tool exists

S3 access logs are one object per few minutes, each with many lines. Finding who downloaded a key or who got AccessDenied means reading them all.

The parser reads the bracketed time and quoted request fields and maps them to the documented field order. Anonymous requests show as anonymous.

How to use it

  1. Download the log objects and paste them or choose the files.
  2. Filter by status such as 403.
  3. Read operations, requesters and top keys.
  4. Switch to the table for each request.

Frequently asked questions

Where do the logs come from?

From server access logging on a bucket, delivered to another bucket.

Is this CloudTrail?

No. CloudTrail data events are a different log; use the CloudTrail viewer.

What if some lines do not match?

They are skipped and the result says how many. Lines with fewer than 17 fields are skipped.

Is my log uploaded?

No. Parsing happens in your browser and nothing is sent. Logs can hold IP addresses and tokens, so the page does not write them into the address bar.
