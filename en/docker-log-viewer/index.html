Docker Log Viewer: docker logs --timestamps with Streams and Gaps

Reads timestamped docker logs, JSON-file driver lines and CRI lines and shows streams, gaps and levels.

Use the tool

Why this tool exists

docker logs --timestamps puts an RFC 3339 time in front of each line. This tool uses it to show time between lines, so pauses and bursts stand out.

Plain docker logs text does not say whether a line came from stdout or stderr. The stream is known only for JSON-file log files and CRI lines, and the summary says so when it is unknown.

How to use it

  1. Run docker logs --timestamps NAME > app.log.
  2. Paste the output or choose the file.
  3. Filter by stream or text.
  4. Read the longest gaps in the summary.

Frequently asked questions

Why is the stream unknown?

docker logs prints both streams without marking them. Use the JSON log file in /var/lib/docker/containers for the stream.

Which levels are detected?

Words such as ERROR, WARN and INFO in the message.

Does it work for compose logs?

Compose prefixes lines with the service name; those lines are shown as plain message text.

Is my log uploaded?

No. Parsing happens in your browser and nothing is sent. Logs can hold IP addresses and tokens, so the page does not write them into the address bar.
