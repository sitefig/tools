Base64 to PDF

Decodes a Base64 string or a data:application/pdf URI back into a PDF file, checks it starts with the %PDF header, and offers it for download.

Use the tool

Why this tool exists

APIs often return documents as Base64 inside JSON: invoices, labels, contracts, reports. When something goes wrong you are left staring at a wall of letters and no idea whether it is a valid PDF. Pasting the string here turns it back into a file you can open, and tells you early if it is not a PDF at all or looks cut off. That makes it a quick debugging step when an integration returns an empty page, a truncated payload or the wrong content type. Because the decoding runs in your browser, confidential documents are not sent to any server, which is the main reason to prefer it over a random online converter.

How to use it

  1. Paste the Base64 text, or the full data:application/pdf;base64 URI, into the input box.
  2. Set the file name you want for the download, such as invoice.pdf.
  3. Run the conversion, read the byte count and PDF version, then download the file.

Frequently asked questions

What checks are made on the data?

The text is decoded, then the first five bytes must be %PDF-. If not, you get an error. The tool also looks for %%EOF near the end and warns if it is missing, which often means truncation.

Can I paste a data URI or JSON string?

Yes. A data: prefix is stripped, and surrounding double quotes are removed. Whitespace and line breaks inside the Base64 are ignored. Base64URL characters are accepted too.

Why does the PDF open blank or fail?

The header can be valid while the file is damaged. A missing %%EOF warning, a cut-off string or double-encoded data are the usual causes. Check what your API sent.

Is a large PDF a problem?

Everything is held in memory in your browser, so files of many megabytes work but may feel slow. Nothing is uploaded at any point.
