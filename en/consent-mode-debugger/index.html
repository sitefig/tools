Consent Mode gcs and gcd Decoder

Decodes the gcs and gcd parameters from Google tag requests to show the consent state of each signal.

Use the tool

Why this tool exists

When you debug Consent Mode you look at network requests and see values like gcs=G101 or gcd=13r3r3q3q5. They are hard to read by eye.

This tool extracts both parameters from a URL or a pasted value and spells out each signal. The gcs form is the original one. Google does not publish the gcd format, so the letter table comes from third-party documentation and may change. Use it as a debugging aid and confirm with Google's own tools when it matters.

How to use it

  1. Open dev tools, Network tab, and find a request to a Google domain such as google-analytics.com/g/collect.
  2. Copy the request URL.
  3. Paste it, or just the gcs and gcd values, one per line.
  4. Read the state for each signal.

Frequently asked questions

Why is gcd not officially documented?

Google has not published the format. The mapping used here comes from CookieHub documentation and may be incomplete.

What does a letter like r mean?

Denied by default, then granted by an update call. Other letters are listed in the output.

Does it need the whole URL?

No. A value like gcd=13r3r3q3q5 is enough.
