Pomodoro Timer with Notifications and Session Count

Cycles focus, short break and long break intervals you set, beeps and optionally notifies at each change, and counts focus sessions.

Use the tool

Why this tool exists

The Pomodoro method alternates focus and rest. Here you set the lengths and how many sessions come before a long break.

Allow notifications if you want a pop-up when the tab is hidden. Browsers may slow timers in background tabs, so the end time is checked against the clock.

How to use it

  1. Set focus, break and long break minutes.
  2. Press Start focus.
  3. Allow notifications if you want them.

Frequently asked questions

Do notifications need permission?

Yes. Press Enable notifications. Without it you still get a sound.

Will it run in a background tab?

Usually, but browsers may delay checks by a few seconds.

Is the count saved?

No, it resets when you leave the page.
