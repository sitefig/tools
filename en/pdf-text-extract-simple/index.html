PDF Text Extractor (simple)

Extract text from PDFs that use simple fonts and plain or Flate-compressed content. It cannot read most modern documents or scanned pages.

Use the tool

Why this tool exists

Sometimes you just want the words out of a PDF: to paste into an email, search, or run through a word counter. This tool exists for the simple cases and is honest about the rest. It reads the page content streams and pulls out text drawn with simple fonts, such as many invoices, reports from older systems and generated documents.

It will not work on files where text uses subset-embedded or composite fonts with Identity-H encoding, which covers most output from Word, Chrome print-to-PDF and LaTeX. In those the codes are not Unicode, so the result is empty or garbled. It also cannot read scanned pages, which are pictures of text and need OCR. When it cannot succeed it warns you. Processing is local, and there is no upload.

How to use it

  1. Choose a PDF file.
  2. Keep Page separators ticked to see where each page starts.
  3. Run the tool.
  4. Copy the extracted text, and read any warnings about fonts.

Frequently asked questions

Why is the result empty or garbled?

The PDF probably uses composite fonts with Identity-H encoding, which most Word, Chrome and LaTeX files do, or it is a scan. This tool cannot map those glyph codes to characters, so use a full PDF reader or an OCR tool.

Does it handle encrypted PDFs?

No. Encrypted files are refused with a message. Remove the restriction using the software that created the file, if you have the right to do so.

Which filters can it read?

Uncompressed and Flate-compressed content streams. Streams using other filters are skipped, and the output tells you how many were left out.

Is the layout kept?

Only roughly. Text is returned in drawing order with line breaks where the file moves to a new line. Columns, tables and reading order can come out jumbled.
