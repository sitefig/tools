SHA-3 / Keccak / SHAKE Hash Generator

Computes SHA3-224, 256, 384 and 512, Keccak-256 and Keccak-512 (the pre-standard padding used by Ethereum), and SHAKE128 and SHAKE256 with a chosen output length, from text or hex bytes.

Use the tool

Why this tool exists

SHA-3 is the newer NIST hash standard, but browsers do not provide it in Web Crypto, so common online hash tools skip it or hide it. Developers still meet it: Ethereum uses Keccak-256, which differs from standard SHA3-256 only in padding and so gives a completely different digest. People mix them up and wonder why a hash does not match a contract. This tool shows all variants side by side, plus the SHAKE extendable-output functions with an output length you choose. The Keccak permutation is written in plain JavaScript, so it works anywhere but is slow for megabytes of data. It is meant for text, test vectors and short inputs. Hashing happens in your browser; nothing is uploaded.

How to use it

  1. Type or paste the input, and choose whether it is UTF-8 text or hex bytes.
  2. Leave "Show all algorithms" on, or turn it off and pick one algorithm. Set the SHAKE output length if needed.
  3. Copy the digest you need, in lower or upper-case hex.

Frequently asked questions

What is the difference between SHA3-256 and Keccak-256?

They use the same core function but different padding, so they produce different digests for the same input. Ethereum uses Keccak-256, whereas NIST standardised SHA3-256.

What are SHAKE128 and SHAKE256?

Extendable-output functions: instead of a fixed length, you ask for as many bytes as you need. The tool lets you set the output length in bytes.

Can I hash binary data?

Yes. Choose hex bytes as the input type and enter the bytes as hex. Text input is encoded as UTF-8 first.

Is it fast enough for big files?

No. It is pure JavaScript, which is fine for text and test vectors but slow for megabytes. Use a native tool for large files.
