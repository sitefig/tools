Coordinate Format Converter (Decimal, DMS, UTM, MGRS, Plus Code)

Reads a coordinate in any of five formats and shows it in all of them: decimal, DMS, degrees and decimal minutes, UTM, MGRS and Plus Code.

Use the tool

Why this tool exists

Surveyors, hikers, pilots and GIS users meet the same point written five ways. This tool converts between them with the WGS 84 ellipsoid and no server. UTM uses the Krueger series, checked against PROJ (pyproj) on 300 random points: all within 0.5 m of the metre-rounded output. MGRS and Plus Codes matched independent libraries on the same points.

Inputs are detected by shape: an MGRS reference such as 18TWL8040712345, UTM as 31U 448251 5411932, a full Plus Code, or a latitude and longitude with N S E W letters, symbols, or signs. UTM covers latitude -80 to 84; near the poles it reports that it is not defined here. Short Plus Codes need a reference location, so use the Plus Code tool for them.

How to use it

  1. Type one position per line in any supported format.
  2. Pick the Plus Code length you want in the output.
  3. Read decimal, DMS, DDM, UTM, MGRS and Plus Code for each line.
  4. Copy the text.

Frequently asked questions

Which datum?

WGS 84 only. Positions from local datums need a datum shift first.

What does the zone letter mean?

The latitude band; C to M are south of the equator, N to X north.

Does it handle Norway and Svalbard zone exceptions?

Yes.

How accurate is UTM?

Better than a millimetre in the maths; the output is rounded to whole metres.
