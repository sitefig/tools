HTML lang, Content-Language and Hreflang Consistency Checker

Reads the language signals on one page and flags missing, invalid or contradicting values.

Use the tool

Why this tool exists

A page can state its language in the lang attribute, in a meta tag, in an HTTP header and in its own hreflang entry. They are meant to agree. The tool pulls each out of your pasted HTML and headers, validates the tags (hyphens, ISO language and region codes) and compares them.

A missing lang attribute is an accessibility failure (WCAG 3.1.1). Disagreeing signals are usually a template mistake. Google does not use lang or hreflang to detect language, so the checks are about consistency and accessibility.

How to use it

  1. Paste the page HTML and, optionally, the response headers.
  2. Read the list of signals found.
  3. Fix errors such as underscores or missing lang.
  4. Make the signals agree.

Frequently asked questions

Which signals are compared?

html lang, xml:lang, meta content-language, the Content-Language header and the hreflang entry for the canonical URL.

Are different regions an error?

A warning: same language, different region.

Do I need Content-Language?

No, it is optional.

Can it fetch the headers?

No; copy them from DevTools or curl -I.
