Link Purpose Checker: Vague, Duplicate and New-Window Links

Reviews links for purpose, names and new-window behaviour.

Use the tool

Why this tool exists

Screen reader users often browse a list of links, where "click here" means nothing.

The tool finds unnamed links, vague phrases, long URLs as text, repeated link text with different targets, target=_blank without a hint, and file links without a format. Under WCAG 2.4.4 context can fix a vague link, so most items are marked review.

How to use it

  1. Paste the HTML.
  2. Read the findings.
  3. Rewrite link text to say where it goes.
  4. Mention new windows and file types.

Frequently asked questions

Is "read more" always a failure?

No, if the context makes it clear. It is still weak in link lists.

Is opening a new tab required to be announced?

It is best practice, not a WCAG requirement.

How is a name computed?

From link text, image alt and aria-label in simplified form.

Is the HTML uploaded?

No.
