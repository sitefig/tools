Markdown Table to CSV

Pulls GitHub-style pipe tables out of Markdown and converts them to CSV, TSV or JSON, either the first table or every table in the document.

Use the tool

Why this tool exists

Tables in READMEs, wiki pages and pull request descriptions are easy to read but awkward to reuse. If you want the numbers in a spreadsheet or a script, copying cell by cell is tedious, and pasting the raw pipes into Excel gives a mess. This tool finds each table by its header row and the dashed separator beneath it, then outputs clean rows. It understands escaped pipes inside cells and can strip bold, italics, code ticks and link syntax so you get plain values. It works on the whole document, so you can paste an entire README and pick the table you need. Nothing is uploaded; the parsing happens in the page.

How to use it

  1. Paste the Markdown, which may contain text around the tables, into the input box.
  2. Choose whether to convert the first table or all tables, and pick CSV, TSV or JSON.
  3. Leave "Strip emphasis / code / links" on for plain values, then copy the output.

Frequently asked questions

How does it recognise a table?

It looks for a line with a pipe followed by a separator row of dashes such as |---|:--:|. Lines after that with pipes belong to the table until a blank line ends it. Text without a separator row is ignored.

What about pipes inside a cell?

An escaped pipe (\|) is treated as a literal character and written back as a plain pipe. CSV cells containing commas, quotes or line breaks are quoted properly.

What does the strip option remove?

It removes bold, italic, strikethrough and code markers, turns [text](url) links and images into their text, and turns line-break tags into real line breaks. Turn it off to keep the raw Markdown.

Does it support HTML tables or tables without a header?

No. Only pipe tables with a header row and separator row are supported, in the GitHub style. For HTML tables, use the HTML table tools on this site.
