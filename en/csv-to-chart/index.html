CSV to Chart (Bar, Line, Pie as SVG)

Visualise a table without a spreadsheet or charting library.

Use the tool

Why this tool exists

The first column is used as labels and each other column as a series. Bar and line charts get a scaled axis with rounded tick values; pie charts use the first value column and show percentages in the legend. The SVG includes a title and a text description of the data so assistive technology can read it, and per-item tooltips.

It is built for small tables (up to 60 rows). For dashboards or large data use a dedicated charting tool.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Paste CSV with a header row.
  2. Choose the chart type and size.
  3. Copy or download the SVG.
  4. Add the chart with an alt text or the built-in description.

Frequently asked questions

Can I change the colours?

The palette is fixed; edit the SVG fill values to customise.

Does it support dates on the axis?

Labels are treated as text in order.

Is the chart accessible?

It has a title and description, but you should still provide the data or a summary in text.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
