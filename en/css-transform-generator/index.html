CSS Transform Generator: Rotate, Scale, Skew, Translate and 3D

Combines the common CSS transform functions into one declaration and shows the result on a box. Identity values are left out so the CSS stays short.

Use the tool

Why this tool exists

The transform property takes functions in a fixed order, and the order changes the result: rotate then translate is not the same as translate then rotate. Writing the string by hand and guessing is slow.

This tool builds the declaration in a sensible order (translate, rotate, scale, skew), adds a perspective on the parent only when you ask for it, and warns when translateZ would have no visible effect without perspective. Everything runs locally.

How to use it

  1. Enter values for the functions you need; leave the rest at their defaults.
  2. Pick a transform-origin and, for 3D, a perspective in pixels.
  3. Check the preview box against the dashed outline of the original position.
  4. Copy the CSS.

Frequently asked questions

Why does translateZ do nothing?

Without a perspective on the parent element, depth has no visual effect. Set the perspective field.

Does the order matter?

Yes. Transforms apply right to left on the element. This tool uses translate, rotate, scale, skew.

Is the output safe for old browsers?

The functions used are widely supported. 3D functions need a browser with 3D transforms, which is all current ones.
