CloudFormation Template Generator (S3, Lambda, DynamoDB, SQS)

Start from a template with safe defaults instead of a blank file.

Use the tool

Why this tool exists

The S3 template blocks public access, enables encryption and versioning and retains the bucket on deletion. The Lambda template creates an execution role, the function and a log group with 14-day retention. DynamoDB uses on-demand billing, point-in-time recovery and encryption; SQS uses managed encryption and a dead-letter queue after five receives.

All four templates parse as YAML with CloudFormation tags. Review names, retention and IAM permissions for your account, and validate with aws cloudformation validate-template.

No data is sent anywhere: the work happens in your browser, so you can use it offline once the page has loaded.

How to use it

  1. Choose the resource type and a logical name.
  2. Copy the template.
  3. Validate it with the AWS CLI.
  4. Create the stack and add outputs you need.

Frequently asked questions

Why DeletionPolicy: Retain?

It keeps data when the stack is deleted, which avoids accidental loss.

Is the Lambda code real?

It is a placeholder inline handler; replace it with your package.

Can I add more resources?

Yes. This is a starting point for the Resources section.

Is my data sent anywhere?

No. Everything is processed in your browser, and the page makes no network requests with your input.
