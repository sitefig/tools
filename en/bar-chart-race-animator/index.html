Bar Chart Race Animator (Animated SVG, Pausable)

Builds an animated bar chart race as a CSS-animated SVG from a table with one row per period and one column per item.

Use the tool

Why this tool exists

Races show how rankings change over time. This version creates an animated SVG with CSS keyframes, which you can embed in a page and pause, rather than a video file. WebM or MP4 export is not offered.

The preview has a Pause animation switch, which starts on if you prefer reduced motion. Choose a single period to see a static frame with values. The table under the chart has all numbers, which is also the text equivalent.

How to use it

  1. Paste a table: first column period, other columns items.
  2. Set how many bars to show and seconds per period.
  3. Type a period name to see one still frame.
  4. Download the SVG to keep the animation.

Frequently asked questions

Can I get a video?

Not here. Record the screen or use the SVG on a web page.

Does it loop?

Yes, forever, and you can pause it.

Why no value labels while moving?

Numbers cannot be animated in CSS; the still frame and table show them.

Limits?

120 periods and 60 items.
