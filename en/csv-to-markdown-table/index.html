CSV to Markdown Table

Turn CSV into an aligned GitHub-flavoured Markdown table. Numeric columns can be right-aligned, pipes inside cells are escaped, and line breaks become a br tag.

Use the tool

Why this tool exists

Documentation, README files and pull requests are full of tables, and typing Markdown tables by hand means counting pipes and padding columns. When your data already lives in a spreadsheet, it makes sense to export CSV and convert it.

The tool pads each column so the raw Markdown stays readable in an editor, adds the separator row and, if you wish, right-aligns columns that contain only numbers. A pipe character inside a cell is escaped so it does not break the table, and line breaks inside a cell are replaced by a br tag. The first CSV row becomes the header. Conversion runs in your browser, so internal figures stay private.

How to use it

  1. Paste your CSV into the input box, with column names in the first row.
  2. Pick the delimiter, or leave it on auto.
  3. Tick Right-align numeric columns if you want numbers aligned to the right.
  4. Copy the Markdown table into your README or document.

Frequently asked questions

Does it work outside GitHub?

The output is standard GitHub-flavoured Markdown with pipes and a dashed separator row. Most renderers, including GitLab, Obsidian and many static site generators, understand it.

What happens to a pipe character in a cell?

It is escaped with a backslash so the table structure is not broken. Line breaks inside cells are turned into a br tag, since Markdown tables are one line per row.

How does alignment work?

Columns are padded to equal width for readability. With the right-align option on, a column whose values are all numbers gets a colon in the separator row, so it renders right-aligned.

Can I turn a Markdown table back into CSV?

Yes. Use the Markdown Table to CSV tool in this collection: paste the table and it gives you CSV back, which you can then convert to JSON or SQL.
