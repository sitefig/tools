JSON to XML

Convert JSON into XML with a declaration, a root element of your choice and tidy indentation. Keys beginning with @ become attributes and #text becomes the element text.

Use the tool

Why this tool exists

Plenty of older systems, SOAP services and feed formats still want XML, while your data starts life as JSON. Writing the conversion by hand means deciding how to treat attributes, arrays and special characters, and that is where mistakes creep in.

Here the rules are simple and visible. A key such as @id becomes an attribute, #text holds the text of an element that also has attributes, arrays repeat the element once per item, and null becomes an empty element. Special characters like & and < are escaped for you, and awkward key names are made into legal XML names. Choose the root element name and indent, then copy the result. The conversion runs in your browser and nothing is uploaded.

How to use it

  1. Paste your JSON into the input box.
  2. Enter the name of the root element, for example root or catalog.
  3. Choose the indent size, or tab.
  4. Copy the XML, including its declaration line.

Frequently asked questions

How do I create XML attributes?

Prefix the key with @. For example {"book":{"@id":"42","title":"Dune"}} gives a book element with an id attribute. Use #text for text content when an element also has attributes.

How are arrays written?

Each array item becomes a repeated element with the same name as the array key. A top-level array is wrapped in item elements inside the root element.

What happens to null and special characters?

A null value becomes an empty self-closing element. The characters &, < and > are escaped in text, and quotes are escaped in attributes. Invalid characters in key names are replaced with underscores.

Can I convert the XML back to JSON?

Yes, with the XML to JSON tool. Its attribute prefix defaults to @, matching this tool, so simple documents round-trip.
