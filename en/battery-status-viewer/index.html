Battery Status Viewer (Level, Charging, Time Left)

See the battery level, charging state and the browser's time estimates for this device.

Use the tool

Why this tool exists

The Battery Status API reports the charge level, whether the device is charging and estimated times to full or empty. This viewer shows them with live updates, which is useful for testing web apps that adapt to low battery and for checking a laptop or phone at a glance.

Chrome, Edge and Opera support the API; Firefox and Safari removed or never shipped it because battery data can be used for fingerprinting, and the page says so when it is missing. Desktops without a battery usually report 100% and charging. Nothing is sent anywhere.

How to use it

  1. Open the page in a Chromium browser.
  2. Plug or unplug the charger to see the values update.
  3. Read the level, charging state and time estimates.

Frequently asked questions

Why does it say unavailable?

Your browser does not provide the API (Firefox, Safari).

Why does time say unknown?

Browsers need a few minutes of data after a change before estimating.

Is this private?

Yes, it only reads the values locally.
