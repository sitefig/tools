TOML to JSON

Convert TOML to JSON. Tables, arrays of tables, inline tables, dotted keys, multi-line strings, numbers in several bases and dates are parsed, and errors give a line number.

Use the tool

Why this tool exists

TOML files such as Cargo.toml or pyproject.toml are pleasant to edit but awkward to process with tools that expect JSON. Converting shows how a parser reads your file: which keys end up under which table, how a repeated [[servers]] section becomes an array, and what type a value has.

Paste the TOML and get JSON with your chosen indent. Dotted keys such as site.name are expanded into nested objects, hex and exponent numbers are converted, and dates are kept as strings in a standard form. If the file has a mistake, the error mentions the line, so you can fix it quickly. Parsing is done in your browser and nothing is uploaded.

How to use it

  1. Paste your TOML into the input box.
  2. Choose the indent for the JSON output.
  3. Read the JSON and check how tables and arrays of tables were nested.
  4. Copy the JSON, or fix the TOML at the line named in the error.

Frequently asked questions

How are arrays of tables converted?

Each [[name]] section adds one object to an array called name. Two [[servers]] sections give a servers array with two objects.

How are dates represented?

JSON has no date type, so TOML dates and times are written as strings in their original form, for example "1979-05-27T07:32:00Z". Parse them in your own code.

What if my TOML has an error?

You get a message that begins with TOML error at line N and explains the problem, such as a duplicate key or a bad value.

Can I convert back to TOML?

Yes, with the JSON to TOML tool in this collection. Remember that TOML cannot hold null values, so any nulls in your JSON need to be removed or replaced first.
