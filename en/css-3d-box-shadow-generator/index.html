CSS 3D Box-Shadow Generator (extrude, long, layered, retro)

Create multi-layer box-shadows that look three-dimensional: stepped extrusion, long flat shadow, smooth realistic elevation or a hard retro offset, with colour, depth and direction controls.

Use the tool

Why this tool exists

A single box-shadow gives a soft blur, but depth effects need many layers. A chunky 3D button is a stack of one-pixel steps in the same direction, a long shadow runs diagonally across the page, and a realistic card shadow is made of several soft layers that grow together. Writing twenty values by hand and keeping them consistent is not fun.

This generator builds the stack from a handful of settings: style, shadow and face colour, depth, direction as an angle and opacity for layered shadows. The preview is a button-like block so you can judge the effect directly. Copy the CSS when it looks right. The calculation runs in your browser, so you can experiment freely.

How to use it

  1. Choose a style: 3D extrude, long shadow, layered realistic or hard retro.
  2. Set the shadow colour, face colour and depth in pixels.
  3. Set the direction in degrees, where 0 points right and 90 points down, and the opacity for layered shadows.
  4. Check the preview and copy the CSS into your stylesheet.

Frequently asked questions

Will many shadow layers slow down my page?

A handful of layers on a few elements is fine. Very deep extrusions on many animated elements can cost rendering time, so keep the depth modest and test on a low-end phone.

What does the angle control?

It sets the direction the shadow extends, measured in degrees, with 0 pointing right and 90 pointing down. A 45 degree angle gives the classic bottom-right look.

Which style is best for a button?

The 3D extrude and hard retro styles read as pressable, since you can shrink the offset on :active to make the button look pushed in. Layered realistic is better suited to cards and panels.
