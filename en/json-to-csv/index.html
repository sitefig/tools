JSON to CSV

Convert an array of JSON objects into CSV for spreadsheets. Nested objects can be flattened into dotted column names, and you choose comma, semicolon, tab or pipe as delimiter.

Use the tool

Why this tool exists

APIs return JSON, but analysts, accountants and support teams want rows and columns. Getting from one to the other usually means a script or a spreadsheet import wizard that mangles nested fields. This tool does the common case in one step.

Each object in the array becomes a row, and the columns are the union of all keys found. With flattening on, a nested value such as address.city becomes its own column, which keeps the data readable in Excel or Google Sheets. Values with commas, quotes or line breaks are quoted correctly. A single object is treated as a one-row array. Conversion happens in your browser, so exported customer data stays on your machine.

How to use it

  1. Paste a JSON array of objects into the input.
  2. Choose the delimiter: comma, semicolon, tab or pipe.
  3. Keep Flatten nested ticked for dotted columns, or untick it to keep nested values as JSON text.
  4. Copy the CSV or paste it into a spreadsheet.

Frequently asked questions

What happens to nested objects and arrays?

With flattening on, nested keys become dotted columns such as address.geo.lat, and array items get numbered columns like tags.0. With it off, nested values are written as JSON text in one cell.

What if objects have different keys?

The header contains every key found in any row, in the order first seen. A row missing a key gets an empty cell in that column.

Are commas and quotes inside values handled?

Yes. Cells containing the delimiter, quotes, line breaks or leading and trailing spaces are wrapped in quotes, and inner quotes are doubled, as in standard CSV.

Which delimiter should I use for Excel?

In many European locales Excel expects a semicolon. If a comma-separated file opens in one column, convert again with the semicolon delimiter.
