Time Tracker Log: Hours per Project and Day with CSV Export

Adds up a log of time entries by project and by day, in a text summary and a downloadable CSV.

Use the tool

Why this tool exists

Write entries like 2026-10-19 Website 09:00-11:30 homepage, or use a duration such as 2.5h or 1h30m. The tool totals hours per project, per day and in a project-by-day grid, with percent share per project.

There is no running timer in this tool; time the work with the stopwatch and write the result in. Entries that cross midnight are counted on the start date. Nothing is stored; the CSV is created in your browser, so you can keep the log in your own file.

How to use it

  1. Write one entry per line: date project time note.
  2. Use 09:00-11:30, 2.5h or 1h30m for the time.
  3. Read the totals and the grid.
  4. Download the CSV.

Frequently asked questions

Does it have a start/stop timer?

No. Use the stopwatch and enter the time here.

Are my entries saved?

No, keep your log text in your own file.

Can project names have spaces?

Use a dash or underscore, since a space ends the name.

What is in the CSV?

Date, project, minutes, hours and note per entry.
